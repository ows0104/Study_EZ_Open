# Map 흐름 예시를 반영한 별도 프롬프트 복사본 — 설계

## 요구사항과 수용 기준
강의 전체의 큰 흐름, 분류/축의 개요 노드, 실제 개념의 짧은 핵심 내용, 여러 부모·가지 간 교차 연결이 드러나도록 지시한다. 원본별 적절한 흐름을 선정하고 예시의 다섯 단계·노드 수·약리학 주제를 다른 강의에 강제하지 않는다.

## 책임·입출력 계약·오류 상태
map-point-prompts의 고정 커밋 59b6b405에 있는 map-extract.md를 출발점으로 map-extract-reference.md만 작성한다. concept-map-extract/2의 JSON 구조와 파일 다운로드 지시는 유지한다. 색·좌표·실선/점선 등 표시 메타데이터를 추가로 수집하지 않는다.

## 호환성과 데이터 보존
원본 시범 폴더·프롬프트·상태·출제포인트·출력 스키마를 수정하지 않는다. 콘텐츠 정확성 검수나 실제 파일 생성 성공을 주장하지 않는다. Map에 문항 평가·누락 판정·회상 목표를 추가하지 않는다.

실험 확장: 선택 자료의 원본 사본만 새 runs/_map-flow-experiment에 고정한다. 기존 결과·사용자 예시·문제은행은 모델 입력에서 제외한다. 짧은 지시문+최소 JSON 파일 형식+원본 텍스트/페이지 이미지만 제공한다. 사용자 자료 선택 답변 후 기존 Codex 어댑터로 1회 호출한다. 실패/거절/시간 초과는 자동 반복하지 않는다. SHA·형식·참조·근거 범위를 확인하고 결과 내용은 임의 수정하지 않는다. 같은 JSON을 로컬 지도 미리보기로 표시한다.
