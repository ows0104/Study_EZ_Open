# 실행 계약

입력은 runs/_root-generation/f0a8f3b68e3642598f85bbf462e1dc55의 packet/normalize/repair-3/medical-3과 완료 원장이다. 원본 sha256/size, packetHash, 완료13단계 outputHash, BANK hash에 귀속된 medical-3 및 원장 수정3회를 검사한다. 새 source 검토는 현재 수정된 생성기의 정확한 원본 대조 context와35쪽PNG/추출자료로 실행한다. raw/usage/입력별schema/코드runtime과 호출 시작/완료/실패를 별도 예시 폴더에 보존한다.

출력은 운영 게시 계약을 흉내 낸 result가 아닌 root-example/1 미리보기 묶음이다. 기존 brief/BANK/medical은 그대로 포함하고 새 sourceAudit/document/validation을 조립한다. 컴파일·문항/검수전수·불변 입력/hash/과제 선택을 재검증한다. 모든 문제·의심·미준비를 보존한다. 이 예시에 실제 학습 성적이나 목표 숙련도를 만들지 않는다.

실제 모델 호출은 source1회뿐이다. 모델 실패/미완료는 자동 반복하지 않으며 원래 source4회/repair3회 기록을 초기화하지 않는다. 예시의 추가 진단1회는 현재 명시적 사용자 요청에 따른 별도 기록으로 원래 횟수와 구분한다. 운영 API/DB/게시/자동전송을 호출하지 않는다. 같은 최종 BANK의 독립 정답 검수를 원문·hash와 함께 재사용한 사실을 표시한다.
