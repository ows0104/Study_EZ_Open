# Main-Quiz 객관식 모드: 이전 선택이 체크된 채 열리지 않게

## 문제와 사용자 효과

사용자(2026-11-14): 「객관식 모드로 키면 왜인지 모르겠는데 몇몇 문제는 기존에 어떠한 선지가 이미 선택되어 있어. 무조건 과거 기록은 삭제되도록 해줘.」

`RootSolve`는 고른 선지를 브라우저 `studyez:root-draft:<scope>:[revision,taskId]:picks`에 보관하고 문항을 열 때 되살렸다.
같은 판·같은 일감 ID로 문항이 다시 나오거나 주관식 「선지 보기」에서 고른 값이 남아 있으면 객관식 모드에서 이미 체크된 채 보였다.

## 범위와 성공 기준

- 문항을 열 때마다 고른 선지는 비어 있다. 보관된 `…:picks`는 되살리지 않고 지운다(이 기기 브라우저 전체).
- 주관식↔객관식 전환 시에도 고른 선지를 비운다.
- 유지: 「선지 보기」를 편/본 기록(`…:choices`, 도움받은 풀이 판정), 다른 초안 보관값, 서버 기록.
- 범위 밖: 서버·DB, BankSolve(별도 화면).
