# 블록 자동 전환 — 설계

## 요구사항과 수용 기준
- 퀴즈 준비·빌드 시각을 기본 블록 선택에 쓰지 않는다. 시간표의 lecture/practice를 블록으로 묶고 첨부 없는 수업도 해당 블록으로 표시한다.
- 실습·PBL/CBL/TBL·시험 꼬리를 정규화한다. 동일 이름이 7일 넘게 비면 별도 기간으로 취급한다. 겹치는 블록은 강의 칸이 많은 주 블록을 우선한다.
- 블록별 마지막 수업 이후의 마지막 시험 종료까지는 해당 블록을 유지하고, 종료 즉시 다음 예정 블록을 선택한다. 중간시험 후 수업이나 후속 시험이 남으면 넘기지 않는다. 명시된 시험명은 같은 블록에 연결하고 제목이 단순 시험인 경우만 가까운 기간의 주 블록에 연결한다. 무관한 종합시험을 임의 연결하지 않는다.
- 시험 종료 시각이 없으면 당일 끝까지 유지한다. 시험이 없는 기간은 마지막 수업일까지 유지한 뒤 다음 예정 기간을 선택한다. 마지막 블록 이후에는 마지막 블록을 유지한다. 빈 표는 전체 보기다.
- 한국 날짜로 일요일은 다음 월요일을 기준일로 삼고 토요일은 그 날짜를 유지한다. 캘린더 startOfWeek의 일요일/토요일 규칙도 회귀 검증한다. 브라우저 시간대가 달라도 기본 선택은 같다.
- 화면을 열어 둬도 1분 이내, 또는 포커스·탭 복귀 시 다시 계산한다. 목록이 뒤늦게 도착하거나 갱신되어도 선택을 다시 계산한다. 동일 기본 블록에서는 수동 선택·전체 보기를 유지하고 기본 블록이 바뀌면 자동 전환한다.
- 실제 시간표에서 2026-11-01은 감염과 면역이다. 퀴즈가 전혀 없어도 같다.

## 책임·입출력
web/src/bank/studyBlocks.ts는 시간표에서 블록 이름·기간·기본 선택을 계산한다. useStudyCourse.ts는 시각 갱신과 수동 선택 유지를 담당한다. StudyOverview는 두 결과를 목록과 드롭다운에 연결한다. calendar/entries.ts의 기존 주간 계산을 재사용한다. API 계약과 새 사용자 행동은 추가하지 않는다.

## 보존과 한계
문항·자료·개인 설정·학습 기록·공개 상태·서버·러너는 변경하지 않는다. 시간표에서 블록 이름을 알 수 없는 세부 강의는 별도 강의명으로 남기며 의학적 과목을 추정하지 않는다. 이름 없는 시험 연결은 시기·강의 칸 수에 근거한 시간표 추정이다.
