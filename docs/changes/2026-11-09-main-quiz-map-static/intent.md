# Main-Quiz 개념 지도 화면 정리

## 문제와 사용자 효과
사용자(2026-11-09)가 지도 위 글자 묶음을 붙여넣었다.
「개념 지도 / 문항 4/57 / 강의 전체가 한 화면에 있어요… / 찾기 / 주제 62개 · 문항 82개 / 미학습 … 다른 주제와의 연결」
그리고 「이런거 중 필요없는 거 싹 다 날리고 화면을 최대한 넓게 쓰자. 그리고 안 움직이게 해도 괜찮을것 같은데?」라고 했다.

## 범위와 성공 기준
- 지도 위의 머리말(제목·문항 위치), 안내 문장, 찾기 줄, 범례 줄을 없앤다.
- 지도 아래 「목록으로 보기」·「자료 범위·출제포인트」 접힘도 없앤다.
- 범례는 지도 아래 도구 막대 안에 작게 둔다(상태 점 색의 뜻).
- 지도 틀이 남은 화면 높이와 콘텐츠 폭을 모두 채운다. 페이지 자체는 스크롤되지 않는다.
- 확대·끌기·휠·두 손가락·＋/－/전체 버튼·+/−/0 키를 없앤다.
  - 지도는 항상 틀에 맞춰진다. 창 크기, 문항 펼침, 크게 보기에 따라 다시 맞춘다.
  - 맞춘 배율이 너무 작아지면(0.5 미만) 폭에 맞추고 틀 안 세로 스크롤만 허용한다.
- 선택 패널은 지도를 줄이지 않고 지도 위에 겹친다. 고른 주제가 오른쪽 절반에 있으면 왼쪽에 연다. 그래서 고를 때 지도가 움직이지 않는다.
- 데이터·서버·학습 기록은 바꾸지 않는다.

## 근거·미정 사항
- 「← 문제로 돌아가기」는 `RootLearning.tsx`에 있어 이번 범위에서 두고, 지도 쪽만 정리한다.
- 찾기를 없애도 주제가 모두 한 화면에 보이므로 찾기는 필요가 줄었다(사용자 지시).
