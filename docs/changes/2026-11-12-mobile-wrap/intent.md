# 좁은 화면 글씨 줄바꿈

## 문제와 사용자 효과

사용자 2026-11-12 채팅: 「지금 이 웹사이트를 반으로 줄이거나 휴대폰에서 보면 글씨가 잘려서
거의 안보여. 차라리 줄을 내리거나 해서 어느정도는 보이게 해줘.」

375px(휴대폰)에서 잰 상태:

- 캘린더 주간 칸의 강의명이 두세 글자만 보였다(「16 헤도」「렙토」). 칸 안쪽 37px에
  `word-break: keep-all`이라 「헤모필루스,」처럼 칸보다 긴 낱말을 못 끊고 통째로 잘렸다.
- 강의 목록의 강의명이 세 글자에서 말줄임됐다(「감염질…」). 표가 숫자 칸을 지키느라
  강의명 칸이 59px이었다.
- 700px 창에서 캘린더 머리 제목이 「감염과 면역…」으로 잘렸다. 오늘 할 일 카드가 옆에 붙고
  줄바꿈은 640px 아래에서만 했다.

## 범위와 성공 기준

범위(사용자 선택 「All main student screens」): 캘린더·강의 목록·Main-Quiz 풀이·노트·공지·이용방법·설정.
Main-Quiz 풀이·노트·공지·이용방법·설정은 375px에서 잘리는 글자가 없어 바꾸지 않는다.

성공: 375px에서 캘린더 한 시간 칸이 제목 세 줄과 교수를 보이고, 강의 목록 강의명이 두 줄까지
보이며, 700px에서 캘린더 제목이 잘리지 않는다. 1280px 화면은 바뀌지 않는다.
