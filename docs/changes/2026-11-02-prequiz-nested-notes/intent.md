# 감염과 면역 예습의 하위 폴더 필기 탐색 누락

사용자는 감염병의 병인론 예습덱이 생성되지 않는 이유를 묻고 현재 블럭이 감염과 면역임을 확인했다.
후속 사용자 승인: “그럼 하위 폴더도 읽도록 고치고 준비 상태 판정도 수정해줘. 내일 예습덱도 다시 돌려줘.”
하위 폴더 탐색·준비 판정 수정과 2026-11-03 감염과 면역 예습 재실행을 승인받았다.
원본 이동·삭제, 다른 날짜/과목 재실행, 검수 상한 초기화로 확대하지 않는다.

확인: 작업 506, 감염과 면역/261102_02/pre는 작년 짝 없음으로 실패했다.
작년 PDF는 SynologyDrive/감염과 면역/필기/2025/1차/[251103_02] 감염병의 병인론(최은화)_신지수_v1.pdf 에 존재한다.
현행 filenames.scan은 glob('*.pdf')만 사용하여 2025 상위 폴더에서 0개를 읽는다. 하위 PDF는 총 70개다.
1차 폴더를 별도로 스캔하면 해당 강의를 읽으며 올해 261102_02와 매칭 점수는 1.0이다.
현재 시간표와 러너 로그는 감염과 면역(2026-11-02~2026-11-26) 범위를 사용한다.
