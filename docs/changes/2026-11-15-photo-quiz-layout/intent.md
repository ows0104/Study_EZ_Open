# Main-Quiz 사진 문항: 사진 크기·정렬, 힌트 버튼

## 문제와 사용자 효과

사용자(2026-11-15): 「사진 실습 문제에서 사진이 너무 크고 정렬이 안 되어 있어. 그래서 답을 눌러도 답이 바로 안 보여.
힌트도 좀 더 누르기 좋게 예습 퀴즈와 같은 버튼 형태로 해 줘.」

사진 반입 문항(2026-11-15 photo-quiz-import)의 그림은 Quiz Bank 공용 CSS(`.bank-stimuli`)만 받아 원본 폭 그대로
카드 왼쪽에 붙고 화면 높이를 거의 다 먹었다(1280×800에서 668px). 답이 그 아래에 열려 스크롤해야 보였다.
힌트는 작은 「is-quiet」 글자 버튼이었다.

## 범위와 성공 기준

- 사진은 카드 가운데, 비율 유지. 답 전에는 화면 높이의 약 절반(최대 560px)까지.
- 답을 열면 사진을 줄이고(최대 28vh·300px, 여러 장이면 한 줄) 답 첫 줄이 스크롤 없이 아래 바 위에 보인다.
- 힌트는 예습 퀴즈 힌트와 같은 알약 버튼(전구·화살표, 42px 높이). H 단축키·문항마다 접힌 채 시작은 그대로.
- 범위 밖: Quiz Bank·족보 화면의 그림, 서버·DB·문항 데이터.
