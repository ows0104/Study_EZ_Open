# Study EZ 예습 브리지 개인정보 처리 요약

최종 수정: 2026-08-20

공개 정책 URL: <https://studyez.kr/privacy>

Study EZ 예습 브리지는 사용자가 선택한 강의 PDF와 예습 프롬프트를 ChatGPT에
준비하고, 완성된 대화 링크를 해당 Study EZ 강의에 연결하는 단일 목적으로
작동합니다.

## 처리하는 데이터

- 선택한 PDF의 파일명·임시 다운로드 URL·파일 내용, 예습 프롬프트, 강의 식별자
- ChatGPT 대화 URL과, 기본 링크 모드에서 생성되는 공개 공유 URL
- 대화 링크와 응답 완료 여부를 확인하는 동안 일시적으로 처리하는 ChatGPT 대화 내용,
  상태, 현재 노드
- ChatGPT 요청을 수행할 때 메모리에서 일시적으로 읽는 액세스 토큰

액세스 토큰은 저장하지 않고 Study EZ 서버로 보내지 않습니다. 진행 중 요청과 아직
저장되지 않은 링크만 Chrome 세션 저장소에 잠시 보관합니다. PDF와 프롬프트는
사용자의 확인과 동의 뒤 ChatGPT에 전달되며, 메시지 전송은 사용자가 직접 합니다.

동의는 링크 모드별로 한 번 받고 그 사실만 브라우저 로컬 저장소에 남깁니다(값은
동의 여부 하나뿐이며 서버로 보내지 않습니다). 확인 카드의 **동의 해제**를 누르면
지워지고 다음 전송부터 다시 묻습니다. 어느 경우에도 무엇이 첨부되는지 보여주는
확인 카드는 매번 뜨고, ChatGPT로 넣는 것은 사용자가 확인 버튼을 누른 뒤입니다.

기본 링크 모드에서는 링크를 가진 누구나 열 수 있는 ChatGPT 공개 스냅샷을 만들고
그 주소를 Study EZ에 저장합니다. 개인 링크 모드에서는 공개 공유를 만들지 않습니다.

데이터를 판매하거나 광고, 신용평가, 사용자 추적에 사용하지 않습니다. Chrome Web
Store 사용자 데이터 정책의 Limited Use 요건을 준수합니다.
