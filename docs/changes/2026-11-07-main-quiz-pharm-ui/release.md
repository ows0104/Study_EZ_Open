## 배포 대상 버전·순서·데이터 변경
PR의 일반 코드 변경이다. 기존 자동 배포 순서(API → 동일 SHA의 Pages)를 따른다. 새 표/칼럼/자료 교체/문항 재출제/권한 변경은 없다. 이번 로컬 구현 승인에 따른 구현·검사·리뷰·PR 준비까지 완료한다. master 병합과 운영 반영은 아직 실행하지 않았다.
신규 selfRating은 Again/Hard/Good/Easy를 그대로 저장한다. 기존 grade 사건은 원래 계산을 유지하고 새 사건에만 고정된 4단계 간격 매개변수를 보존한다. 지도·선지·답만 열람은 보조 기록이며 네 평가의 선택을 차단하지 않는다. 도움 노출을 독립 회상 성공으로 바꾸어 기록하지 않는다.
PDF.js 6.5.438을 잠금 파일에 고정하고 지연 로딩한다. 외부 CDN 없이 worker·문자표·폰트·wasm을 같은 웹 산출물에 포함한다. 기존 Vite/source-map-js 개발 의존성의 npm audit high 2건은 이번 PDF 의존성에서 추가된 취약점이 아니며 범위 밖으로 보존했다.

## 배포 후 확인·롤백·필요한 사람 승인
반영 시 같은 SHA의 API/웹 성공을 확인한 뒤 실제 Main-Quiz에서 Space → 네 평가, 참고 PDF 해당 쪽·확대, 현재 개념·전체 지도/검색, 기존 약리 경로를 읽기 위주로 확인한다. 운영 사람 학습기록에 테스트 평가를 쓰지 않는다. 자료/은행/학습 사건을 지우지 않고 해당 코드 PR만 revert한다. 이번 변경은 공개 대상과 데이터 스키마를 바꾸지 않는다.
현재 상태: 로컬 구현·필수 검사·자체 코드 리뷰 완료, PR 및 CI 확인 단계. 배포 완료로 표현하지 않는다. master 병합은 운영 자동 배포를 유발하므로 별도 최종 확인 대상이다.
