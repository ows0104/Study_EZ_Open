# Main Quiz 통합 — 배포 준비

## 코드 리뷰·검증 결과
기존 /bank 및 /mainquiz에서 검토·공개·계정 허용을 통과한 새 자료를 읽기 전용으로 판정한다. 공개 자료가 없거나 기능이 중지되면 기존 은행이 열리며, 구형 서버404/405만 호환한다. 인증/서버 오류는 드러낸다. hook 상태는 계정·강의별로 구분한다.

시작·문항·정답·빈 표는 기존 Main Quiz 표시를 재사용한다. 선지 비교와 먼저 회상하는 문항의 도움 노출을 구분하고, 지도·답만 보기·앞선 관계 노출 제한은 유지한다. 새 choicesShown 필드가 없는 재시도는 이전 요청 지문과 일치한다. 짝짓기/순서형의 발문 항목·공개 후 답도 허용 목록에 보존한다. 선택·작성 응답은 로컬에 보관하고 확인 전 저장은 기존 outbox·버전 충돌 정책으로 처리한다.

실제 CUA로 시작·응답 복원·평가·undo·Space/3·표의 네 빈칸과 정답·지도 위치/도움·MCQ 단일선택·선지 노출 복원·두 탭 충돌/확인·답만 보기·완료·기존 은행 시작/풀이를 확인했다. 모바일390px에서는 문서375px, 표 가로 넘침 없음. 최종 저장 화면은 desktop JPEG이며 최종 즉시 viewport 측정이 전환 전1280px였던 원기록도 보존했다. 모바일은 앞선 CUA screenshot/evaluate의 실제 관측 근거다. 실제 풀이를 수행한 계정과 DB는 이 작업의 새 localhost 실험 전용이며 기존 E2E 학습은 건드리지 않았다.

처음 회귀의 공유 venv가 원래 폴더 계약을 읽는 문제는 PYTHONPATH를 현재 worktree로 고정했다. 읽기 전용 entry의 의도적 추가를 경로 목록에도 명시했다. 검증용 기존 은행은 완전한 비의학 synthetic fixture를 사용한다. 실패·오래된 지문 검사도 state와 로그에 남기고 최신 동일 지문의 필수 성공을 배포 조건으로 삼는다.

이전 recall-units788adb0c를 의존성으로 포함한다. 추가 author/extract/source 지침·분할 충족·별도 학습 준비 집계와 표 표시를 함께 검증한다. 최초 웹 전송에도 별도 web-author.md를 결합하고 정확한 결합 프롬프트 지문을 고정한다. 공통 bankPrompt1.82 원문은 바꾸지 않는다. 기존3회 상한·소비·실패·원문은 그대로다. 이 작업에서 모델 호출이나 강의 재출제는 수행하지 않았다.

## 배포 대상 버전·순서·데이터 변경
일반 코드 자동 배포 경로: 이 브랜치의 PR 검사·리뷰 후 master 병합, 같은 SHA의 GitHub 검사·고정 API 후보 배포, 그 SHA의 API가 준비된 뒤 Pages 게시. 실제 SHA/실행/배포 확인은 deployment.md에 기록한다. master가 전진하면 이전 후보를 억지로 배포하지 않는다.

신규 DB 표·migration·init·운영 데이터 쓰기 없음. 기존 은행/개인 수정/학습 기록의 자동 변환이나 내용 교체 없음. 새 생성도 기본 내 계정 시범 공개이며 기존 allowlist와 검토/중지 조건을 유지한다. 운영 STUDYEZ_ROOT_LEARNING_ENABLED=true를 읽기 전용으로 확인했으며 설정은 변경하지 않는다. 기존 /roots 주소와 사건 코드는 호환 보존한다. 다른 UI 세션의 App/메뉴/캘린더/목록/GuidePage/전역 styles는 변경하지 않는다. 여러 강의 모아풀기·전체 문제 목록은 기존 경로를 유지한다.

## 승인·배포 후 확인·복원
사용자의 Main Quiz로 구현하고 사이트 Main-Quiz를 대체하라는 요청, 담당 범위에 “그렇게 범위를 나눠 진행”한 명시 승인을 적용한다. 일반 코드 master 자동 배포 허용 범위 안의 PR/검사/배포다. 공용 콘텐츠·허용 계정·기록 변경 승인을 만들어 내거나 확대하지 않는다.

배포 뒤 API health의 정확한 SHA와 공개 보호 경로401, Pages success·동일 SHA 및 실제 Main Quiz bundle의 entry/새 UI·지침을 읽기 전용으로 확인한다. 운영 로그인 사용자 학습 사건은 시험 삼아 쓰지 않는다. 복원은 이전 API traffic 및 이전 성공 Pages, 또는 revert PR이며 DB·학습 기록은 되돌리지 않는다. 자동 재배포/삭제/강의 복구 상한 초기화 없음.
