## 검증

개발용 verify_formats.py에서 두 JSON Schema, 프롬프트 내 합성 예시 일치, 잘못된 필드/버전/참조/중복 ID/근거 위치/쪽수/빈 결과 등 16사례 거절을 확인한다. 중복 JSON 키도 거절한다. 여러 부모·교차 연결·비계층 순환, 미독해 이유가 있는 빈 결과 2사례, 페이지 대신 확인 가능한 locator는 수용한다. 관계의 의미와 분류 순환은 단순 relation 문장을 원본과 대조하는 후속 의미 검토에서 확인하며 기계 검증으로 인증하지 않는다.

이전 단계의 상세 /1 스키마 검사 및 기존 생성/런타임 16개·웹 프롬프트 7개 회귀 통과는 당시 로그에 보존한다. 이번 /2 변경은 두 프롬프트·미연결 출력 계약·개발용 검증에 한정되며 prompt-review를 새로 실행한다. git diff --check와 staged diff 확인도 수행한다. 이전 Python 임시 경로/웹 TypeScript 의존성 환경 오류 및 해결 기록은 Git 이전 판에 보존한다.

## 실제 한 강의 시범 준비

현재 사용자 예시 추출 요청으로 심내막염·중추신경계감염 한 강의의 현재 로컬 올해 필기58쪽(SHA 13da0b35f473f309d00af4120d03fb5a9fc315159cbee87f7d43e3376caa920c)와 해당 TBL2족보13쪽(SHA 4f4b12276147dc4e87e56bb778682eb8629984e2e73b4a2e5204fcdec7243d9f)를 별도 보존했다. Poppler로71개 페이지 PNG와 물리쪽별 텍스트를 만들고, 각각 독립된 Map/포인트 작업 폴더에 같은 원본·해당 프롬프트·스키마를 준비했다. 필기/족보 렌더 화면을 확인했다. 이전 요청548의 과거 원본과 동일하다고 주장하지 않는다.

기존 모델 실행기를 사용한 두 호출은 자동 승인 검토에서 프로세스 시작 전에 거절되었다. 사유: 비공개 강의·족보를 OpenAI 외부 모델 서비스로 보내는 데 대한 구체적인 자료+대상 명시 동의가 부족함. 다른 경로나 간접 실행으로 재시도하지 않았다. 모델 호출/실제 전송/완료 산출물은0이며 원본과 준비 파일만 있다. 사용자에게 해당 두 자료의 OpenAI Codex/GPT 전송·각1회 추출 승인을 요청했다.

## 명시적 승인 이후 실제 추출 완료

사용자가 해당 두 자료의 “OpenAI 전송·추출 승인”을 명시적으로 선택했다. 후속으로 두 강의 합본임을 알려, S1 원본의2~29쪽은 감염 심내막염,30~58쪽은 중추신경계감염으로 분리하고 S2 혼합 지면은 문항별 주제를 구별하게 했다. 입력 PDF를 자르거나 원본 쪽번호를 바꾸지 않았다. Map/포인트 각1회, 총2개 모델 호출로 강의별 독립 JSON4개를 작성했다.

- Map 실제 모델 완료267.134초, session 01a1ac77-fbd6-7c00-9d96-616ee7695555. 심내막염20개념/27관계, CNS감염26개념/35관계.
- 포인트 실제 모델 완료262.101초, session 01a1ac77-f5cd-70d1-837f-cf1b0cf227c6. 심내막염18포인트, CNS감염22포인트.

최초 로컬 후처리는 input-hashes.json 자신의 이전 해시를 준비 과정에서 수록한 구현 오류 때문에 “Model modified input file”로 실패했다. 두 호출의 시작 전 상태에 보존된 inputHashes의 정확한 Windows 줄바꿈 직렬화가 현재 기록 파일과 바이트 단위로 일치하고, 자기 참조 해시가 before-lecture-split의 이전 기록과 일치함을 확인했다. 실제 원본/PNG/텍스트/입력/요청문/스키마/작업 지시는 모두 원래 해시를 유지했다. 오류는 자기 기록을 수록한 사전 준비 코드에 있었으며 내용·판정을 수정하지 않았다.

자기 해시 수록을 이후 준비 코드에서 제외하고, 기존4파일만 명시적 로컬 재검증했다. 추가 모델 호출0건이다. state.json/failure.json과 원본 모델 응답·사용량·파일 SHA 영수증은 그대로 보존하고 별도 postcheck.json에 성공 근거를 남겼다. 첫 로컬 재검증의 LF/CRLF 직렬화 비교 오류도 Windows 생성 방식과 맞춰 해결했다. 네 파일의 JSON 형식/고유ID/출처·쪽수/실제 S1 강의 범위와 모델 파일 영수증 SHA가 일치한다.

사용자용 파일과 ZIP은 원본 JSON 바이트를 그대로 복사하고 SHA를 재확인했다. notes의 원본 충돌·범위/자료 한계와 필기 연도/색상 구분을 보존했다. 이는 독립 추출 시범이며 독립 의학 내용 검수·문항 대조·게시·학습 성공을 뜻하지 않는다.
