# 예습 대상 매칭 보류 원인 표시 및 장내세균 연결 복구 — 구현 계획

## 변경 범위·대상 파일·순서
1. 사람 승인 후 development.py approve/check --phase build로 현재 계획 승인을 확인한다.
2. runner/prequeue.py의 계획 부재 경로에서 정확한 과목/강의 경고를 우선 사용한다. 공통 시간표/과목 실패도 해당 과목 근거로 표시하고, 근거 없는 시간표 부재 단정을 제거한다.
3. tests/runner/test_prequeue_diagnostics.py에 접힌 제목·불확정 매칭·다른 강의 경고·시간표 실패·대상 부재 회귀를 추가한다. tests/runner/test_agent.py에서 대상 사유 전달을 검사한다.
4. 검사/리뷰 후 runs/_pairs/감염과 면역.json을 다시 읽고 기존 값을 이 기록에 보존한 뒤 `261105_02: 251106_02` 한 항목만 추가한다. 근거는 2026-11-01-infection-materials/matching.md다.
5. 읽기 전용 resolve로 작년 PDF·올해 제목·교수·ready를 확인한다.
6. 기존 해당 강의 실행/산출물/저장 응답/서버 상태를 확인한다. 완료·실행 중이면 중복 실행하지 않는다. 나머지는 해당 예습 1건만 force 없이 기존 러너 경로로 재등록·실행하고 현재 검문/게시 규칙을 따른다. 입력이 없으면 대기로 남긴다. 새 웹 대화 생성, 다른 강의 재실행, 검수 횟수 초기화는 하지 않는다.

## 검사 명령과 성공 조건
prequeue: `.venv/Scripts/python.exe -m pytest tests/runner/test_prequeue_diagnostics.py tests/runner/test_agent.py -q`

regression: `.venv/Scripts/python.exe -m pytest tests/runner -q`

development.py verify로 각각 기록하고 review/check --phase release로 확인한다. 실제 로컬 resolve와 실행 결과를 release.md에 남긴다. 코드/계획 변경 시 검사 근거를 갱신한다. 다른 미커밋 작업의 기존 실패는 별도 기록한다.

## 위험·복원·승인할 범위
승인 요청 범위는 로컬 사유 수정·검사·검증된 한 강의 연결 복구·저장 응답 기반 예습 1건 재실행이다. 시간표 등록과 웹/서버 배포는 필요 없다. 자동 매칭 기준은 완화하지 않는다. 복원은 이 작업 코드와 새 pairs 키만 되돌리며 원본·문항·학습/시도 기록은 삭제하지 않는다. 현재는 제보 조사와 계획 작성만 완료했고 구현 승인은 없다.


## 2026-11-05 현재 사용자 승인 및 범위 확장
사용자: “응, 그 계획대로 연결 복구하고 실패 안내도 수정하고 다른 강의들도 마찬가지로 진행해줘.”
위 단일 강의 제한을 현재 블럭 감염과 면역의 같은 연결 누락 전체로 확장한다. 2026-11-01 검증 upload-plan.json/matching.md에서 확정한 강의만 복구하며, 전용 원본 미확인 10칸은 임의 연결하지 않는다. 기존 명시적 연결과 정상 연결을 보존한다.
중복 작년 원본을 쓰는 동영상 수업은 기존 readiness.packet_sources 계약의 별도 입력 사본/출처 해시로 실행 자리를 분리한다. 원본과 기존 결과는 유지한다. 시간표가 원래 합쳐 둔 실습 교시는 임의 분할하지 않는다.
작업 기록 안에 audit/recover 스크립트를 두고 변경 전 pairs와 원본 해시를 보존한다. 실행은 기존 서버/러너 큐에서 저장 응답이 있는 미완료 강의를 선별한다. 전체/개별 중지·취소·완료·진행 중 상태 및 검수 상한은 유지하고 force는 쓰지 않는다. 새 웹 요청·매칭 기준 완화·운영 코드 배포는 제외한다.

실습 3칸은 실제 시간표 course가 `미생물학)`으로 되어 블럭 이름과 다르다. runner/ahead.py에서 명시적으로 검증된 개별 pairs 키만 블럭 이름 필터에 추가하며, 자동 대상 범위나 날짜 제한은 넓히지 않는다. 같은 테스트 파일에 확정 실습 복구·다른 같은 이름 강의 미포함·날짜 경계 회귀를 추가한다. 이는 승인한 다른 강의의 동일한 연결 복구에 필요한 구현이다.
