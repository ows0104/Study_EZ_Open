# 캘린더 복습 막대: 테두리 + 강조색 채움 — 배포 준비

## 코드 리뷰·검증 결과
- web: `tsc -b web --noEmit` 통과(깨끗한 `npm ci` 위).
- 화면(web/tests/calendar-learning.html, 기본 인디고+앰버): 막대 바탕 투명, 테두리 #616161(본문 글자 #171717보다 옅고
  --ink-3 #7c7c7c보다 진함), 채움 rgb(62,99,221)=`--accent`. 예습 토막 미완료 = 같은 회색 테두리, 완료 = rgb(232,147,12) 채움.
- 옛 색 값을 고정한 검사는 없다.
- 다크 모드·다른 강조색 조합은 토큰을 따르나 이 최종안으로는 화면 확인하지 않음(첫 커밋 때 그린 조합에서 토큰 추종 확인).

## 배포 대상 버전·순서·데이터 변경
웹만(Pages). 서버·DB 변경 없음. master 병합이 검사 → 배포를 자동으로 돈다.
