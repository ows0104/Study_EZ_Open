# 블록 자동 전환 — 운영 웹 배포 후보

## 문제와 결과
학습 현황의 기본 블록이 이전 퀴즈 준비 상태에 붙어 있던 문제를 고친다. 마지막 시험이 끝나면 다음 블록으로 전환하며 일요일은 다음 월요일의 주로 본다. 오늘 2026-11-01은 퀴즈가 없어도 감염과 면역이다. 열린 화면의 주기 갱신·복귀 갱신을 지원하고 같은 기본 블록 내 수동 선택을 유지한다.

## 검증 소스·코드 리뷰
기준 운영 0ca1ec7b-bdc2-4775-8916-4b1dca98563d의 고정 후보 9e7a9fdb6bd0b7bf1f726689d485c4c39a4a08465165db9db1fe1dd829b074be와 모든 빌드 파일을 바이트 해시까지 재현했다. 검증 소스는 output/releases/block-auto-deploy다. 소스 지문 a4e8919796c8e96333a41822111ea40ad94752c0a2cc0d4506898581af1531e6에 아홉 파일 allowlist를 고정했고 다른 모든 운영 소스가 보존됨을 검사했다. 기존 이용현황·교수 확인 기능을 포함한 실제 운영을 기준으로 했으며 공유 폴더의 다른 미완료 변경을 넣지 않았다.

studyBlocks의 마지막 수업/시험 연결, 중간·실습시험과 겹친 소수 과목 처리, 한국 날짜와 주간 기준을 재검토했다. useStudyCourse의 주기·포커스·탭 복귀, 수동 선택과 전체 보기 유지, 리스너/타이머 정리를 검토했다. 실제 최초 StudyOverview 렌더에 준비 전 다음 블록이 나타남을 확인했다. 같은 이름의 긴 공백을 나누며 이름이 단순 시험인 경우의 연결은 시간표상 가까운 주 블록 추정이다.

## 실제 검사
동일 계획 지문 630d2da703016d7e0a09c051d507918cba1362ff2090fb3d1b2b605f8db365a9와 위 소스에서 모두 통과했다.
- production-base: 정확한 기존 운영 재현 기록·기존 후보·아홉 파일 차이 확인.
- block-selection: 13개 통과. 실제 학기 시간표의 11월 1일 선택과 두 시험 경계, 해외 시간대 및 SSR 포함.
- browser: 격리 Chrome 11가지 동작 통과. 시각 경과만으로 1분 내 전환, 포커스·탭 복귀, 늦은 목록과 수동 선택 유지 포함.
- web: TypeScript와 production build 통과. 산출물 지문 d27a241fda6356854061146e2b722079a831f7826d8839c180d5ea07727a26fc.
- contracts: 6개 통과, 실패/건너뜀 0. 초기 임시 디렉터리 생성 실패 두 건은 로그에 보존했고 존재하는 검사 기록 폴더 아래 새 임시 경로를 지정해 전부 재실행했다. 제품 코드 변경은 없었다.

## 배포와 승인
현재 사용자 “그럼 운영 사이트에도 배포해줘.”는 직전 구현한 동일 기능의 운영 배포에 대한 명시 승인이다. 위 검증 산출물을 prepare한 뒤 정확한 후보 ID에 이 승인을 기록한다. 기존 Pages study-ez-open/master, studyez.kr 및 study-ez-open.pages.dev에 release_evidence.py publish-web으로 고정 후보만 게시한다. cloudflare_release.py가 업로드 직전 production ID가 0ca1ec7b인지 확인하고 실제 업로드 ID와 최신 production 목록의 일치를 검증한다. Windows 짧은 경로는 samefile로 검증한다. Git push, 서버/API 배포, DB·원문·자료·문항·학습 기록 변경은 없다.

## 사후 확인·복원
postcheck.py는 API 건강/CORS/인증 경계, 권한 있는 읽기 전용 강의 원본 조회, 운영 사이트·Pages·고유 배포 주소의 HTML/JS/CSS/정본 프롬프트 SHA256을 확인한다. 로그인된 실제 브라우저에서 학습 현황 기본 블록이 감염과 면역인지 별도로 확인한다. 퀴즈 평가·숨김·자료 생성/변경은 실행하지 않는다. 게시 영수증과 사후 결과는 state.json, 실제 화면 관찰은 별도 post-deploy.md에 보존한다.

복원 대상은 직전 Pages production 0ca1ec7b-bdc2-4775-8916-4b1dca98563d다. 문제 발생 시 해당 정적 웹 버전을 복원하며 DB/API/자료 복원은 필요 없다. 실패나 확인 불가를 성공으로 처리하지 않는다. 검증·후보·배포 정본은 이 별도 소스의 state.json이며 공유 작업 폴더에는 검증 정본 경로와 사본을 보존한다.
