# 완료된 작성 초안의 구조 수용 실패 복구안

현재 상태: 제안만 작성. 기존 생성 엔진·계약·실행기 수정 및 추가 모델 호출은 실행하지 않았다. CNS의 이미 승인된 검수/보완은 독립적으로 계속한다.

## 확인된 실패

심내막염47문항의 실제 작성 호출은 완료됐으며 원문·사용량·파일 영수증이 있다. generate.raw.json의 T009 clinical evidence에 teaching_emphasis가 들어가 구조 검사가 실패했다. 교수 강조와 임상 근거의 구분은 유지해야 하므로 타입만 강제로 바꾸거나 검사 완화로 통과시키지 않는다. 기존 source-only normalize 복구기는 이 작성 단계에 적용할 수 없다. 수정 소비1회와 실패 ledger를 보존했다.

## 제안하는 변경 범위

별도 기능 브랜치와 작업 기록에서 quizbank/connection_generate_v2.py, studyez_contracts/roots/generation_v2.py, runner/root_native_json.py 및 해당 회귀 검사를 수정한다. 프로세스가 끝난 실제 원문/사용량/파일 영수증과 입력·원본 지문이 모두 일치할 때만, 수용 거절된 초안을 모델 보완 입력으로 재사용한다. 입력 변경·중단/거절된 호출·불명확 실행은 복구하지 않는다.

원래 실패 판정과 원문을 유지한 별도 복구 증명에 이전 실행 지문·누적 소비·현재 실행 지문을 연결한다. 구조 오류가 있는 초안은 채택/게시하지 않는다. 남은 기존 최대3회 안에서 다음 보완1회를 소비하고 모델이 실제 지적만 수정한다. 의학 문항을 상위 에이전트가 수동 수정하지 않는다. 수정본은 전체 구조 수용 검사와 실제 원본/독립 정답 검수를 모두 통과해야 학습 자료로 이어질 수 있다. 실패 단계에 completed를 덮어쓰거나 새 요청으로 예산을 초기화하지 않는다.

## 검사와 종료 조건

- 정상 완료 원문·수정 예산·이전 실패를 함께 검증하는 성공 사례.
- 변조된 원본/입력/작성파일/사용량/영수증, 중단/모델거절, 재복구, 잘못된 예산은 거절.
- 복구 후에도 실제 원본·독립 정답 검수가 없으면 결과 채택 불가.
- 심내막염의 기존47문항을 재사용해 보완·검수·로컬 풀이까지 재개하고 실패/잔여 지적을 그대로 보고.

운영 배포·기존 은행 교체·운영 요청548 재개·실제 학습 기록 승계는 포함하지 않는다. 현재 실험 도구만 쓰는 범위를 넘는 새 엔진 수정이므로 개발 절차의 구체 범위 승인을 받은 뒤 구현한다.
