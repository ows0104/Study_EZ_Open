# 검증된 최신 master 서버·웹 운영 배포 — 설계

## 요구사항과 수용 기준
운영 대상은 Cloud Run meddeck-503318/asia-northeast3/studyez-api와 Cloudflare Pages study-ez-open/master이다.
서버를 먼저 배포하고 정상 확인 후 웹의 고정 검증 산출물을 게시한다. 현재 API 복원 기준은 studyez-api-00171-9wx,
웹 복원 기준은 0fbb9e8b-aa8f-4f8b-93b1-d0e961181427이다.
원격 버전·준비 상태·서버 트래픽 100%, HTTP 인증 차단·CORS, 웹 산출물 해시와 읽기 전용 학습 화면을 확인한다.
DB 모델은 이전 운영 후보와 동일하다. 스키마를 읽기 전용으로 확인하며 자료·학습 기록의 교체/삭제나 배포 중 재출제는 하지 않는다.
기존 운영 설정과 인증 연결을 유지하고 비밀값을 로그·후보에 포함하지 않는다.

## 책임·입출력 계약·오류 상태
기존 development.py/release_evidence.py와 서버 배포 명령을 사용한다. 준비·게시·버전 조회·사후 검사 실패를 구분해 영수증에 남긴다.

## 호환성과 데이터 보존
현재 운영 환경·DB와 호환되는 API를 먼저 반영한다. 원문·상태·개인 수정·기출 파일은 배포 패키지에 넣거나 교체하지 않는다.
