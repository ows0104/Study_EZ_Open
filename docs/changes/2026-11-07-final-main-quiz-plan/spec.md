# C005 마지막1회 구조보완과 검수·이미지·업로드 — 설계

## 요구사항과 수용 기준
정확한 기존 오류 C005 회상계획 누락만 허용한다. CLI 출력은 concept_id=C005, 이미 Q081에 저작된 direct 방향, repetition_budget/target_mastery 한 행이다. 기존 계획 뒤에 한 행만 붙이며 다른 모든 JSON 값은 불변이다. 새 재수정이나 임의 숫자 대입은 금지한다. 실제 호출 전3/3 소비를 영속 기록하고 실패·중단이면 반복하지 않는다.

## 책임·입출력 계약·오류 상태
공용 plan_repair 계약은 기존22검수 proof를 원래91문항/2차 검수로 보존 검증한 뒤 새 한행/3차 단계/재사용 지문/새 전역대조를 검증한다. 원래 source-2 실패/partialUsageUnknown을 보존하고 3차를 새 요청으로 위장하지 않는다. 의학 입력의 canonical clinicalInput·그림이 동일한 경우 원래 blind 판정을 그대로 재사용하고 실제 재호출로 표시하지 않는다. 개별 원본검수도 문항·지도·출처·기준이 동일하며 legacy 학습예산 한 행만 추가됐음을 증명해 보존한다. 전역 전체원본·누락·중복·커버리지는 실제CLI로 다시 검수한다.

## 호환성과 데이터 보존
검수 판정을 수동 변경하지 않는다. 모델·자료·임상내용·이미지·brief·문항이 달라지면 재사용을 거절한다. 모든 기존파일 해시목록과 runtime을 보존한다. 최종 전체 계약/PNG/격리된 실제UI/원본링크를 통과한 뒤 같은 검증 코드의 API/웹 배포를 확인하고 지정 강의 관리자 시범에 반입한다. DB migration/다른 학생 기록 변경 없음.
