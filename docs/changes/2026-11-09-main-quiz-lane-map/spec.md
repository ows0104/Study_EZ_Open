# Main-Quiz 개념 지도 가지 보기 — 설계

## 요구사항과 수용 기준

### 배치 (데스크톱, 폭 760px 이상)
- 맨 위 가운데에 강의 제목 카드를 둔다. 그 아래로 최상위 개념마다 열(가지) 하나가 선으로 이어진다.
- 열 머리는 다음을 보인다.
  - 번호와 가지 색
  - 주제 이름
  - 하위 문항 수
  - 학습 상태 막대(기존 `main-quiz-tree-bar`와 같은 상태 색)
- 열 안에서는 하위 개념이 들여쓰기된 줄로 위에서 아래로 내려가고, 왼쪽에 트리 선을 긋는다.
- 문항(target)은 처음에는 별도 줄이 아니라, 그 문항이 붙은 개념 줄 끝의 상태 점으로 보인다.
  - 점 하나가 문항 하나다.
  - 현재 문제는 테두리를 강조하고 「현재」 표시를 한다.
- 최상위 개념이 9개 이상이면 열을 여러 줄로 감싼다. 평평한 은행(옛 판)에서도 전체가 화면 비율 안에 들어오게 하려는 것이다.
- 첫 화면은 전체 맞춤이다. 현재 문항이 있으면 그 개념 줄과 열 머리를 강조하되, 확대해서 들어가지는 않는다.
- 지도 영역은 콘텐츠 폭 전체와 보이는 화면 높이를 쓴다. 「크게 보기」는 화면 전체를 덮는 겹침 창이 된다.
- 휠·두 손가락 확대, 끌어 옮기기, ＋/－/전체/현재 문제, 키보드(+ − 0 Esc)는 지금처럼 동작한다.

### 펼침·선택
- 개념을 누르면 다음이 일어난다.
  - 그 개념이 선택되고, 그 개념에 붙은 문항이 줄 아래에 제목·상태·쪽으로 펼쳐진다.
  - 조상과 자손은 보통 밝기, 연결된 개념은 강조, 나머지는 흐려진다.
  - 연결된 개념까지 곡선을 그린다. 다른 가지로 가면 가로질러 가고, 같은 가지면 오른쪽 고리로 간다.
  - 같은 개념을 다시 누르면 선택이 풀린다.
- 「문항 펼치기」는 모든 개념의 문항 줄을 펼치고, 「접기」는 되돌린다.
- 「연결선 전체」는 모든 개념 간 연결을 옅게 그린다.
- 문항 줄을 누르면 지금과 같은 패널 내용이 나온다(방향 cue, 답 범위 접힘, 중요도 근거 접힘).
- 개념 패널은 지금 내용(상태별 수, 하위 목록, 다른 주제와의 연결)을 유지한다.
- 찾기는 지금처럼 결과 목록을 보인다. 고르면 그 항목을 선택하고 화면에 들여온다.

### 모바일 (폭 760px 미만)
- 확대 캔버스 대신 열들을 한 줄로 쌓은 세로 목록이 된다. 페이지에 가로 스크롤이 생기지 않는다.
- 선택·패널·문항 펼침은 같은 규칙이다. 연결선은 그리지 않고 패널 목록으로만 보인다.

### 수용 기준
1. 감염병리1형 fixture를 1600×900으로 연 첫 화면:
   - 클릭 없이 모든 개념 노드가 DOM에 있고 지도 틀 안에 들어온다.
   - 확대 배율은 0.6 이상이다.
2. 개념을 누르면 패널이 열리고, 그 개념의 문항 줄이 보이며, 연결된 개념이 강조된다.
3. 390×844에서 `scrollWidth <= innerWidth`이다.
4. 기존 root-learning 브라우저 검사의 나머지 흐름이 통과한다. 지도 왕복, 네 평가, 실행 취소, 새로고침 재개가 그 대상이다.
5. 웹 typecheck와 build가 통과한다.

## 책임·입출력 계약·오류 상태
- 입력은 기존 `RootMapData`·`RootSummary`이고 바꾸지 않는다. `buildTree`의 규칙도 바꾸지 않는다.
  - parent_ids의 첫 부모를 쓴다.
  - 문항은 가장 많이 쓰인 개념에 붙인다.
  - 형제 사이 같은 이름은 합친다.
  - 문항을 품지 않는 말단 개념은 노드가 아니다.
  - 지도는 데이터에 없는 계층을 추측하지 않는다.
- 배치 계산(왼→오 `layout`)은 열 배치로 바꾼다. 열 안 줄은 HTML로 그리고, 가지 연결선과 개념 연결선만 SVG 겹침층에 그린다.
- 지도 API가 실패하거나 비어 있을 때의 처리는 `RootLearning`의 기존 경로를 그대로 쓴다.

## 호환성과 데이터 보존
- 서버, API, DB, 판(root_content), 학습 기록, 출제 데이터를 바꾸지 않는다. 지도 열람 이벤트(`map`)도 기존 그대로다.
- Quiz Bank 개념 지도(`ConceptMap`)와 다른 화면에는 영향이 없다.
- 되돌리기는 이 브랜치의 웹 커밋 revert 하나로 된다.
