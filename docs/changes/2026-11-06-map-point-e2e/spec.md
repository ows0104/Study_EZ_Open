# 심내막염·CNS Map·포인트에서 생성·검수·풀이 E2E 실험 — 설계

## 요구사항과 수용 기준
동일 채팅에서 완료한 원본58쪽+족보13쪽, 원래 Map2개 및 최종 포인트47/60개를 SHA256과 함께 동결한다. S1 2~29쪽/30~58쪽(1쪽 공통 안내), S2 주제별 문항을 구분하며 원본 물리 쪽을 유지한다.

## 책임·입출력 계약·오류 상태
강의별 별도 packet과 ledger를 생성한다. 제공 Map·포인트의 정규화이므로 provenance는 derived다. 원문 포인트 ID·text·근거와 독립 추출의 역사적 출처를 보존하며 원본 재추출로 표시하지 않는다. 기존 엔진의 참조·문항·그림·실제 답 위치·원본 전체 대조·독립 정답 검수·선행 검사를 모두 적용한다. 실패/거절/미실행/보완 상한을 보존한다.

## 호환성과 데이터 보존
최종 roots/1과 BANK, 검수 기록을 검증한 뒤 실험 전용 SQLite/디스크 저장소에만 등록한다. 실제 RootLearning UI를 재사용하고 강의 선택과 실험 안내만 추가한다. API는127.0.0.1로만 열고 실험 사용자에만 로컬 인증을 적용한다. 원본 링크·실제 그림·답 공개 후 평가·진도 저장/복원이 동작해야 한다. 기술 확인용 별도 계정의 사건과 사람의 실제 풀이를 구분한다.
