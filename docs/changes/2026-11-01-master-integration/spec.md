# Spec

원격/로컬 커밋을 잃지 않는 병합을 사용한다. 양쪽 기능과 관리자 전용 대화 링크, 원문 표시, 학습 기록 보존 정책을 유지한다. 충돌 해결은 파일별 실제 의도와 검사로 결정한다.
오래된 테스트는 현재 승인된 표시/권한 계약을 검증하도록 갱신한다. 개발 검사 동시 기록은 일시적 파일 접근 때문에 성공 검사를 stale로 오인하지 않아야 하며 실제 설계 변경은 계속 차단해야 한다.
UTF-8 파일과 로컬 임시 DB 환경에서 루트·서버·웹·확장 검사를 실행한다. 원본 PDF·JSON·그림·개인 작업 사본은 Git 제외 정책대로 보존한다. 통합한 원격 master와 최종 원격 커밋 일치를 확인한다.
