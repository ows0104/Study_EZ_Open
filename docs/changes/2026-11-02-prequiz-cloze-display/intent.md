# 예습 cloze 표시를 복습 Quiz Bank 방식에 맞추기

## 문제와 사용자 효과
사용자 요청(2026-11-02, 현재 채팅): “예습 퀴즈에서 clozed 형식이 복습퀴즈처럼 나왔으면 좋겠어.”
예습 cloze를 복습 Quiz Bank의 빈칸 표시 방식에 맞춘다. 풀이 전 빈칸 표시는 유지하며, 답을 펼치면 문장 안의 해당 위치에서 정답을 확인할 수 있게 한다.

## 범위와 성공 기준
예습 풀이와 완료 후 어려웠던 문제의 cloze 표시를 개선한다. 여러 빈칸과 힌트를 지원하며, 답을 펼치기 전에는 정답을 전달하지 않는다. 기존 문항 내용·학습 기록·이해 확인·되돌리기 동작을 보존한다.

## 근거·미정 사항
확인 파일: web/src/lecture/PreQuiz.tsx, PreQuizDifficult.tsx, PreQuizText.tsx, web/src/bank/BankStem.tsx, server/app/routes/prequiz.py, cards.py, runner/deck.py.
기존 예습은 [____]/[힌트]가 포함된 stem을 그대로 그리며 답은 별도 단락에 표시한다. 복습 Quiz Bank는 번호 빈칸과 문장 안 정답 강조를 제공한다. 기존 mainquiz 화면은 Quiz Bank와 별개이며 이번 변경 대상이 아니다.
복습퀴즈는 현재 복습 Quiz Bank의 표시를 뜻한다고 해석했다. 사용자 후속 승인(2026-11-02, 현재 채팅): “답을 펼치면 문장 속 빈칸에 정답을 채워 강조. 이것만 진행해줘. ‘어려웠던 문제’에서도 같은 방식 적용도.” 풀이 전 번호 추가는 제외하고 공개 후 표시와 어려웠던 문제 적용으로 범위를 확정했다.
