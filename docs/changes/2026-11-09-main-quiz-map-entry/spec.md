# Main-Quiz 개념 지도 바로 열기·화면 끝까지 쓰기 — 설계

## 요구사항과 수용 기준
- `RootLearning.showMap`
  - 먼저 `tab='map'`으로 바꾼다.
  - 세션이 없으면 `begin()`으로 세션을 연 뒤 같은 흐름을 잇는다. 기존 `mapRequested` 효과를 그대로 쓴다.
  - 지도 응답을 받지 못하면(쓰기 거절·409·오류·세션 시작 실패) `tab='learn'`으로 되돌린다.
- 렌더: `tab==='map'`이면 지도가 있을 때는 `RootMap`을, 없을 때는 불러오는 중 상태 한 줄을 그린다. `RootSolve`는 그리지 않는다.
- `RootMap`
  - `onBack` prop을 받는다. 도구 줄 첫 버튼은 「← 문제」(aria-label 「문제로 돌아가기」)다.
  - 쓰지 않던 `position` prop은 없앤다.
  - 틀 높이는 창 높이에서 틀 위치를 뺀 값이다(아래 여백 0).
- CSS(`main-quiz.css`)
  - `.app-main:has(.main-quiz-map)`는 padding 0이고 max-width가 없다.
  - `.main-quiz-learning:has(.main-quiz-map)`는 margin 0, padding 0이고 max-width가 없다. 앱 틀 규칙보다 우선한다.
  - 지도 틀은 테두리 0, 모서리 0이다.
  - 크게 보기는 inset 0이다.
- 회귀 검사 페이지(`tests/root-learning.tsx`)는 사이트와 같은 앱 틀(좌측 메뉴, `.app-main`) 안에서 그린다.

수용 기준(브라우저)
- 지도 틀의 왼쪽은 메뉴 오른쪽 끝과 맞닿는다. 오른쪽·아래와 창 사이 여백은 0이다.
- 위쪽은 창 위와 맞닿는다. 이 검사가 일부러 남긴 보존 충돌 줄이 있으면 그 줄 바로 아래다.
- 페이지 스크롤이 없다.
- 시작 화면에서 「개념 지도」를 누르면, 지도가 뜰 때까지 문제 문장이 한 번도 나타나지 않는다.
  - 옛 코드에서는 이 검사가 실패하는 것을 확인했다.

## 책임·입출력 계약·오류 상태
API·데이터 계약은 그대로다. 오류는 기존 경고 줄에 나온다.
