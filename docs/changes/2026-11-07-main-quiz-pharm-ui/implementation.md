# Main-Quiz 약리 UI 복원

사용자 기준: 참고 슬라이드를 실제로 읽을 수 있어야 하며, 화면은 문제와 답에 집중한다. 답을 타이핑하도록 요구하지 않는다. 답을 열면 1~4 자기평가는 언제나 모두 선택 가능하다. 개념지도는 개념의 연결을 보여 주어야 한다.

RootSolve를 기존 Quiz Bank의 문제 카드·하단 고정 평가바 구성으로 바꿨다. 상단은 개념지도·쉬기·더 보기이고, 답만 보기/보류는 더 보기에 넣었다. 생성/공개 관리는 시작 화면에만 남긴다. 정상 저장 상태를 반복해서 표시하지 않으며 미확인 요청·충돌·재시도는 계속 노출한다. 이전 텍스트 초안 키는 읽어서 삭제하거나 새 평가에 몰래 제출하지 않는다.

신규 요청은 선택적 selfRating을 쓴다. Again→missed, Hard→partial, Good/Easy→independent의 자기평가 의미를 보존하고 도움 여부를 별도 저장한다. 원래 요청의 생략 필드는 그대로 생략하여 과거 요청의 재시도 ID/본문 비교가 유지된다. 신규 평가의 복습 간격은 약리 Quiz Bank의 네 단계 매개변수를 사건에 고정하여 쓰며, 동일 학습일 반복으로 간격을 부풀리지 않고 시험일 압박을 유지한다. 과거 사건은 수정하지 않는다.

원래 새 자료의 정답 응답은 slides:[]였으므로 UI만 고쳐서는 슬라이드가 나타나지 않았다. evidence.py가 문항의 실제 source_refs/그림 쪽과 검토 자료의 출처 SHA를 출제 당시 보관본에 대조한다. 기존 Quiz Bank 자료면 일치하는 기존 근거 이미지를 재사용한다. PDF만 있으면 서명 URL로 해당 쪽을 읽어 PDF.js로 렌더링하고 기존 확대 보기를 재사용한다. 최초 인용 쪽을 참고 자료로 먼저 표시하며 임의로 핵심 근거로 판정하지 않는다. 나머지는 추가 참고 슬라이드로 접는다. 쪽 정보가 없으면 첫 쪽으로 대신하지 않는다.

현재 공개 자료의 로컬 보존본(261104_02-v1 curated-result.json/packet.json)을 읽기 전용으로 대조했다. 98문항 모두 파싱 가능한 실제 PDF 쪽 인용이 있고, 원본 SHA는 4b4229bc65d9636a3326efb2dba187a75327f6d21e9eec9e9c598671c4248751이다. 개념 130개는 parent_ids가 비어 있고 실제 관계 98개가 association으로 보관돼 있다. UI가 새 의학적 계층을 추측하지 않고 이 연결을 사용한다. 현재 문제에 연결된 목표의 개념과 인접 관계부터 열고 검색·전체 지도로 확장한다. 개념/문제/검수 내용을 편집하지 않았다.

행동 기록은 기존 root 시작/회상/평가/취소 사건과 카탈로그를 재사용한다. 새 행동 종류나 접속 기록표를 만들지 않았다. root_usage 및 usage_actions 검사도 통과했다.
