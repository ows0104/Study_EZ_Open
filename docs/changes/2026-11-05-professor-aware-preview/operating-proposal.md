# 운영 적용 후보 — 미적용

2026-11-05 로컬 구현의 읽기 전용 후보 목록. 운영 DB·첨부·공유 링크 변경은 실행하지 않았다.

감염과 면역 83개 로컬 대상: 자료 선택 71개, 작년 대응과 다른 원본 후보 8개, 담당 변경 판정 11개. 시간표 기준은 잠정이고 교수 표기 충돌·합본·자료 미상은 확인 필요다. 기존 운영 대상/첨부와의 최종 조건부 대조는 승인 후 별도 읽기 전용 사전 확인에서 수행한다.

2024 폴더가 없다. 신규 교수는 보유 2021~2025 동일 강의 필기 기준이며 자료가 없거나 불명확한 것을 실제 신규 임용으로 주장하지 않는다.

## 적용 순서와 승인 범위

1. 현재 러너의 자동 업로드를 중지한 상태에서 운영 스키마에 `lecture.preview_source JSON NULL` 한 칼럼만 준비한다. 기존 자료·사용자·권한·은행/문항 표는 변경하지 않는다. 전체 init-db를 이번 칼럼 추가 대신 실행하지 않는다.
2. 검사와 source hash가 같은 API/웹 후보를 준비해 배포한다. API `/api/admin/previews`가 `previewSourceVersion: 1`을 반환하는지 확인한다. 준비 전 새 러너는 읽기 확인만 하고 강의·첨부 변경을 보류한다.
3. 아래 대상과 기존 운영 연결/파일/수동 예외를 조건부 대조하고 이전 객체가 존재함을 확인한다. 변경 후보를 다시 확인한 뒤 notes-only 자료 전환을 수행한다. 각 원본은 선택 해시별 키에 업로드하며 이전 PDF·바이트 해시·연결/복원 정보는 내부 보존 이력에 남긴다.
4. 변경된 예습 필기의 실제 바이트/교수/연도와 캘린더 태그/실제 파일 표시를 확인한다. 동일 교수 미발견 대상은 확인된 2025 자료를 사용한다. 기존 공유 대화·퀴즈·학습 기록을 자동 재생성/삭제/완료 처리하지 않는다.
5. 자료가 바뀐 대화는 출처 변경 안내를 유지한다. 새 필기로 만든 새 공유 링크 확인 전 Pre-Quiz 자동 처리와 기존 결과의 재귀속은 보류한다. 확인 필요/합본/표기 충돌을 자동 확정하지 않는다.
6. 사후 확인 후 정상 러너를 재개한다. 롤백 시 러너 업로드를 먼저 멈추고 저장된 이전 파일 키/해시와 연결 정보를 사용한다. JSON 칼럼과 보존 이력은 남기며 학습 기록/예습 대화를 되돌리지 않는다.

승인이 필요한 실제 운영 범위는 위 단일 칼럼·검사된 코드 배포·아래 자료 메타데이터/첨부 전환이다. 이 문서는 운영 실행 명령이나 실행 영수증이 아니다.
