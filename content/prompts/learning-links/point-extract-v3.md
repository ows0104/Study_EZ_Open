위 필기와 족보를 보고 출제포인트를 추출해줘. 각 포인트에는 무엇을 스스로 인출·구별·설명·적용할 수 있어야 하는지 구체적으로 적어줘.

- 교수 강조·학습목표·족보를 참고하고 원본 전체에서 학습 가치가 있는 목표를 찾아줘.
- 각 포인트에 어떤 단서에서 무엇을 떠올리거나 판단할지 드러내줘. 중요한 기초 연결과 그 위의 비교·기전·적용을 살펴보고, 필요한 방향·조건·예외를 포함해줘.
- 각 포인트는 독립적으로 회상·판단할 가치가 있는 하나의 학습 목표로 정해줘. 서로 다른 단서·답 범위에서 따로 성공하거나 실패할 수 있는 정의·기전·분류·예외·적용은 각각 기록해줘.
- 분류 목록 전체를 떠올리기, 같은 축에서 비교하기, 과정의 순서를 재구성하기 자체가 하나의 목표라면 함께 묶어줘. 목표의 의미를 기준으로 묶음의 크기를 정해줘.
- 적용 상황에서 주어진 관계를 활용하는 목표와, 그 관계 자체를 스스로 떠올리는 기초 목표를 각각 살펴봐. 마지막에 포인트별 단서와 답 범위를 확인해 독립 목표가 큰 묶음 안에 가려지지 않도록 정리해줘.
- 족보에서는 실제로 판단한 연결과 혼동 지점을 살펴봐. 기출 내용·교수 강조·필기자 표시의 차이를 고려해 목표를 선정해줘.
- 해당 강의의 원본 범위 안에서 추출하고, 중요한 그림·자료 충돌·불확실성과 제외 판단은 해당 포인트나 notes에 간단히 남겨줘.

## 중요도 근거 (importance_basis)

포인트마다 원본에서 실제로 확인한 중요도 근거를 importance_basis에 적어줘. 근거가 없으면 []야. 등급은 쓰지 마. 등급과 점수는 코드가 근거로 계산해.

- exam_forecast: 교수가 이 내용을 시험에 낸다거나 반드시 알아야 한다고 한 것. 「시험에 내기 좋겠죠?」, 「이 정도는 알아야겠죠?」 같은 완곡한 표현도 포함해. quote에 실제 문장을 옮겨줘.
- exam_exclusion: 교수가 시험에 안 낸다고 한 것. 「별표 했지만 시험에 안 낸다」처럼 다른 표시와 함께 있어도 적어줘. quote에 실제 문장을 옮겨줘.
- current_exam: 올해 담당 교수의 족보 문항이 이 포인트의 회상 단위를 실제로 물은 것. 연도마다 한 줄씩 쓰고 year와 번호를 적어줘. 넓은 주제가 같다는 이유만으로 쓰지 마.
- other_exam: 다른 교수의 같은 주제 기출.
- learning_objective: 학습목표·Summary·Take-home에 이 내용이 있는 것.
- slide_emphasis: 슬라이드 원본의 굵은 글씨·강조색·밑줄·네모. 제목·소제목의 굵은 글씨는 세지 마.
- professor_remark: 필기에 옮겨 적은 교수의 말이 이 내용을 강조한 것. 출처는 색이 아니라 문장으로 가려줘(「교수님께서 ~하셨다」, 인용, 교수의 말투). 출제 예고면 exam_forecast로 써줘.
- writer_remark: 누가 한 말인지 문장으로 알 수 없는 필기 첨언.
- writer_mark: 필기자의 하이라이트·밑줄(교수가 읽은 부분 표시).
- writer_stamp: 필기자의 중요 스탬프.
- last_year_emphasis: 작년 필기의 강조.
- clinical: 임상적으로 중요한 것(진단·치료 판단, 감별, 위험).
- structural: 다른 핵심 목표를 이해하는 데 먼저 필요하거나 그 위의 개념인 것. reason에 어떤 목표의 선행·상위인지 적어줘.

같은 쪽·같은 표·같은 슬라이드에 있다는 이유로 근거를 다른 사실에 옮기지 마. 각 근거는 그 포인트의 회상 단위를 직접 가리켜야 해. refs에는 원본 ID와 물리 쪽을, reason에는 무엇을 보고 판단했는지를 적어줘.

notebook_profile에는 필기본 전체의 표시 방식을 적어줘.
- legend: 필기본에 범례(색·스탬프·기호의 뜻)가 있으면 그 내용을 요약해줘. 없으면 빈 문자열이야.
- emphasis_style: 교수가 슬라이드 원본에 강조를 거의 두지 않고 말로 강조해서 필기자 표시가 주된 강조 수단이면 verbal, 그 밖에는 slide야.
- reason: 그렇게 판단한 근거.

범례·색상·스탬프의 쓰임은 필기자마다 달라. 범례는 단서로만 쓰고, 실제 표시와 문장이 범례와 다르면 실제를 따라줘. 애매하면 낮은 쪽 kind로 쓰고 이유를 reason에 남겨줘.

## 출력

전체 결과를 실제 UTF-8 JSON 파일 exam-points.json으로 작성하고 다운로드 링크를 제공해줘. 파일 안에는 아래 구조의 JSON 객체 하나를 담아줘.

- schema_version은 exam-point-extract/3, title은 강의명이야.
- points의 point_id는 P001부터 부여해줘. point에는 하나의 독립적인 회상·판단 목표와 그 답 범위를 간결하게 적어줘. 그 목표를 특정하는 조건·방향은 함께 표현해줘.
- source_refs에는 제공된 원본 ID와 실제 근거 위치를 남겨줘. pages는 PDF 물리 쪽 번호이며, 페이지를 특정하기 어려우면 []와 확인 가능한 locator를 써줘. 족보의 교수·연도·번호나 강조 발언 등 필요한 근거 설명도 locator에 적어줘. 위치 설명이 따로 필요 없으면 locator는 null이야.
- notes에는 중요한 제외 판단·자료 충돌·확인하지 못한 범위를 간단히 적어줘. 해당 사항이 없으면 []야. 자료를 읽을 수 없어 포인트를 추출하지 못했다면 points는 []로 두고 그 이유를 notes에 적어줘.

아래는 S1의 1쪽에 사각형 정의와 포함 관계가 제시된 합성 예시야. 포인트의 수·내용은 실제 강의에 맞춰 작성해줘.

```json
{
  "schema_version": "exam-point-extract/3",
  "title": "사각형 분류",
  "points": [{"point_id": "P001", "point": "정사각형이 속하는 상위 분류로 직사각형을 인출한다.", "source_refs": [{"source_id": "S1", "pages": [1], "locator": null}], "importance_basis": [{"kind": "slide_emphasis", "refs": [{"source_id": "S1", "pages": [1]}], "quote": "", "reason": "1쪽 원본에서 포함 관계 문장이 빨간 네모로 강조됨", "year": null}]}],
  "notes": [],
  "notebook_profile": {"legend": "", "emphasis_style": "slide", "reason": "원본 슬라이드에 강조 표시가 있고 필기자 범례는 없음"}
}
```
