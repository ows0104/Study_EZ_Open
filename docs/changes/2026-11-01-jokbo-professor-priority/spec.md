# Spec

- 기준 입력: output/materials/감염과 면역_2026_JSON/catalog.json, sections/*.json, source/감염과 면역 족보_2026_원본.pdf 및 answer-audit/upload-plan.json. 입력 파일 해시를 새 계획에 고정한다.
- PDF에 별도 표지·전체 교수 목록을 넣지 않는다. 단원 제목, 연도·해당 연도 교수·문항 번호, 우선/참고 구분, 원본 정답/확인 필요 상태와 원본 쪽만 간결하게 표시한다. 원문 영역은 그대로 가져오고 원문 공용 자료와 정답표를 끝에 보존한다.
- PDF 순서는 올해 담당 교수와 겹치는 기출, 다른/미상 교수 기출 순이며 각 구분 내 연도 내림차순이다. 공동 담당은 한 명 이상 겹치면 우선하되 전체 해당 연도 교수명을 표시하고 단독 출제로 단정하지 않는다. 교수 이력이 없으면 미상으로 둔다.
- 자료 게시 시 올해 notes_current 파일명이 있으면 그 교수로 강의별 우선순위를 정한다. 아직 올해 필기가 없으면 시간표 기준임을 기록한다. 같은 단원도 실제 교수 구성이 다르면 별도 PDF를 만들 수 있다.
- 복습 프롬프트와 Quiz Bank 정본은 첨부한 올해 필기의 파일명 교수 정보를 우선 확인하고 시간표/족보의 올해 열과 다를 때 실제 필기를 따른다. 이름을 읽을 수 없으면 추정하지 않는다. 다른 교수 기출은 참고로 남긴다. 예습 프롬프트는 변경하지 않는다.
- 업로드는 jokbo 자산만 교체한다. 기존 PDF는 로컬 바이트/해시와 연결을 보존한다. 필기·강의 속성·기존 퀴즈와 학습 상태는 변경하지 않는다. 서비스 코드는 로컬 검증까지이며 별도 고정 후보 승인 없이 다른 변경을 섞어 배포하지 않는다.
