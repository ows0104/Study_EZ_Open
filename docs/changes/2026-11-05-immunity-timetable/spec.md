# 수정 감염과 면역 시간표 — Spec

## 요구사항과 수용 기준
전체 369 event ID를 보존하며 원본 PDF 4쪽에 따라 변경한다. 시험·실습·TBL·CBL 시간도 모두 대조한다.
주제 기준 기존 ID를 사용: 12↔22, 13↔17, 23↔30, 기존 40→47/47→40, 46→48/48→46, 65↔66.
병원감염은 같은 김의석 강의의 의료관련감염으로 표기 변경. 전신경화증·알레르기비염·두드러기·호산구성질환·다양한알레르기질환 담당을 원본대로 수정.
동영상 5의 professor에 잘못 들어간 ‘폐렴’을 비운다. 1~66, TBL 1~2, CBL 1~9, 실습과 시험 모두 원본 표 대조.

## 책임·입출력 계약·오류 상태
data/timetable의 기존 정본을 수정한다. data/timetable/identities/2026-2.json은 이동 event ID→기존 run_id만 보관한다.
runner.ahead는 JSON/SQLite 시간표 양쪽에서 이 식별자를 읽어 기존 예습 자리·확인된 작년 짝을 유지한다. 일시/교시는 수정된 시간표를 쓴다.
DB 반영 도구는 전체 시간표 기대 전후값을 검사하고 변경 칸만 한 트랜잭션에서 갱신한다. 모든 강의 FK/ID를 보존하며 이동한 기존 연결만 시각 대조 근거로 confirmed 설정한다.
기대 원본 불일치·미확인 링크·중복 ID·중복 자리이면 실패하고 commit하지 않는다. 운영 인증값·개인 응답 원문은 출력하지 않는다.

## 호환성과 데이터 보존
run_id와 기존 uid·자료 경로·은행·링크·학습 기록은 변경하지 않는다. 전체 lecture 스냅샷을 반영 전후 대조하며 허용한 confirmed 변경 외에는 동일해야 한다.
일반 seed의 재매칭도 confirmed 연결을 보존한다. 추가 파일·이벤트·강의 삭제 없음.
원본 PDF와 정본 전후 해시, 변경 칸 패치 및 DB 전후 검증 요약을 보관한다. 원본 확인된 _pairs 사용자 기록은 수정하지 않는다.

수정 위치에 올해 필기가 도착할 때도 기존 자료를 덮지 않도록 runner/filenames.py에서 날짜/교시와 명시적 전체 주제가 일치하는 12강의만 기존 키로 해석한다. data/timetable/identities/2026-2-notes.json의 검토된 정확한 별칭만 사용하며 다른 과목/시기에는 적용하지 않는다.
