# 실행 계획

1. 직전 정리본의 38개 확인 항목과 원본 문제·정답 지면을 대조한다.
2. 작업 폴더의 일회성 자료 스크립트만 교정한다. 소수점 14개 오인, 숫자 외 정답 2개, 동일 문항 중복 및 이로 인한 중복 번호 연결을 정정한다.
3. 영향 있는 단원을 새 출력 폴더로 생성하고 이전 자료는 그대로 둔다. 새 업로드 계획은 바뀌지 않은 단원의 기존 파일을 유지한다.
4. 전체 자료 검사 및 최신 수정 지면 시각 검토 후 변경된 jokbo만 업로드하고 전체 80개 저장 파일과 기존 필기·강의·퀴즈 보존을 검사한다.
5. 실제 남은 확인 항목을 단원·연도·번호·사유로 답변한다. 복원은 직전 정리본 업로드 계획을 사용한다.

기존 사용자 명시적 제작·업로드 승인이 같은 정리본의 기술 오류 수정을 포함한다. 원본 의료 내용은 수정하지 않는다.
