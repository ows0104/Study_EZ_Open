# 예습 기본 링크·GPT 초안 복구 운영 웹 배포 — 설계

## 요구사항과 수용 기준
운영 예습 기본 링크 만들기는 직접전송 준비 요청을 보내고 별도 자동전송은 자동 첨부·전송을 유지한다. GPT 브리지 1.3.21은 확인된 실패 초안만 자동 복구하고 출처 불명 초안은 팝업의 명시적 선택 뒤 정리한다. 중복 전송·사용자 수정·첨부 제거 실패 중지 조건은 원 승인 구현과 같다. 배포본의 기본 버튼 코드·가이드·ZIP 해시를 고정 후보와 대조해 확인한다.

## 책임·입출력 계약·오류 상태
운영 검증 사본을 새 tmp/preview-bridge-20261105에 복제한다. baseline 빌드를 기존 성공 Pages 후보 manifest와 비교한 뒤 원 작업의 bridge 파일·예습 카드·테스트를 복사하고 가이드는 이번 설명 hunk만 반영한다. release_evidence prepare/publish-web으로 고정 후보·실제 revision·health/읽기 전용 사후 검사 근거를 기록한다. 원격 branch push 없이 정적 후보만 업로드한다.

## 호환성과 데이터 보존
서버 API/DB·기존 대화/공유 링크·학습/검수·미저장 응답·원본/시범 작업·출제 상한은 변경하지 않는다. 이전 운영 웹의 다른 기능을 제거하거나 미배포 기능을 섞지 않는다. 실제 GPT에 접속·전송하지 않는다. ZIP 게시와 사용자의 확장 설치를 구분한다.
