# Map와 독립 출제포인트 추출 지침 정리 — 설계

## 요구사항과 수용 기준
Map 요청문은 원본의 중심 질문·개념·의미 있는 관계·교차 연결·큰 흐름만 다룬다. 문제/문항/누락 판정/회상 평가/문항 학습 순서는 지시하지 않는다. 포인트는 원본 전체에서 회상·판단 목표, 단서→답 범위, 조건/예외/필요 방향과 중요도 근거를 추출한다. 문항 수에 맞추거나 모든 사실을 자동 분할하지 않는다.

## 책임·입출력 계약·오류 상태
같은 원본만 각각 제공하여 독립 추출한다. 출력 구체화 승인에 따라 Map은 개념·관계 목록의 JSON, 포인트는 목표·방향 목록의 JSON으로 작성한다. 버전·원본·범위·근거·불확실성을 보존한다. 문항 대응·누락 판단은 이후 별도 대조이며 원본 추출만으로 실제 누락 문항을 확정하지 않는다. 현행 자동 생성기 연결과 호출 분리는 이번 범위가 아니다.

Map 관계는 종류·방향·조건·출처·지지 상태를 가진다. 분류 관계만으로 모든 관계를 계층화하지 않는다. 포인트에는 단서·답 범위·핵심 답 요소·필요 방향·그림 여부와 구조/시험/임상 중요도 근거를 둔다. 두 결과는 서로의 ID를 추출 입력으로 요구하지 않는다. 미확인은 null/빈 배열/명시적 상태로 보존한다.

## 호환성과 데이터 보존
원본·범위·교수/연도·그림·불확실성 및 기존 문항/기록/검수 상한을 보존한다. 현행 learning-brief/2 및 PLAN JSON을 교체하지 않는다. 구조적 위치·시험·임상 중요성과 심화를 구별한다.
