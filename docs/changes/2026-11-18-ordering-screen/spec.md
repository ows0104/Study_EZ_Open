# Main-Quiz 순서 맞추기 화면 — Spec

## 무엇을 바꾸나
순서형으로 판정된 나열 문항은 선지 대신 **순서 맞추기 화면**으로 푼다. 다른 문항은 지금 그대로다.
문항·정답·판·학습 기록·선지 asset(`root_mcq`)은 읽기만 한다.

## R1. 순서형 판정은 판별 asset으로
- 새 asset 종류 `root_order`, 파일명 `<revision>.json`, schema `root-order/1`. 판(revision)마다 하나.
- 대상은 정답 단위가 3개 이상인 `list` 문항뿐이다(2개는 순서를 맞춰도 반반이라 뺀다).
- 모델이 문항마다 판정한다. 순서형은 「답 단위들이 하나의 과정·단계·경로·연쇄를 이루고, 그 순서가 곧 묻는 내용」인 문항이다.
  「경로 두 가지」, 「대표 원생동물 두 가지」처럼 단순히 여럿을 나열한 문항은 순서형이 아니다.
- 순서형이면 `order`(정답 단위의 올바른 순서, 단위 번호의 순열)와 근거 한 줄을 쓴다.
  저장된 단위 순서가 틀렸으면 모델이 바로잡은 순서를 쓴다. 문항 글은 고치지 않는다.
- 키워드 규칙은 쓰지 않는다. 로컬 공개판 나열 4,044개 중 「단계·순서·과정·경로·주기」가 들어간 275개의
  상당수가 순서형이 아니다(「포도알균의 접촉 전파 경로 두 가지」 등).
- 코드 검사: 순열인지, 대상 문항인지, 판·문항 글 해시가 맞는지. 어긋난 줄은 버리고 그 문항은 지금처럼 나온다.

## R2. 서버가 붙이는 것
`server/app/root_learning/mcq.py`의 `attach_front`·`attach_answer` 안에서 처리한다(`routes/root_learning.py`는 고치지 않는다).
- 앞면: 순서형 문항이면 `order_items: [{id, text}]`를 붙이고, 그 문항의 `mcq_choices`·`mcq_groups`는 붙이지 않는다.
  섞는 순서는 선지와 같은 씨앗(사용자·문항·학습일)으로 정한다. 같은 날은 같고 다음 복습 날에는 달라진다.
  올바른 순서와 같은 배열로 섞이면 한 번 더 섞는다. ID는 글에서 만든 해시라서 앞면만 보고는 순서를 알 수 없다.
- 답면: `orderCorrectIds`(올바른 순서의 ID 배열).
- 개인 수정본·형식을 바꾼 문항은 지금 선지 규칙과 같다. 정답을 고쳤으면 순서 화면 없이 주관식으로 나온다.

## R3. 화면
객관식 모드에서는 처음부터, 주관식 모드에서는 「선지 보기」 자리의 「순서 맞추기」(V)로 펴서 순서형 문항을 푼다.
V를 한 번 더(또는 Z) 누르면 접히고 놓은 단계는 비워진다. 편 기록은 선지와 같이 남는다.
- 위: 섞인 단계 버튼. 누르면 아래 「내 순서」 줄 끝에 번호가 붙어 들어간다. 숫자 1~9 키로도 고른다.
- 아래: 「내 순서」. 들어간 단계를 누르면 그 단계만 빠진다. Backspace는 마지막 하나를 뺀다.
- Space(답 보기): 지금처럼 확인한다. 다 놓지 않아도 확인할 수 있다.
- 답면: 자리마다 내 순서와 정답 순서를 나란히 보여 주고, 맞은 자리 ✓, 틀린 자리 ✗, 빈 자리 「—」를 표시한다.
  「맞은 자리 n / 전체 m」 한 줄.
- 평가는 지금처럼 네 버튼이다. 자동 채점은 하지 않는다.
- 기록: `response`에 `순서: <id> → <id> …`를 남긴다. 「도움받은 풀이」 판정은 객관식 모드의 선지와 같다.
- 휴대폰 폭에서도 버튼이 줄을 바꿔 넘치지 않게 한다.

## R4. 만들기·올리기
- 러너가 판을 게시한 뒤 선지(`root_mcq`) 옆에서 판정을 기본으로 돌린다. 실패해도 게시 결과는 그대로다.
- 이미 게시된 판은 수동 명령으로 채운다:
  `python -m runner.root_order --all-published --subject 감염과 면역 --missing`.
  강의마다 모델 호출은 한 번이다(그 판의 나열 문항만 보낸다). 모델은 Codex CLI(`studyez_llm.codex`)를 하위 프로세스로 부른다.
- 운영 asset 올리기는 구현과 검사가 끝난 뒤 사용자 승인을 받고 한다.

## 범위 밖
- 출제 파이프라인이 sequence 형식을 쓰게 바꾸는 일(미래 판에만 효과가 있고, 출제 정책 변경이다).
- 오답(다른 바이러스의 단계)을 섞는 일. 이번에는 정답 단위만 순서대로 놓는다.
- 자리 점수에 따른 자동 평가.
- 옛 Quiz Bank·Pre-Quiz 화면.

## 성공 기준
- Q174가 객관식 모드에서 단계 7개를 섞은 순서 맞추기로 나오고, 답면에 자리별 ✓/✗가 보인다.
- 판정 asset이 없는 판, 순서형이 아닌 나열, 다른 형식은 지금과 같은 화면이 나온다(회귀 검사).
- 앞면 응답에 정답 순서가 들어 있지 않다.
