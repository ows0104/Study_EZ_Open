# 배포 준비
사용자 현재 지시가 버튼 조건만 수정·확인·사이트 반영 및 EventPanel의 예정 작업 중 이 부분의 분리 수정을 승인한다.
제품 변경은 EventPanel.tsx의 기존 hook import/호출과 조건 한 곳뿐이다. 새 Main Quiz는 기존 계정/공개 판정 API를 재사용하고 기존 usable 은행의 접근은 유지한다. 버튼 이름·URL·그 외 화면·서버·데이터·학습기록은 변경하지 않는다.
실제 CalendarPage/강의 패널에서 새 자료만 있음·기존 은행만 있음·둘 다 없음 3경우의 버튼/주소/클릭 확인 통과. 웹 타입/운영 빌드 통과. 최종 근거는 state.json의 source_hash 232357f51f168fe613c868b76aaffdf47116e63cc289e5cc7a16e471f279a88a이다. 첫 웹 검증은 PDF 준비 파일의 생성으로 소스 지문이 바뀌어 exit2였으며, 준비 후 재검증하여 성공을 기록했다.
조건의 OR 우선순위·hook 호출 위치·기존 계정 변경/404 fallback·권한 제한 보존을 리뷰했다. 이름이나 단축키 변화가 없으므로 GuidePage 변경은 없다.
PR CI 후 사용자 승인에 따라 병합한다. 자동 배포의 API와 Pages가 같은 merge SHA를 반영하는지, 실제 EventPanel 파일에 새 조건이 제공되는지 읽기 전용 확인한다. 실패 시 이 코드만 revert하고 원본/기록은 보존한다. 운영 학습 쓰기 0을 유지한다.
