## 배포
러너 표시만 바뀐다. 병합만으로는 실행 중 러너에 반영되지 않는다. 반영은 `.runtime` 재설치 → 바로가기로 창 다시 열기.
실행 중 강의가 끝난 뒤에 한다. 되돌리기는 revert 후 재설치.
