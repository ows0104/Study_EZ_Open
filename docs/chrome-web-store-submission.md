# Study EZ 예습 브리지 — Chrome Web Store 등록표

기준 버전: 1.3.24 (사용자판)
작성일: 2026-08-25 · 개정 2026-10-09 (예습 수동·자동 입력, 개인 복습, 링크 복구) · 2026-11-10 (학생용 사용자판)

**스토어에는 학생용 사용자판만 올린다(2026-11-10 관리자 지시).** 같은 소스에서
`build-store-package.ps1`이 `protocol.js`의 `EDITION`을 `user`로 바꾸고 관리자 Quiz Bank 파일 회수
스크립트(`bank-file.js`·`bank-download.js`)를 뺀다. 사용자판은 개인 예습·복습을 **수동입력**으로만
연다. 자동전송, 공개 공유 링크(`shared`), Quiz Bank(`bank`) 요청은 배경에서 거절한다. 사이트는 학생에게
이 셋을 요청하지 않으므로(관리자 화면에서만 보낸다) 학생 화면은 바뀌지 않는다.
사이트의 `studyez-extension.zip`도 같은 사용자판이다(`bridge/user-edition.mjs` 공용 변환).
관리자는 저장소의 `bridge` 폴더(관리자판, `EDITION: "full"`)를 압축 해제 상태로 로드해 쓴다. 관리자 크롬에 스토어판과
관리자판을 같이 켜 두지 않는다.

웹스토어 공개판은 1.2.0으로 관리한다(2026-11-10 기준). 1.2.0은 복습 요청도 확인 카드 제목이
「Study EZ 예습 자료」로 고정돼 있고, 1.3.16부터 「복습 자료」로 구분한다. 1.3.24 제출·심사만으로 공개판이 갱신된 것으로
취급하지 않는다. 스토어에 새 버전이 실제 공개된 것을 확인한 뒤 Pages 빌드 변수
`VITE_EXTENSION_STORE_VERSION`을 해당 버전으로 변경하고 웹을 다시 빌드한다.
웹은 필요한 버전(직접 전송하는 예습·복습·문제은행 1.2.0, 자동전송 1.3.3)을 스토어 공개판이 제공하지
못하면 빌드에 포함된 최신 ZIP과 설치·업데이트 방법을 안내한다.
1.2에서는 첨부·프롬프트 입력 후 사용자가 직접 전송한다. 1.3.0~1.3.2는 수동 요청도
자동 전송하므로 수동·자동 선택을 지원하는 1.3.3 이상으로 갱신하도록 안내한다.
복습 구분을 모르는 1.3.5 미만 확장에는 개인 대화 요청을 보내며, 사이트가 요청의
식별자에 복습 표시를 넣는다. 돌아온 개인 링크를 사이트가 복습 저장 경로로 보내고,
확장에는 원래 식별자·종류로 저장 완료를 회신한다. 예습과 복습이 같은 강의에서
동시에 진행되거나 사이트를 새로고침해도 서로의 저장 위치를 덮어쓰지 않는다.

사이트의 버튼·문구·프롬프트와 기존 요청을 사용하는 기능은 확장 업데이트 없이 변경할 수 있다.
새 AI 서비스 조작, 첨부·전송 방식, 결과 회수 방식이나 링크 저장 모드를 확장에 추가할 때만
해당 기능의 최소 버전을 올린다. 사이트 전체의 최소 버전을 일괄 올리지 않는다.

## 자세한 설명

Study EZ 예습 브리지는 Study EZ에서 선택한 강의 자료와 예습·복습 프롬프트를
선택한 AI 서비스의 새 대화에 준비합니다. 확인 화면에서 자료와 데이터 처리를 검토하고
동의하면 PDF가 첨부되고 프롬프트가 채워집니다. 전송은 사용자가 직접 누릅니다.

답변이 완성되면 사용자의 개인 대화 주소를 해당 Study EZ 강의의 예습 또는 복습 자리에 연결합니다.

주요 기능:

- 선택한 강의 PDF와 프롬프트를 ChatGPT·Gemini·Claude 중 선택한 서비스의 입력창에 준비
- 첫 실행에 파일 목록과 데이터 처리 내용을 확인하고 명시적으로 동의, 동의 해제 제공
- 전송은 사용자가 직접 수행(확장은 자동 전송하지 않음)
- 완성된 개인 대화 주소를 Study EZ 강의의 예습·복습에 연결
- Study EZ, ChatGPT, Gemini, Claude, 지정된 Cloudflare R2 주소에서만 작동

## 단일 목적

사용자가 Study EZ에서 선택한 강의 자료와 프롬프트로 선택한 AI 서비스의 대화를 준비하고,
완성된 개인 대화의 링크를 해당 강의에 연결하는 기능만 제공합니다.

## 권한 사유

### storage

진행 중인 강의 요청과 아직 Study EZ에 저장되지 않은 대화 링크를 해당 브라우저
세션 동안 임시 보관합니다. 저장 확인을 받으면 삭제되며 장기 추적에 사용하지
않습니다. 자료 입력과 결과 저장에 대한 AI 서비스·모드별 동의 여부는 로컬 저장소에 보관하며 확인 카드의
“동의 해제”를 누르면 삭제합니다.

### scripting

Gemini가 파일 업로드 메뉴를 누른 순간 동적으로 만드는 파일 입력을 포착해, 사용자가
확인한 PDF를 넣는 데만 사용합니다. 다른 페이지 코드나 동작에는 사용하지 않습니다.

### 호스트 권한

`studyez.kr`에서 사용자가 선택한 강의·파일 요청을 받고 완성된 링크를
돌려줍니다. `chatgpt.com`, `gemini.google.com`, `claude.ai`에서 사용자가 동의한 PDF와 프롬프트를 준비하고 대화
완료 및 링크를 확인합니다. 지정된 Cloudflare R2 origin에서는 사용자가 선택한
PDF를 임시 서명 URL로 내려받습니다. 다른 웹사이트를 읽거나 추적하지 않습니다.

### 원격 코드

**아니요.** 모든 실행 코드는 ZIP에 포함되어 있습니다. 외부에서는 사용자 선택
PDF와 서비스 API 응답만 받아오며 JavaScript 또는 WebAssembly를 내려받아
실행하지 않습니다.

- 웹 기록

데이터는 핵심 기능 제공에만 사용하고 판매,
광고, 신용평가, 사용자 추적에 사용하지 않는다는 Limited Use 확인란에 동의합니다.

구체적으로 PDF 파일 내용과 예습 프롬프트를 사용자의 동의 뒤 선택한 AI 서비스에 입력하고,
대화 주소·완료 상태를 기능 수행 중 일시적으로 처리합니다. ChatGPT 액세스
토큰은 대화 완료 확인 요청에만 메모리에서 사용하며 저장하거나 Study EZ로
전송하지 않습니다.

## 심사자 안내 초안

1. 제공된 Study EZ 심사용 계정으로 로그인합니다.
2. 승인된 캘린더에서 필기가 연결된 강의를 누릅니다.
3. AI를 선택하고 예습의 “개인 대화” 만들기(또는 복습의 “개인 링크” 만들기)를 누르면 해당 AI 새 탭과 확장 확인 카드가 열립니다.
4. 해당 AI 서비스·모드를 처음 사용하는 경우 데이터 처리 설명을 읽고 동의 확인란을 선택한 뒤
   “동의하고 입력”을 누릅니다. 이후에는 같은 서비스·모드의 동의를 기억하며(버튼은 “자료·프롬프트 넣기”),
   확인 카드의 “동의 해제”로 되돌릴 수 있습니다.
5. PDF와 프롬프트가 입력창에 준비됩니다. 내용을 확인한 뒤 사용자가 직접 전송합니다.
6. 답변이 끝나면 개인 대화 링크가 Study EZ 강의에 연결됩니다.

로그인 토큰은 ChatGPT 요청에 메모리에서만 사용하며 Study EZ로 전송하거나 저장하지 않습니다.

> 제출 전 실제 심사용 계정 이메일·비밀번호와, 필기가 연결된 강의명을 이 절에
> 추가해야 합니다. 비밀번호는 저장소에 커밋하지 않습니다.

## 등록용 ZIP 만들기

PowerShell에서:

```powershell
.\bridge\build-store-package.ps1
```

결과: `bridge/release/studyez-preview-bridge-<manifest version>-web-store.zip` (지금은 1.3.24 사용자판)

스크립트는 bank 스크립트를 빼고 `importScripts`·manifest를 그에 맞게 고친 뒤, 실행에 필요한
파일이 모두 ZIP에 있는지 대조한다. 감사 스크립트는 사용자판 표시·거절 분기·bank 스크립트 부재와
같은 대조를 따로 한다. 2026-11-10 이전 스크립트는 1.3.19·1.3.20의 `importScripts`에 추가된
`bank-file.js`·`bank-download.js`를 고려하지 않아, 그 ZIP은 서비스 워커가 시작하지 못한다.

```powershell
.\server\.venv\Scripts\python.exe .\bridge\audit-store-package.py
```

스토어 항목의 실제 공개 버전을 확인한 뒤 Cloudflare Pages 빌드 변수
`VITE_EXTENSION_STORE_URL`에 실제 스토어 URL을, `VITE_EXTENSION_STORE_VERSION`에
공개된 버전을 넣습니다. 해당 기능에 필요한 버전 이상일 때 웹스토어 설치 버튼을 표시합니다.
