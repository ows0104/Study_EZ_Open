2026-11-03 후속: [분류·나열 구분과 첫 10묶음 역할 검토](../2026-11-03-question-role-refinement/first-ten-review.md)를 적용한다. 기존 content-review.md는 CLI 원문으로 보존하며, 후속 교육 설계 메모가 원문 의학 검수 판정을 대체하지 않는다.

## 결과와 확인

사용자가 구체적으로 자료의 OpenAI Codex 전송과 1회 작성을 승인한 후 실행했다. CLI 세션 `01a19b33-5b0f-76c2-9ed9-a7969a535cdc`의 원문 응답을 content-review.md에 보존했다. 35개 강의 이미지와 12개 시험 이미지의 실제 반환은 image-access-evidence.json에 확인했다. 원본/파생 입력 55개의 전후 지문이 일치한다. 부모 에이전트도 학습목표 p.4, 억제 도식 p.20, 시험 수정 표시 p.33을 직접 열어 확인했다.

새 후보 포인트 P01–P24, 질문 D01–D49의 고유성과 모든 D 참조, 보고서가 직접 인용한 기존 Q/LNK ID의 존재를 확인했다. 이는 내용 정확성 검수가 아니다. 원본 은행과 첨부 파일은 변경하지 않았다. 코드·운영 프롬프트·학습 UI·DB 배포도 없다.

## 초안 사용 시 보완할 설계 사항

1. 보고서 4절의 “각 문항은 해당 가지의 세 근거를 상속한다”는 문구는 최종 중요도 판정 규칙으로 채택하지 않는다. 가지별 표는 공유 맥락이며 각 문항의 실제 시험 관계에 근거가 연결돼야 한다. 같은 가지에 있다는 이유만으로 기출/임상 중요성을 모든 세부로 전이하지 않는다. 문항별 등급/점수는 이번 결과에 확정하지 않았다.
2. D02·08·24·37·47 등은 여러 답 단위를 묶은 설명 과제다. 전체 흐름을 배우는 질문으로는 쓸 수 있지만 현재 단일 자기평가 제품에 그대로 넣어 여러 목표의 성공을 일괄 기록하면 안 된다. 부분 평가 경계 또는 분할은 후속 과제다.
3. 발문 제공/시험 구분은 이번 표에 적혀 있으나, 실제 첫 학습자의 부담과 누설 단서는 아직 학습 실험으로 확인하지 않았다. 제목·지도를 노출하면 정답 단서가 될 수 있다.
4. 49문항 외 보류 잎의 열람은 첫 노출이며 회상 시도·첫 학습 집계와 구별한다. 보고서의 “강의 1차 순회 완료” 제안은 기존 제품의 목표별 첫 학습 완료 조건을 변경하지 않는다. 10문항 완료도 전체 강의 완료가 아니다.
5. † 문항과 마지막 불확실성 표는 확정 답 채점에 사용하지 않는다. 원문과 기존 정정의 차이를 배운다는 것과 의학적 정답 검수를 통과했다는 것은 다르다.

새 구조는 이전 15목표/8경로와 옛 17개념/80문항에 고정되지 않는다. 기존 69문항을 폐기하거나 새 49문항을 추가 게시하라는 결론도 아니다. 이번 결과는 사용자가 전체 학습 경험을 검토할 수 있는 별도 프로토타입이다.
