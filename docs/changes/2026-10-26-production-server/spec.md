# 요구사항

기존 인증·학습·개인 수정·문항·계약 보존. 운영에서 읽기 전용 인증/학습 UI 확인, 쓰기 학습 동작은 격리 DB 검사. 서버 전체 파일별 검사, 웹 타입/빌드, 공통 계약과 개발 루프 검사. 고정 후보 승인 후 서버→웹 배포. health/익명 차단/CORS/화면 및 실제 버전 확인. 스키마·콘텐츠 변경 없음. 운영 학습 데이터에 테스트 채점 금지. 다른 미커밋 작업을 커밋/푸시하지 않는다.

운영 웹은 .env.local이 존재해도 로컬 테스트 인증 분기를 포함하지 않는다. DEV에서만 허용하고 실제 생성 번들로 확인한다.
