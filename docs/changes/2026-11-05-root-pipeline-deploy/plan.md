# 공통 뿌리 파이프라인 운영 배포와 다른 강의 1건 실증 — 구현 계획

## 변경 범위·대상 파일·순서
운영 보존 소스에서 분리 사본 tmp/rp5를 만든다. 공통6종 계약·생성기·이미지·모델 어댑터·root API/계획/화면 및 직접 필요한 보존 수정만 반영한다. 명시적 파일 목록과 baseline hash를 보존한다. 기존 작업트리를 되돌리거나 전체 배포하지 않는다.

리뷰와 고정 후보 준비 뒤 현 사용자 승인을 기록해 웹→서버 순서로 배포한다. 러너의 새 하위 프로세스가 검증한 생성기/계약을 읽는지 확인한다. 운영에서 다른 강의1건만 자동전송 버튼으로 시작하고 실제 회수/검수/게시/질문·답·지도 화면을 확인한다. 결과와 실제 배포ID는 deployment.md에 남긴다.

## 검사 명령과 성공 조건
사본에서 scripts/check_root_pipeline.py contracts/generator/runner/server/web을 실제 실행한다. 서버는 격리 DB, 모델은 합성 어댑터, 브라우저는 로컬 fixture를 사용한다. 운영 기준 재빌드 및 API 후보 manifest를 대조한다. 리뷰 뒤 server/prepare-build.ps1와 release_evidence.py로 고정 후보를 준비한다. 운영 health/auth·배포 바이트·실제 로그인 흐름을 별도로 확인한다.
