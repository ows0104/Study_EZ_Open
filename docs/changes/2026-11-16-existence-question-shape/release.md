나아진 것:
- 발문이 cue 모양이 됐다. 예를 들어 「비브리오 감염의 고위험군은?」→ 간질환 환자, 「P. aeruginosa에 쓰는 대표 항균제 계열은?」→ β-lactam; Fluoroquinolone.
- 「콜레라독소 A 소단위의 구성 성분은?」「콜레라독소의 소단위는?」이 이제 Q020·Q021·Q135 앞에 선다(R6).

새로 나온 결함은 R7로 고쳤다.
- 둘째 add 라운드가 첫 라운드의 존재 문항을 똑같이 다시 썼다. Q244 = Q253은 둘 다 과제가 됐고, Q237 = Q251, Q240 = Q252도 같았다.
  원인은 첫 문항이 원소를 한 층으로 답했는데 목표 component에는 다른 층이 남아 커버가 「빠짐」으로 본 것이다.
- 정규화가 「P. aeruginosa의 독력인자」 하나에 원소 10개(Alginate·Exotoxin A·색소·LasA·LasB·…·ExoS·ExoT)를 합쳤다.
  사용자가 처음 짚은 「조직 손상 효소」 문항이 사라졌다.
- 정규화가 겹침을 피하려고 「비카바페넴 β-lactam」을 component로 지었다.
- 남은 것(별도로 볼 것): 「H. pylori의 병인은? → 정착; 부착; 조직 손상」, 「Vibrio의 감염 양상은? → 장염; 침습성 감염」처럼 범주가 넓은 목표.
  이번 R1·R2 범위가 아니라 지적 5번(두루뭉술)에 가깝다.
