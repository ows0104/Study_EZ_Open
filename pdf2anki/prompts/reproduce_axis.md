# 과제 — 빈칸이 무엇을 묻는지 말한다

아래에는 빈칸 카드의 앞면 텍스트만 있다. 빈칸은 `[1]`·`[2]` 처럼 번호로 표시했다.

**답을 맞히지 마라.** 각 빈칸이 **무엇을 묻고 있는지**만 말한다. 그 자리에 들어갈 것이
어떤 종류의 값인지 — 이름인지 수치인지 기간인지 부위인지 방향인지 — 를 남은 문장만
보고 대는 것이다.

- 남은 문장이 그 자리의 축을 알려 주면 몇 마디로 적는다 (`잎의 너비`, `최적 온도`,
  `제1중간숙주`).
- **어떤 종류의 값인지 좁힐 수 없으면 `told=false`** 로 표시하고, 무엇이 애매한지 적는다.
  「이 생물의 무언가」 정도로밖에 못 좁히면 그것이 `told=false` 다.
- 답을 아는지 여부는 상관없다. 아는 답이 떠올라도 그것을 적지 마라 — 묻는 것은
  **남은 문장이 물음을 세우고 있는가** 하나다.

아래 경로에 이 형태로 쓴다. 다른 말은 덧붙이지 않는다.

```json
{"axes": [
  {"id": "c001", "blanks": [
     {"n": 1, "told": true,  "asks": "잎의 너비"},
     {"n": 2, "told": true,  "asks": "잘 견디는 환경"}]},
  {"id": "c002", "blanks": [
     {"n": 1, "told": false, "asks": "", "why_not": "선충류의 무엇을 묻는지 — 형태·크기·생식·감염경로 중 어느 것도 정해지지 않는다"}]}
]}
```
