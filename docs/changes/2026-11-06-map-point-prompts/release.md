자기 해시 수록을 이후 준비 코드에서 제외하고, 기존4파일만 명시적 로컬 재검증했다. 추가 모델 호출0건이다. state.json/failure.json과 원본 모델 응답·사용량·파일 SHA 영수증은 그대로 보존하고 별도 postcheck.json에 성공 근거를 남겼다. 첫 로컬 재검증의 LF/CRLF 직렬화 비교 오류도 Windows 생성 방식과 맞춰 해결했다. 네 파일의 JSON 형식/고유ID/출처·쪽수/실제 S1 강의 범위와 모델 파일 영수증 SHA가 일치한다.

사용자용 파일과 ZIP은 원본 JSON 바이트를 그대로 복사하고 SHA를 재확인했다. notes의 원본 충돌·범위/자료 한계와 필기 연도/색상 구분을 보존했다. 이는 독립 추출 시범이며 독립 의학 내용 검수·문항 대조·게시·학습 성공을 뜻하지 않는다.

## 포인트 독립 회상 단위 후속 개선

기준 후속 revision 5dc43e1a에서 point-extract.md와 합성 예시를 개선했다. 포인트마다 따로 성공/실패할 수 있는 단서와 답 범위를 기준으로 정의·기전·적용을 분리하되, 목록·같은 축 비교·과정 전체가 하나의 의미 있는 목표이면 유지한다. JSON 필드와 Map은 변경하지 않았다.

별도 원본 대조1회는 실제 과도한 묶음4곳만 지적했다. 심내막염 P001(정의/사진 식별), P011(원인균 목록/최빈균 선택), CNS P002(진단요소 회상/진단 흐름 적용), P030(정상CSF 외관/opening pressure)이다. 선택 제안·자료 한계는 실제 수정 지적과 구별했다.
