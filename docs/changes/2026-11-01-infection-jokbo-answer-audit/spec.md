# 교정 계약

소수점 검사값(0.5%, 36.9℃, 6.0mg/dL 등)은 문항 경계로 삼지 않고 원래 문항에 이어 붙인다. 공백 없는 실제 문항 36.38세, 7.56 세 등은 유지한다.
원본 정답표의 “모두 정답”, “전원정답”은 원문 그대로 연결한다. 동일 연도·번호가 중복되어도 문제와 보기가 완전히 같은 경우에만 같은 원본 정답을 양쪽에 표시한다. 중복 원문은 삭제하지 않는다.
그 외 단원·연도·번호 불일치는 자동 추정하지 않고 실제 목록과 출처를 사용자에게 설명한다. 종전 38개 확인 표시에서 잘못 포함된 항목을 정확히 구분한다.
새 출력 폴더에 수정본을 만들어 직전 정리본 바이트를 보존한다. 변경된 단원만 기존 80개 연결에서 교체한다. 전체 원본 지면·글·이미지·렌더 검증과 게시 후 바이트 및 기존 필기/강의/퀴즈 보존 검사를 수행한다.
