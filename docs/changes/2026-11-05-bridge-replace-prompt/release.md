# Bridge 기본 프롬프트 교체 — Release

## 결과
Bridge 1.3.22는 입력 시작 시 기존 텍스트 충돌로 멈추지 않고, 현재 입력창의 기존 텍스트를 지운 뒤 이번 요청 프롬프트를 넣는다. textarea는 value 교체, contenteditable은 선택·삭제·삽입을 사용한다. 준비 중 입력/첨부 변경은 스냅샷으로 확인하고 중지하며, 출처 불명 첨부의 복구 선택 및 직접/자동전송 구분·전송 1회·전송 후 불확실 상태 판정은 유지한다.

## 검증과 리뷰
- Node 브리지 상태/연결/파일 회귀 92개 통과.
- Python tests/bridge 9개 통과.
- 실제 Chrome의 로컬 모의 화면 21개 통과. ChatGPT/Gemini/Claude의 textarea/contenteditable 기본 교체, 직접전송 유지, 자동전송 1회, 동일 프롬프트 중복 없음, 중간 수정 보존·첨부/취소 경계를 확인했다.
- 첫 Gemini 모의 화면에는 파일 업로드 준비 메시지/메뉴가 없어 테스트 2개가 실패했다. 기존 제품 코드를 바꾸지 않고 모의 업로드 경로를 제공한 뒤 21개를 통과했다. 실패 근거는 state.json에 보존했다.
- 검사 지문이 web/tests를 포함하도록 site 영역으로 설정한 뒤 모든 필수 검사를 같은 최신 지문으로 다시 기록했다.
- 소스 비교: 기존 미커밋 초안 복구 코드를 유지하면서 텍스트 충돌 조건과 명시적 삭제만 변경했다. 미저장 결과·대화·서버 데이터에는 쓰지 않았다.

## 패키지·적용
로컬 ZIP: web/public/studyez-extension.zip, 버전 1.3.22. ZIP의 모든 파일을 현재 bridge 소스와 바이트 대조했고 무결성 검사를 통과했다.
SHA-256: 1abce950196c7e2203ef21841736c9f2210cd713116565f2fe5ad55ff62292d5

현재 사용자 지시의 로컬 구현/패키지 범위다. 운영 웹/스토어 배포·사용자 확장 설치·실제 AI 전송은 실행하지 않았다. 압축해제 확장은 chrome://extensions에서 새로고침하고 AI 탭을 새로고침해야 적용된다. ZIP 설치는 이 새 패키지로 업데이트한다.

## 복원·보존
이 작업의 프롬프트 교체 조건·삭제 호출·버전/안내·테스트 변경만 복원한다. 다른 작업의 미커밋 변경·기존 대화·링크·문항·학습/검수 기록은 유지한다.
