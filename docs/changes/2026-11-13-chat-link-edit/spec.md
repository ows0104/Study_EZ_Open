# 개인 대화 ▾ 「링크 수정」 — 설계

## 요구사항과 수용 기준
- `ChatSplit` 메뉴 끝에 「🔗 링크 수정」(열려 있으면 「링크 접기」). 링크가 있든 없든 ▾가 있으면 선다.
- 편집칸: AI 고르개, 주소 한 칸(지금 값이 채워져 있음), 저장·취소. 설명 문구 없음.
- 저장 → 해당 PUT → 칸 닫힘 → `bumpPreviewVersion()`으로 패널 상세 다시 받기.

## 책임·입출력 계약·오류 상태
- 예습: `PUT my-preview`, 복습: `PUT my-review`, 본문 `{provider, conversationUrl}`. 빈 값 저장은 지우기(서버 기존 동작).
- 주소 꼴이 틀리면 서버 422 문구를 칸 아래에 보인다.

## 호환성과 데이터 보존
- 사용자 본인 행만 바뀐다(토큰 기준). 공통 링크·학습 기록 불변.
