# Bridge 입력 시 기존 프롬프트 기본 교체

사용자 요청: “그니까 Bridge에서 프롬프트를 입력할때 기본적으로 원래있던 프롬프트를 비우고 자기 프롬프트를 넣도록”. 현재 명시적 요청을 이 구체적 동작의 구현 승인으로 적용한다. 이전 초안 보존 정책 중 텍스트 충돌 중지만 이번 요청으로 변경한다.

성공 기준: 기존 텍스트가 있어도 별도 복구 클릭 없이 이번 요청 프롬프트로 교체한다. 입력 준비 중 새로 수정한 텍스트는 덮어쓰지 않는다. 기존 첨부 확인·직접/자동전송 동의·전송 1회·전송 후 불확실 상태 판정은 유지한다. 확장 소스/검사/로컬 ZIP까지 작업하며 외부 AI 실제 전송·사용자 설치·운영 배포는 제외한다.
