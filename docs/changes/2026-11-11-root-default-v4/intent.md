# Main-Quiz 관리자 출제 기본값을 새 구조 2로

## 문제와 사용자 효과
관리자 강의 패널의 「Main Quiz 만들기」는 아무것도 고르지 않으면 첫 구조(map-tree/1)로 요청했다.
지금 쓰는 출제는 「새 구조 2」(map-tree/3, root-generation/4)다. 리케차 261110_03을 이 구조로 출제해 학생에게 공개했다.
그래서 관리자는 요청할 때마다 설정을 펼쳐 새 구조 2를 직접 골라야 했다.
이번 변경 뒤에는 버튼만 누르면 새 구조 2로 요청된다.

## 범위와 성공 기준
- 사용자 요청(2026-11-11): 「관리자 출제 기본값을 새 구조 2로 바꾸자.」
- 새 요청의 기본 선택이 map-tree/3이고, 설정 목록의 맨 위에 「새 구조 2 (기본)」로 표시된다.
- 「기존 Concept map·출제포인트 사용」을 껐을 때도 기본인 새 구조 2로 돌아간다.
- 이전 구조(map-tree/1·map-tree/2·병렬)는 그대로 고를 수 있다.
- 이어 하기(resume)는 원래 요청의 구조를 그대로 쓴다.

## 근거·미정 사항
- 서버(`root_generation.py`)에는 기본 파이프라인이 없다. `pipeline`은 화면이 고른 값을 그대로 받는다. 그래서 웹 화면의 기본 선택만 바꾼다.
- 「새 구조 시범이라 예상 시간은 아직 모릅니다」 안내 문구는 그대로 둔다. 실측 소요 시간이 정리되면 따로 고친다.
