# Main-Quiz 접수: 접두어가 붙은 문항 번호의 오류도 그 문항에 귀속

## 문제와 사용자 효과
포도알균 261104_01(b1fe4257)의 앞 단계 문제은행이 문항 번호를 `ST-Q001`처럼 썼다. 접수 검사는 `Q`로 시작하는 번호의 오류만 문항 오류로 보아,
`ST-Q061: integration의 기초 문항 필요`(그 문항만 빼면 되는 오류)를 「문항에 속하지 않는 오류」로 보고 강의 전체를 두 번 보류했다.

## 범위와 성공 기준
- 사용자 요청(2026-11-12): 「고쳐서 출제」.
- 접두어-Q 형식 번호의 오류가 그 문항의 탈락으로 처리되고, 문항에 속하지 않는 오류(`retrieval_plan: …` 등)는 지금처럼 멈춘다.

## 근거·미정 사항
- `Q`로 시작하는 번호만 가정하는 다른 코드는 `next_question_ids`뿐이다. 접두어 번호가 있으면 새 번호가 Q001부터라 겹치지 않는다.
- 접두어 번호의 문제은행이 생성 단계 끝까지 가는지는 이 강의의 실제 실행이 첫 확인이다.
