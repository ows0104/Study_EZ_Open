# 한 번 누르는 뿌리 학습

사용자: “이것도 그냥 누르면 알아서 작동하게 해줘. 메인 퀴즈처럼.” 기존 배포/실제 1건 시범 요청을 이어, 지도·포인트의 수동 파일 선택과 별도 입력이 기본 실행을 막지 않게 한다. 강의 패널/뿌리 화면에서 자동전송 한 번이면 등록된 올해 필기·족보로 웹 출제→원문 회수→원본 전용 지도·포인트 추출→대조/독립 정답 검수→상한 내 수정→개인 시범 게시까지 이어져야 한다.

기존에 받은 지도·포인트를 직접 쓰는 경로도 고급 옵션으로 보존한다. ChatGPT 직접 UI 접속과 기존 은행/학습 기록 교체는 하지 않는다. 이전 실제 자료 사용 승인과 운영 배포 승인은 이 기능의 같은 서비스·개인 시범 범위에 계속 적용한다.
