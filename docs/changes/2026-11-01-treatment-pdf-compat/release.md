# 진단 및 로컬 호환 사본 검증 완료

확인 대상은 캡처의 감염병의 치료 원칙 필기 1개다. 원본과 현재 서버 파일의 SHA-256이 동일해 업로드 변형 근거는 없다. 원본은 PyMuPDF에서 정상으로 표시됐다. 원본에는 FreeText/Stamp 등 215개 주석이 있으며, FreeText의 저장 외관과 기본 글꼴·색 정의가 다르다. 사용자의 ChatGPT 화면은 저장 외관과 다른 겹친 텍스트를 표시하므로 웹 뷰어 주석 호환 문제로 추정한다. ChatGPT 내부 원인이나 실제 모델 읽기 정확도는 확인하지 않았다.

원본을 덮어쓰지 않고 주석의 저장 외관을 본문으로 고정한 웹 호환 PDF 한 개를 output/pdf에 준비했다. 48쪽 모두 추출 텍스트가 동일하고, 렌더 픽셀 차이 0.0이며, 주석은 215개에서 0개로 고정됐다. 따라서 원문·필기·그림의 보이는 모습이 유지된다. PyMuPDF와 Poppler의 대표 페이지 PNG를 시각 확인했다.

근거: artifact.json, verification.json 및 state.json의 materials 성공 기록. 결과는 로컬 제공용 파일이며 운영 첨부 교체·대화 조작·모델 호출·학습 기록 변경은 하지 않았다. 기존 ChatGPT 첨부를 이 파일로 바꿔 보는 과정은 사용자에게 남아 있으며 실제 웹 미리보기 검증 완료로 표시하지 않는다.
