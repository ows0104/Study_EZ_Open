### 실측: 모델 재선택이 실제로 바꾼 것 (리케차 126문항)

| 결과 | 문항 수 |
|---|---|
| 인용한 쪽과 같음 | 99 |
| 여러 쪽 인용 중 하나로 좁힘 | 4 |
| 인용과 다른 한 쪽으로 바꿈 | 16 |
| 인용한 쪽에 한 쪽을 더함(linked) | 7 |

전체 장수는 인용 131쪽 → 선택 133쪽이다. 장수가 늘어난 것은 아니다. 바뀐 23문항을 실제 필기 지면 텍스트와 하나씩 대조했다(이 세션, 판정은 사람 확인 전).

- **인용이 틀렸거나 모자란 것(선택이 나음) 약 8문항**
  - 한 쪽 어긋남: Q108·Q127(23→22, 87%·9%는 22쪽), Q075(3→2, 절대·통성 비교는 2쪽), Q026(7→6, Sennetsu 행은 6쪽 표)
  - 인용 쪽에 답 일부만 있음: Q080(12쪽은 scrub typhus만), Q085(9쪽에 R. typhi 없음), Q094(DIC는 12쪽)
  - Q097: 인용 39쪽에 추출 텍스트가 없다(그림 쪽일 수 있음, 미확인)
- **둘째 장을 더한 것 7문항**: Q030·Q079·Q088·Q116·Q120·Q122·Q123. 대체로 타당하다.
- **둘 다 맞는데 다른 쪽을 고른 것 약 8문항**: Q017·Q066·Q073·Q081·Q091·Q095·Q119·Q077
  - Q017: 인용 2쪽에도 「혈관내피세포 내로 침입」이 있다.
  - Q077: 인용 5쪽(「대사 유전자를 많이 잃어 숙주세포에 의존」)이 정확하다. 선택한 34쪽은 필기자가 강의 전체를 세 쪽으로 요약한 쪽이다.
  - 선택된 133쪽 중 6쪽이 이런 요약 쪽(34~36쪽)이었다. 인용 쪽 중에는 1쪽뿐이었다.

정리하면 다음과 같다.
- 출제 인용은 약 94%(126문항 중 약 118문항)가 그대로 근거로 쓸 만하다.
- 나머지 약 6%는 한 쪽 어긋남이나 답 일부만 담긴 쪽이었다.
- 모델 재선택은 그 6%를 고치지만, 맞던 인용을 요약 쪽으로 옮기기도 한다.

## 범위와 성공 기준

- **범위**: Main-Quiz 판 게시 뒤 근거 보강(`quizbank/root_evidence.py`·`runner/root_evidence.py`)과 그 입력이 되는 생성기 단계
- **범위 밖**
  - Quiz Bank(웹 출제) 근거 경로 `quizbank/evidence.py`. 이미 `authored`를 쓴다.
  - 서버·웹 근거 표시. `claude/main-quiz-latency`가 작업 중이다.
  - 족보 지면 연결(`jokbo_pages`). 모델을 쓰지 않고 몇 초면 끝난다.
- **성공 기준**
  - 리케차와 같은 강의에서 근거 보강 단계가 몇 분 안에 끝난다. 모델 재선택은 확인이 필요한 문항에만 한다.
  - 학생에게 보이는 근거 쪽 정확도가 지금보다 나빠지지 않는다. 위 「인용이 틀린」 8문항 같은 경우를 그대로 내보내지 않는다.
  - 근거 JSON 계약(`root-evidence/1`, `slideFocus` version 2/3)과 서버·웹은 바뀌지 않는다.
