- 묶음 제목 없이 Q001부터 확정본의 모든 문항 블록과 충돌 기록을 이 대화 본문에 연속 출력한다. 파일 링크로 본문을 대신하지 않는다. 사용자에게 계속 여부를 묻지 않는다. 출력 한도가 가까우면 완성된 문항 경계에서 끝내고 완료 표식을 붙이지 않는다.
- 이어서 출력할 때는 같은 확정본의 다음 미출력 ID부터 쓰며, 이미 완성한 문항을 중복 출력하지 않는다. 미완성 문항은 원래 ID로 전체 블록을 다시 작성한다. 마지막에 필요한 충돌 기록을 모두 출력한다.
- 확정본과 실제 출력의 문항 ID 집합·총수·중복 여부, 문항별 보기 ID·정답 짝·순서·빈칸 수, 충돌 ID 연결을 대조한다. 실제로 출력하지 않은 문항을 출력 완료로 세지 않는다. 전체 문항·보기·정답·충돌 기록이 완성되고 이 대조가 끝난 경우에만 마지막 줄에 STUDYEZ_BANK_COMPLETE를 쓴다.
