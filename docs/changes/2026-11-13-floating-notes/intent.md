# 자유 노트 플로팅·강의명·로컬 사진

## 문제와 사용자 효과
2026-11-13 사용자 요청(원문 요약):
1. 자유 노트는 지금 좌측 메뉴 `/notes`로 가야 한다 → 우측 하단 플로팅 버튼으로 어느 화면에서든 띄우고 싶다.
2. 퀴즈 도중 띄우면 현재 강의명을 자동으로 넣는 버튼이 있으면 좋겠다.
3. 사진을 넣고 싶다. 단 서버 용량 때문에 사진은 서버에 올리지 말고 로컬에만 저장.

## 범위와 성공 기준
- 로그인·승인된 모든 화면(단 `/notes` 자체 제외) 우측 하단에 노트 버튼 → 누르면 화면을 떠나지 않고 노트 창이 뜬다. 닫아도 퀴즈 진행은 그대로.
- 퀴즈 화면에서 연 노트 창에 「강의명」 버튼 → 지금 노트에 현재 강의명이 들어간다.
- 노트에 사진 추가(붙여넣기·끌어놓기·`/` 메뉴). 사진 바이트는 이 브라우저(IndexedDB)에만, 서버에는 사진 id만.

## 근거·미정 사항
- 2026-11-13 사용자 결정: 강의명은 태그가 아니라 **본문**에, 맨 앞이 아니라 **누른 순간의 커서 위치**에 넣는다.
- 로컬 저장의 한계(다른 기기·브라우저에서는 사진이 안 보임, 사이트 데이터 삭제 시 사라짐)는 사용자 요구의 결과로 수용.
