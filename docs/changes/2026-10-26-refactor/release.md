# 배포 준비 상태

현재 범위는 로컬 소스 반영과 검사다. 운영 배포는 승인되지 않았다.

## 리뷰와 검증
검증 상세는 test-results.md 및 state.json에 기록한다.
공유 검증 본문과 프롬프트 21파일은 이동 전후 SHA-256이 동일하다.
기존 서버 import는 동일 모듈의 별칭으로 유지하고 출제기는 독립 계약을 import한다.
서버 test_bank_coverage의 기준점 실패가 남아 있으며 별도 작업으로 조사한다.

## 다음 배포 조건
기존 상태 보존 검사 실패를 해결하거나 원인과 허용 범위를 사람에게 명시하고 판단받아야 한다.
서버 requirements를 갱신하고 prepare-build로 패키징한다. 웹은 새 prompt 준비 단계와 함께 빌드한다.
검사 결과와 리뷰가 현재 소스와 맞고, 정확한 운영 revision·영향·되돌리기가 확정된 후 배포 승인받는다.

## 복원
이번 변경의 원본 파일 백업·SHA-256 manifest를 사용하되 이후 변경을 먼저 비교한다.
운영은 변경하지 않았으므로 운영 롤백은 필요 없다. 다른 작업의 기존 수정은 유지한다.
