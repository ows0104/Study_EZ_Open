# 과제 — 빈칸 카드를 판정한다

아래는 여러 덱에서 모은 빈칸 카드다. **어느 덱에서 왔는지는 가려 두었다.** 앞면과
정답을 보고 카드마다 판정한다. 카드를 고치지 말고 판정만 한다.

판정 기준은 둘이다.

**① 회수할 값어치가 있는 것을 비웠는가.** 빈칸을 맞히는 일이 곧 그 지식을 아는 일이어야
한다. 조사·곁말을 뚫었거나, 단계 이름·번호·기호 같은 **표지만** 가려서 맞혀도 아는 것이
없으면 어긋난 것이다.

**② 무엇을 묻는지 남는 문장이 말하는가.** 빈칸이 여럿이면 각 자리의 축이 서 있어야 한다.
「[ ]가 [ ]이며 [ ]다」처럼 구별이 안 되면 어긋난 것이다.

그리고 **반대로 남는 문장이 답을 알려주어도 안 된다.** 반대말을 대 놓고 그 반대를 묻는
것(「[ ]가 어른보다 많다」→ 어린이)이 흔한 실패다 — 축을 세운 것처럼 보이지만 답을 준
것이다. 이것도 ②의 어긋남으로 본다.

각 카드에 `ok` / `weak` / `bad` 하나를 준다.

    ok     둘 다 지켰다
    weak   지키긴 했으나 어느 한쪽이 아슬아슬하다
    bad    하나라도 분명히 어긋났다

`weak` 와 `bad` 에는 **어느 기준이 왜 어긋났는지** 한 줄로 적는다. 자료를 찾아보지 말고
카드에 적힌 것만으로 판정한다 — 의학적 사실의 옳고 그름은 여기서 묻지 않는다.

아래 경로에 이 형태로 쓴다. 다른 말은 덧붙이지 않는다.

```json
{"judgements": [
  {"id": "j001", "verdict": "ok"},
  {"id": "j002", "verdict": "bad",
   "why": "② 세 빈칸이 각각 무엇을 묻는지 문장이 정하지 않는다"}
]}
```
