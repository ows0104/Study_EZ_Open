# root-generation/3: 판정 값이 강의를 멈추지 않게

## 문제와 사용자 효과

사용자 2026-11-10: 「지금 현재 파이프라인은 계속 어딘가 막혀. 막힐 때마다 고치는데 이게 임시방편 같아. 다른 강의에 일반화가 제대로 될지도 의문이야. 근본적인 구조를 네가 뜯어보고 진단한 후, 일반적으로 작동하도록 하는 게 목표야. 네 주관대로 해줘.」

감염병의 병인론(261102_02)은 root-generation/3으로 일곱 번 멈췄고, 그때마다 하나씩 고쳤다(PR #71–#78). 일곱 번째는 임상 정리(`context-0`)가 「오염」으로 판정해 멈춘 것이다.

## 진단 (실행 기록과 코드를 읽고 센 것)

**잘 도는 부분.** 모델이 단계 안에서 `check_result.py`를 스스로 돌려 고치는 구조는 문제가 없다. 이 실행의 모델 단계 38개에서 수신 검사가 첫 출력을 돌려보낸 일은 0건이다.

**멈춘 곳은 전부 그 바깥이다.** 세 종류다.

1. **판정 값 하나가 강의 전체를 멈춘다.**
   - 임상 정리는 모델 호출 한 번이 낸 값 하나다. 「일치」가 아니면 의학 검토 전에 멈추고, /2 조립은 모든 목표를 막는다.
   - 이 강의에서 충돌 기록은 CF01–CF03 셋이고, 인용한 문항은 134개 중 3개(Q009·Q044·Q046)다. 세 기록의 글 때문에 134문항이 멈췄다.
   - 같은 세 기록을 첫 판정은 「출처상 충돌과 현재 채택 관계는 확인된다」고 했고, 두 번째 판정은 「저작자의 정답 선택이 섞였다(오염)」고 했다.
     - 저작 지시(add.md·fix.md)는 facts에 「원본의 충돌 주장과 현재 답의 관계」를 쓰라고 한다.
     - 판정 지시(context-v2.md)는 「저작 이력」을 오염으로 본다. 「현재 정답은 A로 채택했다」가 어느 쪽인지 정해져 있지 않다.
   - 완료된 단계의 값이 멈춤 사유라서, 이어 하기는 같은 값을 다시 읽고 같은 자리에서 멈춘다. 코드를 바꾸지 않으면 나갈 길이 없다.
   - 같은 종류가 더 있다.
     - 의학 검토 입력 `medical_input`은 문항 하나의 글에 「검토 판정」 같은 표현이 있으면 입력 전체를 거절한다. 마지막 단계에서 강의가 멈춘다.
     - 의학 검토 한 묶음이 문항 하나의 판정을 빠뜨리면 단계 전체가 실패한다. 의학 검토는 /3에서 과제를 빼지 않는 해설인데도 그렇다.
2. **조립 검사가 모든 모델 호출 뒤에 돈다.**
   - 조립(`assessment_raw` → /2 `compile_assessment` → `make_document`)과 결과 검증은 의학 검토까지 끝난 뒤에 돈다. 네 번째 멈춤(과제 0개)은 서버가 거절해서야 알았다.
   - 과제가 왜 적은지도 결과에 없다. `notReady`는 이유가 두 가지뿐인데 조립이 목표를 막는 조건은 여덟 가지다.
3. **검사가 실제 경로와 실제 판정을 지나지 않는다.**
   - 가짜 모델은 형식만 맞추고 판정은 늘 통과다. 판정이 바뀌는 경우를 시험하지 않는다.
   - 모델이 쓴 파일의 글자가 깨져도 받았다. 원인은 모델이 PowerShell here-string을 `python -`에 파이프로 넘긴 것이다. PowerShell 5.1은 파이프를 ASCII로 보내서 한글이 전부 `?`가 됐다(Codex 세션 기록 `rollout-2026-11-10T20-53-02-…`).

## 범위와 성공 기준

- root-generation/3의 생성기·계약·러너 수신 검사·프롬프트 한 개(새 `v3/context.md`)를 고친다. /2의 계약·프롬프트·실행 기록은 바꾸지 않는다(`medical_input`의 정규식에 이름만 붙인다).
- 성공 기준
  1. 판정 값의 어떤 조합에서도 강의가 결과까지 가거나, 이름 붙은 두 가지 이유로만 멈춘다: 과제가 하나도 없다, 한 단계가 두 번 연속 아무것도 판정하지 않았다. 검사가 임의 조합으로 확인한다.
  2. 임상 정리 판정은 그 충돌 기록과 그것을 인용한 문항에만 미친다.
  3. 조립은 의학 검토 전에 돈다. 목표마다 과제가 안 된 이유가 결과에 있다.
  4. 261102_02 실제 기록의 사본이 러너 `_generate`부터 업로드 직전까지 간다.

## 근거·미정 사항

- 이 구조를 끝까지 돈 실제 강의는 아직 261102_02 하나다. 일반화는 임의 판정 검사와 이 강의의 재생으로 확인한 범위까지다. 다른 강의에서 새 종류의 멈춤이 나오면 위 세 종류 중 어디에 드는지부터 본다.
- 임상 정리에서 「일치」가 아닌 충돌을 인용한 문항을 과제에 남길지는 사용자가 뒤집을 수 있는 결정이다(spec 「결정」).
