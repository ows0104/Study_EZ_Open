# 웹 문제은행 순수 JSON 전달과 프롬프트 간소화 — 배포 준비

## 코드 리뷰·검증 결과
후속 보완(사용자 승인): 프롬프트 1.81에서 기초 연결 회상·목표 묶기/분리·Cloze 단서의 구체 예시 3개를 복원했다. 자료/철학/기준/작업·검수/JSON/전달의 6단계 제목과 JSON 하위 객체 계층을 구분했다. 공통 품질 추출은 철학·예시·기준만 가져오고 구형 템플릿도 계속 지원한다. 최신 보완의 검사 지문·로그는 state.json의 각 체크 마지막 기록에 있다. JSON 데이터 계약은 그대로다.

공용 계약/생산자/소비자의 동일 구현 지문 63ca04bd9c6e0846be05016b9b8c514e6dedc2a58b210acfc757c2c2fade57df에 대해 필수 검사 5종을 development.py verify로 기록했다. contracts 158개, quizbank 및 은행 러너 505개, bridge Node 115개, 웹 프롬프트·전달 12개와 타입 포함 프로덕션 빌드, 서버 격리 검사 5개 모듈이 통과했다.

리뷰: JSON 중복 키/잘린 파일/필드·타입·정답 참조·cloze·근거·충돌·요청 판·generation ID·실제 UTF-8 해시 거절을 대조했다. 새 JSON의 잘못된 입력은 모델 변환으로 우회하지 않는다. 은행/학습 기록을 바꾸지 않는 수신·재전달과 기존 MD 호환을 확인했다. 뿌리 생성은 결정적 원문의 문항을 보존하고 학습 구조/원본 그림/임상 충돌 분리 후 기존 검수를 유지한다. 실제 의학 문항 재출제·운영 게시나 실제 ChatGPT 다운로드 UI 실험은 수행하지 않았다.

초기 넓은 검사에는 임시 경로 권한/Windows 경로 길이/작업 공간의 런타임 부재/별도 브라우저 시험 환경 부재가 있었다. 해당 실패 로그를 보존했다. 최종 필수 범위는 짧은 격리 임시 경로, 서버 고유 런타임, 정해진 웹 단위 검사와 빌드로 재검증했다. 전 저장소·실제 브라우저 전체 검사가 통과했다고 주장하지 않는다.

## 배포 대상 버전·순서·데이터 변경
검토 브랜치 codex/bank-json-delivery. 프롬프트 1.80, authored JSON schema_version=2, 브리지 1.3.23. 앱 BANK는 기존 3.2로 유지한다. DB migration 및 기존 은행·파일·학습 기록 변경은 없다. 현재 운영 배포는 하지 않았다.

향후 운영 반영 시 JSON·MD 호환 API와 로컬 러너를 먼저 준비하고, 브리지 1.3.23과 새 웹 프롬프트를 함께 제공한다. 새 웹은 구형 브리지로 JSON 요청을 보내지 않는다. master 병합은 자동 배포를 유발하므로 현재 로컬 구현 승인에 포함하지 않는다.

## 배포 후 확인·롤백·필요한 사람 승인
운영 반영 전 API/러너/브리지/웹의 구체적 배포 범위를 승인받는다. 실제 웹 파일 다운로드→저장→검수 대기, 수동 JSON 선택, 기존 MD 재전달 및 학습 기록 보존을 사후 확인한다. 복원은 코드 revert이며 보존된 원문/학습 상태를 삭제하거나 재출제로 덮어쓰지 않는다.
