# Main-Quiz 개념 지도 바로 열기·화면 끝까지 쓰기

## 문제와 사용자 효과
#52 배포 뒤 사용자(2026-11-09):
1. 「개념지도를 누르면 문제화면을 안 거치고 바로 개념지도로 가게 해줘.」
2. 「화면 최대한 끝까지 써줘. 지금은 좌우, 위아래에 빈칸이 남아있어.」

원인
- 시작 화면의 「개념 지도」는 세션을 연 뒤 문제 화면을 그리고, 그다음 지도 요청을 보냈다. 그래서 문제 화면이 잠깐 지나갔다.
- 사이트에서 Main-Quiz는 좌측 메뉴 안에 선다(`.app-shell:not(.is-bare)`).
  - 이 틀의 본문 여백(28px 36px 40px)이 지도에도 그대로 남았다.
  - `.main-quiz-learning:not(.is-start)`의 1100px 폭 제한도 지도에 걸렸다.
  - #52의 「좌우 8px」 규칙은 이 규칙보다 우선순위가 낮아 사이트에서는 효과가 없었다.
  - 회귀 검사 페이지에는 앱 틀이 없어서 이 문제를 잡지 못했다.

## 범위와 성공 기준
- 시작 화면이나 문제 화면에서 「개념 지도」를 누르면 곧바로 지도 탭이 된다.
  - 지도가 오기 전에는 「개념 지도를 불러오는 중…」만 보인다. 문제 화면은 그리지 않는다.
  - 실패하면 이전 화면으로 돌아가고 오류를 보인다.
- 지도가 좌측 메뉴 오른쪽의 본문 칸 전체를 쓴다. 왼쪽(메뉴 경계)·오른쪽·위·아래 여백은 0이고, 틀 테두리와 둥근 모서리도 없다.
- 「← 문제로 돌아가기」 줄을 지도 위에서 없애고, 지도 도구 줄의 「← 문제」 버튼으로 옮긴다.
- 「크게 보기」는 창 전체(좌측 메뉴 포함)를 덮는다.
- 좌측 메뉴는 그대로 둔다. 접기 버튼은 기존 것을 쓴다.
- 서버·데이터·학습 기록 처리는 바꾸지 않는다. 지도 열람 이벤트(`kind:'map'`)도 지금처럼 보낸다.
