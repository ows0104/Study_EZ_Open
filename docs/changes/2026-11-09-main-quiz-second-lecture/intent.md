## 문제와 사용자 효과
Main-Quiz 생성은 감염병리1(261104_02) 한 편만 성공했다. 그 한 번에도 실행이 다섯 번 멈췄고, 매번 코드를 고치거나 복구 도구를 새로 만들었다.
고친 것들이 다른 강의에서도 통하는지는 아무도 모른다. 사용자 2026-11-09 「두 번째 강의 시범」 → 「사슬알균」.
같은 스크립트를 다른 강의에 돌려 새 실패 모드를 모은다. 러너 경로로 일반화하는 일은 그 결과를 본 뒤에 한다.

## 범위와 성공 기준
- 대상: 감염과 면역 261105_01 「사슬알균」(김범준).
  - S1 올해 필기: 배수성 v1, 38쪽.
  - S2 족보: `2026-S9-족보-김범준.pdf`, 8쪽. 같은 교수 기출 4문항(2021–2023)과 2025년 다른 교수 참고 2문항.
- 실행: `run.py`(감염병리1 importance-basis 스크립트 사본). Map /3 → 포인트 /3 → 대조 → 보완 ≤1 → 재대조 → packet → root-generation/2(보완 ≤3) → 조립.
- 성공: `result.json`이 `validate_result`를 통과한다.
- 실패해도 결과다. 멈춘 단계·원인·필요했던 수정을 기록하는 것이 이 작업의 산출물이다.
- 범위 밖: 운영 반입·학생 공개. 각각 별도로 승인받는다.

- 승인(2026-11-09 사용자 「승인」): S1·S2를 OpenAI Codex CLI(gpt-6.1-sol)로 보낸다. 호출 범위는 Map 1 · 포인트 1 · 대조 1 · 보완 ≤1 · 재대조 1, 생성·대조·검수 보완 ≤3, 필요하면 중요도 보완 1이다.
