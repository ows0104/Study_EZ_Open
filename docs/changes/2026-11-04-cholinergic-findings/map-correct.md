원본만 보는 독립 지도 교정이다. material의 원본 PDF 텍스트/35개 PNG와 족보 전체를 확인한다. 기존 brief도 원본 독립 추출이며 비교 대상으로만 제공된다. 문항/BANK/웹 응답/문항 검수 결과는 제공되지 않는다. 원본에서 먼저 실제 포함·제외 범위와 회상 사실을 확인한 뒤 지도를 교정한다.

기존 지도는 너무 넓은 관계 하나가 서로 다른 세부 회상 사실을 대신하거나, 방향 cue/answer_scope와 relation_ids가 서로 다른 지식을 가리킬 수 있다. 전체 원본에서 명칭·분류·구조 특징·인과·임상 용도·독성·비교를 빠짐없이 점검하고 실제 필요한 관계/방향만 표현한다. 단지 나열된 모든 세부를 필수로 승격하지 않는다. target의 모든 방향이 연결된 각 point에 공동 집계되므로 서로 무관한 포인트를 넓은 target 하나로 묶지 않는다. 실제 한 번에 회상할 수 있는 독립 목표로 설계하되 과분할하지 않는다.

원본의 의학적으로 의심스러운 분류/기전/용도/시간표를 안전한 임상 사실로 확정하지 않는다. 원본이 말한 내용과 올바른 기초 기전·적용 한계·자료 충돌을 relation.condition/reason 및 scope.limitations에 구별한다. 원본 출처는 원본이 무엇을 제시했는지를 뒷받침하며 외부 검증을 읽었다고 주장하지 않는다. 정확한 개요 수치를 약물마다 일반화하는 등 원본이 확정하지 않은 요구는 제거/재정의한 근거를 남긴다. 자료 부족한 세부 용량/중추효과를 임의로 채우지 않는다. 원본 그림 식별을 요구하는지 텍스트 구조특징 이해를 요구하는지 실제 강의/기출에서 판단하고 시각 목표는 별도로 명시한다.

같은 의미의 concept/relation/target/direction ID는 보존한다. 의미가 바뀌면 이유를 명시하고 새 ID를 쓰거나 정의 변경을 provenance.notes에 기록한다. 기존 point_id와 원문 text·제외 상태 및 exclusions를 보존하고 target_ids/근거/이유는 실제 교정에 맞게 수정한다. 과거 포함 목표를 조용히 지워 준비율을 높이지 않는다. 필수/확장/미정 판단은 원본 근거로만 한다. 교수 색상 지시를 해당 지면 밖으로 확대하지 않는다.

learning-brief/1 완전본만 반환한다. sources/lecture_id는 입력 재고와 일치해야 한다. provenance.independent_points=confirmed는 BANK를 보지 않은 독립 실행의 의미이며 의학적 정확성 확정이 아니다. 원본 전체 확인과 변경 이유·남은 한계를 정직하게 기록한다.
