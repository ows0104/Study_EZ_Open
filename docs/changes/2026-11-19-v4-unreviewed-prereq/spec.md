# Main-Quiz /4 조립: 검토가 확인하지 않은 선행 연결을 투영에서 뺀다 — 설계

## 요구사항과 수용 기준
- R1 `generation_v4._compile`: 관계 review_status를 투영한 직후, `projected['prerequisites']`를 `relation_checks[relation_id].status == 'supported'`인 것만 남긴다.
- R2 지지된 선행 연결은 결과 문서의 `prerequisites`에 지금처럼 남는다.
  - 문서 쪽 선행 연결은 `assemble`이 원래 brief에서 검토된 관계만 골라 만든다. 이것은 바뀌지 않는다.
- R3 지금 통과하는 /4 결과는 바뀌지 않는다.
  - 검토되지 않은 선행 연결이 있는 결과는 지금은 모두 이 오류로 멈춘다. 그래서 그런 결과가 게시돼 있을 수 없다.

## 책임·입출력 계약·오류 상태
- 계약 모듈 한 줄이다. 서버도 같은 모듈로 결과를 검사하므로 병합(자동 배포) 뒤 러너를 새로 설치한다.
