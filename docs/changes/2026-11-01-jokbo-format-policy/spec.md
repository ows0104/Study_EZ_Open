# Spec

공통 정책 docs/policies/jokbo-attachments.md를 만들고 루트 CLAUDE.md·runner/CLAUDE.md·docs/map.md와 기존 과목 정책에서 연결한다.

기본 첨부는 검증된 PDF다. JSON은 기준/관리 자료로 보존하고 그림·표·원문·정답·확인 상태를 유지한다. 전체 교수 목록/별도 표지를 제외하고 단원, 연도·교수·번호, 우선/참고, 원본 쪽, 정답 상태를 간결하게 표시한다. 같은 교수 기출을 먼저 두고 구분별 최신 연도부터 배열한다. 공동 교수와 미상은 명시한다.

복습은 실제 올해 필기 파일명으로 재확인하고 예습은 기존 올해 대상 판정을 유지한다. 실제 필기 없으면 시간표 기준을 명시한다. 기존 자료/학습 기록과 이전 PDF를 보존하고 첨부 전 원본 영역 및 실제 PDF 렌더를 검증한다. 문서만 변경하며 기존 코드의 자동 PDF 변환 구현이나 웹 배포 완료로 표시하지 않는다.
