## 배포 대상 버전·순서·데이터 변경
운영 배포는 실행하지 않았다. 새 표 `root_generation`과 RLS가 필요하며 기존 root_content/control/session/event 표도 준비되어 있어야 한다. 기존 표 칼럼 변경·기존 은행 교체는 없다.

실제 배포는 이 로컬 검사 상태의 고정 후보를 별도로 준비하고 구체적인 사용자 운영 승인 후 진행한다. 현재 작업 폴더에는 다른 작업의 미커밋 변경이 있으므로 전체 변경을 묶어 커밋/배포하지 않는다. 서버/공유 계약과 DB 준비 → 새 러너 배포 → 웹 배포 순서를 검토한다. 서버 초기화는 이번 변경의 새 표 생성과 RLS만 대상으로 하고 운영 DB를 테스트에 사용하지 않는다. 실제 모델 연결 확인에 사용할 강의·입력·시범 대상도 별도로 특정해야 한다.

`STUDYEZ_ROOT_LEARNING_ENABLED` 기존 기본 false를 유지한다. 생성 결과 저장과 실제 학습 접근은 별개로 표시된다. 공개가 허용된 환경에서만 전체 설정을 켜고, 처음에는 요청 관리자 개인 시범으로 확인한다. 새 학습은 이미 선택된 적응형 복습·한국시간 04:00 경계를 사용한다.

## 배포 후 확인·롤백·필요한 사람 승인
운영 이후에는 기존 은행/학습 기록 읽기, 관리자 요청·러너 claim·단계 표시·새 판/원본 지문, 허용/비허용 계정의 접근, 답 전 비노출과 답 후 검수/원본, 포인트 충족 표시, 요청/완료 이용현황을 확인한다. 실제 자료·모델 실행은 이번 합성 검사와 구분한다.

문제가 생기면 새 자동출제 요청을 중지하고 해당 RootControl을 비활성화하거나 이전 검토 판으로 되돌린다. 필요하면 이전 앱·러너 revision으로 복원한다. 기존 QuizBank와 학습 기록은 이번 경로가 교체하지 않으며, 새 콘텐츠/이전 콘텐츠/생성 입력·원본 사본/ledger·검수·실패 기록/사용자 사건도 삭제하지 않는다. 이전 판 복원 시 그 판의 학습 사건을 유지하며 새 판 성취를 임의로 승계하지 않는다.

중요 사람 승인 대상: 운영 DB 표/RLS 준비·실제 배포 후보·전체 기능 설정/학생 공개 대상·실제 강의 모델 전송. 현재 사용자 승인은 이 기능의 로컬 구현·합성 검증·Build 범위에 적용했다.
