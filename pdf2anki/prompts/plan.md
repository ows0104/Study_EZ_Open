# 과제 ① — 학습 목표를 세운다

카드는 아직 만들지 않는다. 제공된 자료와 선택된 목적 프로필을 바탕으로 회수할 학습
목표만 세운다.

## 목표 선택

후보를 다음 기준으로 평가한다.

- 개념적 중심성: 단원의 뼈대인가
- 구분력: 혼동하기 쉬운 대상을 가르는가
- 비자명성: 질문할 학습 가치가 있는가
- 전이 가능성: 새로운 문제·사례·그림에 적용되는가
- 자료상 중요도: 반복·요약·강조·평가 자료가 뒷받침하는가

목표는 `식별한다`, `구분한다`, `설명한다`, `적용한다`, `재구성한다`처럼 실제로
검증할 수 있는 동사로 쓴다. `이해한다`, `안다`, `숙지한다`만으로 끝내지 않는다.

각 목표의 `retrieval_targets`에는 실제로 회수할 핵심을 적고, 근거가 된 슬라이드를
`slides`에 단다. 목표는 강의 진행 순서로 정렬한다.

## 선택적 과거 평가 자료

과거 평가 어댑터가 제공된 경우에만 `jokbo_objectives`를 사용한다. 반복 문항은 연도별로
복제하지 않고 같은 지식과 회수 방향을 합친다. 강의 자료 목표와 같은 주제를 다뤄도 되지만,
동일한 방향의 중복 목표는 만들지 않는다.

## 제외 기록

검토했지만 목표로 삼지 않은 후보는 `rejected_candidates`에 남긴다. 표지·목차·장식,
중복, 범위 밖, 근거 부족, 저가치 후보를 기록해 누락과 의도적 제외를 구분한다.
