# 이용현황 자료 첨부 칸 정리와 빠진 행동 기록

## 문제와 사용자 효과
사용자 원문(2026-11-18): 「지금 관리 기록에 예습 자동 첨부 요청 52강의 복습 자동 첨부 요청 24강의 같은게 미상으로
되어있어. 이거 뭔지 제대로 정리해서 기록해주고, 다른 기록할만한 행동 새는 거 없는지 확인해줘.」

관리 → 이용현황 표의 마지막 칸 머리가 「파일 요청·미상」이었다. 그 칸 안의 「예습 자동 첨부 요청 52강의」·
「복습 자동 첨부 요청 24강의」는 목적이 정해진 기록인데 칸 이름 때문에 전부 미상으로 읽혔다.

이 둘의 실제 뜻(코드로 확인):
- **예습 자동 첨부 요청** = 강의 패널 예습 칸에서 「공통 대화 만들기」(관리자) 또는 「개인 대화 만들기」를 눌러,
  화면이 작년 필기·족보의 서명 링크를 받아 크롬 확장에 넘긴 기록이다(`PreviewAction.start`, `purpose=preview_attach`).
  N강의 = 기간 안에 그렇게 한 강의 수. 확장이 실제로 첨부·전송했는지는 모른다.
- **복습 자동 첨부 요청** = 복습 칸 「개인 대화 만들기」로 올해 필기·족보를 넘긴 기록이다(`ReviewAction.start`, `purpose=review_attach`).
- 진짜 「목적 미상」은 2026-11-02 목적 구분(`file_requests.FilePurpose`) 전에 쌓인 요청뿐이다.

점검에서 같이 드러난 것: 공통 예습 대화 만들기(관리자)·복습 대화 만들기·복습 링크 열기는 **기록 자체가 없어** 파일 요청으로만
간접적으로 보였고, 개인 복습 링크 저장(`user_review`)과 Main-Quiz 보류·제외·내 문제·뒷면 메모·개념 지도 열기(`root_event`)는
DB에 쌓이는데 이용현황에 안 나왔다.

## 범위와 성공 기준
- 칸·행동 이름이 무엇을 눌렀는지로 읽힌다. 「미상」은 2026-11-02 전 요청 한 줄에만 남는다.
- 새로 센다(2026-11-18부터): 공통 예습 대화 만들기 시도(관리자), 개인 복습 대화 만들기 시도, 개인 복습 링크 열기.
- 이미 있던 기록을 표에 올린다(과거분 포함): 개인 복습 링크 저장, Main-Quiz 문제 보류·문항 제외·내 문제 저장·삭제·뒷면 메모·개념 지도 열기.
- 기존 기록·숫자는 바꾸지 않는다. DB 스키마 변경 없음.

## 근거·미정 사항
아직 안 세는 것(점검 결과, 사용자 결정 대기): 족보 회독 시작(`jokbo_round`), 플로팅 노트(`user_note`),
Quiz Bank 내 문제·중요도·보류(은행 상태 JSON 안), 예습/복습 프롬프트 수정(예습만 상세에 문구로 보임), 숨긴 강의 설정,
사이트 피드백(관리 피드백 탭에 따로 있음), Main-Quiz 과목 중요도·선택 과목 설정(focus/optional), 풀이 중 지도 펼침(map).
