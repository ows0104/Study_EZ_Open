# 감염과 면역 2026 족보 배포·관리 형식

앞으로의 공통 기본 형식은 [족보 정리·첨부 정책](jokbo-attachments.md)을 따른다. 아래 과목별 보존 자료와 검증 기록도 유지한다.

2026-11-01 사용자 명시 지시: “ㅇㅋ 그럼 감염과 면역 족보는 사이트에 PDF로 올려두고, JSON이랑 그림은 관리용으로 보관해줘.”

- 사이트의 강의별 족보 첨부는 검증된 PDF 정리본을 사용한다. 현재 기준은 `docs/changes/2026-11-01-jokbo-professor-priority/upload-plan.json`의 80개 수업 / 69개 단원, 교수 구성별 74개 PDF다. 직전 answer-audit PDF와 연결·해시는 새 작업의 remote-before.json에 보존한다.
- 문항 JSON과 연결 그림은 관리용으로 보존한다. 기준 자료는 `output/materials/감염과 면역_2026_JSON/`의 catalog.json, questions.json, sections/, images/, source/ 및 관련 보존 자료다. 전체 ZIP도 같은 상위 폴더에 보존한다.
- 관리용 JSON·PNG·MD·ZIP으로 사이트의 PDF 족보 첨부를 교체하지 않는다. GPT 첨부용 MD·그림 묶음은 필요할 때 쓰는 파생 자료로 보존한다.
- 원본 PDF·원본 이미지·문항 ID·출처 및 정답 연결 확인 19개 상태를 보존한다. 내용 변경 시 관리 자료와 게시 PDF의 대응을 검증한다.
- 생성 자료를 갱신할 때 이전 버전을 보존하고 새 버전으로 기록한다. 기존 필기·퀴즈·개인 학습 기록은 유지한다.

관리 자료 제작·검증 근거: `docs/changes/2026-11-01-infection-jokbo-json/`.

## 2026-11-01 후속 표시·교수 우선순위 지시

사용자 요청: 뒤쪽 전체 교수 목록 페이지는 빼고, JSON의 각 연도 담당을 해당 연도 옆에 표시한다. 올해 같은 교수의 기출을 먼저 두고 주요 정보만 보이도록 정리하여 첨부한다.

- PDF는 별도 표지·전체 교수표 없이 단원, 연도·교수·번호, 같은 교수 우선/참고, 원본 쪽과 정답/연결 확인 상태를 간결하게 표시한다. 원문·그림·공용 자료·정답표를 보존한다.
- 같은 교수와 겹치는 연도를 먼저, 다른/미상 교수의 연도를 뒤에 두며 각 구분 내 최신 연도부터 배열한다. 공동 담당은 전체 이름을 표시하고 특정 문항의 단독 출제자를 추정하지 않는다.
- 복습 출제는 실제 올해 필기의 파일명을 한 번 더 확인한다. 시간표·족보 올해 열과 다르면 실제 필기 교수를 우선하며, 미확인 교수는 추정하지 않는다. 첨부 PDF가 시간표 기준이면 실제 필기 교수로 출제 우선순위를 다시 판단한다. 다른 교수의 기출도 참고로 보존한다.
- 예습의 기존 교수 판정은 유지한다. 현재 이 과목의 올해 필기는 0개이므로 이번 PDF 정렬은 시간표 기준임을 하단과 자료 목록에 명시한다.

검증·게시 결과: `docs/changes/2026-11-01-jokbo-professor-priority/`. 관리 JSON과 원본·이전 PDF는 변경하지 않았다.
