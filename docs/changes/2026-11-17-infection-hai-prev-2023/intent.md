# 의료관련감염(261118_01, 김의석) 예습 필기를 2023 김의석 판으로

## 문제

사용자 2026-11-17: 「내일 있는 의료관련감염 수업 교수 김의석에서 지금 작년 교수와 달라서 23년도 교수로 예습을 해야하는데 잘못됐어. 고쳐줘.」

- 올해 시간표 제목은 「의료관련감염」, 과거 필기 제목은 「병원감염」이다.
  - 2025: `[251120_06]병원감염(문송미)_이용욱v2.pdf`
  - 2023: `[231116_06] 병원감염(김의석)_김지훈v1.pdf`
- 제목이 달라 점수기가 작년 짝을 못 찾았고, 작년 짝이 없으니 같은 교수 검색의 기준(anchor)도 올해 제목뿐이라 2023 판도 못 찾았다.
- 결과: 예습 필기 없음, 「교수/과거 자료 확인 필요」. 러너 로그 「작년 짝을 못 찾았다」.

## 고침

`runs/_pairs/감염과 면역.json`에 사람이 확인한 짝 `"261118_01": "251120_06"` 한 줄.
작년 짝이 「병원감염」으로 정해지면 기존 교수 기준 선택(최근 5년 동일 교수 최신)이 2023 김의석 판을 고른다.
코드·프롬프트·DB 스키마 변경 없음.

## 확인

master 코드로 `publish.plan_subject`를 읽기 전용 재현(라이브 runs 짝 파일):

- 고치기 전: `261118_01 → 없음 · 교수/과거 자료 확인 필요`
- 고친 뒤: `261118_01 → 2023 [231116_06] 병원감염(김의석)_김지훈v1.pdf · 동일 교수의 최신 보유 필기` (교수 변경: 문송미 → 김의석)
- 11-18·11-19 다른 강의 선택은 그대로.

러너 라이브 짝 파일(메인 체크아웃 runs/, 번호 변경 작업의 미커밋 줄 포함)에도 같은 한 줄만 더했다.
