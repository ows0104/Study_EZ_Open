# Maintain

연결/오류 안내 코드와 메타데이터 복구는 적용했다. 49개 집중 검사와 557개 전체 검사, release gate가 통과했다. 기존 예습 9건은 유지하고 기술적 연결 실패 7건만 새 작업으로 재등록했다. 이후 실행은 기존 러너 및 상태 창에서 관측한다. 새 자동화/러너를 만들지 않았다.

미확인 전용 작년 자료 10칸은 여전히 보류한다. 현재 2건 실행/5건 대기이며 덱 생성·검수·게시 완료로 표시하지 않는다. 새 문제가 생기면 실제 단계·로그·기존 검수 횟수를 근거로 구분하고 이력이나 상한을 초기화하지 않는다.
