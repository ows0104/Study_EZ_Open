# Main-Quiz 운영자 제공 normalize 가져오기(operator-stage-result/1)와 261109_02 이어 하기

## 문제와 사용자 효과
- 감염과 면역 261109_02(레지오넬라·리스테리아·바실루스) Main-Quiz는 GPT 생성기의 첫 단계 normalize에서 OpenAI 생물 콘텐츠 제한에 7번 모두 걸렸다(11-18, job 698~701).
  - 탄저 쪽을 모델 입력에서 다 뺀 뒤에도 같았다(docs/changes/2026-11-18-root-exclude-pages).
  - 그래서 새 판이 나오지 않는다. 공개판은 옛 auto-2bcdcf1f 그대로다.
- 사용자가 ChatGPT 웹에서 같은 normalize 과제를 돌렸다. 가리지 않은 자료(바실루스 포함)로 돌렸고, 받은 result.json을 보냈다.
  - 한글 깨짐을 고친 판 `result_바실루스포함_깨짐수정.json`은 러너의 normalize 검사(`check_file('normalize')`)를 통과한다.
  - 내용은 개념 196·관계 209·목표 108·포인트 83이다.
- 지금은 웹 결과를 실행에 넣을 길이 없다. 단계 영수증에는 모델 세션 증거(provider.json·세션 ID)가 있어야 해서, 가짜 영수증을 만드는 수밖에 없다.

## 범위와 성공 기준
- 사용자 결정(2026-11-19):
  - 「이걸로 돌려줘」
  - 「가져오기 + 뒤 단계 GPT」: 가져오기 기능을 만들고, 뒤 단계는 GPT 기본 경로로 둔다. 거절은 두 번째쯤에서 멈추고 알린다.
  - 「가린 쪽 풀기」: 뒤 단계 자료는 원본 그대로 보인다.
- 성공:
  1. 운영자 기록 파일이 가리킨 결과 파일로 normalize 단계를 채운다.
     - 기록이 없는 실행은 지금과 같다.
     - 영수증에는 「운영자 제공」(누가 만들었는지, 이유·승인·파일 sha256)이 남는다.
     - 모델 세션 증거는 만들지 않는다.
  2. 가져온 결과도 모델 결과와 같은 normalize 검사(스키마·깨짐·자료·강의)를 지나야 받는다.
  3. 완료 결과의 재검증(validate_stage)이 운영자 영수증을 확인한다: 기록 파일, 결과 sha, 보관본.
  4. 261109_02 job 700을 이어 해서 게시까지 가거나, 실패를 사람에게 넘길 기록을 남긴다.
