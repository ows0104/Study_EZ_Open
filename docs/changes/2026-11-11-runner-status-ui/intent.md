안 보여. 그리고 예상 시간도 안 보이고, 디자인도 구려. 진행도 바가 시간에 비례하지 않아서 착각을 만들어. 필요없는 정보가 너무 많아.」
제안한 개편안에 「이대로 진행」으로 승인.

원인(2026-11-11 실측, 261111_02·261104_03 동시 실행 중):
- 바탕화면 창(`desktop.py`)이 카드 영역 높이를 130px로 고정 → 카드 하나만 보이고 나머지는 스크롤 아래.
- 단계 칸에 내부 이름(`연결 파일 실행 v4-coverage-fix-3-0 · 실제 JSON 파일과 완료 영수증 대기`)이 그대로 나온다.
- 예상 시간은 서버의 같은 과목·종류 완료 표본 3개 이상이 있어야 나온다. Main-Quiz는 표본이 없어 늘 「계산 대기」.
- 진행 바는 단계 이름의 단어로 7칸 중 몇 칸을 정한다. 시간의 절반 이상인 검토·수정이 4/7로 보여 거의 다 된 것처럼 보인다.

## 범위와 성공 기준
- 실행 중인 강의가 전부 카드로 보인다(스크롤 없이, 2개 이상).
- Main-Quiz(root-generation) 카드는 사람이 읽는 6구간(지도·포인트 → 커버 확인 → 추가 출제 → 검토·수정 → 의학 검토 → 게시)과 현재 구간을 보인다.
- 예상 남은 시간과 완료 예상 시각을 지난 실행의 구간별 소요 시간(로컬 `runs/_root-generation/` 파일 시각)으로 낸다.
  표본이 없으면 숫자를 만들지 않는다. 평소보다 길어지면 「평소보다 오래 걸리는 중」으로 말한다.
- 진행 바는 경과 ÷ (경과 + 예상 남은 시간). 예상이 없으면 바를 그리지 않는다.
- 2026-10-17 지시(한 거/하는 거/할 거/확인 필요 목록과 개수)는 한 줄 개수 요약 + 「목록」 펼치기로 지킨다.
- 내부 단계 이름·러너 로그는 「상세 기록」에서만.
