# Main-Quiz 순서 맞추기 화면

## 문제와 사용자 효과
순서가 곧 내용인 나열 문항(예: 감염과 면역 261110_02 Q174 「폭스바이러스의 복제주기 단계는?」, 정답 7단계)이
객관식 모드에서 「해당하는 것을 모두 고르기」로 나온다. 단계마다 선지 하나가 되고 다른 바이러스의 단계(역전사·숙주 염색체 통합·분절 재편성)가
오답으로 섞인다. 순서를 몰라도 다 맞힐 수 있는데, 답면에는 순서대로 이은 글이 나온다. 묻는 것과 푸는 것이 다르다.

## 원인
1. Main-Quiz 출제 프롬프트는 sequence 형식을 쓰지 않는다(`content/prompts/learning-links/automation/generate.md:5`). 단계는 list로 저장된다.
2. 문항에 순서형 표시가 없다. Q174는 `format: list`, `retrieval_direction: direct`다.
3. 선지 계약(`studyez_contracts/roots/mcq.py`)은 list를 「정답 단위 전부 + 오답」 다중선택으로 만든다. 순서는 이 단계에서 버려진다.
