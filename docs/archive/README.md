# 닫힌 인계 메모

여기 있는 것은 **스스로 「닫았다」고 적은 문서**다. 지우지 않고 옮겨 두는 이유는
넷 다 본문에 *왜 그렇게 만들었는지의 근거*를 남겨 두었다고 적고 있기 때문이다 —
결론은 코드로 갔고 이유는 여기만 있다.

| 문서 | 무엇이 닫혔나 |
|---|---|
| `handoff-260823-jokbo.md` | 기출 파트에 자기 계획을 준다. 2026-08-29 에 16편이 끝났다 |
| `handoff-260825-terminology.md` | 번역어가 계획 단계에서 새던 자리 |
| `handoff-260903-incremental-cards.md` | 판이 갈렸을 때 바뀐 부분만 갈아 끼운다 → `slidediff.py`·`revise.py` |
| `handoff-260904-version-bump.md` | 새 판을 알아보는 자리 → `fingerprint.py` |

**여기 있는 문서로 현재 상태를 판단하지 마라.** 닫힌 시점의 사실이다. 지금 도는
규칙은 `CLAUDE.md` 와 프롬프트 폴더에 있고, 배포 상태는 `docs/handoff.md` 에 있다.

새 인계 메모를 쓸 때는 `docs/` 에 두고, 닫으면 여기로 옮긴다.
