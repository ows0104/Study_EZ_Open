# Review · Map/포인트 요청문 작성 완료

기준 revision: a3f67d13, 작업 브랜치 codex/map-point-prompts. 새 원본 전용 요청문 두 개와 사용 안내만 작성했다. 실제 모델 호출·출제 재개·운영 배포는 없다.

## 최종 변경

- map-extract.md: 중심 질문·목적, 큰 구조와 세부, 의미 있는 관계·교차 연결, 비슷한 개념의 구별, 원본 위치와 불확실성. 후속 사용자 교정대로 문항·누락·회상 평가·문항 순서 이야기를 본문에서 제외했다.
- point-extract.md: 원본의 실제 목표를 단서→답 범위로 구체화한다. 중요한 기초 연결·필요 방향·조건·예외·그림과 교수/기출/강조 근거를 구별한다. 자동 원자화·과도한 묶기·중요도 전이·범위 확장을 제한한다.
- README: 같은 원본을 별도로 제공하고 후속 대조 전까지 독립성을 유지한다. Markdown 검토용 요청문이며 자동 생성기의 기존 통합 추출/JSON 계약은 바뀌지 않았음을 명시했다.

## 검증과 한계

원문 비교 수동 리뷰: Map은 원본 개념 구조에만 집중한다. 포인트는 앞선 points.md의 원본 전체 확인·목표 묶기·근거·제외/불확실성을 보존하면서 과목 공통 연결 회상 철학을 적용한다. 내부 JSON/ID 운영 설명을 본문에 넣지 않았다. 기본 출력은 사람이 검토할 구조이며 JSON 연동을 완성했다고 주장하지 않는다.

git diff --check 및 신규 파일을 포함한 git diff --cached --check를 실행한다. 이는 텍스트 무결성 확인이며 모델의 추출 품질 검증이 아니다. 코드·계약·UI 변경이 없어 모델/서버/웹 통합 검사는 실행하지 않는다.

## 배포·보존

운영 미배포. 중단된 요청 548과 기존 입력·원장·문항·학습 기록·검수 상한은 변경하지 않았다. 두 요청문을 자동 생성기로 연결하고 독립 호출을 분리하려면 별도 실행 설계가 필요하다. 복원은 이 요청문 및 안내의 변경만 되돌린다.
