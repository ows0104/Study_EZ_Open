# 캘린더 복습 막대: 테두리 + 강조색 채움

## 문제와 사용자 효과
같은 날 #129에서 캘린더 칸 아래 복습 학습률 막대를 진하게 했다(바탕 메인 색 30%, 테두리 72%, 채움 60–100%).
사용자 2026-11-12:
1. 「바 색깔이 좀 진하다. 차라리 캘린더 화면 오른쪽 위에 예습 박스, 복습 박스 안의 색 정도로 하자.」 → 박스 색으로 바꿈(첫 커밋).
2. 이어서 「아니면 차라리 복습이 만들어지면 테두리만 있는 바를 보여주고, 사용자가 설정한 진한 강조색으로 빈칸을 채워가는
   식으로 할까?」 — 옛 규칙 「덜 채울수록 진하다」가 없어진다는 설명 뒤 「응 그렇게 하자. 예습 토막도 진하게 채워.
   진한 색이라는 건 원래 기본 강조색 정도.」
3. PR 뒤 「테두리 색 때문에 눈이 아파. 검은색으로 할까?」 → 회색 제안 → 「어 근데 너무 흐리지는 않은 회색」.
4. 「잠깐 회색이었다가 파란색이 되는데?」(불러오는 중 → 불러온 뒤) → 불러오는 중도 같은 회색 제안 → 「Yes, same grey」 → 이 기록의 최종 범위.

## 범위와 성공 기준
- 복습 막대(Main-Quiz 있을 때): 바탕 없이 너무 흐리지 않은 회색(`--bar-edge` = `--ink-2`와 `--ink-3`의 중간) 1px 테두리,
  학습률만큼 메인 색(`--accent`)으로 채움. 불러오는 중도 같은 회색 테두리(채움만 나중에 생긴다).
  사용자 강조색 조합(theme.ts)을 따른다. 옛 「덜 채울수록 진하다」는 없앤다.
- 예습 토막: 미완료 = 같은 회색 테두리, 완료 = 두 번째 색(`--accent2`)으로 채움.
- 범례 표본·사이드 패널 학습률 막대도 같은 `.meter`.
- 막대가 그려지는 조건(Main-Quiz 있을 때만)·높이 5px·강의록 회독 토막(회색)은 그대로.
