# 족보 PDF 정리·첨부 형식의 공통 기본값 보존 — 배포 준비

## 코드 리뷰·검증 결과
사용자가 확인한 PDF의 표시·교수 확인·정렬·이미지/원문 보존·검증 기준을 공통 정책으로 작성했다. 루트/runner 안내, 작업 지도 및 기존 과목 정책에서 연결했다. 관련 Markdown 링크의 실제 경로와 diff 공백을 확인하고, 기존 과목 보존 규칙 및 웹 배포 보류가 유지됨을 검토했다. 문서 변경이므로 서비스 동작 테스트나 자료 재생성은 실행하지 않는다.

## 배포 대상 버전·순서·데이터 변경
로컬 정책 문서와 안내만 변경했다. 코드·기존 PDF/JSON·운영 첨부·학습 데이터·웹 배포를 변경하지 않았다. 현재 사용자 지시를 앞으로의 자료 작업 기본값으로 보존한 것이며 자동 변환 기능 구현 완료로 표시하지 않는다.

## 배포 후 확인·롤백·필요한 사람 승인
운영 배포 대상이 없다. 이후 족보 작업은 공통 정책과 해당 과목 보존 계약을 함께 읽는다. 변경을 되돌릴 때는 이번 문서의 추가 문장/링크만 제거하고, 기존 작업/보존 자료는 그대로 둔다.
