# 캘린더 복습 막대 색 옅게 — 배포 준비

## 코드 리뷰·검증 결과
- web: `tsc -b web --noEmit` 통과(깨끗한 `npm ci` 위).
- 화면: web/tests/calendar-learning.html 고정물에 「내일 예습」「오늘 복습」 박스를 나란히 놓고 확인. 막대 바탕 계산값이
  「오늘 복습」 박스 바탕과 같고(color(srgb 0.932 0.945 0.988)), 채움(0.68–0.79)이 바탕과 구분된다. 예습 완료 토막은 옅은 주황 + 주황 테두리.
- 옛 색 값을 고정한 검사는 없다(web/tests에 `accent) 30%`·`72%` 없음).

## 배포 대상 버전·순서·데이터 변경
웹만(Pages). 서버·DB 변경 없음. master 병합이 검사 → 배포를 자동으로 돈다.

## 배포 후 확인·롤백·필요한 사람 승인
배포 뒤 캘린더 칸 아래 막대가 오른쪽 위 박스 색과 같은 옅기인지 본다. 롤백은 git revert.
