# Spec
새 명시적 CLI 병렬 경로만 적용한다. 각 저작은 같은 불변 원본과 독립 프롬프트를 사용하고 다른 결과를 보지 않는다. 세 결과가 유효하게 완료된 뒤 통합·기존 원본/독립정답 검수 및 최대3회 수정 경로로 연결한다. 기존 웹 요청·실패·중단·제한·수정 예산을 새 경로로 초기화하지 않는다. 입력·코드·프롬프트·모델·자료 지문 및 결과/사용량을 보존한다. 실패 모델 호출을 자동 재실행하지 않는다.
그림은 원본에서 추출해 ID·쪽·좌표·해시와 함께 보존하고, 직접 추출이 적합하지 않으면 원본 영역 렌더를 사용한다. 실제 문항 그림을 독립 검수 및 학습 화면에 동일 bytes로 전달한다. 요약 설명만으로 그림 검수를 대신하지 않는다. 기존 복구 후보와 내용 정책을 보존한다.
러너에는 문제은행·개념도·포인트와 후속 통합/검수를 구분해 대기/실행/완료/실패를 표시한다. 종료 프로세스를 실행 중으로 표시하지 않는다. 시간/가짜 백분율을 만들지 않는다. 시범은 격리 저장소/DB에서 수행하고 기존 운영 은행·학습 기록은 바꾸지 않는다.
