# 모아풀기 시작 화면 선택지

## 문제와 사용자 효과
예전 강의 목록에는 강의를 골라 복습 퀴즈를 한꺼번에 푸는 기능이 있었다(Quiz Bank 모아풀기).
2026-11-11 Main-Quiz로 바꾸며 막혔고, #219(2026-11-18-main-quiz-batch)가 Main-Quiz 모아풀기를 되살렸다.
#219는 강의마다 「오늘 추천」 목록을 그대로 섞기만 한다. 사용자는 여러 강의를 모아 풀 때도 진입 페이지에서
무엇을·어떤 순서로 풀지 고르고 싶다.

사용자 원문(2026-11-18):
- 「강의 여러 개를 모아 풀어도 진입 페이지를 보여줘.」
- 「1. 지금과 같은 중요도 선택 기능을 구현해줘.」
- 「2. 섞어서 풀기/순서대로 풀기 선택지를 만들어줘. 순서대로 풀기를 고르면 강의 번호 순서대로 고르고, 섞어서 풀기를 고르면
  랜덤하게 문제 순서를 섞어줘. 랜덤하게 섞을 때에는 강의 간에서 순서를 섞는 것뿐만 아니라 강의 내에서도 순서를 섞어줘.」
- 「3. "기존 학습률 무시" 체크 선택지를 만들어줘. 기존 학습률을 무시한다는 건 아직 복습 주기가 안 된 문항들까지 전부 풀겠다는
  의미야. 체크하지 않으면 복습 주기가 된 문항들만 풀어.」
- 「build on top of #219」
- 「미열람 문항 보기 체크를 별도로 만들어줘. 기존 학습률 무시랑 별개로 계산해서, 미열람 문항 보기를 체크하면 미열람 문항까지
  전부 볼 수 있게 하고, 미열람 문항 보기를 체크하지 않으면 기존에 풀지 않은 문제는 제외해줘.」
- 「중요도는 기본적으로는 한꺼번에 체크하고, 세부사항을 눌러볼 수 있는 아래 화살표를 눌러보면 각 강의별로도 세부적으로 선택할 수
  있게 해줘. 전체적으로 체크한 걸 기본값으로 각 강의에 적용하고, 각 강의별로 좀 더 세부적으로 고를 수 있도록 해줘.」

## 범위와 성공 기준
- 모아풀기 시작 화면(`/study/mix`)에 중요도(전체 + 강의별 ▾), 순서대로/섞어서, 기존 학습률 무시, 미열람 문항 보기, 주관식/객관식.
- 시작 단추의 문항 수가 선택을 바꾸는 즉시 바뀐다.
- 고른 조건의 문항만 풀고, 기록·복습일·학습률은 강의별로 그대로 쌓인다.
- 강의 하나 화면의 「오늘 학습」 흐름·중요도 칩은 바뀌지 않는다.

## 근거·미정 사항
- 「복습 주기가 된 문항」은 강의 목록 「복습」 칸과 같은 뜻(평가했고 복습일이 오늘 이전, 오늘 아직 안 푼 것)에
  「본 적은 있으나 평가하지 않은 문항」을 더한다(오늘 추천의 미평가 과제와 같은 대우).
- 「미열람」은 강의 목록 「미열람」 칸과 같은 뜻(시도·평가 기록 없음).
- 섞어서: 강의 안에서도 섞되, 선행 문항은 그 문항을 전제로 한 문항보다 앞에 둔다(배우는 길 보존).
