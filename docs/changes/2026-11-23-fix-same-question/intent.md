## 범위와 성공 기준

PR #238(Draft)의 R3·R4만 옮긴다. 사용자 2026-11-23 「R3/R4만 넣어줘」.

1. fix.md: 고친 문항은 원래 문항이 묻던 것을 묻는다. 같은 물음 안에서 형식·발문·정답·채점 단위를 고친다.
   다른 물음을 요구하는 지적은 이 ID에 적용하지 않고, 이유를 exam_rationale에 남긴다.
2. 같은 물음으로 치는 셋은 남긴다. 사용자가 좋다고 한 사례가 여기에 든다.
   - 정답 교체: Q006, 단일 답을 원본이 함께 든 세 후보로
   - 같은 범주 목록의 빠진 원소: Q156 염소, Q011 발문의 호중구 감소를 답으로
   - 줄이거나 나누어 한 층으로: Q081 대사증후군 뺌
3. item-review.md: fix는 그 문항이 묻는 것 안에서 고칠 방향이다. 다른 물음은 note의 「별도 문항: …」으로 남긴다. 그 이유만으로 design을 낮추지 않는다.
4. 새 검사가 문장을 고정한다. 그 검사는 master 지시문에서 실패한다. `pytest tests studyez_contracts`도 통과한다.

- 사용자 2026-11-23: 같은 목록의 일부 원소에만 근거가 있어도 목록 전체가 그 등급을 받는 것은 문제가 아니다(「C 빼고 다 좋은데?」).
- 답 강조 표시는 나중에 한다(「답 강조는 지금 말고 나중에 하자」).
