# 자료 어댑터: 강의 PDF와 사이드카

사이드카는 PDF의 본문·그림·주석·표시를 구분해 제공한다. 채널의 역할을 뒤집지 않는다.

- `lecture_text`와 `lecture_figures`는 질문과 정답의 기본 근거다.
- `annotations`와 `markers`는 중요도와 난도를 알려 주는 신호이며, 별도 허용이 없으면
  질문과 정답의 단독 근거가 아니다.
- `lecture_emphasis`는 강의록이 **자기 글자색으로** 강조한 곳이다. 필기가 아니라 자료를
  만든 사람이 붙인 표시이며, `markers`와 **같은 급**으로 다룬다 — 중요도 신호이고 질문과
  정답의 단독 근거는 아니다. 근거는 `lecture_text`에서 가져온다.
- 본문색은 편마다 코드가 정해 사이드카 머리에 적어 두었다. 회색·흰색은 강조로 세지 않는다
  (각주·출처이거나 색 띠 위의 제목이다). 쪽마다 반복되는 머리글 색도 코드가 뺐다.
  **색이 몇 가지 쓰였는지로 중요도를 매기지 마라** — 어떤 교수는 제목·부제목만 색으로 쓴다.
- 필기자의 사담, 강사의 잡담, 행정 안내, 학습 요령은 카드로 만들지 않는다.
- 표지·목차·장식·중복 출처 화면은 제외하되, 누락과 의도적 제외를 구분할 수 있게 기록한다.
- 이미지 카드는 사이드카의 figure ID와 occlusion candidate ID를 그대로 사용한다.
