# Study EZ 예습 브리지 개인정보 처리 요약

최종 수정: 2026-10-13

공개 정책 URL: <https://studyez.kr/privacy>

Study EZ 예습 브리지는 사용자가 선택한 강의 자료와 프롬프트를 ChatGPT, Gemini 또는 Claude에
준비하고, 완성된 대화의 결과를 해당 Study EZ 강의에 연결하는 단일 목적으로
작동합니다. 예습·복습 모드는 대화 링크를, 관리자 문제은행 모드는 링크와 완성된 문항 본문을 연결합니다.

## 처리하는 데이터

- 선택한 PDF·족보 조각 문서의 파일명·임시 다운로드 URL·파일 내용, 예습 프롬프트, 강의 식별자
- 선택한 AI의 대화 URL과, 기본 링크 모드에서 생성되는 공개 공유 URL
- 대화 링크와 응답 완료 여부를 확인하는 동안 일시적으로 처리하는 AI 대화 내용,
  상태, 현재 노드
- ChatGPT 공유 요청을 수행할 때 메모리에서 일시적으로 읽는 액세스 토큰
- 관리자의 Quiz Bank 모드에서 공개 공유 주소·생성자의 개인 대화 주소를 각각 저장한다.
  공유 주소는 기본 링크 버튼에서 열며 개인 주소는 관리자에게만 제공한다. 예습 링크 저장 경로와 구분한다.
  완성된 문항 본문을 Study EZ로 전달·저장하며 러너가 검수·보완해 Main-Quiz로 게시한다.

액세스 토큰은 저장하지 않고 Study EZ 서버로 보내지 않습니다. 진행 중 요청과 아직
저장되지 않은 링크와 문항 본문을 Chrome 세션 저장소에 잠시 보관합니다. PDF와 프롬프트는
사용자의 확인과 동의 뒤 선택한 AI 서비스에 첨부되며, 자동입력에서는 업로드 완료를 확인하면 자동 전송합니다. 수동입력에서는 사용자가 직접 전송합니다.

자동 첨부·전송 및 결과 저장 동의는 AI 서비스·모드·입력 방식별로 한 번 받고 그 사실만 브라우저 로컬 저장소에 남깁니다(값은
동의 여부 하나뿐이며 서버로 보내지 않습니다). 확인 카드의 **동의 해제**를 누르면
지워지고 진행을 중지하며 다음 실행부터 다시 묻습니다. 이전 수동 전송 동의로 자동 전송하지 않습니다.
자동입력 동의가 기억된 뒤에는 Study EZ에서 시작하면 3초 후 자동 진행합니다. 확인 카드가 파일명과
링크 모드, 체크된 동의 상태를 표시하며, 상세 자료 목록과 개인정보 처리 설명은 **자세히**를 눌러
다시 볼 수 있습니다. 전송 전 카드의 ×를 누르면 이후 자동 진행을 중지합니다.
이미 첨부한 자료는 입력창에 남을 수 있으며, 이미 전송한 메시지는 취소되지 않습니다.

기본 링크 모드에서는 링크를 가진 누구나 열 수 있는 선택한 AI 서비스의 공개 스냅샷을 만들고
그 주소를 Study EZ에 저장합니다. 개인 링크 모드에서는 공개 공유를 만들지 않습니다.

데이터를 판매하거나 광고, 신용평가, 사용자 추적에 사용하지 않습니다. Chrome Web
Store 사용자 데이터 정책의 Limited Use 요건을 준수합니다.
