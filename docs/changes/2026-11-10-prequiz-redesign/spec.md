# 예습 퀴즈 풀이 화면 디자인 통일

## 지시

2026-11-10 사용자: 예습 퀴즈 풀이 페이지가 과거 사이트 디자인 그대로다. 개편된 사이트 디자인과 통일성 있게 수정한다.

## 범위

화면 모양만 바꾼다. API·문항·풀이 기록·단축키·버튼 동작은 그대로다.

- `/prequiz/…`를 bare 화면(상단 이동 줄)에서 빼고 새 Main-Quiz처럼 좌측 메뉴 안에서 푼다(`src/App.tsx`).
- 틀은 새 Main-Quiz 풀이(`src/bank/main-quiz.css`)와 같다: 배지·강의 제목·도구 버튼 머리줄 → 진행 막대 →
  테두리 카드(답 앞 점선) → 화면 아래 떠 있는 독(되돌리기·답 보기/헷갈려요·이해했어요).
- 예습 갈래 색은 두 번째 강조색(`--accent2`)이다(2026-11-06 결정: 예습 = 두 번째 색).
- 완료 화면도 Main-Quiz 완료 카드 형태: 완료 카드(문항 수·헷갈림 수·되돌리기·다시 훑어보기·예습 마치기),
  추가 학습 카드, 어려웠던 문제 목록, 「오늘 챙긴 핵심」 접기.
- 화면 설명 문장(「수업을 들을 준비가 됐어요…」, 「‘아직 헷갈려요’를 고른 문제예요…」 등)은 개편 원칙(설명 문장 없이
  라벨·숫자만)에 맞춰 뺐다. 버튼 이름 「되돌리기」는 Main-Quiz와 같게 줄였다(단축키 Z 그대로).
- 스타일은 `src/lecture/prequiz.css`. base.css의 쓰지 않게 된 예전 예습 규칙을 지웠다.
- 기존 Main 웹 풀이(`/legacy-mainquiz/`)는 바꾸지 않았다.
