## 제출본에서 확인한 대조 항목

- 다섯 큰 구조의 트리와 달리 우선순위·포인트·쪽/기출 번호·정답 충돌 주장·체크리스트를 담는다. 단순 문항 색인은 아니지만 전체 범위 추출의 완전성은 미검증이다.
- 신경전달 억제 지점은 포인트에 별도로 등장하지만 트리의 명시적 큰 가지에는 없다. 원본에서 실제 범위와 위치를 확인할 후보이며 트리 누락으로 확정하지 않는다.
- 트리는 구조 비교에 2022-39를, 포인트는 2022-42를 인용한다. 포인트는 2022-65를 (1)의 임상응용 근거와 (2)의 구분 항목 양쪽에 둔다. 복합 문항일 가능성을 포함해 실제 문항의 해당 부분을 대조해야 한다.
- 19문항·동일 반복률 0%는 분모·대상 강의·반복 정의를 확인하기 전 통계나 교수 스타일의 확정 근거로 쓰지 않는다.
- A/B/C는 제출본의 임시 우선순위다. 제품의 중요도 등급에 자동 매핑하지 않는다. 낮은 우선순위·강의 설명 생략을 올해 시험 범위 제외로 자동 해석하지 않는다.
- 2022-42, 2023-14, 2018-22의 정답 오류/수정 주장은 원본 대조가 필요한 검토 항목이다. 기존 정답이나 검수 판정을 고치지 않는다.
- '0/10 완료', '초기화'는 제출된 출력의 일부이며 실제 학습 기록이 아니다. 체크리스트 10개를 목표 분모나 필수 양방향 과제로 자동 채택하지 않는다.
