# 캘린더 복습 막대 채움을 연한 강조색으로

## 문제와 사용자 효과
#140으로 캘린더 복습 막대가 회색 테두리(`--bar-edge`) + 학습률만큼 메인 색(`--accent`) 채움이 됐다.
사용자 2026-11-12: 「머지했는데 여전히 바는 그대로 파란색이야. 나는 그냥 회색을 원해.」 → 남은 파란색은 채움이라는 설명 뒤
「바 안쪽 색을 연한 강조색으로도 해볼까?」 → 미리보기(고정물 화면) 확인 → 「Yes, open PR」.

## 범위와 성공 기준
- 복습 막대 채움(`.meter > span`)만 진한 메인 색 → 연한 메인 색 `--accent-line`(메인 28%·표면 72%, 「오늘 복습」 상자 테두리와 같은 색).
- 회색 테두리·불러오는 중 회색·막대 높이·막대가 그려지는 조건은 그대로.
- 예습 토막(`.rl-pre.is-on`, 두 번째 색 채움)은 그대로 — 사용자가 따로 원하면 바꾼다.
- 범례 표본·사이드 패널 학습률 막대도 같은 `.meter`라 함께 바뀐다.

## 근거·미정 사항
웹 표시만. 서버·DB·API 변경 없음. 상자 안 색(`--accent-soft`, 9%)은 5px 막대에서 빈 막대와 구별이 어려워 쓰지 않았다.
