# Main-Quiz 풀이 중 내 중요도 변경

## 문제와 사용자 효과
사용자 요청(2026-11-09 채팅): 「Main-Quiz 풀면서 중요도 수정할 수 있게 해줘.」
후속(같은 날): 「중요도를 학습 간격에 안 써? … Quiz-Bank의 목표 기억률 방식을 안 챙겨온거야?」 → 선택 「새 평가부터 적용」.

기존 Quiz Bank 풀이에는 문항 머리의 「내 중요도」 선택(Must-Know·Core·Important·Optional, 원래대로)이 있다.
Main-Quiz는 판 문서(`bank_snapshot.questions[].tier`)에 문항 중요도를 갖고 있으나 학생 화면에는
`Core`로 고정해 보내고(`content.front`), 복습 간격도 안정도만으로 `ceil(S)`일(최대 30일)로 정한다.
중요도와 숙련도를 쓰지 않으니 모든 문항이 기억률 90%(Must-Know 목표)에 맞춰 복습되는 셈이다.
Quiz Bank는 숙련도 이동평균과 중요도별 목표 기억률로 `9S(M/목표−1)`일 간격을 쓴다.

## 범위와 성공 기준
- Main-Quiz 풀이 화면에 이 문항의 현재 중요도와 「내 중요도」 선택, 바꾼 경우 「원래대로」가 보인다.
- 고른 값은 내 계정·이 판에만 저장되고, 새로고침·다음 회차·미리 받은 문항에서도 같은 값이 보인다.
- 새 평가부터 Quiz Bank와 같이 숙련도·목표 기억률(중요도별)로 복습 간격을 정한다. 이전 평가의 예정일은 그대로다.
- 내 중요도를 바꾸면 그 문항의 목표 기억률이 바뀐다(올리면 더 자주, 내리면 덜 자주). 화면에 「목표 N%」가 보인다.
- 이용현황에 「Main Quiz 내 중요도 변경 저장」이 따로 집계된다.

## 근거·미정 사항
- 저장은 기존 append-only `root_event`의 새 종류 `tier`. 표·칼럼 추가 없음(운영 DB 준비 불필요).
- 오늘 목록 순서(새 목표·복습 순서)는 지금처럼 목표의 시험·임상 근거 축을 쓰고 바꾸지 않는다
  (server/CLAUDE.md 2026-10-16 지시: 신규 문항을 등급으로 묶지 않는다).
- 다른 판으로 바뀌면 문항 ID만으로 개인 중요도를 승계하지 않는다(CLAUDE.md 보존 원칙).
