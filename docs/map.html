예시로 쓴 편으로 그 규칙을 재지 마라. 2026-09-05 에 코어 예시가 한 편에 몰려 있었고, 그 편을 새 프롬프트로 돌려 보니 cloze 14장 중 5장이 예시에서 그대로 나왔다. 「규칙이 작동했다」로 읽을 뻔했다. 어느 편이 예시에 들었는지는 prompting.py 의 DOMAINS 위 주석에 있다 — 주제까지 봐야 한다.

문구가 나은지는 파이프라인 실행으로 재지 마라. 같은 편 같은 자료인데 판마다 cloze 6~16장 · 재현 78~91% 로 흔들려, 만들려던 효과가 그 폭에 묻힌다. python -m quizgen.judge cloze out/exp_A out/exp_B — 30초 · $0.35.

python spotter/scripts/build_master.py   # species·specimens csv → json
python spotter/scripts/build_web.py      # → build/quiz_db.json
python spotter/scripts/upload_web.py     # → R2

06 안 겹치는 것

  • 풀이 화면 둘은 다른 제품이다. Study_EZ 는 자기채점 자유회상이고 땡시는 시간 재는 다지선다다. 한쪽을 고칠 때 다른 쪽을 볼 일이 없다.
  • quizgen/prequiz/ 는 quizgen/ 의 복제가 아니다. ..build·..pack·..validate 를 import 한다 — 이미 나뉘어 있다.
  • spotter-dist/ 는 산출물이다. spotter/ 를 고치고 deploy_pages.py 를 돌린다.
  • docs/archive/ 는 닫힌 기록이다. 현재 상태로 읽지 마라.

07 이 지도를 안 믿어야 할 때

줄수는 금방 낡는다. 하지만 경계(02절)는 두 명령으로 다시 잴 수 있다.

python scripts/map_numbers.py            # 실측과 지도를 나란히
python scripts/map_numbers.py --check    # 다른 줄만 찍고 1 로 끝난다

cd server && .venv/Scripts/python.exe -m tests.test_routes_golden

늘었으면 이 지도가 아니라 구조가 틀린 것이다. 그 import 를 없앨 수 있는지 먼저 본다.
