# Map 흐름 예시를 반영한 별도 프롬프트 복사본

## 문제와 사용자 효과
사용자가 콜린성 약리학 Concept Map 예시를 제공하며 큰 흐름·짧은 노드 설명·가지 사이 연결 같은 느낌을 원했다. 예시의 의학 내용을 기준 답안으로 삼는 대신 일반적인 표현 방식을 Map 추출 지시문에 반영한다.

## 범위와 성공 기준
실제 시범이 준비 중인 다른 작업 폴더와 프롬프트를 보존하고 별도 복사본만 작성한다. 기존 /2 출력 구조를 유지한다. 실제 모델 호출·재개·배포·화면 구현은 없다.

## 근거·미정 사항
현재 사용자 “이전에 Chatgpt가 뽑은 건데 약간 요런 느낌으로 뽑혀도 좋을듯.” 이후 겹침 질문에 “시범은 유지하고 별도 복사본에 정리”를 선택했다. 입력 예시는 현재 첨부 Pasted text.txt 및 사용자 제공 flowchart이며 원문 수정·의학 판정은 수행하지 않는다.
