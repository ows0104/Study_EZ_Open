# 결과·시험일 기반 초기 복습 정책

2026-11-03 사용자 선택: 학습 결과와 시험일까지 남은 기간에 따라 간격을 유동적으로 조정하고 하루는 한국시간 새벽 4시에 바꾼다. 고정 1→3→7→14일·09시 제안은 새 기본 정책으로 사용하지 않는다.

정책 판은 roots-adaptive/1이다. 회상 결과는 사용자 자기평가이며 아래 규칙은 초기 제품의 보수적인 일정 규칙이다. 실제 기억 확률, 최적 학습 효과 또는 FSRS를 인증하는 수치는 아니다. 같은 사건·시각·자료·정책에서는 같은 결과를 재현한다.

## 간격 계산

- 첫 독립 회상 성공의 기본 간격은 1일이다. 이후 새 학습일의 성공은 기존 기본 간격과 실제 경과 일수×2 중 큰 값을 올림하며 최대 30일이다.
- 같은 학습일의 반복 성공은 간격을 늘리지 않는다. 시험 때문에 예정 간격이 짧아졌어도 짧은 재노출만으로 기본 간격을 계속 두 배로 늘리지 않는다.
- 일부만/도움 받은 회상은 기존 기본 간격과 실제 경과 일수 중 작은 값의 절반을 올림해 최소 1일로 줄인다. 실패는 1일로 되돌린다. 도움을 본 성공을 독립 회상으로 올리지 않는다.
- 시험 전/당일에는 남은 한국 달력 일수의 1/4을 내림(최소 1일)한 값을 다음 예정 간격의 상한으로 쓴다. 시험일 미정 또는 이미 지난 시험에는 이 상한을 적용하지 않는다. 압축 전 기본 간격과 실제 예정 간격은 별도로 둔다.
- 시험이 다가오면 마지막 평가일에 현재 시험 상한을 더한 날과 원래 예정일 중 이른 날이 유효 예정일이다. 오늘 날짜에 계속 상한을 더해 예정일이 앞으로 밀려나는 방식은 쓰지 않는다.
- 새 진도는 기존대로 시험 2일 전까지 준비된 미학습 목표를 나눠 확보한다. 실패를 이유로 진행 중 목록을 늘리지 않는다.

## 사람이 확인할 예시

모든 예시는 한국시간 오전 10시에 평가한 가상의 한 방향이며, 다른 방향이나 강의의 완료를 뜻하지 않는다.

| 입력 | 다음 간격/예정일 |
|---|---|
| 시험일 미정, 11/3 첫 독립 회상 | 1일, 11/4 |
| 이어서 11/4에도 독립 회상 | 실제 1일 경과를 반영해 2일, 11/6 |
| 이어서 11/6에도 독립 회상 | 실제 2일 경과를 반영해 4일, 11/10 |
| 11/4의 기본 2일 상태에서 11/9에 늦게 와 독립 회상 | 실제 5일을 반영해 기본 10일, 시험일 미정이면 11/19 |
| 위 11/6 성공 때 시험이 11/12로 정해져 있음 | 기본 4일은 보존하고 예정 간격은 1일로 압축, 11/7 |
| 11/10의 기본 8일 상태에서 11/18에 일부만/도움 회상, 시험일 미정 | 기본 4일, 11/22 |
| 같은 상황에서 실패 | 1일, 11/19 |
| 같은 학습일에 다시 성공 | 기존 기본 간격 유지, 당일 반복으로 단계 상승 없음 |
| 03:59:59에 답 확인 후 04:00:00이 됨 | 첫 학습 사실은 보존하고 오늘 새 목표/추천 날짜만 새 학습일로 전환 |

## 보존과 적용

정책 전체와 자료 판·시험일은 사건/회차에 고정한다. 이미 시작한 이전 간격표/09시 회차는 원래 정책을 유지하고 새 추천은 새 정책으로 만든다. 기록을 덮어쓰거나 같은 ID만으로 판 사이를 승계하지 않는다. 평가를 취소하면 남아 있는 사건에서 간격도 다시 계산한다. 기본 정책 채택은 운영 공개를 뜻하지 않는다. 전체 기능·강의별 검토/활성화·허용 계정 조건과 실제 콘텐츠 채택은 여전히 필요하다.
