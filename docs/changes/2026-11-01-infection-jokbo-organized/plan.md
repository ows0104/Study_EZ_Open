# 실행 계획

1. 이전 약리학 정리본과 현재 원본의 제목·문항·정답·교수표를 확인한다.
2. 이 폴더의 일회성 스크립트에서 검증된 단원 경계로 연도/문항을 나누고 정답을 보수적으로 결합한다. 서비스 파서는 바꾸지 않는다.
3. output/pdf/감염과 면역_2026_정리본/에 정리 PDF를 만들고 원본 그림·표·텍스트 및 정답 자료를 보존한다. 원문 대응표를 기록한다.
4. materials 검사·렌더 시각 검토·리뷰 후 승인된 jokbo 80개를 업로드한다. 교체 전 원격 첨부와 보관 로컬 파일 해시를 고정한다.
5. upload 검사로 저장 바이트·시간표 연결·기존 71개 필기·80개 강의·퀴즈 보존을 확인한다. 실패 시 완성 로컬 자료로 재개하고, 복원은 직전 업로드 계획을 사용한다.

수정 경로는 이 작업 기록, output/pdf 새 자료, 업로드 ledger뿐이다. 다른 미커밋 변경을 포함하지 않으며 원본·직전 자료를 삭제하지 않는다. 현재 사용자의 제작·업로드 요청을 build 및 첨부 교체 승인으로 기록한다.
