# 분류·나열 역할과 연결 회상 검토 기준 — 구현 계획

## 변경 범위·대상 파일·순서
현재 반영 요청을 직전 합의 범위의 승인으로 적용한다. 새 설계 기록 → 로컬 mapping-review 안내 보강 → first-ten-review 역할 검토표 작성 → 기존 시범 review-notes에서 링크한다. 운영 bankPrompt·코드·DB·CLI 원문은 변경하지 않는다.

## 검사 명령과 성공 조건
document-review: 문서 링크, 첫 10행, 필수 구분 기준, 원본 content-review.md SHA256 보존을 확인한다. 실행 코드 변경이 없으므로 제품 테스트는 실행하지 않는다.

## 위험·복원·승인할 범위
질문 형식을 근거로 중요도나 숙련을 자동 판정하지 않는다. 복원은 이번 추가 단락·문서만 대상으로 한다. 새 모델 호출·자료 전송·의학 답안 변경·재검수·배포는 범위 밖이다.
