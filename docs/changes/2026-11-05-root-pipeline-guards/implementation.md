# 공통 파이프라인 6종 구현 결과

사용자가 승인한 범위만 구현했다. 콜린성 예시 ID·특정 페이지에 맞춘 보정은 추가하지 않았으며 실제 강의 내용은 수정하지 않았다.

| 재발 원인 | 공통 처리 |
|---|---|
| 부분 질문으로 전체 목표가 준비됨 | 목표를 필수 구성요소로 선언한다. 한 질문의 실제 정답 단위가 전체 요소를 회상하게 하고 관계·범위·중요도·그림 검수를 통과해야 준비로 인정한다. 제공된 단서·해설·여러 부분 질문의 단순 합산은 전체 회상으로 인정하지 않는다. |
| 잘못된 목표를 둔 채 문항만 수정 | 지도와 BANK를 같은 최대 3회 수정 안에서 교정하고 수정 사유·버전을 보존한다. 원본·범위·출제포인트 원문은 유지하며 관계·목표·중요도·선행 조건을 다시 검수한다. 문항을 본 지도는 derived로 남기며 독립 추출로 승격하지 않는다. 내용이 달라지면 같은 ID라도 숙련도를 자동 승계하지 않는다. |
| 모든 지적이 수정 상한을 소진 | 문항 수정·지도 수정·필수 누락과 선택 확장·한계·확인을 구분한다. 불명확한 근거는 unknown으로 보류하고 없는 것으로 단정해 반복 수정하지 않는다. 실제 수정만 기존 상한을 사용하며 중단·오류·버전 업그레이드가 예산을 초기화하지 않는다. |
| 예시 전용 그림 연결 | 임의 원본 ID·물리 페이지·좌표의 PDF 그림을 추출하고 출처 SHA·PNG 바이트·크기·개수를 검증한다. 원본 검수·독립 검수·사용자 화면에 같은 그림을 전달한다. 이미지 확인 전 독립 회상은 화면과 서버 양쪽에서 차단한다. |
| 과도하거나 순환하는 선행 조건 | 각 문항 선행 관계의 필요성을 검수한다. 문항·목표를 합친 그래프에서 순환을 검사하고 준비되지 않은 선행 문제의 후속 문제를 보류한다. 추천에 선행 문제를 앞세우되 오답 후 다음 문제 이동은 유지한다. |
| 이전 판정이 독립 검수를 유도 | 의학 검수에는 문항·답·해설·임상 사실만 허용 목록으로 전달한다. 이전 검수 객체·원본 출제 근거는 분리한다. 임상 사실 전사가 잘못되면 의학 호출을 blocked로 남기고 완료로 세지 않는다. 기계적 이력 표식은 차단하되 정상 임상 문구를 무작정 금지하지 않는다. |

## 구현 위치

- 공용 계약: `studyez_contracts/roots/generation_v2.py`, `media.py`, `automation.py`, `validate.py`, BANK·learning-links 검증기.
- 생성/원본 그림: `quizbank/connection_generate_v2.py`, `connection_visuals.py`, `content/prompts/learning-links/automation/*-v2.md`.
- 실제 모델 이미지 전달: `studyez_llm/codex.py`의 이미지 첨부 및 실행 지문.
- 재개/게시/학습: `runner/connection_generation.py`, `server/app/routes/root_generation.py`, `server/app/root_learning/`, `server/app/routes/root_learning.py`.
- 화면: 공통 `BankQuestion` 그림 표시, `RootSolve` 로딩·확인값, `RootMap` 원본 대조/준비 상태 분리.
- 재현 가능한 검증: `scripts/check_root_pipeline.py contracts|generator|runner|server|web` 및 각 영역 회귀 검사.

## 증거와 보존

원본 검수/의학 검수의 입력·원문 응답·사용량·출력 지문을 각각 보존한다. 재개 시 증거를 검증하고, 시작했으나 완료되지 않은 모델 호출은 자동 재호출하지 않는다. 기존 /1 계약은 보존한다. 새 클라이언트 확인값이 없는 그림 회상은 거절하지만 기존 그림 없는 요청의 재시도 지문은 바꾸지 않는다.

다른 원본 ID와 42페이지 합성 PDF를 포함한 검사로 특정 강의·35페이지 의존이 없음을 확인했다. 실제 HTTP·작업자·모델 하위 프로세스·게시·화면을 통합하되 모델 결과는 합성 어댑터에서 제공한다. 실모델의 의학 성능 평가나 운영 완료를 주장하지 않는다.
