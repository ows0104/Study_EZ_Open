## 배포 후 확인·롤백·필요한 사람 승인
운영 배포 없음. 미확인 항목과 복합 질문의 평가 경계, 문항별 중요성 근거를 검토하기 전 기존 은행에 반영하지 않는다. 초안을 사용하지 않아도 원본과 이전 은행은 유지되므로 별도 데이터 복원은 필요하지 않다. 초기 실행 실패·자동 승인 거절과 이후 구체 승인·완료는 모두 기록을 보존한다.
