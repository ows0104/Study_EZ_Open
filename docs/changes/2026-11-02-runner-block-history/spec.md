# 러너 현재 블럭 화면과 이전 기록 분리 — 설계

- 첫 화면의 작업·진행 카드·완료·대기·보류·오류 집계는 현재 블럭의 과목과 강의에 한정한다.
- 현재 블럭 자료를 확인하지 못하면 지난 기록을 현재 작업으로 대신 표시하지 않는다.
- 이전/다른 블럭과 미분류 기록은 별도 읽기 전용 창에서 조회한다. 이 창에는 작업 실행 버튼을 두지 않는다.
- 서버의 최근 50개 제한 밖 작업도 읽기 전용으로 조회하여 보관한다. 분류 기준과 상태·오류·시각·ID를 보존한다.
- runs/_history/runner에 내용 해시로 구분한 JSON 조회본을 추가 저장한다. 같은 내용은 중복 저장하지 않는다.
- 등록된 일괄 작업 완료/실패 기록과 원본 로그 위치도 보관한다. 원본 runs/work/DB·HOLD·CHOSEN은 이동·삭제·갱신하지 않는다.
- 현재 진행 중인 생성기와 러너를 중단하지 않는다. 화면 갱신은 자동 시작을 다시 켜지 않는 방식으로 한다.
- 현재 과목·강의 복합 키를 사용하고 다른 블럭 상태를 완료·실행으로 오인하지 않는다.
