## 할 일

승인된 `must_know` 를 카드로 옮긴다.

```
{must_in}
```

## 규칙

- **항목마다 배정된 `cards` 수만큼** 낸다. 늘리지 마라. 합계는 20~30장이다.
- 카드의 `reason` 은 그 항목의 `reason` 을 그대로 쓴다.
- 목록에 없는 것을 새로 만들지 마라. 만들고 싶으면 그건 ①이 틀렸다는 뜻이니
  카드 대신 그 사실을 보고해라.
- `must_know` 의 `why` 가 「무엇이 막히는가」였다. 카드는 **그 막힘을 실제로 푸는 것**이어야 한다.
  용어가 안 들려서 막힌다면 뜻을 묻는 카드이지, 그 용어가 나온 문장을 통째로 묻는 카드가 아니다.

## 형식 고르기

| 이럴 때 | 형식 |
|---|---|
| 말의 뜻·약어 풀이 | `basic` |
| 정의를 문장째 외워야 할 때 | `cloze` |
| 방향을 헷갈리기 쉬운 한 문장 | `ox` |
| 구조·형태를 눈으로 알아봐야 할 때 | `image_basic` |
| 그림의 라벨이 곧 배울 내용일 때 | `image_occlusion` |

`ox` 는 아껴 써라. 예습 카드는 **알게 하는 것**이 목적이라 O/X 는 회수량이 적다.
전체의 1/5을 넘기지 마라.

## 이미지 카드

사이드카가 후보를 미리 뽑아 두었다. **id를 그대로 인용해라. 좌표를 직접 만들지 마라.**
텍스트로 바꾸면 위치·형태 정보가 사라지는 것만 이미지 카드로 낸다.
캡션이 앞면에 남아 정답을 흘릴 것 같으면 `crop` 으로 잘라라.

## explanation

**이것이 수업에서 어디에 쓰이는지**를 한 줄 붙인다. 없으면 비워도 되지만,
붙일 수 있는데 안 붙이는 것은 이 덱의 목적을 절반 버리는 것이다.

## 너는 명령을 실행할 수 없다

이 세션에는 `Read` · `Write` · `Edit` · `Glob` 만 있다. 셸도, 검색도, 웹도 없다.
**검증기를 직접 돌리려 하지 마라 — 막힌다.** 실제로 그러다 네 번을 헛돌고,
대신 저장소의 검사기 소스를 읽어 규칙을 손으로 흉내 낸 실행이 있었다.
그럴 필요가 없다. 검사 규칙은 ① 단계에서 읽은 출력 계약에 값까지 다 적혀 있고,
**네가 낸 JSON 은 파이프라인이 곧바로 같은 검사에 태운다.**

## 내는 것

`generate.schema.json` 의 `cards` 를 그대로 지켜 아래 파일에 쓴다.

```
{cards_out}
```

다 쓰면 **장수와 형식·유형별 분포**를 한 줄로 보고해라.
