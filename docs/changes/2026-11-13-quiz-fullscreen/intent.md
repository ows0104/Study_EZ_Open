# 퀴즈 전체 화면 버튼

## 문제와 사용자 효과
퀴즈를 푸는 동안 브라우저 탭·주소창·작업 표시줄이 보여 집중을 흐린다.
사용자 요청(2026-11-13): 「집중 모드」 논의 뒤 「그럼 퀴즈에서 전체 화면 모드만 추가해줘」.
OS·다른 앱 알림을 끄는 것은 웹에서 불가능하므로 범위에서 뺀다. Windows에서는 전체 화면이면
"전체 화면 앱 사용 시 방해 금지" 규칙이 켜진 경우 알림 팝업이 함께 가려질 수 있으나 보장하지 않는다.

## 범위와 성공 기준
- 학습 화면 이동 줄(`StudyNav`: Main-Quiz 풀이, Quiz Bank·뿌리·연결 학습·강의 화면)에 `전체 화면` 버튼.
- 누르면 페이지 전체가 전체 화면, 다시 누르거나 Esc로 해제. 버튼 글자가 상태를 따른다.
- 학습 화면을 떠나 캘린더 등으로 가면 전체 화면을 해제한다.
- 전체 화면을 지원하지 않는 브라우저(iPhone Safari 등)에는 버튼을 그리지 않는다.

## 근거·미정 사항
- 예습 퀴즈(`/prequiz`, `lecture/QuizPage.tsx`)는 플로팅 노트 작업(PR #152)이 같은 파일을 고치고 있어
  이번 범위에서 뺀다. 포함 여부는 사용자 확인 대기.
- 집중 모드의 다른 요소(사이트 안 알림 숨김·화면 꺼짐 방지·이탈 기록)는 이번 범위가 아니다.
