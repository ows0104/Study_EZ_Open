# 복습 퀴즈 객관식 모드

## 문제와 사용자 효과
복습 퀴즈(Main-Quiz)는 대부분 주관식이고 객관식은 일부 문항뿐이다. 시험(2026-11-20) 전에 감염과 면역 블록 문항을
다 풀기에 주관식만으로는 느리다. 진입 화면에서 「주관식/객관식」을 고르고, 객관식을 고르면 같은 문항을 모두 선지로 푼다.

## 범위와 성공 기준
- 진입 화면(시작 카드)과 풀이 화면 머리에 주관식/객관식 전환. 이 기기 브라우저에 보관.
- 객관식 모드: 선지가 있는 모든 문항을 처음부터 선지로. 다중선택이 섞이고 정답 개수는 알리지 않는다. 고른 뒤 Space로 확인, 결과 표시, 네 버튼 평가.
- 문제 자체(질문·정답·판)는 그대로. 선지만 판(revision)마다 asset `root_mcq`(`root-mcq/1`)로 덧붙인다.
- 오답은 둘 중 하나만: ① 같은 블록 다른 병원체의 기전(block) ② 헷갈리는 사소한 부분 변경(subtle: Fe2+→Fe3+, 순서 바꾸기 등).
- 이미 게시된 감염과 면역 판 전부에 선지를 만들어 올린다(아침까지).
- 모드를 바꿔도 풀이·평가·학습 기록과 자료는 하나로 같다.

범위 밖: 출제 파이프라인 변경(게시 직후 자동 실행), 옛 Quiz Bank·Pre-Quiz.
