# 미정 CBL 3개 작년 필기 확인과 연결

## 문제와 사용자 효과
사용자가 ‘작년 자료 연결이 미정인 CBL 3개도 확인해서 맞는 작년 필기로 연결해줘.’라고 요청했다. 대상은 감염과 면역 261118_03(방어기전손상환자의 감염), 261125_07(암면역), 261126_07(류마티스관절염)이다. 실제 PDF 범위를 확인하고 작년 자료를 연결해 예습할 수 있게 한다. 단순 제목 점수만으로 일반 강의를 CBL 전용 필기라고 단정하지 않는다.

## 범위와 성공 기준
세 CBL만 2025년의 주제와 범위가 맞는 필기로 예습할 수 있게 하고, 기존 일반 강의와 자료·대화·학습 기록을 보존한다. 실제 연결과 운영 화면을 확인해야 완료다.

## 근거·미정 사항
2026-11-05 현재 사용자 직접 요청을 구현·운영 승인으로 적용한다. 2025 폴더에서 해당 주제 일반 강의 세 PDF를 발견했으며 CBL 전용 자료 여부와 범위를 본문 대조 중이다. 별도 CBL 필기가 없으면 참고 원본의 성격을 명시한다.
