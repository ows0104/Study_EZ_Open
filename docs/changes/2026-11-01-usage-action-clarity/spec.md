## 책임·입출력 계약·오류 상태
web/src/admin/UsageTab.tsx는 preview=true를 제목 아래 '개인 대화'로만 표시한다. 링크 칸은 opens만 사용한다. server/app/routes/usage.py는 UserPreview의 저장 여부/updated_at과 PreviewOpen의 클릭을 별도로 읽지만, 파일 종류 외 횟수/개별 시각은 상세 응답에서 생략한다.

web/src/calendar/PreviewAction.tsx의 start()는 /files/{id}를 요청해 확장에 자료를 전달한다. 저장된 링크를 여는 SharedOpen/PersonalOpen만 noteOpen()을 호출한다. 따라서 새 개인 예습을 만들고 URL을 저장해도 파일 요청만 표시되고 링크 칸은 비어 있을 수 있다. put_my_preview는 수동으로도 URL을 받을 수 있으므로 자동 생성 경로 사용은 정황이며 확정 이벤트가 아니다.

후속 개선 제안: 개인 예습 대화 저장, 기존 예습 링크 열기, 웹 퀴즈 평가, 파일 요청을 독립된 행동으로 표시한다. 현재 데이터만으로 확실한 항목부터 표시하고 개별 시각을 제공한다. 수동 받기/열기/예습 첨부 구분은 앞으로 기록해야 하며 과거 기록을 추정으로 채우지 않는다.

## 호환성과 데이터 보존
기존 학습·파일 요청·대화 저장·개인정보를 보존한다. 운영 조회에서 transaction_read_only=on을 확인했으며 마지막에 rollback했다. 개인 대화 URL/본문은 출력하거나 문서에 저장하지 않았다. 기존 접속 기록 폐지 지시는 그대로 유지하고 새 접속 기록표를 제안하지 않는다.

## 승인된 개선 계약
- 요약 표를 개인 예습 대화 저장/예습 링크 열기/웹 퀴즈 풀이/파일 요청으로 나누고 각 단위를 강의/문항으로 명시한다. 저장은 현재 남은 대화의 최종 저장 시각이 선택 기간에 드는 강의 수이며 생성/열람/완료로 해석하지 않는다. 상세는 전체 기간이며 행동별 최종 시각을 제공한다.
- asset_grab.request_stats JSON 칼럼(default {})에 download/view/preview_attach/review_attach/quiz_attach/unknown별 count/firstAt/lastAt을 저장한다. 기존 count/first_at/last_at와 캘린더 계약을 유지한다. 잔여 과거 count는 unknown으로 보존하고 다음 요청 전에 과거 시각을 고정한다. 미표기 구버전 요청도 unknown이다. 자동 첨부는 요청 목적일 뿐 실제 첨부 완료가 아니다.
- 파일 서명 API에 선택 purpose를 검증해 전달한다. 명시적 view와 inline 열기는 view, 직접 받기는 download, 예습/복습/문제 생성 자동 자료 요청은 각각 attach로 보낸다. 모아받기와 은행 Anki 내보내기는 download다. 자동 슬라이드 로드는 기존처럼 집계하지 않는다. 파일 전송 완료를 주장하지 않는다.
- 요약의 파일 요청 수는 목적별로 선택 기간에 최종 요청이 있는 고유 강의 수다(누적 요청 횟수를 기간 횟수로 잘못 표시하지 않는다). 상세에는 목적/자료 종류/전체 요청 횟수/첫·마지막 시각을 표시한다. 링크 요약은 기존처럼 클릭한 강의 수, 상세는 누적 클릭 횟수다.
- 저장만 있는 사용자, 링크만 있는 사용자, 파일만 있는 사용자도 활동 사용자에 포함한다. 개인 대화 URL은 관리 응답에도 새로 노출하지 않는다.

## 후속 확정 계약
- 공용 링크 열기/개인 링크 열기/개인 링크 만들기 시도/개인 링크 저장/예습 퀴즈 풀이/기존 복습 퀴즈/복습 카드/각 파일 목적·미상을 구별한다. 만들기 시도는 PreviewOpen의 새 kind=create로 보존하고 기존 share/mine 집계에 섞지 않는다. PreviewOpen은 기존 VARCHAR(8)로 수용하므로 추가 스키마 변경은 없다. 실제 외부 생성 완료를 주장하지 않는다.
- server/app/usage_actions.py에 행동 코드·한국어 이름·그룹·단위·기존 기록 수집 경로를 한 번 정의한다. API가 카탈로그와 행동별 수/시각을 내려주고 웹은 정의를 순회해 표시한다. 새 행동을 정의·수집 경로에 추가하면 별도의 웹 목록 수정 없이 표시된다. 새 파일 목적과 링크 행동의 등록 누락은 회귀 검사로 막는다. 기능 개발 지침에 기록/정의/수집/검사 동시 추가를 명시한다.
- 과거 만들기 시도는 추정 복원하지 않는다. 기존 저장 행은 현재 저장됨으로만 표시한다. 공개 응답에는 대화 URL·본문을 추가하지 않는다.
