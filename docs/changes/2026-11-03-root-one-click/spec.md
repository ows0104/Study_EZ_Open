# 동작과 보존

- 기본 입력 모드는 source다. 등록된 올해 원본이 있으면 지도·포인트를 입력하지 않고 실행한다. 서버가 실제 원본 사본/지문과 확인 가능한 해당 과목 시험일을 고정한다. 시험을 확인할 수 없으면 미정으로 둔다. provided 모드는 두 입력을 모두 요구하고 기존 동작을 보존한다.
- source 모드도 최초 문항은 Study EZ 자동전송 브리지로 ChatGPT 웹에서 만든다. CLI 최초 문항 대체 출제는 하지 않는다. 웹 파일 전에는 held, 검증된 파일 수신 뒤에는 같은 작업을 queued로 바꾼다.
- source 모드의 지도·포인트 정규화 모델은 원본 전용 별도 세션이다. 기존 문항·웹 응답·사용자 지도/포인트는 해당 세션 입력에 들어가지 않는다. 원본과 문항을 역으로 맞추지 않는다. 이후 원본 대조는 생성된 지도·포인트와 실제 문항을 함께 읽는다. supplied 입력을 독립 추출로 인증하는 기존 금지는 유지한다.
- 원문·자료·문항 ID·검수/수정 ledger·실패/취소와 중복 방지는 유지한다. 수정 최대 3회/검수 최대 4회를 재실행으로 초기화하지 않는다. 기존 문제은행·링크·개인 수정·제외·학습 기록을 그대로 보존하며 새 뿌리 판만 게시한다.
- 강의 패널에는 접힌 설정을 먼저 열지 않아도 자동전송 버튼이 보인다. 고급 설정에서 수동 지도/포인트·범위·시험일·시범 대상을 선택한다. 진행은 웹 응답 대기/러너 대기/검수/게시/중지로 구별하고 새로고침 후에도 이어 보인다.
- 현재 사용자 요청을 구현 승인과 기존 운영 배포 요청의 후속 적용으로 기록한다. 관련 변경만 배포 사본 tmp/root-web에서 검증·고정해 기존 API/Pages로 배포한다. 새로운 권한/공개 대상 확대와 다른 강의 일괄 실행은 포함하지 않는다.
