## 요구사항과 수용 기준
원본 AUDIT/BANK/brief/medical/coverage·전송 MD·원장·사용량·실패 기록을 수정하지 않는다. 문항 내용·검수 등급·목표·포인트·출처·필수 방향과 제외 이유를 바꾸거나 새 관계를 추정하지 않는다. 확인되지 않은 것을 confirmed로 올리지 않는다. 모델 호출0회, 문항 수정3/3·검수4/4 소비 상태를 유지한다.

## 책임·입출력 계약·오류 상태
roots 공용 계약에 별도의 순수 채택 함수를 둔다. 원본 입력 지문·CORE·문항 해시·검수 전수·방향 소유권·전역 참조·coverage 전수/상호배타는 먼저 검사하며 불일치는 계속 전체 보류한다. 그 다음 규칙에 어긋난 관계 역할/방향 배정은 행 전체를 채택하지 않고 해당 방향을 unknown으로 남긴다. 방향별 confirmed/partial/missing 주장이 실제 검증 가능한 관계와 모순되면 unknown으로만 낮춘다. 파생 coverage 상태는 상향하지 않는다. 마지막에 기존 validate_review/validate_document의 모든 규칙을 그대로 통과해야 한다. 추가 실패 또는 과제0개면 게시하지 않는다.
