# Bridge 기본 텍스트 교체 — Spec

Study EZ 요청을 시작하면 이전 입력 텍스트 자체는 충돌로 취급하지 않는다. 다운로드 전 스냅샷과 비교해 중간 수정/이동/취소가 없을 때만 입력창 텍스트를 비우고 현재 프롬프트를 넣는다. 동일 텍스트도 결과는 한 부만 남는다. textarea와 contenteditable, ChatGPT/Gemini/Claude의 공통 입력 경로에 적용한다.

알 수 없는 기존 첨부의 자동 제거 범위는 넓히지 않는다. 기존 소유 확인 또는 명시 복구가 필요하다. 완료 대화·링크·미저장 응답·학습/검수/서버 작업과 다른 작업 변경은 보존한다. 외부 전송 검증은 로컬 모의 화면으로 대신하며 전송 규칙 자체는 바꾸지 않는다.
