# 현재 사람 승인 근거

2026-11-05 최초 요청: “지금까지 한 거 전부 Git에 커밋, 푸시해주고, Git을 변경하면 자동으로 배포되게 해줄 수 있어? 슬슬 공동작업을 준비하고 있어서.”

권한 연결의 정확한 범위를 질문한 뒤 사용자가 “승인 — 위 범위로 자동 배포 연결”을 선택했다.
승인된 구체적 범위는 다음과 같다.

- Google Cloud 전용 배포 계정 생성, 소스 배포·서비스 사용·기존 서버 실행 계정 사용 권한.
- 이 저장소 ID/소유자/master/배포 workflow로 제한된 Google 임시 인증(OIDC), 장기 키 생성 없음.
- GitHub에 계정/연결 이름 변수 두 개 등록. 운영 DB/R2/runner 비밀 복사 없음.
- Cloudflare 웹은 같은 커밋의 API 배포 확인 후 공개. 브랜치 preview 자동 배포 중지.

자동 승인 검토의 첫 차단은 구체적인 지속 권한 변경의 별도 승인 부재가 이유였다.
그 이후 위 사람의 명시적 승인을 받아 동일 범위만 실행했다. 이 기록은 자동으로 만든 승인 발언이 아니다.
