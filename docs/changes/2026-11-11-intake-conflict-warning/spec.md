# 접수 단계의 출처 충돌 인용 누락을 경고로 — 명세

- `quizbank/connection_generate_v3.intake_rejections(errors)`: `validate_bank` 오류 목록을 받아 접수에서 뺄 문항을 돌려준다.
  - `^\S+: \S+ 기준 문항 누락$`(해결된 충돌의 출처 인용 누락)은 건너뛴다. 같은 문구는 한 번만 `접수 경고(출처 충돌 인용 누락, 진행): …`로 출력한다.
  - 문항 ID(`Q…`)로 시작하는 오류는 이전처럼 `{'question_id', 'error'}`로 돌려준다(중복 포함, 이전과 같은 기록).
  - 그 밖의 오류는 이전처럼 `문제은행 형식 오류가 특정 문항에 속하지 않습니다…`로 멈춘다.
- /3 `_intake`와 /4 `_intake`가 이 함수를 쓴다.
- `intakeProjection`·`rejectedAtIntake` 형식은 바뀌지 않는다. 경고는 결과 계약(`result3`/`result4`) 칸에 새로 넣지 않는다. 최종 은행의 `validation`이 같은 오류를 그대로 보존한다.
- 바꾸지 않는 것: 검사기, 프롬프트, 모델 고치기 단계(이 오류를 고치기 과제로 보내지 않는다), 수정 상한.
