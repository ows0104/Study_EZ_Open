# 계약
이 도구는 기본이 읽기 전용 검사다. 명시적 계속/driver 호출에서만 같은 native session을1회 계속한다. 원래 실패 ledger·정확한 original prompt/inputHash·런타임/모델·세션/cwd·완료/취소/오류 출력 없음·원본/완료 캐시·자료 지문·이전 알려진 부분 사용량을 확인한다. 기존 프로세스가 종료됐어야 한다. 이전 사용량 미확인은0으로 만들지 않으며 완료 후 세션 누적 사용량과 새 사용량을 함께 보존한다.
모델에는 동일 원본 계약의 AUTHOR 출력 완료만 요청한다. 원문/내용/검수 판정을 부모가 수정하지 않는다. budget은 같은 원래 문항 정리 시도1회를 유지하며 추가 교정 라운드를 만들거나 상한을 초기화하지 않는다. 실제 model turn 완료와 모든 기존 AUTHOR/원본ID/지도계보/그림 검증 후에만 캐시를 채운다. 실패/중단/변조/재실행은 보류한다.
삭제된 임시 작업 공간은 검증한 전용 temp경로에 기존 material 사본의 동일 바이트만 복원한다. 이미 있는 다른 내용은 덮어쓰지 않는다. 원래 실패한 서버 작업은 그대로 두고 로컬 결과를 확보한다. 기존 Agent의 취소/데스크톱 중지 확인을 유지한다. 완료 후 같은입력 재개 버튼으로 기존 작업을 이어간다. API/DB/웹 배포나 기존 은행·학습 교체는 하지 않는다.
