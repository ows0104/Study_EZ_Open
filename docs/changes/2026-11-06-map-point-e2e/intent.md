# 심내막염·CNS Map·포인트에서 생성·검수·풀이 E2E 실험

## 문제와 사용자 효과
사용자: “좋아. 이제 문제까지 만들고 풀어보면서 파이프라인을 End-to-End 실험해보자.” 동일 채팅의 심내막염·중추신경계감염 Map 및 최종47/60포인트를 실제 문항 생성·검수·연결 대조·학습 순서·풀이까지 이어 본다.

## 범위와 성공 기준
기존 원본·Map·포인트를 읽기 전용 입력으로 고정하고 강의별로 독립 실행한다. 기존 root-generation/2와 NativeJson 실행기를 재사용한다. 두 JSON을 엔진의 상세 학습 구조로 정규화한 결과는 파생본으로 표시한다. 생성/원본검수/독립정답검수와 최대3회 보완 상한을 유지한다. 실제 학생용 풀이 UI·서버를 격리 DB에서 실행하고 답 공개·평가·새로고침 후 보존을 확인한 후 사용자가 풀 수 있게 제공한다.

## 근거·미정 사항
현재 요청은 같은 승인 자료와 생성된 Map·포인트를 이용한 문제 생성·검수 및 로컬 풀이 실험의 실행 지시다. 과거에 승인된 원본 OpenAI 전송과 파생 포인트 전송 근거를 보존하고, 이번 목적의 자료 사용 범위를 명시한다. 운영 요청548·기존 은행·학습 기록은 변경하지 않는다. 공개·운영 활성화가 필요하면 구체적 검토 결과를 준비해 중요 승인을 판단한다. 실제 기존 사용자 학습 결과를 합성 평가로 대신하지 않는다.

자동 승인 검토는 문제 생성 목적의 새 외부 전송 동의가 기존 추출 승인에 포함되지 않는다는 이유로 두 실행을 프로세스 생성 전에 차단했다. 추가 전송·모델 호출0건이며 우회하지 않았다. 이후 사용자가 원본 PDF2개(58/13쪽), Map2개, 최종47/60포인트의 OpenAI Codex/GPT 전송·문제 생성·원본/독립 정답검수, 생성문항/검수결과의 후속전송 및 강의별 최대3회 보완/재검수를 묻는 질문에 “위 자료 전송·문제 생성·검수 승인”을 선택했다. 이 구체적 범위에만 적용한다.
