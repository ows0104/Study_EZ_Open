## 범위와 성공 기준
- 운영에서 답을 연 뒤 해당 PDF 쪽이 실제로 그려진다. 원인: PDF.js가 R2 서명 URL을 fetch로 읽는데 R2 버킷에 CORS 규칙이 없다(2026-11-07 preflight 403 재확인). 서버 경유로 바이트를 넘긴다.
- 개념지도는 강의 → 주제 → 문항의 트리로 보이고, 끌기·휠/핀치·버튼으로 확대/이동하며, 확대 또는 주제 클릭 시 문항이 펼쳐진다. 노드를 누르면 옆 패널에 세부(문항·쪽·학습 상태·중요도 근거, 답은 접힘)가 나온다. 현재 문제의 위치가 강조된다.
- 공개(3번)는 코드가 아니라 운영 공개 설정(관리자 시범 → 승인된 학생)이다. 이 작업에서 바꾸지 않고 별도 승인으로 다룬다.

## 근거·미정 사항
- 공개 판 261104_02: 실제 문항 98개가 11개 주제 개념(C###)에 하나씩 매달린다(parent_ids는 비어 있음, 관계는 C### → 답 개념 association 98개). 트리는 이 실제 연결만으로 만들고 새 의학적 계층을 추측하지 않는다. 같은 이름의 주제 개념은 한 노드로 합친다.
- 원본 PDF는 22.7MB. 전체 전송 대신 Range 요청을 넘겨 필요한 부분만 읽게 한다.
- R2 CORS 규칙이 나중에 붙으면 경유 경로를 지우고 서명 URL로 돌아갈 수 있다(덱 모아받기와 같은 사정).
