# 감염과 면역 예습의 하위 폴더 필기 탐색 누락 — 배포 준비

## Review와 Test

원인: 연도 폴더 바로 아래 PDF만 읽어 2025/1차와 2차의 70개 PDF가 누락됐다.
재귀 탐색을 추가하며 보관/숨김/작업 폴더·심볼릭 링크·junction은 제외한다.
사본 판정은 같은 폴더 안에서 수행하고 기존 연도·교수·회차·최신 판·UID 규칙을 유지한다.

readiness는 기존 매칭·확정 매칭·ahead 규칙과 공통 run ID 배정을 재사용하며 생성/대화 회수/파일 쓰기를 하지 않는다.
링크만 있고 작년 자료가 없거나 매칭되지 않으면 준비됨으로 표시하지 않고 시작·자동 등록을 막는다.
파생 입력은 명시적 매칭과 원본/합본 SHA-256을 확인하며 변경 시 보류한다.

- runner: 전체 504개 통과(494 + 새 GUI 8 + 기존 상태 창 2).
- desktop-db: 격리 SQLite의 링크만 존재/작년 자료 누락/매칭/시작 거절/상한·취소·재개 계약 통과.
- 읽기 전용 실자료 확인: 261102_02 → 251103_02, 261103_01 → 파생 입력 251104_01.
- 합본 입력: 작년 위장관·피부연조직 63쪽 + 요로감염·폐렴 64쪽 = 127쪽.
  전 페이지의 크기·내용 스트림을 원본과 대조했고 시작·접합 앞뒤·마지막 페이지를 렌더링해 확인했다.
  원본 PDF는 변경하지 않았다. 251104_01은 실제 역사적 강의가 아닌 충돌 없는 파생 작업 ID다.
  출처/해시/대상/승인은 runs/_materials/감염과 면역/prequiz-inputs/261103_01.json에 기록했다.
- 실제 작업 515는 PDF 렌더용 uv Python 프록시 실행 거절로 must_know 출력 전에 실패했다.
  실행 환경을 기존 agent.ps1과 동일한 설치 Anaconda로 맞췄고, 프로그램의 재시작 선택도 일치시켰다.
  권한/보안 설정은 변경하지 않았다. 작업 516은 같은 261102-1655 시도와 prep를 재사용해 재개했으며
  127개 PDF 이미지 생성 및 첫 저작 단계 진행을 확인했다. 완료·업로드로 간주하지 않는다.

## 로컬 릴리스와 운영 범위

현재 작업 트리의 정본 source/plan 지문은 state.json 검사·리뷰 근거다.
이 저장소의 다른 작업은 커밋·배포하지 않는다. 서버/웹 배포·DB 스키마 변경은 없다.
사용자의 “하위 폴더도 읽도록 고치고 준비 상태 판정도 수정해줘. 내일 예습덱도 다시 돌려줘”를
해당 로컬 코드 반영과 2026-11-03 감염과 면역 예습 재실행 승인으로 적용한다.

원본 두 편과 매칭 이력은 보존하고, runs/_materials의 검증된 합본과 _pairs의 대상 하나만 추가했다.
변경한 매칭은 내일 TBL의 네 주제 전체에 한정한다. 현재 시간표 범위는 감염과 면역이다.
러너를 유휴 상태에서 새 코드로 연결하고 기존 실패 기록을 보존한 새 예습 요청을 force 없이 등록한다.
완료·실행 중·중지·취소 및 링크 없음은 별개로 보고하며 검수 상한을 초기화하지 않는다.
