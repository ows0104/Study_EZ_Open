# 학습자 여정과 핵심 화면 구성 — 설계

상태: 합의한 화면·여정의 방향을 정리한 사용자 검토본 (최초 2026-10-27, 후속 반영 2026-10-29 KST).
승인 범위: intent에 따른 공동 설계와 이 spec의 정리. 앱 구현·원본 추출·문항 변경·운영 반영은 포함하지 않는다.
근거: [사이트 전체 intent](../2026-10-27-site-intent/intent.md), [이 작업의 사용자 결정 기록](intent.md).

## 요구사항과 수용 기준

### 검토할 핵심 합의

| 항목 | 정한 방향 |
|---|---|
| 첫 화면 | 전체 범위의 본 곳·빈 곳·현재 앎을 먼저 보고, 중요한 미학습을 발견한 뒤 추천 학습을 바로 시작 |
| 강의별 현황 | 강의마다 한 개의 구간 막대로 회상 가능·공부함/회상 보강·아직 안 봄을 함께 표시 |
| 지도 첫 진입 | 뼈대와 큰 가지만 먼저 표시하고 원하는 가지를 펼침. 접힌 가지에도 미학습·중요 미학습 수 유지 |
| 학습 방식 | 머릿속 회상 → 정답 확인 → 자기평가. 입력을 매번 요구하지 않으며 한 가지의 완벽한 숙련을 다음 진입 조건으로 삼지 않음 |
| 현재 위치 | 강의·가지·지점 경로와 작은 지도에서 현재 학습 중인 곳을 계속 표시. 지도 탐색 후 같은 질문 상태로 복귀 |
| 평가 후 이동 | 평가 즉시 다음 질문으로 이동. 새 현재 위치와 방금 지점의 변화를 잠깐 보여주며 추가 확인·대기는 요구하지 않음 |
| 오늘 완료 | 오늘 새로 공부한 범위·회상 상태 변화·남은 중요한 미학습을 함께 표시. 기본 행동은 오늘은 여기까지, 잔여 범위 확인은 선택 |
| 회상 방향 | 같은 관계라도 방향별 학습 상태를 따로 표시. 여러 방향·문항으로 공부해도 같은 내용의 전체 범위를 중복 증가시키지 않음 |
| 내용 집계 | 같은 학습목표는 한 번만 집계. 한 방향 이상 공부하면 한 번 접한 내용, 모든 필수 방향을 도움 없이 회상하면 회상 가능. 필요한 방향만 필수로 정함 |
| 자료가 추가되는 블록 | 시험일·전체 강의 목록을 먼저 파악하고 준비된 강의부터 학습. 슬라이드·필기가 추가되면 지도와 추천 분량을 보정 |
| 학습 시작 기준 | 예습은 기존 예습 퀴즈를 이용. 새 강의 지도 학습은 필기가 들어온 뒤 시작 |
| 지도 범위 | 강의마다 독립 지도. 블록 전체는 강의별 현황을 모아 보고 현재 강의 간 지도 연결·통합은 하지 않음 |
| 하루 시간 설정 | 시간 입력 없이 시험일까지 남은 기간과 준비된 범위·학습 상태로 필요한 분량을 먼저 추천 |
| 시험 전 목표 | 시험 2일 전까지 전체 범위를 한 번 공부하는 것을 목표로 하고 마지막 이틀은 복습·약점 보완 중심. 늦게 들어온 필기·중요 미학습은 마지막 이틀에도 새 학습 가능 |
| 추천 구성 | 고정 비율 대신 필요한 새 진도와 우선순위 높은 복습을 함께 추천. 복습 증가로 새 범위를 계속 못 보는 일을 막음 |
| 보완량 조정 | 보완 10개 고정안을 사용하지 않고 복습 필요도·실제 학습 기록에 따라 자동 조정하는 방향. 세부 산정은 공동 검토 |
| 분량 증가가 필요한 날 | 필요한 새 진도와 급한 복습이 최근 학습량을 넘으면 두 가지를 기본 추천에 포함해 분량을 늘림. 최근 학습량은 강제 상한으로 쓰지 않음 |
| 콘텐츠 준비의 목적 | 필기·족보에서 문제·출제 포인트·개념트리를 만들고, 포인트별 문제의 누락·적절성을 검증하며 트리에 따라 큰 흐름을 이해하는 학습 순서를 구성 |

위 표는 사용자가 선택한 방향이다. 아래의 구체적인 배치·기호·문구·숫자·의학 사례는 검토 예시이며,
최종 UI나 학습 계산 계약으로 일괄 확정한 것이 아니다. 후속으로 정할 사항은 문서 끝에 모았다.

### 대표 여정

전체 현황 확인 → 오늘 추천 학습 시작 → 회상·정답 확인·자기평가 → 다음 질문으로 즉시 이동 → 오늘 추천 학습 완료 → 오늘의 변화 확인 → 오늘은 여기까지.
남은 범위를 확인하거나 더 공부하는 것은 완료 후의 선택이며 기본 종료 흐름을 막지 않는다.
강의 지도를 보고 싶은 경우 홈이나 학습 중에 해당 강의의 지도를 열고 원래 위치로 돌아온다.
지도 방문은 학습 시작의 필수 단계가 아니다.

| 상황 | 필요한 경험 |
|---|---|
| 처음 공부함 | 전체 시험 범위와 빈 곳을 보고 추천을 시작한다. 큰 뼈대부터 회상하며 다음 가지를 만난다 |
| 다음 날 돌아옴 | 이미 본 범위는 유지하고 현재 앎·복습 필요와 중요한 미학습을 구분한다. 재조정한 오늘 분량을 시작한다 |
| 공부를 중단했다 돌아옴 | 재개 위치와 현재 저장 상태를 확인한다. 정답을 열어본 것만으로 회상 성공을 만들지 않는다 |
| 일부를 틀림 | 해당 평가를 남기고 다음 내용으로 진행할 수 있다. 한 가지의 완벽한 숙련을 진입 조건으로 삼지 않는다 |
| 오늘 분량을 마침 | 오늘 완료와 범위·회상 변화를 확인한 뒤 오늘은 여기까지로 마친다. 잔여 확인·추가 학습은 선택이다 |
| 오늘 분량을 못 마침 | 다음 날 남은 기간·범위로 조정한다. 못한 범위를 숨기거나 완료 처리하지 않는다 |
| 준비되지 않은 강의·개념이 있음 | 준비 필요 또는 평가 자료 부족으로 표시하고 전체 범위에는 남긴다 |

### 블록 시작부터 자료가 추가되는 흐름

사용자 확인: 시험 일정·전체 강의 목록은 미리 알 수 있고 슬라이드·필기는 블록 진행 중 추가된다.
준비된 강의부터 공부하며 새 자료가 들어오면 지도와 추천 분량을 보정한다.
사용자 후속 선택: 예습은 기존 예습 퀴즈를 이용하고 새 강의 지도 학습은 필기가 들어온 뒤 시작한다.
필기가 없는 강의는 기존 예습 경로를 유지한다. 필기 도착과 실제 학습 준비 완료의 구체적인 확인 절차는 후속 설계한다.
각 강의는 독립 지도를 가지며 블록 전체 화면은 강의별 준비·학습 현황을 모아 보여준다.
새 자료는 해당 강의 지도를 보정하고 오늘 추천을 조정하는 데 반영하며, 다른 강의와 연결한 통합 지도를 만들지 않는다.

이를 화면과 추천에 반영하기 위한 세부 검토안:

- 처음부터 전체 강의 목록을 보여준다. 자료 대기·학습 준비·공부한 상태를 구별하며 자료가 없는 강의를 숨기지 않는다.
- 자료가 없는 강의의 세부 목표 수를 아는 것처럼 꾸미지 않는다. 준비된 내용의 진행과 아직 구체화되지 않은 강의를 함께 표시하고 준비된 범위의 완료를 전체 시험 범위 완료로 표현하지 않는다.
- 준비된 강의의 새 범위와 복습으로 오늘 학습을 구성한다. 준비되지 않은 범위를 완료로 처리하거나 반복 가능한 기존 내용만으로 전체 준비가 충분한 것처럼 표시하지 않는다.
- 새 자료는 확인 후 기존 지도·근거·중요도와 대조해 추가·보정할 부분을 구분한다. 단순 자료 도착만으로 내용 검증·학습 준비가 끝났다고 간주하지 않는다.
- 내용이 유지된 목표의 기존 학습 기록을 보존한다. 새 목표·수정된 답·구조 재배치의 구분과 기록 연결은 후속 계약에서 정하며, 강의 전체를 일괄 초기화하거나 새 내용을 자동 회상 가능으로 만들지 않는다.
- 자료 추가로 분모나 필수 방향이 달라진 변화는 학습·망각 변화와 구분한다. 오늘 완료를 지우거나 완료한 분량을 밀린 숙제로 다시 쌓지 않는 기존 원칙과 함께 추천을 보정한다.

구체적인 준비 상태의 문구·범위 확정 표시·검증 절차·학습 도중 보정 여부는 검토 전이다.
첫 Concept Tree 작업의 강의별 뿌리 범위와 구현 보류를 유지하며 자료 처리·전체 Tree 구현으로 확대하지 않는다.

### 핵심 화면의 역할

화면은 정보와 행동의 단위다. 실제 URL·탭·패널 수는 아직 정하지 않는다.

| 화면/맥락 | 사용자가 답을 얻는 질문 | 주 정보 | 기본 행동 |
|---|---|---|---|
| 전체 현황 홈 | 어디까지 봤고 어디가 비었는가? | 시험 범위, 강의별 첫 학습/앎, 중요한 미학습, 오늘 추천 | 오늘 학습 시작 또는 재개 |
| 학습 | 지금 무엇을 회상해야 하는가? | 질문, 현재 강의·학습 위치, 정답·해설·근거, 자기평가, 오늘 진도 | 답을 떠올림 → 정답 확인 → 자기평가 → 다음 |
| 오늘의 변화 | 오늘 무엇이 달라졌는가? | 오늘 완료 여부, 새로 공부한 범위, 앎의 변화, 회복한 약점, 중요한 잔여 범위 | 기본은 오늘은 여기까지. 잔여 범위 확인은 선택 |
| 강의별 지도 | 이 개념은 어디에 붙는가? | 강의 뼈대와 가지, 개념별 첫 학습/앎/중요도 근거, 관련 위치 | 선택 지점 보기·공부 또는 원래 학습으로 복귀 |

### 홈의 정보 구성

1. 어떤 시험·범위를 보고 있는지, 일정이 등록되었다면 시험일까지 남은 기간.
2. 전체 범위와 강의별 첫 학습·현재 앎을 함께 보여주는 시각 현황.
3. 특히 중요한 미학습 부분의 위치·내용. 요약만 제시하면 전체 목록을 확인할 경로를 둔다.
4. 매일 조정한 오늘 분량과 추천 이유의 짧은 설명, 시작/재개 행동.

사용자 선택: 강의별 막대형. 한 번 공부함과 회상 가능을 한 막대 안에서 함께 보여준다.
현재 프로젝트의 `web/src/bank/StudyOverview.tsx`의 StageBar와 `overview.css`를 참고했다.
강의마다 한 개의 구간 막대를 두고 전체 범위를 회상 가능 / 공부함·보완 필요 / 아직 안 봄으로 나눈다.
보완 필요에는 추가 필수 방향의 미학습과 현재 회상 부족을 포함하고 지도에서 원인을 구분한다.
구간의 합은 전체 범위와 같고 중복 합산하지 않는다. 한 번 접한 전체는 회상 가능과 보완 필요의 합이다.
회상 가능은 한 번 공부한 범위 안에 포함된다는 사실을 숫자와 문구로 함께 보여준다.
좁은 화면에서도 전체 요약과 추천 시작 행동을 상단에서 찾을 수 있게 배치한다.
강의 단위로 묶으며 전 강의를 하나의 새 Tree로 합치지 않는다. 홈의 강의별 막대와 오늘 추천은
독립 강의 지도를 함께 안내하는 역할이다. 여러 강의를 추천에 포함하더라도 지도 연결이나 목표 통합을 뜻하지 않는다.
완료율 하나로 서로 다른 상태를 합치지 않는다. 문항 수를 곧 개념 수로 표현하지 않는다.

현재 프로젝트의 기존 막대는 미열람·인지·인출·기억 유지의 카드별 구간이다.
기존 인지는 열어봤지만 평가하지 않은 카드도 포함하므로 이번 intent의 첫 학습과 같다고 간주하지 않는다.
기존 인출·기억 유지의 등급/날짜/숙련도 조건을 새 개념의 앎 기준으로 자동 복사하지 않는다.
표현 방식을 참고하며 기존 지표·학습 기록은 보존한다. 실제 집계 단위와 상태 연결은 후속 설계한다.

### 오늘 추천의 분량과 구성 — 공동 검토 초안

상태: 사용자는 시간 설정 없이 필요한 분량을 추천받는 방식을 선택했다.
시험 2일 전까지 전체 첫 학습, 마지막 이틀 복습·약점 보완 중심과 늦은 필기·중요 미학습의 새 학습을 합의했다.
고정 비율 대신 필요한 새 진도와 우선순위 높은 복습을 함께 추천하는 방향도 합의했다.
아래 일일 목표 계산의 세부 조건·보완 한도·초기 수치는 사용자 검토 전이다.

#### 시간 설정 없이 분량을 추천하는 기준

- 첫 학습 목표일까지 필요한 범위 확대 페이스: 시험 2일 전을 목표로 준비된 강의의 미학습 목표와 그때까지 남은 학습일을 보고 하루 진도를 참고한다. 미학습 목표 수를 남은 학습일로 나눈 값은 현재 준비 범위의 참고값이며 시험 준비 전체를 보장하는 분량이 아니다. 목표일 이후의 잔여·늦은 필기는 별도 보정하며 0 이하의 남은 날로 같은 계산을 계속하지 않는다.
- 오늘의 구체 분량: 시간 입력이나 매일의 계획 선택 없이 새 내용·새 회상 방향·복습의 목표 수와 구성을 제안하고 바로 시작하게 한다. 실제 학습 속도·완료 기록은 관측이 있을 때 분량 추정의 보조 근거로 검토하며, 사용자가 공부할 수 있는 시간을 안다고 간주하지 않는다. 추정이 잠정이면 이를 구분한다.

필기가 아직 없는 강의는 새 지도 학습 대상으로 넣지 않고 대기 범위로 남긴다.
앞으로 들어올 필기·강의 일정도 재계획에 고려하며, 모르는 목표 수를 확정값으로 만들어 계산하지 않는다.
최근 학습 진도보다 필요한 진도가 많으면 필요한 양과 관측된 속도의 차이를 보여주는 안이다.
가용 시간이 입력되지 않은 상태에서 불가능·충분함을 단정하지 않는다. 추천의 완료가 전체 시험 준비에
충분하다고 꾸미거나, 남은 범위를 숨기거나, 오늘 분량을 무제한 늘리지 않는 안이다.

합의한 첫 학습 목표: 시험 2일 전까지 전체 범위를 한 번 공부하고 마지막 이틀은 복습·약점 보완 중심으로 둔다.
한 번 공부함은 앞서 합의한 목표별 첫 접촉 기준을 따르며 모든 필수 방향의 회상 가능을 요구하지 않는다.
늦게 들어온 필기와 중요한 미학습은 마지막 이틀에도 새 학습으로 배정한다. 첫 학습 목표일은 새 학습의
차단 조건이 아니다. 목표일이 지났다는 이유로 잔여를 완료 처리하거나 숨기지 않는다.
마지막 이틀에도 덜 중요한 미학습의 위치와 잔여는 열람할 수 있고, 추천 우선순위와 범위 표시는 구분한다.
목표일·복습 중심 구간의 정확한 날짜/시각 경계와 재계획 시점은 시험 일정 계약에서 구체화한다.

#### 새 학습과 복습의 구분

| 종류 | 포함할 내용 | 우선순위와 집계 |
|---|---|---|
| 새 내용 | 어떤 방향으로도 아직 공부하지 않은 목표 | 안 본 강의의 뼈대·큰 가지와 중요한 미학습부터. 한 번 접한 내용의 범위가 늘어남 |
| 새 회상 방향 | 이미 접한 목표의 아직 안 해본 필수 방향 | 첫 방향 학습으로 표시. 같은 목표의 범위를 다시 늘리지 않으며 다른 미학습 강의를 장기간 막지 않음 |
| 복습 | 이미 시도한 방향의 회상 보강·복습 시점 도래 | 중요한 반복 오답·회상 부족과 복습이 필요한 내용부터. 이미 잘 아는 내용의 불필요한 반복을 줄임 |

추천의 큰 구성은 새 학습과 복습으로 보여주되, 새 학습 안에서도 새 내용과 새 방향을 구별하는 안이다.
회상에 실패한 새 목표도 시도·정답 확인을 마치면 첫 학습 진전을 인정하고 다음으로 진행한다.
같은 날 반복 오답을 즉시 성공할 때까지 다시 내어 새 범위의 진입을 막지 않는다.

#### 배분 방식 — 근거 조사 후 재검토

앞서 제안한 새 학습 70%·복습 30%는 연구로 확인한 비율이나 사용자 합의가 아니므로 채택하지 않은
초기 가설로 남긴다. 사용자 요청에 따라 Anki 공식 문서와 인출·간격·교차 학습 연구를 확인했다.
자료와 해석의 범위는 [조사 기록](review-notes.md)에 연결했다.

합의한 방향은 범위 계획과 복습 시점의 역할을 분리하는 것이다. 시험 2일 전까지 첫 접촉에 필요한
오늘의 새 범위를 확보하고, 방향별 회상 기록으로 간격 반복의 복습 후보를 선정한 뒤 중요도·시험일까지의
기간·당일 부담을 보고 오늘 추천에 함께 배정한다. 비율은 그 결과로 달라질 수 있다.
Anki의 FSRS는 복습 시점 모델의 후보이며 채택·구현을 승인받은 상태가 아니다.
방향별 상태와 도움 여부·실패/성공 평가의 입력 계약, 초기 기록이 부족할 때의 처리, 복습의 하한/상한은 미정이다.
모델의 회상 확률 추정은 실제 앎·시험 정답률의 보증으로 표시하지 않는다.

복습 후보가 많을 때도 새 범위가 밀리지 않게 하되, 추천에서 미룬 복습의 필요와 기존 평가·시각을 지우지 않는다.
일일 숙제를 단순 누적하지 않는 것과 미완료 복습을 없던 것으로 만드는 것은 구분한다.
새 학습 중에는 내용 첫 접촉의 진도를 먼저 확보하고 필요한 새 방향을 함께 배치한다.
남은 날에 비해 미학습이 많으면 새 학습 비중을 높이는 안이다. 필요한 복습 자리도 남기되,
현재 진도로 미학습이 남을 것으로 추정되면 그 범위를 보여준다. 고정 비율로 첫 접촉의 진도를 막지 않는다.
복습 후보가 없으면 비율을 맞추려고 이미 아는 문제를 반복하지 않는다. 준비된 새 범위가 없으면
필요한 복습을 추천하고 자료 대기 범위를 별도로 보여준다. 억지로 시간이나 문제 수를 채우지 않는다.

시험이 가까워지면 고정 비율보다 중요한 미학습과 중요한 반복 오답을 먼저 배정하되, 반복 오답만으로
추천을 채워 중요한 새 내용을 못 보는 상황을 막는다. 첫 접촉이 충분히 진행되면 남은 필수 방향과
복습의 비중을 늘리는 안이다. 마지막 이틀의 복습 중심 원칙은 합의했으며, 그 전부터 긴급도를 높이는
조건·각 최소량·반복 상한과 소요 시간 추정 방식은 미정이다.

#### 새 진도 확보와 보완량 자동 조정 — 검토안

사용자는 보완 10개 고정보다 복습 필요도와 실제 학습 기록에 따른 조정을 선택했다.
평일 강의 유입은 하루 3~6개, 평균 약 4개다. 강의 일정과 필기 도착 시점은 같다고 가정하지 않는다.
아래는 평소 첫 학습 기간의 계산 제안이며 세부 공식·수치는 구현 기준으로 승인받은 상태가 아니다.

1. 준비된 범위에서 어떤 방향으로도 아직 공부하지 않은 목표 수를 U, 첫 학습 목표일까지 오늘을 포함해 배정할 수 있는 날 수를 D로 둔다. D가 양수일 때 오늘의 새 내용 목표 N은 U/D를 올림한 값으로 삼는 안이다. U가 0이면 N도 0이다.
2. N은 복습 후보 수와 별도로 확보한다. 같은 목표의 다른 방향·다른 문항·반복은 새 내용 목표를 대신 채우지 않는다. 실패해도 회상 시도·정답 확인을 마치면 첫 접촉으로 인정한다.
3. 새 내용은 미학습 강의의 뼈대·큰 가지와 중요 미학습부터 고른다. 하나의 강의나 가지의 완벽한 숙련을 선행 조건으로 삼지 않는다. 구체적인 강의 사이 배분은 후속 설계한다.
4. 보완 학습은 이미 공부한 방향의 복습과 아직 해보지 않은 필수 방향으로 구분하되, 이 둘이 새 내용 N을 잠식하지 않도록 합친 일일 한도 K를 별도로 둔다. 중요도·반복 오답·현재 회상 부족·복습 시점 등을 보고 후보를 정한다. 후보가 적으면 억지로 채우지 않는다.
5. 보완량 K는 고정 개수가 아니라 실제 일일 학습량의 참고값과 오늘의 새 진도 부담, 우선순위 높은 보완 필요량으로 조정한다. 아래의 구체 계산은 검토안이며 기록이 없는 초기 처리도 추가 설계한다.
6. 복습을 모두 끝낸 뒤 새 내용으로 진입하게 하지 않는다. 첫 학습 묶음에서 새 범위에 진입하고 이후 보완을 섞는 안이며, 정답 여부가 새 범위 진입을 잠그지 않는다.
7. N과 K가 정해진 오늘 분량은 세션 중 오답이 생겼다는 이유로 계속 늘어나지 않는다. 한도 밖의 보완은 대기 범위로 표시하고 추가 학습은 선택으로 둔다. 미뤘다는 이유로 필요·기록·평가 시각을 지우지 않는다.

**앞으로 들어올 범위의 보정:** 오늘 준비된 U만 마지막 날까지 균등 분배하면 추가 강의가 뒤에 몰릴 수 있다.
남은 강의 일정과 기존 강의에서 실제 확인한 목표량을 참고해 앞으로 들어올 학습량을 예측하고,
준비된 범위를 미리 공부해 여유를 만드는 보정을 제안한다. 평균 4강을 고정 일일 진도로 쓰지 않는다.
정확한 강의 일정이 있으면 평균 유입보다 우선하며 주말을 학습일에서 자동 제외하지 않는다.
아직 준비되지 않은 목표의 추정치는 계획용으로 구분하고 지도·전체 막대의 확정 분모에 넣지 않는다.
지금 준비된 범위 이상을 새 학습으로 배정하지 않고 필기 도착 후 실제 범위와 예측 차이를 보정한다.

**최근 학습량 참고값:** 최근 며칠의 실제 신규·보완 학습으로 평소 하루 학습량 H를 추정하는 안이다.
단순 클릭·같은 문제의 즉시 반복으로 부풀리지 않고 자료 대기·미접속·저장 실패와 실제 학습을 구분한다.
추가 학습이나 하루 몰아공부가 다음 날 기본량을 즉시 끌어올리지 않도록 대표값을 검토한다.
H는 사용자의 가용 시간이나 실제 능력의 확정 상한이 아니다. 기록 기간·과제별 부담 가중치·조정 폭은
미정이며 사용자에게 시간 입력을 요구하지 않는다. 추정에 필요한 기록이 없으면 잠정임을 표시한다.

**보완량의 기본 계산 후보:** H에서 오늘 확보할 새 진도의 부담을 뺀 여유와 우선순위 높은 보완 필요량 중
작은 쪽으로 K를 정한다. 비교는 같은 부담 단위로 하며 문항 수가 곧 난이도라는 전제를 두지 않는다.
급하지 않거나 아직 복습할 필요가 없는 항목으로 양을 채우지 않는다. 미시도 필수 방향과 복습은
같은 보완 범위에 배정하더라도 상태·후보 사유를 구별하며 가짜 복습 이력을 만들지 않는다.
따라서 새 진도가 가볍고 복습 필요가 크면 보완이 늘고, 새 진도가 크면 덜 급한 보완부터 줄어든다.

사용자 선택: 필요한 새 진도와 급한 복습이 H를 넘는 날에는 둘을 기본 추천에 포함해 분량을 늘린다.
급한 복습을 추가 권장으로만 분리하거나 H에 맞추려고 새 진도를 줄이지 않는다. 늘어난 이유와 구성,
최근 학습량과의 차이를 보여준다. 모든 보완 후보를 급한 복습으로 간주해 한꺼번에 넣는 것은 아니다.
따라서 보완량 계산 후보에는 오늘 포함할 급한 복습량을 하한으로 두고, 나머지 덜 급한 보완은
H에서 새 진도·급한 복습을 배정한 뒤 남는 여유와 필요도에 따라 조정한다. 같은 후보는 중복 배정하지 않는다.
급한 복습의 판정·선정 수치와 H를 추정할 기록이 없는 초기 처리는 미정이다.
보완 10개나 고정 새 학습/복습 비율로 이 예외를 대신하지 않는다. 분량 증가일의 결과만으로
다음 날의 평소 학습량을 즉시 올리거나, 세션 중 오답 때문에 오늘 분량을 계속 늘리지 않는다.

필기 대기 강의는 U에 세부 목표를 추정해 더하지 않고 별도 표시한다. 새 필기가 준비되면 U와 이후 계획을
갱신한다. 마지막 이틀에는 위 U/D 계산을 연장하지 않고 복습·약점 중심과 늦은 필기·중요 미학습의
예외를 적용하며, 이때의 보완량도 복습 필요와 실제 기록에 따라 조정하는 기준을 별도 검토한다.
새 내용 N 자체가 최근 학습량보다 매우 커져도 필요한 새 진도는 기본 추천에 유지하고 증가 이유와 잔여를
보여준다. 미완료 시에는 실제 남은 범위로 다음 날 다시 산정하며 전날 목록을 그대로 누적하지 않는다.

#### 재계획과 하루의 끝

매일 남은 기간·준비 범위·실제 학습 상태로 다시 산정한다. 전날 미완료 목록을 오늘 할 일 뒤에
그대로 더하지 않는다. 필기가 새로 들어오면 해당 강의와 추천을 보정하되, 학습 중 적용 시점은 후속 논의한다.
오늘 할 일은 끝이 보이는 분량으로 제시하고, 오답이 생겼다는 이유로 완료 조건을 끝없이 늘리지 않는다.
오늘 완료는 합의된 추천 범위를 공부한 결과이며 전체 범위 숙련을 의미하지 않는다.

### 문제·출제 포인트·개념트리의 연결

사용자 의도: 필기·족보를 보고 문제, 출제 포인트, 개념트리를 만들고 출제 포인트마다 문제가
누락 없이 적절하게 만들어졌는지 확인한다. 개념트리는 큰 흐름을 보면서 재미있게 익힐 수 있는
문제 제공 순서를 구성하는 데 사용한다. 아래는 이 의도를 구체화하는 검토안이다.

#### 원본에서 만드는 세 결과물

| 결과물 | 역할 | 검토할 정보 |
|---|---|---|
| 문제 | 실제 회상·판단·시험 연습을 제공 | 질문, 정답, 해설, 평가할 목표·방향과 원본 근거 |
| 출제 포인트 | 원본에서 확인한 물어볼 내용·구별할 내용을 대조 기준으로 제공 | 포인트의 구체 내용, 올해 필기/족보 등 근거와 위치, 중요도·불확실성 |
| 강의별 개념트리 | 강의의 목적·분류·순서·관계 속에 문제의 위치를 제공 | 뿌리 질문, 큰 가지, 학습목표와 연결의 의미·근거 |

세 결과물은 각각 원본을 근거로 만든 뒤 대조하는 기존 독립 추출 의도를 유지한다.
문제에서만 출제 포인트·트리를 역으로 만들어 그 결과로 문제의 완전성을 판정하지 않는다.
사용자가 적은 1·2·3을 반드시 직렬로 실행할 순서나 단일 생성 단계로 확정하지 않는다.
기존 문제가 해당 목표를 적절히 평가하면 연결해 활용하고 세 결과물을 맞추기 위해 전체 은행을 재생성하지 않는다.
족보에 없다는 이유로 올해 범위의 학습목표를 제외하지 않으며, 중요도는 기존 교수별 기준을 따른다.

#### 출제 포인트를 기준으로 문제 검증

포인트별로 원본 근거 → 학습목표·회상 방향 → 대응 문제를 추적할 수 있는 대조표를 제안한다.
문제가 존재하는지뿐 아니라 해당 포인트의 구별·관계·판단을 실제로 묻는지, 정답·해설이 근거와
맞는지도 검토한다. 복합 포인트의 일부만 묻는 문제 하나로 전체 포인트가 검증됐다고 처리하지 않는다.
하나의 포인트에 여러 문제가, 하나의 문제에 여러 포인트가 연결될 수 있어 일대일 개수를 강제하지 않는다.

대조 판정은 충족·부분 충족·누락·근거 충돌·검토 전 등을 구분하는 안이다. 정확한 명칭과 통과 조건은 후속 설계한다.
대응 문제가 없거나 부적절하면 보완 필요를 남긴다. 모든 경우를 자동 생성·승인·공개로 연결하지 않는다.
이 준비 검증 상태는 학습자의 미학습·첫 학습·회상 가능과 별도 상태다.

#### 개념트리를 기준으로 학습 순서 구성

문제를 해당 목표·방향과 트리의 위치에 연결해 뿌리에서 큰 가지와 세부로, 이후 비교·역방향·혼합
회상으로 깊이를 늘리는 기존 합의를 적용한다. 뿌리·전환점에 필요한 구조 질문이 없으면 누락 후보로 표시한다.
구조 제목마다 문제를 기계적으로 추가하지 않고 실제 회상 목표가 있는지 확인한다.
각 단계에서 현재 강의·가지·목표의 위치와 다음 내용으로 이어지는 흐름을 보여준다.
첫 학습에서는 구조를 이해할 수 있는 묶음을 유지하고, 복습에서는 상태·필요도에 따라 다시 방문한다.
트리의 선을 모두 의학적 선행조건이나 강제 순서로 해석하지 않고, 틀려도 다른 범위로 진행할 수 있게 한다.

이 절의 전체 연결 구조는 사이트 설계 방향이다. 현재 첫 작업은 강의별 뿌리이며, 강의 전체 맥락을
살펴 뿌리를 고르는 것과 모든 세부 가지·문항을 한 번에 구현하는 것은 구분한다. 강의 간 통합 지도는 현재 범위 밖이다.
현재까지 원본 추출·새 문제 생성·문항 수정·운영 반영을 실행하지 않았다.

### 강의 지도: 뼈대·가지·학습 상태

이번 검토는 콜린성 약리학을 예시로 한다. 제목과 뼈대 분류는 사용자 인터뷰를 참고했고,
하위 학습 지점·질문·중요도·학습 상태는 화면 검토용 예시다. 실제 강의 전체에서 추출한 결과가 아니다.
현재 단계에서는 지도의 구성과 탐색 경험을 검토하며 의학 내용이나 원본 근거를 새로 확정하지 않는다.

화면 상단에는 강의명, 홈과 같은 의미의 단일 구간 막대, 중요한 미학습 지점으로 이동하는 행동을 둔다.
지도는 위의 뼈대 질문에서 큰 가지와 세부 학습 지점으로 이어진다.

| 지도 요소 | 역할 | 제안하는 표시 |
|---|---|---|
| 뼈대 질문 | 전체 강의를 조직하는 분류·순서·목적 등을 회상하는 지점 | 지도 상단에 질문과 그 질문 자체의 상태를 표시 |
| 큰 가지 | 하위 학습 지점들을 묶는 구조 제목 | 이름, 본 곳/전체, 회상 가능한 곳, 아직 안 본 곳, 중요 미학습 수 |
| 세부 학습 지점 | 실제로 회상하는 목표 또는 관계 | 짧은 이름과 회상 가능/공부함·회상 보강/아직 안 봄 상태 |

구조 제목이라는 이유로 별도의 학습 점수를 만들지 않는다. 예시의 전체 8지점은 뼈대 질문 1개와
하위 지점 7개이며 큰 가지 제목을 다시 더하지 않는다. 실제 집계 단위는 별도 계약에서 정한다.
뼈대 질문이 회상 가능해도 하위 가지를 공부한 것으로 처리하지 않는다.
큰 가지의 요약은 그 가지 아래 학습 지점의 집계이며 그 제목 자체를 외웠다는 판정이 아니다.

#### 처음 보이는 구조와 상태

- 사용자 선택: 처음에는 뼈대와 큰 가지만 보이고, 하위 지점은 원하는 가지를 펼쳐서 본다.
- 아직 안 본 지점도 이름과 연결 위치를 보여준다. 부모의 완벽한 숙련을 요구하는 잠금을 두지 않는다.
- 회상 가능은 체크와 채움, 공부함·회상 보강은 무늬와 상태 문구, 아직 안 봄은 빈 원과 상태 문구로 구분한다.
- 중요한 미학습은 별도 표식으로 표시한다. 중요도는 학습 상태 색을 대신하지 않는다.
- 가지를 접어도 본 곳·빈 곳·중요 미학습 수는 가지 제목 옆에 남긴다. 0개도 표시하고 중요한 미학습이 있으면 강조한다. 접힌 곳을 범위에서 빼지 않는다.
- 구조 연결선은 분류·학습 위치를 보여준다. 이를 의학적 선행관계나 강제 학습 순서로 자동 해석하지 않는다.

#### 눌렀을 때의 경험

학습 지점을 누르면 선택 강조와 함께 경로, 첫 학습 여부, 현재 회상 상태, 회상 질문의 미리보기를 보여준다.
큰 가지 제목을 누르면 그 가지의 집계를 보여준다. 정답·해설을 기본 상세 정보에 펼쳐놓지는 않는다.
중요 미학습 지점 보기 행동은 해당 가지를 펼치고 그 위치를 선택한다. 선택 자체로 학습 기록을 만들지 않는다.
가지 펼침·접힘과 지점 선택은 탐색 동작이며 첫 학습·회상 성공을 기록하지 않는다.
이미지·노드 제목 등에서 답을 직접 확인한 경험을 도움 없는 회상 성공으로 추정하지 않는다.

넓은 화면은 지도 옆에 선택 정보를 둔다. 좁은 화면은 가지를 세로로 이어 배치하고,
선택 정보를 누른 지점 바로 아래에 보여준다. 지도 전체를 축소해 글자를 작게 만들지 않는다.
키보드로 지점 선택·펼침을 할 수 있어야 하며 선택 위치와 펼침 상태를 유지한다.

노드의 이름/질문 표시 비중과 정답 단서를 가리는 세부 방식은 후속으로 다듬는다.
지도에서 시작하기와 추천 학습 중 지도에 들렀다 돌아오는 흐름은 아래 학습 흐름에 연결한다.

### 상태를 표현하는 공통 규칙

첫 학습 여부와 현재 앎은 별개의 축이다. 중요도와 복습 필요도 독립된 표시로 둔다.

| 상태 | 의미 | 표현 시 주의 |
|---|---|---|
| 아직 안 봄 | 회상 시도와 정답 확인을 마치지 않음 | 빈 곳으로 남긴다 |
| 한 번 공부함 | 답을 떠올려 보고 정답까지 확인함 | 틀려도 인정하고 잊었다고 지우지 않는다 |
| 현재 앎 | 문항 성격에 맞는 자기평가·기존 기록에 기반한 상태 | 객관식 정답만으로 동일하게 판단하지 않는다 |
| 복습 필요 | 현재 회상 부족 또는 복습 시점 도래 | 아직 안 본 범위와 구분한다 |
| 준비/평가 자료 부족 | 내용 또는 평가 연결을 아직 준비하지 못함 | 목표 달성 또는 0점으로 단정하지 않는다 |
| 조회 실패/미확인 | 현황을 불러오지 못함 | 빈 범위·학습 0으로 바꾸지 않는다 |

색과 함께 텍스트·무늬·기호를 사용한다. 같은 범위·단위로 본 곳과 앎을 비교한다.
문항이 없는 목표를 분모에서 자동 삭제해 전체 완료로 만들지 않는다.
내용 중복을 제거한 목표 단위와 필수 회상 방향의 합산 기준은 아래 합의를 따른다.
실제 목표 분할·기록 연결·회상 유지 판단은 후속 계약 설계에서 정한다.

### 학습목표·회상 방향·지도 집계 — 합의한 기준과 후속 검토

사용자는 방향별 상태 분리·동일 내용 중복 방지에 이어, 한 방향 이상 공부하면 한 번 접한 내용으로
세고 모든 필수 방향을 도움 없이 회상하면 회상 가능으로 표시하는 기준에 동의했다.
모든 관계에 역방향을 필수로 붙이지 않고 필요한 방향만 정한다. 실제 목표의 분할·동일성 판정,
필수 방향 선정과 준비 상태·기준 변경의 세부 처리는 후속 검토 사항이다.

#### 내용 단위와 평가 단위

개념은 지도에서 지식이 붙는 자리이고, 학습목표는 알아야 할 사실·관계·분류·순서·목적이다.
회상 방향/과제는 어떤 단서에서 어떤 답·판단 근거를 떠올릴지 지정하며, 문항은 그 과제를 묻는 표현이다.
같은 목표의 정방향·역방향·다른 문항 형식은 그 목표 안에 연결한다. 모든 관계에 역방향을 자동 생성하지 않는다.
실제 범위에 필요한 방향과 선택 확장 방향을 근거에 따라 정한다. 무엇이 필수인지는 아직 결정하지 않았다.

전체 범위의 분모는 중복을 제거한 학습목표 수다. 방향 수·문항 수·반복 횟수를 분모로 쓰지 않는다.
구조 제목이나 개념 묶음이라는 이유만으로 학습목표를 더하지 않는다.
같은 목표가 지도 여러 위치에 보이면 전체 범위에서는 한 번만 센다. 단어가 같아도 조건·뜻이 다른 목표를
임의로 합치지 않는다. 목표의 실제 분할과 동일성 판정은 원본·목표·기존 문항을 대조해 정할 계약이다.
현재는 강의별 독립 목표 안에서 방향·문항의 중복 집계를 막는다. 강의 사이에 비슷한 개념이 있다는
이유로 목표나 학습 상태를 자동 통합·승계하지 않는다. 강의 간 연결과 목표 통합 기준은 현재 범위 밖이다.

#### 지도와 단일 막대로 합치는 기준

| 목표 상태 | 합산 조건 | 전체 막대에서 세는 수 |
|---|---|---|
| 내용 미학습 | 목표를 실제로 회상하는 유효 과제에서 회상 시도·정답 확인을 아직 하지 않음 | 그 목표 1개 |
| 한 번 접함·보완 필요 | 한 방향 이상 공부했지만 필수 방향이 모두 현재 회상 가능한 상태는 아님 | 그 목표 1개 |
| 필수 방향 회상 가능 | 필요한 모든 필수 방향이 준비·평가되어 현재 도움 없이 회상 가능한 상태 | 그 목표 1개 |

예를 들어 한 관계의 정방향을 공부한 뒤 역방향도 공부해도 전체 내용 수는 1개다.
정방향만 회상 가능하고 필수 역방향이 미학습이면 목표를 보완 필요로 표시한다.
첫 학습 지점은 잊어도 남으며, 회상 가능에서 보완 필요로 바뀌어도 내용 미학습으로 되돌리지 않는다.
필수 방향이 미정·누락·준비 전이면 회상 가능으로 통과시키지 않는다. 준비 상태는 별도 표시로 남긴다.
선택 확장 방향은 그 자체의 상태를 보여주되 필수 방향의 완료를 막는 조건으로 일괄 포함하지 않는다.

한 방향을 공부하면 한 번 접한 내용에는 포함하지만 모든 필요한 방향을 한 번 공부한 것과는 구분한다.
지도 지점에는 필수 방향 첫 학습 a/b와 회상 가능 c/b를 함께 볼 수 있게 한다.
따라서 내용의 첫 학습이 전체에 닿아도 방향 미학습이나 회상 부족은 지도에 계속 드러난다.
중간 구간은 방향 미학습·현재 회상 부족을 함께 포함하므로, 보완 필요라는 요약 아래 원인을 구분하는 안이다.

접힌 가지의 요약에서도 중요한 내용 자체의 미학습과, 한 번 접한 중요한 내용의 추가 방향 미학습을
구분해 표시한다. 방향 개수를 내용 개수에 더하지 않는다. 분모에서 평가 자료 없는 목표를 빼지 않는다.
필수 방향을 새로 추가했을 때는 내용 수를 늘리지 않되 회상 조건이 달라졌다는 근거를 표시하는 방식을 검토한다.
이 기준에 맞는 실제 목표·방향의 정의와 기존 기록의 연결은 후속 설계하며, 기존 운영 지표를 변경하지 않는다.

### 학습 화면의 원칙

질문이 중심이고 위치 정보는 짧게 유지한다. 정답·해설·근거는 확인 이후에 보여준다.
현재 위치를 보여주는 지도가 질문의 답을 드러내면 관련 부분을 접는다. 원하면 명시적으로 지도를
탐색할 수 있지만 그 방문을 회상 성공으로 기록하지 않는다.

자기평가는 머릿속 회상과 판단 이유를 기준으로 한다. 단답 전환형 객관식에서 선지를 보고만
떠올린 상태는 중간 단계이며, 문장 OX형에서 판단 이유를 설명하지 못하면 앎이 부족한 상태다.
평가 버튼의 개수·명칭은 미정이다. 예시 화면의 버튼은 동작 설명용이다.
첫 학습을 기록하는 시점과 평가를 보류했을 때의 처리는 별도 계약으로 구체화한다.

### 지도에서 질문·자기평가·다음 지점으로 이어지는 흐름

상태: 단계 전환은 사용자 선택을 반영했다. 버튼 문구·평가 척도와 짧은 피드백의 세부 표현은 검토 중이다.

| 단계 | 사용자 경험 | 이 단계에서 구분할 상태 |
|---|---|---|
| 지도 지점 선택 | 선택한 지점의 위치·첫 학습·현재 회상 정보를 보고 여기서 학습을 시작 | 지도 선택과 실제 학습 중인 지점은 별도 |
| 질문 | 강의·가지·지점 경로와 작은 위치 지도를 보며 머릿속으로 답을 떠올림 | 질문을 열기만 한 상태는 첫 학습 완료 아님 |
| 회상 후 정답 확인 | 떠올려본 뒤 정답 확인이라는 단일 행동으로 회상 시도를 표현하고 정답을 확인 | 첫 학습은 인정하고, 자기평가 전임을 별도 표시하는 안 |
| 자기평가 | 못 떠올림 / 도움 필요 / 스스로 회상 등의 문항 성격에 맞는 선택 | 첫 학습과 현재 회상 성공을 구분 |
| 지점 연결 | 자기평가 즉시 다음 질문으로 이동하고 새 현재 위치와 방금 지점의 변화를 짧게 확인 | 틀려도 다음 범위로 진행 가능 |
| 경로 마침 | 이번 경로의 학습 변화와 회상 보강 지점을 확인 | 경로 완료·오늘 완료·강의 전체 완료는 별도 |

#### 위치를 계속 이해할 수 있게 한다

질문 화면의 상단에 강의 › 큰 가지 › 현재 학습 지점을 표시한다.
작은 위치 지도는 개념 구조 안에서 현재 지점을 강조하며, 추천 문제의 배열 순서를 개념 구조로 대신 표시하지 않는다.
좁은 화면에서도 경로와 현재 지점은 질문 가까이에 남긴다.
이번 경로의 몇 번째 지점인지와 지도에서의 위치는 다른 정보로 구분한다.

학습 중 지도를 열면 현재 지점을 강조하고 필요한 가지를 펼친다.
그 안에서 다른 지점을 살펴봐도 현재 질문을 자동으로 바꾸지 않는다.
현재 질문으로 돌아가기는 질문·정답 확인 여부·평가 전/후 단계·경로 진행을 유지한다.
마지막 지점의 자기평가 뒤에는 경로 결과로 바로 이어진다. 이후 지도로 돌아와도 평가 결과를 유지한다.

#### 답의 단서와 자기평가

풀이 중 위치 지도나 전체 지도에서 현재 질문의 정답을 직접 드러내는 명칭은 접거나 중립적인 이름으로 표시한다.
이미 지도를 통해 답의 단서를 확인한 경우에는 도움을 받은 회상임을 구분한다.
검토 예시의 뼈대 질문은 시작 지도에서 큰 분류를 확인했으므로, 이번 회상은 지도 도움을 받은 학습으로 표시한다.
첫 학습의 진전은 남기면서 도움 없는 회상 성공이나 장기 기억 유지로 과대 표시하지 않는 안이다.
실제 단서 판정과 숙련도 반영 계약은 후속 설계한다.

단답 전환형 객관식에서 선지를 보고만 떠올린 경우는 중간 단계이며, 문장 OX형에서 판단 이유를
설명하지 못하면 앎이 부족한 상태라는 기존 intent를 유지한다. 현재 동작 예시는 단답 회상의 세 가지
자기평가 문구를 보여주는 것이며 모든 형식에 동일한 척도를 확정한 것이 아니다.

#### 다음 지점과 기록 경계

사용자 선택: 자기평가를 누르면 별도의 다음 확인 버튼이나 대기 화면 없이 다음 질문으로 바로 이동한다.
새 질문 화면에서 현재 위치 강조를 다음 지점으로 옮기고, 방금 공부한 지점의 첫 학습·회상 상태 변화를
수초간 짧게 표시한다. 이 피드백은 다음 질문을 풀기 위한 대기나 추가 확인을 요구하지 않는다.
짧은 강조가 끝나도 지도에는 이전 지점의 학습 상태와 현재 위치가 계속 남는다.
피드백이 사라질 때 읽고 있는 질문의 위치가 흔들리지 않도록 한다.
피드백에 정답이나 다음 질문의 답이 되는 명칭을 노출하지 않도록 위치 지도의 단서 처리와 함께 검토한다.
마지막 평가 뒤에는 별도의 경로 마침 버튼 없이 결과로 이동한다. 수초의 정확한 길이와 강조 방식은 검토 중이다.
원하는 지점에서 시작할 수 있지만 이후에는 매번 다음 범위를 직접 계획하게 하지 않는다.
오답·중간 평가에서도 다음 지점으로 이동하며 같은 문제의 즉시 정답 성공을 다음 진입 조건으로 삼지 않는다.
예시의 3지점 순서는 동작 설명용이고 실제 추천 알고리즘이나 출제/추출 결과가 아니다.

첫 학습 표시 시점은 회상 시도와 정답 확인을 함께 표현하는 행동을 기준으로 하는 제안이다.
이때 평가 전 상태를 회상 실패와 구분한다. 단순 자료 열람·지도 탐색은 첫 학습으로 세지 않는다.
실제 저장 요청·저장 중/실패·중복 평가·되돌리기·복원은 구현 명세에서 기존 기록 보존과 함께 설계한다.
검토용 화면의 상태 변화는 로컬 예시이며 서버에 저장했다는 뜻이 아니다.

### 오늘의 변화와 완료

오늘 추천 분량 완료·전체 범위 첫 학습 완료·현재 앎을 구분한다.
학습 중 목표가 계속 늘어나 끝이 없어 보이는 상황을 피하는 표현을 검토한다.
계획이 갱신되면 기준이 바뀐 사실을 보여주며, 전체 범위의 잔여 학습을 지우지 않는다.
오늘의 전후 변화는 같은 범위와 일관된 계산 기준으로 비교한다. 자료 판이나 평가 기준이 바뀌면
비교 불가 또는 기준 변경을 표시한다. 시간 경과와 실제 학습 변화의 구분 방법은 후속 설계 사항이다.

#### 오늘 추천 학습의 완료 화면

오늘 새로 공부한 범위·회상 상태의 변화·남은 중요한 미학습을 함께 보여준다.
사용자는 기본 행동을 오늘은 여기까지로 정했고 잔여 범위 확인은 선택으로 두었다.
아래의 전후 비교 배치·집계 예시는 검토용이며 실제 문항·학습 기록·추천 분량 계산과 연결하지 않는다.

1. 상단에서 오늘 추천 학습 완료를 명확히 표시한다. 전체 범위의 미학습과 중요한 미학습 수는 별도로 남긴다.
2. 오늘 처음 공부한 범위와 현재 회상 가능한 범위를 나누어 전후 값과 변화를 표시한다.
3. 강의별로 홈과 같은 단일 구간 막대의 전후 모습을 함께 보여준다. 같은 학습 지점을 여러 문항으로 반복해도 범위가 중복 증가하지 않는다.
4. 중요한 미학습은 개수와 강의·가지·지점의 위치를 보여준다. 요약할 경우에도 전체 잔여를 열람할 수 있어야 한다.
5. 기본 행동인 오늘은 여기까지로 마친다. 검토안에서는 전체 현황으로 돌아간다. 잔여 확인을 필수 단계로 두지 않으며, 선택해서 살펴봐도 오늘 완료 상태를 해제하거나 새 의무 분량을 만들지 않는다.

강의명을 누르면 오늘 새로 본 지점, 회상 가능으로 바뀐 지점, 다시 보강이 필요한 지점을 펼쳐 볼 수 있다.
전후 순변화와 회복한 지점의 수는 다를 수 있다. 기존 약점의 회복·새로 본 지점의 회상 성공·다시 보강으로
바뀐 지점을 구분하고, 회상 가능한 총수가 늘었다는 이유로 보강이 필요한 변화를 숨기지 않는다.
첫 학습으로 인정된 지점이 다시 회상되지 않아도 첫 학습의 진전은 지우지 않는다.

검토용 예시는 4강의 32지점에서 첫 학습 18→23(+5), 현재 회상 가능 10→14(+4)다.
회상 가능 증가의 구성은 기존 약점 회복 3, 새로 공부하며 회상 가능 2, 다시 보강 필요 1이며 순변화는 +4다.
중요한 미학습 3곳은 전체 미학습 9곳 안에 포함한다. 숫자·지점 이름·중요도는 UI 동작 설명용이다.

실제 완료 표시는 오늘 추천 범위의 평가·저장 상태 확인과 연결해 설계한다. 저장 실패나 미확인 상태를
완료로 꾸미지 않는다. 오늘 기준 범위·시작 시점·평가 기준이 없거나 바뀌면 증가량을 만들어내지 않는다.
복수 세션·추가 학습·되돌리기·날짜 경계와 현재 추정 회상의 시간 변화를 비교에 반영하는 방식은 미정이다.
오늘 완료의 성취, 전체 범위의 빈 곳, 실제 회상 상태가 동시에 이해되는지를 사용자와 검토한다.
복습만 한 날은 첫 학습 증가가 0이어도 기억을 보강한 진전을 보여준다. 회상 상태가 제자리이거나
낮아졌다면 그 사실을 표시하되 오늘 분량을 마친 성취를 취소하지 않는다.
중요한 미학습이 0이어도 전체 범위의 첫 학습 완료나 전체 숙련을 자동 선언하지 않는다.
앞선 3지점 경로의 종료만으로 오늘 추천 전체의 완료를 확정하지 않는다. 오늘 계획 범위의 완료 조건과
연결한 뒤 이 화면으로 진입하며, 현재 화면 예시는 그 조건을 충족한 상황을 가정한다.

### 검토 수용 기준

- 처음 보는 사용자가 본 곳·빈 곳·앎을 구별하고 중요한 미학습 강의를 찾을 수 있다.
- 홈에서 강의·분량·모드를 매번 선택하지 않고 추천 학습을 시작할 수 있다.
- 틀린 답을 확인한 뒤 새 범위로 진행할 수 있다.
- 지도·자료를 열어본 사실이 첫 학습·앎의 가짜 기록을 만들지 않는다.
- 오늘 학습의 범위 확대와 앎의 변화가 구분되며, 오늘 완료가 전체 완료로 보이지 않는다.
- 자료 부족·조회 실패·미확인 상태가 0점이나 학습 완료로 표시되지 않는다.
- 작은 화면과 키보드 사용에서도 상태와 기본 행동을 이해할 수 있다.
- 처음 들어온 지도는 큰 가지까지만 보이고, 가지를 접어도 중요한 미학습 수를 확인할 수 있다.
- 자기평가 뒤 추가 클릭 없이 새 질문과 새 현재 위치가 표시되고, 짧은 변화 표시가 사라져도 읽는 위치는 유지된다.
- 지도를 살펴본 뒤 현재 질문의 정답 확인·평가 단계를 유지하며 돌아온다.
- 오늘은 여기까지로 기본 여정을 마칠 수 있으며 잔여 범위 확인을 완료 조건으로 요구하지 않는다.

## 책임·입출력 계약·오류 상태

현재 단계는 화면 구성의 공동 설계다. 시각 예시는 예시 데이터만 사용하며 API·DB에 연결하지 않는다.
화면 상태를 실제 운영 데이터나 실행된 검사 결과로 표시하지 않는다.
서버가 학습 상태·계획·평가·저장의 책임을 유지하고, 웹이 별도로 숙련도나 추천 정책을 계산하는
구조로 확정하지 않는다. 향후 계약·보존·인증·오류/재시도·저장 확인은 서버와 웹을 함께 설계한다.
