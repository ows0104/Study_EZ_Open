# 웹 문제은행 순수 JSON 전달과 프롬프트 간소화

## 문제와 사용자 효과
사용자는 웹 출제 프롬프트의 반복·내부 처리 설명을 줄이고 교수 정보를 준비 단계에서 확정해 전달하기를 요청했다. 이어 “순수 JSON으로 받는 방식으로 바꾸고, 프롬프트도 그에 맞춰 정리해줘. 기존 수집·검증·변환 과정도 같이 수정해줘.”라고 구현을 명시적으로 요청했다.

새 웹 출제는 JSON 파일 하나를 반환하고 기계적인 변환에는 모델을 쓰지 않는다. 기존 MD 원문, 문항 내용·ID·근거·검수 상한·사용자 학습 기록은 보존한다. 운영 자료 재출제·교체와 운영 배포는 범위 밖이다.

## 범위와 성공 기준
프롬프트에서 생성한 JSON이 확장/수동 수집→서버→러너→결정적 BANK 변환으로 연결되고 손상 입력을 거절한다. 기존 MD 호환을 함께 검사한다.

## 근거·미정 사항
근거는 이 채팅의 사용자 직접 구현 요청이다. 실제 강의 교수 정보가 없으면 미확인으로 전달하며 이름을 추정하지 않는다.
