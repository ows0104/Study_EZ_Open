# Main-Quiz 오늘 학습 이어 풀기

## 문제와 사용자 효과

사용자(2026-11-14): 「문제 선택이 바뀌면 예를 들어 Optional을 켰다가 안키면 … 처음 문제로 돌아오는데?」
→ 원인 설명(중요도 칩 조합마다 회차가 따로라 새 계획이 1번부터) 뒤
「나는 회차 개념보다는 그냥 연속적으로 계속 푸는 느낌을 생각하긴 했어. 그래서 Optional을 껐다 켜는게 어차피 영향을 안 주게.
회차는 그냥 오늘 풀 학습량을 제안해주는 느낌?」
제안량을 다 푼 뒤: 「계속 풀기」(「더 풀기」로 같은 흐름에 이어 붙임) 선택.

지금(2026-11-12 tier-filter R5)은 오늘 회차가 칩 조합마다 따로다. 칩을 바꾸면 새 계획이 1번부터 시작하고,
바꿀 때마다 오늘 새 목표 몫을 남은 목표 수로 다시 계산해 새 목표가 한 번 더 붙는다.
제안량을 다 풀면 「오늘 목록을 마쳤어요」에서 멈추고, 다시 시작하면 또 새 회차가 1번부터 센다.

## 범위와 성공 기준

- 강의마다 하루에 오늘 학습 흐름은 하나다. 칩을 바꿔도 같은 흐름이고, 이미 푼 문항과 번호는 그대로다.
  바뀌는 것은 아직 안 푼 뒷부분뿐이다(새 칩에 맞춰 다시 고름).
- 칩을 껐다 켜도 오늘 새 목표 개수는 늘지 않는다.
- 제안량(오늘 목록)을 다 풀면 시작 화면에 「더 풀기」가 나오고, 누르면 다음 새 목표·복습을 같은 흐름 뒤에 붙여 번호가 이어진다.
- 학습 기록·복습 일정·「내 중요도」·학습 목표/첫 학습/회상 가능 숫자는 바뀌지 않는다.
