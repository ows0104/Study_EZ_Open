# 콜린성 약리학 실제 자료 예시

사용자가 수정된 흐름을 콜린성 약리학 자료로1회 실행해 실제 결과를 보여 달라고 요청했다. 운영에 쓰지 않는 예시 조건을 유지한다. 원본은 승인된 콜린성(1)의35쪽PDF/족보와 기존 수신 문항·최종88문항이며 원래13단계/수정3회 원장은 보존한다.

새 원본 대조1회→source-assessment/1→엄격한 AUDIT→roots 문서/전체 방향 과제 생성까지 실제 자료로 확인한다. 결과에는 새 원본 판정·재사용된 같은 BANK의 독립 정답 판정·미준비 방향·입력 지적·문항 원문/정답/근거를 구분해 표시한다. 부모가 임상 내용을 저작하거나 판정을 교정하지 않는다.
