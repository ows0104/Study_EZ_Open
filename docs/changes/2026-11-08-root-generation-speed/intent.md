# 루트 생성 효율화 — 임상 확인 단계·원본 대조‖정답 검수·정답 검수 재사용

## 문제와 사용자 효과
사용자 요청(2026-11-08 곁가지 세션, 이후 이 세션에서 「효율화 1·2 진행해」).
- 원본 대조(source-n)와 정답 검수(medical-n)가 회차마다 차례로 돌고, 둘 다 전체를 다시 판정한다(26110802: source-0 7.0분, source-2 8.4분).
- 정답 검수는 원본 대조의 임상 충돌 정리 판정(`clinical_context_status`)에만 기다린다.

## 범위와 성공 기준
1. 정답 검수 재사용: 이전 회차와 문항·그림·임상 정리가 같은 문항의 판정을 재사용하고, 바뀐 문항만 모델에 보낸다.
2. 동시 실행: 짧은 임상 정리 확인 단계(`context-n`)를 먼저 돌린다. 「일치」일 때만 원본 대조와 정답 검수를 동시에 돌린다.
   검증 전 임상 입력이 정답 검수 모델에 닿지 않는다는 안전 규칙(기존 검사)을 지킨다.
- 판정 기준(지시문의 의미)과 수정 상한 3회는 바꾸지 않는다.
- 원본 대조의 부분 재사용은 범위 밖이다. 원본 대조는 강의 전체(누락·목표·방향)를 판정하므로 3번(분할 대조) 결정과 함께 정한다.
- packet `speedStages: true`로 켤 때만 적용한다. 기존 서버 경로와 진행 중인 ledger는 그대로다.
