# Main-Quiz 학습률 통일과 Quiz Bank legacy화

## 문제와 사용자 효과
같은 「학습률」이라는 이름이 두 가지 계산을 가리킨다.
- Quiz Bank: 개념별로 목표 숙련도까지 찬 정도를 구하고 `1 − RMS(부족분)`으로 묶는다(`server/app/study_engine/mastery.py`).
- Main-Quiz: `회상 가능 목표 ÷ 전체 목표`로 센다(`web/src/bank/useRootCatalog.ts` `rootRate`).

강의 목록·캘린더 막대·사이드 패널은 강의에 두 시스템이 다 있으면 Quiz Bank 값을 먼저 보인다.
시험별 하루 목표 계획(`/api/study-plan`)은 Quiz Bank만 센다.
사용자가 두 값을 구분하기 어려워 헷갈린다.

이번 블럭부터는 Main-Quiz 하나로 공부한다. Quiz Bank는 옛 시스템(legacy)으로 둔다.
변경 뒤에는 학생이 보는 학습률이 모두 Main-Quiz 기록에서 나온 한 가지 값이 된다.
- 문항마다 목표치까지 찬 정도를 부분 점수로 준다.
- 약한 목표를 더 크게 반영한다.
- 복습하지 않으면 시간이 지나며 서서히 떨어진다.

## 범위와 성공 기준
사용자 발언(2026-11-11 채팅):
- 「둘 다 같은 방식으로 통일해줘. 이제 Quiz bank는 쓰지 않을거야. 이제부터 현재 기존 방식으로 Main-Quiz 하나로만 갈꺼야.」
- 「Quiz bank는 옛날꺼고, 이번 블럭부터는 싹다 Main-Quiz로 갈꺼야. Quiz-bank에서 좋은 건 가져와줘.」
- 학습률 식 선택: 「목표마다 숙련도 ÷ 목표치(최대 1)의 평균 … 부분 점수에 '약한 목표를 더 크게' 반영 … 기한이 지나도 0으로 뚝 떨어지지 않고 서서히 내려감. 이 방식이 좋을 것 같아. 1. 약한 목표를 더 크게 반영 2. 시간이 지나면 떨어짐.」
- 묶는 단위: 「추천대로 가자」(점수는 문항에서 만들고 지도 목표 단위로 묶는 안).
- 가져올 기능: 시험별 하루 목표 계획(「3일 전이 아니라 2일 전으로」), 강의 목록 평균·캘린더 막대·패널, 미준비 강의도 0%로 포함. 「Quiz Bank와 그 흔적은 다 legacy로 넘겨줘.」

성공 기준:
1. 강의 목록 행·학습률 평균, 캘린더 막대, 사이드 패널, 시험별 하루 목표 계획이 모두 같은 Main-Quiz 학습률을 쓴다.
2. Main-Quiz 학습률은 [spec](spec.md)의 식을 따른다.
   - 복습 없이 시간이 지나면 값이 내려가고, 기한이 지나도 0으로 뚝 떨어지지 않는다.
   - 약한 목표를 채울 때 점수가 더 오른다.
3. 하루 목표 계획은 시험 시작 48시간 전(2일 전)을 도달 시각으로 둔다.
   - 문제가 아직 없는 강의는 0%로 포함하고, 그 개수를 보여 준다.
4. 학생 화면에 Quiz Bank 학습률·진입 단추가 보이지 않는다.
   - 옛 기록은 지우지 않는다.
   - 옛 기록은 「기존 문제·기록 보기」 같은 legacy 입구로만 열린다.

- 2026-11-09 이전에 평가한 Main-Quiz 기록에는 문항 목표치가 저장되어 있지 않다.
  - 이 기록은 지금 정책(`target_parameters()`)과 그 문항의 등급·내 중요도로 목표치를 다시 계산한다.
- 아래 두 작업과 파일이 겹친다. 그래서 구현은 두 작업이 병합된 뒤 최신 master에서 시작한다. 대시보드에 적었다.
  - 「강의 목록 Main-Quiz 숫자 열」: HungryPotato01, `claude/main-quiz-list-columns`.
  - 「내일 예습·새벽 4시」: PR #97.
- Quiz Bank 코드를 `legacy/` 폴더로 옮기는 물리적 이동은 이번 범위에 넣지 않는다. 화면과 계산 경로만 끊는다.
  - 이동 여부는 [plan](plan.md)의 「승인할 범위」에서 사용자에게 묻는다.
