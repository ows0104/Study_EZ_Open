# Implementation Plan
BankPanel.tsx는 공부하기·Main Quiz 생성·문항 검토 링크만 표시하고 구형 중복 패널 코드를 제거한다. RootGenerationPanel.tsx는 Main Quiz 만들기 주 버튼으로 진행/재개를 통합하고 초기 조회, 강의 전환, 실패, 수동 복구를 처리한다. 기존 rootWeb→수신→CLI→러너 업로드 경로는 보존한다.
web-main-quiz: 컴포넌트 상태와 요청에 대한 격리 검사, 기존 Main Quiz 전송/렌더 검사. web-build: 타입·프로덕션 빌드. GuidePage는 확인했으며 다른 UI 세션 담당이라 수정하지 않고 버튼명 변경을 대시보드에 전달한다.
검사·리뷰·브랜치 커밋까지 수행한다. 운영 병합/배포, 실제 모델 실행·운영 콘텐츠 변경은 로컬 구현과 구분한다. 복원은 코드 커밋 revert다.
사용자 승인: “그럼 Main Quiz 쪽만 네가 맡아서 진행해. 버튼 하나로 생성부터 업로드까지 되게 하고, 사이드 패널의 뿌리학습 같은 중복 패널은 없애줘.” 직접 구현 요청을 현재 범위에 적용한다. calendar/셸/프롬프트는 제외한다.
