# Main-Quiz 개념 지도 회차 분리

## 문제와 사용자 효과
Main-Quiz 첫 화면(오늘 추천)에서 「개념 지도」를 누르면 웹이 지도를 보이려고 먼저 학습 회차를 연다
(`POST …/sessions`). 오늘 추천 과제가 0개이거나 오늘 목록을 이미 끝낸 상태면 서버가 409로 거절하고,
쓰기 큐가 그 응답을 「충돌 응답」으로 보관해 「이전에 저장 확인을 받지 못한 요청 또는 충돌 응답이 있습니다」
배너와 함께 모든 학습 쓰기를 막는다. 풀 과제가 없을 때도 지도는 볼 수 있어야 한다.

## 범위와 성공 기준
- 진행 중인 회차가 없을 때 「개념 지도」는 회차를 만들지 않고 강의 단위로 지도를 연다.
- 과제 0개·오늘 목록 완료 상태에서 지도를 열어도 409·충돌 배너가 생기지 않는다.
- 지도에는 답이 보이므로, 같은 학습일에 지도를 본 뒤 시작한 회차는 지금처럼 `mapSeen`(도움받은 회상)으로 기록된다.
- 진행 중인 회차에서 여는 지도는 기존 경로(`map` 이벤트) 그대로.

## 근거·미정 사항
- 사용자 요청(2026-11-12): 「지금 "개념 지도"가 퀴즈 안에 묶여있잖아 … 개념 지도를 퀴즈에서 빼야 할 거 같은데 어떻게 해야 할까?」
  → 제안에 「네, 진행」. 겹침 조정: 「함수 달라서 병행」(「시험일 미정」 작업과 같은 `root_learning.py`, 다른 함수).
- 이미 브라우저에 보관된 충돌 응답은 이 변경으로 지워지지 않는다. 사용자가 「보관 응답 확인」을 한 번 누른다.
