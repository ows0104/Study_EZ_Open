# Main-Quiz 주관식 모드: 문항 자체 선지의 정답·오답 표시

## 문제와 사용자 효과

사용자(2026-11-27): 「주관식 모드에서 객관식 유형에서 답을 고르면 초록색으로 안 바뀌어.」

주관식 모드에서 객관식·복수 선택 문항(문항 자체 선지 `options`)은 선지를 고르고 답을 봐도
고른 표시(`is-picked`)만 남고 정답 초록(`is-correct`)·오답 빨강(`is-wrong`)·빠뜨린 정답(`is-missed`)이 붙지 않았다.

원인: `RootSolve`는 점수 상자를 숨기려고 `showChoiceScore={false}`를 주는데, `QuestionBody`는 같은 값으로
선지 채점 표시까지 껐다. 객관식 모드는 선지를 `recallChoices`로 넘겨 다른 길로 채점해서 표시가 났다.

## 범위와 성공 기준

- 주관식 모드의 문항 자체 선지: 답을 보면 객관식 모드와 같은 초록·빨강·점선 표시와 한 줄 라벨.
- 점수 상자는 여전히 숨긴다. 문제 목록·카탈로그(`showChoiceScore={false}`, 고른 것 없음)는 그대로.
- 범위 밖: 서버·기록·평가, 객관식 모드, 「선지 보기」(V) 선지.
