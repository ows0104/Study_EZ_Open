# 실행 계획

1. 2026판 PDF 전체 읽기·해시/페이지 확인 및 기존 parse_edition 결과를 점검한다.
2. 새 runs/_materials/감염과 면역 판에서 기존 족보 분할 도구를 사용한다. 두 시험 구역이 모두 반영되고 문항·정답·원본 지면·교수 구분이 유지되는지 확인한다.
3. 올해 시간표와 분할 자료를 연결하고 강의별 계획을 고정한다. 기존 족보 파일은 이전 작업 폴더의 자료/해시로 보존한다.
4. materials 검사와 자료 리뷰 후 승인된 기존 족보 업로드 범위로 jokbo 자료만 반영한다. 새로운 족보가 있는 별도 수업은 시간표에 정확한 자리로 등록할 수 있다. 원본 없는 필기를 만들지 않는다.
5. upload 검사에서 원격 파일 존재·저장 바이트 해시·연결·기존 필기와 학습 데이터 보존을 확인하고 결과를 기록한다.

코드 기능 변경이나 운영 코드 배포는 없다. 사용자 최초 요청의 같은 과목 자료 정리·업로드 승인 범위로 진행하며, 피드백만을 새 구현 승인으로 사용하지 않는다.
## 실제 원본 구조 확인에 따른 자료 추출 방식

기존 parse_edition은 2차 문제를 정답 구역으로 삼켜 50개 섹션만 반환하고, 1차의 3줄 제목도 놓쳤다. 잘못된 JSON/Markdown을 정본으로 게시하지 않는다. 기존 프로덕션 파서는 바꾸지 않고, 이 변경 폴더의 일회성 자료 스크립트에서 실제 원본 제목·지면 위치로 문제 구간과 정답 구간을 각각 지정한다. 1차는 문제 p4~102, 정답 p102~118, 2차는 교수표 p119, 문제 p120~175, 정답 p176~183이다. 1차 교수표 p2~3도 함께 보존한다.

각 강의 PDF는 출처 안내·교수표·해당 문제 및 정답의 원본 열 구간을 포함한다. 원본 두 단의 읽기 순서와 제목 경계 좌표를 기록하고 CropBox만 지정해 원문·그림·정답을 보존한다. 원본과 복사된 각 구간의 렌더 및 텍스트를 검사하고 경계 PNG를 시각 검토한다. 원본의 합본 26~28강, 병리 7~8강, TBL1·2 및 실습은 합본 범위를 명시해 연결한다. CBL 7~9는 원본의 관련 일반강의에 포함된 CBL 문항을 연결한다. CBL6은 원본에 출제 없음 안내만 존재한다. 형성평가 칸은 원본 범위가 없어 남긴다. 기존 필기는 변경하지 않는다.
