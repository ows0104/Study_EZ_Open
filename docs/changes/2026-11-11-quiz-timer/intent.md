# 복습 퀴즈 문항 타이머

## 문제와 사용자 효과
복습 퀴즈(Main-Quiz 풀이, `RootSolve`)에 문항 타이머가 없다. 모든 문항에 같은 시간을 주면
형식에 따라 지나치게 짧거나 길어서, 형식별 기본 시간을 두고 해설 보는 시간도 제한한다.

## 범위와 성공 기준
- 문제 시간: 기본 30초, ox 20초, matching·sequence 40초. `item_difficulty`는 쓰지 않는다.
- 해설 시간: 답을 편 뒤 일괄 40초.
- 문제 0초 → 자동으로 답 보기. 해설 0초 → 자동으로 Again 평가 후 다음 문항.
- 오른쪽 위에 타이머 on/off 토글과 남은 초만 작게 표시한다. 줄어드는 막대 등은 그리지 않는다.
- 끄면 타이머가 돌지 않는다. 처음 상태는 켜짐이고 선택은 이 브라우저에 기억한다.
- Tab: 일시정지 / 다시 Tab: 재개.

## 근거·미정 사항
- 사용자 2026-11-11 지시(채팅): 형식별 초·토글·남은 초·Tab 일시정지, 이어서 「해설 보고 있는 시간도 일괄 40초」.
- 사용자 2026-11-11 선택: 문제 0초 「자동으로 답 보기」, 해설 0초 「자동으로 Again 평가」, 기본값 「켜짐」.
- 기존 Quiz Bank(legacy `BankSolve`)와 예습 퀴즈는 범위 밖이다.
