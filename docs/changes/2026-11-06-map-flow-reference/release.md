입력/원본 불변·실제 파일SHA·JSON스키마·고유개념ID·참조·강의별 물리쪽 범위를 확인했다. 결과는 임의 수정하지 않았고 notes의 범위/원본 충돌/불확실성을 보존했다. source-only 추출이며 독립 의학 검수 완료는 아니다.

동일 JSON으로 HTML/PNG/Mermaid를 결정적으로 만들었다. PNG는 오프라인 Pillow로 렌더해 두 장을 육안 확인했다. 노드에는 긴 core_facts 일부를 표시하고 전체 내용은 JSON/HTML에 남겼다. 색과 기본선/추가선은 배치용이며 의학적 중요도나 관계 검수 판정이 아니다. 개념 연결은 원본 추출 그대로다. 큰 갈래/교차 연결은 나왔지만 예시보다 노드 설명이 길고 단순 배치에 연결선 교차가 있어 표시 개선의 여지는 있다.

로컬 HTML에 대한 CUA 브라우저 접근은 file 프로토콜 정책으로 거절됐다. 다른 브라우저 경로나 로컬 HTTP 서버로 우회하지 않았다. HTML은 생성/JS 문법 확인까지만 했고 브라우저 동작은 미검증이다. 대신 외부 접근 없는 정적 PNG를 제공한다. 모델/렌더 스크립트 문법과 JS 문법도 확인했다.
