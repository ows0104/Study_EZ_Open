# Spec

- 기본 문구는 `{파일명}`과 사용자가 지정한 한 문장으로 구성한다.
- 실제 전송 문구에는 빈 줄 뒤 `올해 담당 교수: 김범준` 형식의 한 줄만 추가한다. 중복 파일명·시간표 대조·기출 우선순위 설명은 붙이지 않는다.
- 현재 필기 파일명의 교수 파싱과 `{교수}` 치환을 유지한다. 공동 교수는 `·`로 연결하고 확인되지 않으면 `올해 담당 교수: 교수 미상`으로 표시한다. 필기자나 시간표의 추정 교수로 대체하지 않는다.
- 기존 개인 저장 문구와 대화 링크, 예습 문구·교수 판정, 첨부 선택, 족보·문항·학습 기록은 보존한다. 현재 필기가 없는 기존 렌더링 분기는 유지한다.
- 수용 기준: 사용자 예시의 정확한 최종 문구, 교수 변경·미상·공동 교수·개인 문구와 예습 분리, 웹 타입/빌드 통과.
