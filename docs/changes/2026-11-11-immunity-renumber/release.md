# 감염과 면역 이동 12강의 run ID를 현재 시간표 번호로 — 배포 준비

## 코드 리뷰·검증 결과

### 바뀐 것
- `scripts/immunity_renumber.py`(새)
  - 기본 실행은 운영을 읽기만 하고 계획·판정표·지문을 출력한다.
  - `--copy-r2`는 R2 객체를 새 경로로 복사한다. 지우지 않는다.
  - `--apply --expect-plan`은 검토한 계획만 한 트랜잭션으로 적용하고 영수증을 쓴다.
  - `--reverse`는 영수증으로 되돌린다. `--local-runs`는 러너 파일을 옮긴다.
- `data/timetable/identities/2026-2.json`·`2026-2-notes.json`을 `{}`로 비웠다.
  - 원본은 `docs/changes/2026-11-05-immunity-timetable/identities/`에 두었다.
  - 11-05 도구(`scripts/immunity_timetable_update.py`)는 그 원본을 읽는다.
- `tests/runner/test_timetable_identity.py`: 12강의가 현재 칸 번호를 갖고, 필기는 이름의 번호를 그대로 쓴다.
- `data/timetable/README.md`: 되돌린 이유와 다음 시간표 변경 때의 규칙을 적었다.

### spec과 다른 점
- 덱 이름·판 문서·생성 입력처럼 이미 만든 것을 설명하는 JSON은 바꾸지 않는다(spec R1에 반영).
- 실패한 Main-Quiz 생성이 남아 있으면 멈춘다.
  - 이어 하기가 packet의 옛 번호로 강의를 찾기 때문이다. 이어 하면 바뀐 상대 강의로 간다.
  - 다시 요청하기로 하면 `--abandon-generation <id>`로 명시한다.

### 독립 리뷰(하위 에이전트, 코드만 줌) — 8건 중 7건 수정
1. **계획 뒤에 쓰인 행이 옛 번호에 남음 → 수정**
   - 계획을 잠금 안에서 다시 만들고, 지문이 검토한 것과 같을 때만 적용한다.
   - 12강의의 모든 행 키가 계획에 있어야 한다.
   - `--reverse`는 지금 DB에서 다시 계획한다. 그 뒤 쓰인 행은 맞바뀐 쌍이면 강의를 따라가고, 섞인 쌍이면 멈춘다.
2. **영수증을 commit 뒤에 씀 → 수정**: commit 전에 쓰고 fsync한다. commit 뒤에 `committed: true`로 다시 쓴다.
3. **새 키가 다른 파일의 키와 겹칠 수 있음 → 수정**: 계획에서 멈춘다. R2 비교도 크기와 ETag로 한다(멀티파트 원본은 크기만).
4. **검사가 FK를 켜지 않음 → 수정**: SQLite `foreign_keys=ON`. 단계 행 삭제의 CASCADE까지 검사한다.
5. **섞인 쌍의 풀이 기록은 주제 판정이 안 됨 → 남김**: 멈추는 쪽으로 안전하다. 운영 섞인 쌍에는 그런 행이 없다.
6. **숨김 갱신이 행 수를 확인하지 않음 → 수정**
7. **`--local-runs`가 중간에 멈출 수 있음 → 수정**: 이름 바꾸기 전에 모두 확인한다. prequeue.json은 러너가 다시 만들어 그대로 둔다.
8. **R2 확인이 잠금 중에 돎 → 수정**: 잠금 전에 한다.

## 배포 대상 버전·순서·데이터 변경
- 코드 PR은 도구·검사·빈 별칭이다. 서버·웹 코드는 바뀌지 않는다.
  - 병합하면 자동 배포가 돌지만 API 동작은 같다.
- **운영 데이터 적용 순서**
  1. 아데노 Main-Quiz 실패 건을 정리한다(고쳐서 이어 하기, 또는 포기 표시).
  2. 러너를 끈다.
  3. 읽기 계획을 다시 보이고 사용자 승인을 받는다.
  4. `--copy-r2`
  5. `--apply --expect-plan <sha> --output runs/_development/2026-11-11-immunity-renumber/receipt.json`
  6. `--local-runs runs --apply`
  7. 새 master로 러너를 다시 설치하고 실행한다(빈 별칭).
  8. 화면을 확인한다.
- 빈 별칭을 가진 러너는 DB 적용 뒤에만 돌아야 한다. 적용 전에 돌면 새 번호 필기가 옛 번호 행에 붙는다.
  - 그래서 러너 재설치는 적용 뒤에 한다.
