## 범위와 성공 기준

1. 존재 목표 선행은 문항 단위로 끌어온다: 오늘 목록에 있는 문항 X가 전제하는 연결을 답하는 문항 Y만, 필터 밖이어도 앞에 둔다.
   X가 오늘 목록에 없으면 Y를 끌어오지 않는다. 같은 존재 목표의 다른 과제는 따라오지 않는다.
2. 복습 풀어 주기(11-15 tree-edge-goals R2)는 끌어올 문항 Y 자신의 기록으로 판단한다(쉽게 맞혔으면 안 끌어옴, 오늘 푼 것은 다시 안 끌어옴).
3. 지도 관계 선행(필터 안에서만 목표 단위)과 문항 사이 선행(`questions[].prerequisites`)은 그대로다.
4. 문항 단위 기록이 없는 판(생성 기록 없음)은 지금과 같다.

- 성공: 261110_02 운영 사본(읽기 전용으로 받은 판·기록, 로컬 계산)에서 Q107은 오늘 목록에 없고, 끌려오는 Optional은
  오늘 목록 문항의 전제를 답하는 것뿐이다. 판·학습 기록·DB 스키마 불변. 기존 검사 통과.
- 범위 밖: 전제 판정의 질(예: Q102를 E1A·E1B 존재 문항으로 본 판정)은 출제 쪽 일이다. 이 변경은 Q102를 여전히 끌어온다
  (Q012의 전제를 답하는 문항으로 기록되어 있다).
