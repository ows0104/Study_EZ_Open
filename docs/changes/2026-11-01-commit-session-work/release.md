# 커밋·푸시 검토

사용자가 현재 및 다른 세션 변경의 정리·커밋·푸시를 명시적으로 요청했다. 원격 origin/master가 로컬 기준점보다 162커밋 앞서 있어 원격을 수정하거나 덮지 않고 codex/session-work-20261101 브랜치로 현재 검토한 작업을 보존·푸시한다. master 통합이나 서비스 배포는 이번 작업이 아니다.

포함: 런타임 코드·공유 계약·프롬프트·테스트와 개발 도구, 문서/정책/작업 상태, 감염과 면역 자료 처리 스크립트와 정책.
보존/제외: 10GB 이상 개인 작업 사본·강의 PDF/이미지/JSON 원문·실행 캐시·운영 스냅샷·비밀 환경. 파일은 삭제하지 않고 기존 위치에 둔다. .gitignore에 제외 규칙을 보강했다.

검증 결과:
- 웹 TypeScript/Vite 빌드 통과.
- 서버: 독립 임시 DB 환경에서 85개 테스트 파일 전부 통과.
- Python 관련 전체 검사: 1474 통과, 동시 기록 검사 1개 간헐 실패. 동일 소스에서 해당 검사를 분리 재실행해 통과했다. 간헐성은 잠재 이슈로 남긴다. 변경 없는 Spotter 검사는 루트 환경의 requests 부재로 제외했다.
- 확장 관련 Node 검사 69개 통과.
- 추가 웹 정적 단위 검사에서 answerPoints의 이전 is-item/indented 기대 3개와 bank-links의 오래된 모듈 mock 1개가 실패했다. 현재 구현은 원문 줄 구조 유지와 관리자 전용 링크 정책을 사용한다. 제품 동작을 과거 기대에 맞춰 되돌리지 않고 기존 검사의 갱신 과제로 남긴다. 모든 검사가 통과한 운영 출시로 표시하지 않는다.
- 게시 검사: 스테이징 파일의 credential 패턴·대용량·충돌 마커·개인 자료 포함 없음. README 두 파일의 잘못된 CRCRLF를 정돈했다. runner 두 파일의 기존 EOF 공백 경고는 실행 코드 보존을 위해 남긴다.

커밋 구성: 연결된 런타임/개발 도구/테스트, 일반 설계/개발 기록, 감염과 면역 자료 제작/보관 기록을 구분한다. 공유 런타임 파일은 의존성을 보존하도록 하나로 묶는다. 실제 커밋 ID와 원격 확인은 publication-result.json에 로컬 보관한다.
