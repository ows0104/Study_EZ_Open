# Main-Quiz 개념 지도 빠진 주제 복원

## 문제와 사용자 효과
가지 보기(#49) 배포 뒤, 감염병리1 지도에 개념 75개 중 62개만 보인다.
항산염색 AFB·한센병·PAS·Mucicarmine·ARDS 같은 개념이 빠지고, 그래서 결핵↔AFB 같은 연결도 그려지지 않는다.

사용자(2026-11-09): 「이게 정말 중요한 건데 왜 연결이 안되지? site는 왜 prototype과 다른거야?」 → 「고쳐줘」.

원인은 웹의 `buildTree`다. 개념 계층이 아니라 문항에서 트리를 세운다.
- 문항 하나를 개념 하나(가장 많이 쓰인 개념)에만 달고, 그 개념과 조상만 노드로 만든다.
- 옛 은행 변환본의 「정답」 노드를 숨기려던 규칙인데, Map 판에서는 진짜 개념도 같이 숨긴다.
- 빠지는 것은 문항이 있는 보조 개념 9개와 문항이 없는 개념 4개다.

## 범위와 성공 기준
- 판의 개념 계층(parent_ids)에 있는 개념은 모두 지도 주제로 보인다. 감염병리1은 75개다.
- 답(사실) 노드는 지금처럼 숨긴다.
- 문항은 그 답 노드의 부모 주제에 단다. 답 노드가 부모가 없으면 기존처럼 가장 많이 쓰인 개념에 단다.
  - 예: AFB 문항(T025)은 항산염색 AFB 아래로 간다.
- 결핵↔항산염색 AFB 연결선이 보인다.
- 부모도, 자식도, 문항도, 연결도 없는 고립 개념은 지금처럼 숨긴다.
- 웹 읽기 규칙만 바꾼다. 서버·API·DB·판·학습 기록은 바꾸지 않는다.

## 근거·미정 사항
- 판 review의 개념 150개는 C 75개(주제)와 F 75개(포인트 답 노드)다.
- 다음 규칙이 이 둘을 정확히 가른다(실측 C 75 / F 75, 오분류 0).
  - 답 노드 = 문항 하나에만 쓰이고, 자식이 없고, 연결이 모두 부모와의 것이다.
  - 부모가 없으면 연결이 모두 같은 문항의 다른 개념과의 것이다.
- 옛 공개판 모양(N1_A 등)도 같은 규칙으로 답 노드가 된다.
- 개념별 핵심 사실(core_facts)은 판에 없어 범위 밖이다.

## 추가(같은 날): 순서
사용자: 「순서도 왜 Prototype과 다르지? 강의 순서랑 안 맞는거 아니야?」

원인은 정렬이다. 형제를 「아래 문항 근거의 가장 작은 쪽」으로 정렬했고, 문제가 둘 있었다.
- S1(필기)과 S2(족보) 쪽을 섞었다. 「바이러스별 세포 형태 감별」이 족보 p.1 때문에 맨 앞에 왔다.
- S1만 보더라도 문항 하나가 앞쪽 개요 쪽을 인용하면 가지 전체가 앞으로 당겨진다.

고친 뒤의 규칙은 다음과 같다.
- 순서는 판의 순서다. 주제는 Map 단계가 강의를 읽으며 쓴 개념 순서(C001 → …), 문항은 목표 순서다.
- 화면의 쪽 번호는 가장 많이 인용된 출처(강의 필기 S1)의 것만 쓴다.
