# 감염과 면역 이동 12강의 run ID를 현재 시간표 번호로

## 문제와 사용자 효과

2026-11-05 시간표 수정 때 자리가 바뀐 12강의(6쌍)는 날짜·교시만 새 시간표로 바꾸고 run ID는 주제를 따라 옛 번호를 유지했다(`docs/changes/2026-11-05-immunity-timetable`).
그래서 관리자 화면·러너·덱 이름에 보이는 번호가 실제 시간표와 다르다.
- 예: 아데노·폭스(방예지)는 지금 11-10 10:00(감염과 면역 23)인데 `261113_01`로 나온다. 헤르페스(김현제)는 11-13 09:00인데 `261110_02`다.

올해 필기 파일은 이미 새 번호로 온다(예: `[261110_02] 아데노바이러스, 폭스바이러스(방예지)_신서환v1.pdf`).
러너의 별칭은 주제 글자가 정확히 같을 때만 옛 번호로 돌린다. 「미코플라스마」 대신 「미코플라즈마」처럼 철자가 다르면 그대로 새 번호에 붙는다.
그 결과 이미 한 쌍이 섞였다. 운영 DB에서 읽기만 해서 확인했다(2026-11-11).

| 운영 행 | 연결된 시간표 칸 | 제목·올해 필기·작년 필기·예습 덱 | 족보·예습 문항(pre_item) |
|---|---|---|---|
| `261105_06` | 11-06 14:00 무산소성세균(염진기) | 미코플라스마·클라미디아(김동현) | 무산소(S13-염진기, 「절대무산소균이…」) |
| `261106_06` | 11-05 14:00 미코플라스마(김동현) | 무산소세균(염진기) | 미코(S17-김동현, 「Mycoplasma의 세포벽…」) |

사용자 2026-11-11:
- 「261113_01이 틀린거야. 현재 시간표대로 맞춰야해.」
- 11-05 결정과 이전 범위를 설명한 뒤 「12강 다 맞춰줘」.

## 범위와 성공 기준

- **범위**: 감염과 면역 6쌍 12강의의 run ID를 현재 시간표 번호(날짜 + 교시)로 바꾼다.
  - 12↔22: 렙토스피라 `261105_05`→`261110_01`, 콜레라 `261110_01`→`261105_05`
  - 13↔17: 미코플라스마 → `261105_06`, 무산소 → `261106_06` (섞인 것을 내용 단위로 정리)
  - 23↔30: 아데노·폭스 `261113_01`→`261110_02`, 헤르페스 `261110_02`→`261113_01`
  - 40↔47: 의료관련감염 `261119_06`→`261118_01`, 신종 감염병 `261118_01`→`261119_06`
  - 46↔48: 형성평가 `261119_07`→`261119_05`, 감염병의 예방 `261119_05`→`261119_07`
  - 65↔66: 다양한 알레르기 `261126_05`→`261126_03`, 호산구성 질환 `261126_03`→`261126_05`
- **성공 기준**
  - 각 강의의 자료·예습 문항·덱·학생 학습 기록·Main-Quiz 판이 같은 주제를 따라 새 번호로 옮겨진다. 잃거나 다른 강의로 붙은 것이 0이다.
  - 화면·러너·덱 이름의 번호가 시간표와 같다. 별칭 파일은 비거나 사라진다.
  - 다른 과목·다른 강의의 행은 바이트까지 그대로다.

## 근거·미정 사항

- 운영 읽기 전용 집계(2026-11-11 15:4x KST): 12 ID는 25개 표에 있다.
  - 예습: pre_item 92, quiz_attempt 20, pre_review_log 20, preview·user_preview·preview_open, user_review 4
  - 자료: asset 136행이며 R2 키 134개에 번호가 박혀 있다. asset_grab 25
  - 그 밖: prequiz_job 9, run_meta 6, root_generation·root_event 각 1(진행 중인 아데노 Main-Quiz)
  - 학생의 Main-Quiz 학습 기록은 아직 없다.
- 족보 배정이 맞는지는 이번 범위가 아니다.
  - 호산구·알레르기 쌍은 족보 파일의 교수 이름이 행의 담당과 다르다(S64-박흥우가 호산구(김세훈) 행에 있음).
  - 이번에는 행을 통째로 옮기고 족보는 따로 보고한다. 단 미코·무산소 쌍은 족보까지 주제로 가른다.
