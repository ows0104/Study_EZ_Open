# Main-Quiz 오늘 학습 중요도 필터

## 문제와 사용자 효과

사용자(2026-11-12): 「문제 풀기 전에 어떤 중요도만 체크해서 풀 수 있게 하고 싶어. optional 문제를 풀어보니까
너무 지엽적이라 초반 회독에는 좀 빼고 풀고 싶거든.」 → Optional 토글과 4단계 선택 중 「4단계로 진행」.

지금 Main-Quiz 오늘 학습은 준비된 과제를 중요도와 상관없이 모두 후보로 삼는다. 초반 회독에서 Optional을 빼거나,
시험 직전에 Essential·Core만 돌리는 방법이 없다.

## 범위와 성공 기준

- 오늘 추천 카드에 Essential·Core·Important·Optional 칩 4개(다중 선택, 각 칩에 준비된 과제 수).
- 고른 중요도의 과제만 오늘 목록에 들어간다. 중요도는 「내 중요도」가 있으면 그것, 없으면 판의 tier, 없으면 Core.
- 선택은 과목(subject)마다 내 계정에 남는다. 다른 기기·강의 목록 ▶ 시작에도 같다.
- 학습 목표·첫 학습·회상 가능 숫자와 진척 분모, 학습 기록·복습 일정은 바뀌지 않는다.

## 근거·미정 사항

- 중요도 4단계와 「내 중요도」는 이미 있다(server/app/root_learning/policy.py TIERS, state.personal_tiers).
- 미정 없음. 범위 밖: 옛 Quiz Bank(study_engine) 풀이, 강의 목록 칩 표시.
