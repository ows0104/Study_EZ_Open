# 감염과 면역 족보 JSON·그림 관리 자료

현재 사용자 승인: “ㅇㅎ ㅇㅋ 그러면 그렇게 정리해줘.” 직전 설명의 문항 JSON + 연결 그림 폴더 + 원본 PDF 구성을 같은 과목에 적용한다.
기준은 검증된 2026판 원본과 직전 정리본의 69단원·850문항 항목·80개 강의 연결이다. 19개 정답 연결 확인 상태를 유지한다.
JSON을 기준 데이터로 만들고 같은 데이터에서 GPT 첨부용 MD를 내보낸다. 그림·표·벡터 도식, 원문 지면 및 원본 PDF를 보존한다. 자료 제작·검증과 다운로드 묶음 제공 범위다. 서비스 코드·퀴즈·학습 기록·현재 사이트 PDF 첨부를 변경하는 기능 배포는 없다.
