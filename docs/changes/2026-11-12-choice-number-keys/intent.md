# 복습 퀴즈 객관식 선지 번호 표시와 1–4 키 선택 · 5 키 제외

## 문제와 사용자 효과

사용자 요청(2026-11-12): 복습 퀴즈의 A/B/C/D 객관식을 1/2/3/4로 바꾸고, 키보드 1/2/3/4로 선지를 고르게 한다.
문제 제외도 단축키로 한다(키는 `5`, 사용자 결정 「5 유지하고 진행」). 「실제로 누르면 제외할 수 있게 구현해줘」.

현재 학생의 복습 퀴즈는 Main-Quiz(`RootSolve`)다(2026-11-11부터 Quiz Bank는 legacy, `?legacy=1`).
- 선지 머리표는 저장된 선지 ID(A·B·C·D)를 그대로 보여 준다. 숫자 1–4는 답 공개 뒤 Again–Easy 평가에만 쓰인다.
- Main-Quiz에는 제외가 없다. 「이 문제 보류」는 이 회차에서만 넘긴다. 옛 Quiz Bank의 개인 제외 목록은 읽기만 한다.

## 범위와 성공 기준

- 객관식 선지 머리표를 화면 순서의 1, 2, 3…로 표시(문제·선지별 해설·정답 줄). Main-Quiz·옛 Quiz Bank·전체 문제 보기 공통.
- Main-Quiz 답 공개 전 1–4 키로 해당 선지 선택(복수 선택은 다시 누르면 해제). 답 공개 뒤 1–4는 지금처럼 평가.
- Main-Quiz `5` 키(와 더 보기 메뉴 「이 문제 제외」)로 현재 문항을 내 학습에서 제외하고 다음 문제로. 이후 오늘 목록·계획에서 빠진다.
  Z로 되돌리면 제외가 없던 일이 된다.
- 저장된 문항·선지 ID·정답·기존 학습 기록·옛 Quiz Bank 제외 목록은 바꾸지 않는다.

## 근거·미정 사항

- 선지가 5개 이상이면 5번 이후 선지는 마우스로 고른다(`5` = 제외).
- 해설 본문 안에 "B는 …"처럼 쓴 글자는 원문 그대로 남는다. 줄 앞 머리표만 번호로 바꿔 보인다.
- 제외 해제는 회차 안의 Z 되돌리기뿐이다. 회차가 끝난 뒤 복원하는 화면은 이번 범위 밖(후속).
