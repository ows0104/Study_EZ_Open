# 캘린더 오늘 복습에 오늘 푼 문제 수 — 배포 준비

## 코드 리뷰·검증 결과
- `npm --prefix web run typecheck`, `build` 통과.
- 고정물 `web/tests/redesign-shell.html`의 임시 사본(study-plan 응답을 넣음, 확인 뒤 삭제)에서 확인:
  진행 중 「오늘 복습 / 푼 문제 27 / 3.2%p」, 완료(회색) 「푼 문제 64 / ✓ 5.3%p」, 계획 없음 「–」(푼 문제 줄 없음).
  칸 높이 56px로 내일 예습 칸과 같음, 375px 폭에서 넘침 없음, 콘솔 오류 없음.

## 배포 대상 버전·순서·데이터 변경
웹만(Pages). 서버·API·DB 변경 없음. master 병합 = 배포.

## 배포 후 확인·롤백·필요한 사람 승인
- 운영 칸의 「–」는 시험 칸 이름(`2026-11-13-immunity-exam-titles`)이 운영 DB에 반영돼야 사라진다. 그 뒤 「푼 문제 n」이 보이는지 확인.
- 롤백: 병합 커밋 revert. 병합은 사용자 승인.
