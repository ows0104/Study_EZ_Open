# 실행 계획

1. 로컬 원본·현재 서버 파일 해시를 대조하고 원본 첫 페이지를 렌더링해 사용자가 제시한 화면과 비교한다.
2. 별도 출력 경로에 원문 외관을 유지하면서 주석을 고정한 PDF 사본을 작성한다. 원본 PDF를 덮어쓰지 않는다.
3. materials 검사에서 원본 보존·48쪽·주석 0·페이지별 렌더 및 텍스트를 확인한다. 대표 페이지는 Poppler로도 확인한다.
4. 진단의 확정 사실과 추정을 구분해 설명하고 검증한 호환본을 제공한다. 웹 미리보기 수정 및 모델 이해 정확도는 실제 확인하지 않은 것으로 명시한다.

코드 기능 구현이나 운영 배포는 없다. 초기 자료 정리 지시의 같은 자료에 대한 로컬 보존 사본이며, 사용자 후속 질문만으로 대량 자료 교체를 하지 않는다.
