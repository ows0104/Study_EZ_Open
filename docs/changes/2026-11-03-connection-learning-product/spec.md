# 제품 계약

강의별 불변 콘텐츠 판을 관리자 등록하고 별도 공개 상태로 제어한다. 학생은 공개된 판만 접근한다. 첫 질문·답 공개·후속 질문·후속 답·항목별 자기평가를 서버가 순서 검증한다. 사용자/강의/판별 저장, revision 조건부 쓰기, request ID 재전달 중복 방지를 적용한다. 지도 열람 노출을 저장하고 열람/시도/자기평가를 구분한다. 기존 은행/학습기록은 수정하지 않는다. 서버 저장 실패 시 입력과 요청을 유지해 재시도하며 충돌 시 재조회한다. 준비되지 않은 강의는 준비 전으로 표시한다. 운영 공개·배포는 실행하지 않는다. 분류/나열·구조적 역할·이해/시험/임상 근거와 누락은 각 콘텐츠 항목에 저장한다. 자동 중요도 점수나 미합의 복습 정책은 만들지 않는다.
