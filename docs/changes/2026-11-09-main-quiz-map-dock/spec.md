# Main-Quiz 개념 지도 패널 옆 붙이기·확대 복원 — 설계

## 요구사항과 수용 기준
- 배경: `.main-quiz-tree-stage`에 점 격자 background-image를 두지 않는다.
- 확대·이동
  - 입력: 휠(커서 기준), 두 손가락, 끌기(4px 넘게 움직이면 클릭 억제), ＋/－/전체 버튼, +/−/0 키
  - 배율은 0.25–2.6이다.
- 맞춤
  - 처음에는 전체를 맞춘다(배율 상한 1.2). 사용자가 아직 확대·이동하지 않았으면, 틀이나 지도 영역 폭이 바뀔 때(창, 크게 보기, 패널 열고 닫기) 다시 맞춘다.
  - 한 번이라도 확대·이동했으면 그 뒤에는 그 화면을 유지한다. 패널이 열리면 고른 노드가 영역 밖일 때만 그 노드로 옮긴다.
  - 「전체」나 0 키를 누르면 다시 맞춤 상태로 돌아간다.
- 패널: 틀 안 flex 열(폭 340px, 데스크톱)로 지도 영역(stage) 옆에 붙는다. 지도 영역과 겹치는 부분은 없다.
- 좌우 여백
  - 지도 화면에서 `.main-quiz-learning`의 좌우 패딩을 8px로 줄인다.
  - 틀은 모서리를 8px로 한다.
- 좁은 화면(760px 미만): 세로 목록과 아래 패널은 지금 그대로다.

수용 기준
- 확대 버튼을 누르면 transform이 바뀐다.
- 패널이 열려 있을 때 패널 사각형과 지도 영역 사각형이 겹치지 않는다.
- 고른 노드는 지도 영역 안에 있다.
- 페이지 스크롤이 없다.
- 기존 흐름 검사가 통과한다.

## 책임·입출력 계약·오류 상태
데이터 계약과 `buildTree`는 그대로다.

## 호환성과 데이터 보존
화면만 바뀐다. 되돌리기는 병합 커밋 revert다.
