# Main-Quiz 재배치 판에 기존 학습 기록 승계 — 의도

## 사용자 요청 (2026-11-15)
- 「이거 기존 학습기록은 어떻게 됐어?」 → 재배치(unplaced-only/1)로 교체한 3편의 기록이 새 판으로 넘어가지 않았음을 확인.
- 「결론적으로 나는 원래 지도에 붙지 못한 문제가 과제에 추가되면 좋겠고, 그 과정에서 기존 학습기록이 승계되었으면 좋겠어.」

- 기록은 지워지지 않았다(옛 판 revision에 남음). 화면이 새 판만 읽어 처음부터 시작한 상태다.
- 승계 장치는 이미 있다: 새 판 `equivalences`(이전 판·방향 → 새 방향)가 있으면 `state.replay_tasks`가 이전 판 이벤트를
  같은 방향·같은 문항 지문(`question_sha256`)의 과제로 잇는다. 생성기는 이 칸을 늘 빈 목록으로 낸다.
- 세 편 모두 옛 판 과제가 새 판에 (방향, 지문) 그대로 있다(145/145, 155/155, 203/203). 옛 판의 답 보기·평가 이벤트는 모두 지문을 담고 있어 연결만 있으면 전부 잇는다.
- 넘어가지 않는 것: 「내 중요도」(tier)·「이 문제 제외」(exclude)는 판마다 따로라고 설계돼 있다(`personal_tiers`, `excluded_ids`). 세 편 합쳐 tier 11건·exclude 3건.

## 목표
미배치 문항을 과제로 더하는 교체를 계속하되, 교체한 판이 이전 판들의 학습 기록을 잇는다. 이미 교체한 3편도 기록을 되찾는다.
