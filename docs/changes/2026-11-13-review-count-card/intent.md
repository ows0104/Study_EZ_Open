# 캘린더 오늘 복습에 오늘 푼 문제 수

## 문제와 사용자 효과
사용자 2026-11-13: 「남은 복습을 %p가 아니라 문제 수로 바꾸고 싶은데」 → 하루 목표의 문제 수 환산은
「핸드오프 문서를 작성해줘. 우선 지금은 -로 안 뜨게 수정하고, 내가 푼 문제 수를 같이 표시해줘.」

오늘 평가 수 `reviewedToday`는 `/api/study-plan`에 이미 있으나 화면에 없었다.

## 범위와 성공 기준
- 칸 라벨 아래 「푼 문제 n」(`plans[0].reviewedToday`). 큰 수·막대(%p)는 그대로.
- 이용 안내 한 줄.
- 문제 수 환산: `docs/changes/2026-11-13-daily-goal-questions/handoff.md`(이번에 구현하지 않음).

## 근거·미정 사항
- 「–」: 계획이 없을 때(운영: 시험 칸 제목 「시험」). 고침은 `2026-11-13-immunity-exam-titles`의 운영 반영.
