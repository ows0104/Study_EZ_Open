# StudyEZ 웹 운영 반영

대상: Cloudflare Pages study-ez-open / master, https://studyez.kr.
이전 운영 배포: 6c7ffce7-3d35-43c6-aa28-fc9390739fd5. 복원 주소는 release-config.json에 기록한다.
API studyez-api-00171-9wx에 100% 트래픽과 사후 HTTP 8항목 통과를 확인한 뒤 웹을 반영한다.
웹 검사에서 TypeScript/Vite 빌드 및 로컬 설정이 있어도 운영 번들에 로컬 테스트 토큰·가짜 로그인 분기가 포함되지 않음을 확인했다.
공통 계약 6개, 개발 루프 29개, 공개 HTTP 8항목 통과. 동일 소스의 서버 검사 85파일 통과.
검사에서 생성한 web/dist를 고정 후보로 복사하고 해당 파일만 게시한다. 재빌드나 Git push를 하지 않는다.
변경 범위는 기존 사이트 리팩토링과 개발 모드 전용 테스트 인증 분기 제한이다.
DB·문항·학습 기록·운영 계정은 변경하지 않는다. Cloudflare는 사용자가 승인한 범위의 로그인 갱신을 직접 완료했다.
기존 인증 세션에서 학습 현황과 79문항을 조회했다. 새 로그인·해설 펼치기 및 배포 후 인증된 UI는 미확인이다.
사후 검사: 실제 배포 ID 조회, health/공개 웹/API 인증 차단/CORS 8항목, 공개 도메인과 배포 주소의 index·주요 JS/CSS 파일이 고정 후보와 일치하는지 비교한다.
기존 퀴즈 준비 현황 갱신 실패 표시는 별도 미해결 문제로 유지한다.
중요 승인 근거: 사용자 실제 운영 배포 요청과 후속 '완료했어. 웹 배포와 배포 후 검사까지 이어서 진행해줘.'
