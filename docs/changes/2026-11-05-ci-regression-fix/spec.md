# 덱 promote 동일성 판정

## 요구사항과 수용 기준
선택한 덱과 목적지 크기가 같아도 실제 바이트가 다르면 복사한다. 같은 수정 시각 또는 더 오래된 원본 시각을 강제한 검사로 재현한다. 내용이 같으면 원본 시각이 달라도 목적지 바이트와 mtime을 그대로 둔다.

## 책임·입출력 계약·오류 상태
promote의 판 선택·CHOSEN·옛 폴더·누락 오류·반환 경로는 유지한다. 크기 비교 후 파일을 스트리밍 SHA-256으로 비교하여 시각 정밀도와 비교 캐시에 의존하지 않는다. 파일 읽기 실패는 성공으로 숨기지 않는다.

## 호환성과 데이터 보존
새 의존성 없이 기존 hashlib를 사용한다. 메모리 사용은 파일 크기와 무관한 스트리밍이다. 운영 runs, 문항, ID, 학습 기록, HOLD, CHOSEN을 변경하지 않는다. 테스트의 임시 파일만 조작한다.
