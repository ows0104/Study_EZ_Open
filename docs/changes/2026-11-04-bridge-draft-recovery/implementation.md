# 구현·검토 기록

2026-11-04 사용자 “응, 그 범위로 수정해줘”에 따라 정정한 예습 범위만 로컬 구현했다.

## 결과

- PreviewAction의 기본 링크 만들기를 실제 button과 start("shared", false)에 연결했다. 관리자/필기/호환/진행 중 조건, 별도 자동전송, 기존 링크 열기와 교체 확인은 유지했다.
- GPT 팝업은 다른 초안 또는 예상하지 못한 첨부가 있으면 다운로드 전에 멈추고 복구 버튼을 표시한다. 사용자가 버튼을 누르면 초안·첨부가 처음 확인한 상태와 같은지 재검사한 뒤 현재 입력창만 정리한다.
- 확장이 입력한 미전송 실패 초안은 내용/첨부 상태의 SHA-256 지문만 Chrome 세션에 기록한다. 요청·제공자·모드를 검증하고 한 번만 소비한다. 동시 claim을 직렬화하며 최대 100건으로 제한한다. 원문·파일 본문은 이 기록에 저장하지 않는다.
- 사용자의 입력 수정, 직접 전송, 첨부 제거/파일 선택/드롭은 실패 초안 근거를 해제한다. 자료 입력 중 사용자 수정은 자동 진행을 중지한다. 확장 자체의 execCommand가 만드는 trusted input은 사용자 수정으로 오인하지 않는다.
- 각 첨부 제거 후 입력창과 첨부를 다시 읽어 React DOM 교체와 제거 실패를 처리한다. 전송 버튼을 한 번이라도 시도했으면 팝업 복구/자동 재전송/실패 초안 등록을 하지 않는다.
- 브리지 manifest/protocol은 1.3.21로 맞추고 README·개인정보 요약·사이트 이용방법을 갱신했다. 제품 BankPanel/서버/문항·학습 기록/대기 응답은 변경하지 않았다.
