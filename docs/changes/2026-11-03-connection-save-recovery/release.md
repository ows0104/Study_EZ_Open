# 연결 학습 저장 복구 — Review / 로컬 Build 완료

## 결과와 검토

요청 ID별 보관함으로 탭 간 미확인 요청 덮어쓰기/잘못된 삭제를 방지한다. 기존 보관함을 이관하고, 충돌 입력을 보존하여 화면에서 확인하게 했다. 작성 중 응답은 계정/강의/판/질문/단계별로 보관한다. POST 재전달 응답은 과거 스냅샷일 수 있어 최신 GET 확인 뒤 해당 요청만 확정한다. 브라우저 보관 실패 시 입력을 화면에 유지하고 추적되지 않는 서버 쓰기를 막는다. 이용방법을 갱신했다.

검토: 서버의 동일 요청 중복 처리 계약을 유지하며 기존 은행/개인 수정/학습 사건에 쓰지 않는다. 실제 제품 컴포넌트를 사용한 합성 API 검사는 UI 복구를 검증하며 의학 내용의 검증이 아니다. 탭별 요청은 각각 보존하지만 같은 질문의 작성 중 초안은 계정/질문별 마지막 로컬 보관값이다. 충돌 응답은 별도 보존하며 자동 재적용하지 않는다.
