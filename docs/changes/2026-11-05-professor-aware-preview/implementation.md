# 교수 기준 예습 자료 — 로컬 구현 결과

사용자가 승인한 최근 5년 동일 교수 최신 필기와 미발견 시 작년 필기 대체를 구현했다. `notes_prev` kind와 강의 ID는 유지한다. 실제 올해 필기 우선·필기 전 시간표 잠정, 교수 집합 변경, 보유 자료 기준 신규 교수, 미상/충돌/합본 범위의 확인 필요를 구분한다.

`runner/preview_sources.py`가 검색/선택/원본 지문을 소유하고 publish/readiness/prequeue/데스크톱이 결과와 대화 출처 검사를 공유한다. 작년 대응을 새 예습 원본으로 덮어쓰지 않는다. 서버 준비 신호가 없으면 강의·첨부 쓰기 전에 중단한다.

서버의 선택적 JSON은 구형 입력에 의해 지워지지 않는다. 공개 요약에 내부 파일 경로나 보존 키를 싣지 않는다. 원본 변경 전 기존 PDF는 해시와 연결 정보를 기록하고 객체를 보존하며, 새 자료는 별도 해시 키를 사용한다. 기존 대화는 원본 연결을 보존하고 새 필기로 만든 새 링크 전까지 예습 문항 재게시를 보류한다.

캘린더는 교수 변경/신규 교수/확인 필요 태그를 표시한다. 월간의 좁은 칸은 신규 교수 표시를 우선하고 상세에서 전체 상태를 제공한다. 상세에는 과거→올해 담당, 담당 근거, 실제 예습 연도/교수, 미보유 연도와 자료 변경 안내를 표시한다. 첨부 갱신 중에는 새 예습 전송을 보류한다.

실제 검증 결과와 소스/빌드 지문은 [release.md](release.md), 운영 적용 전 대상/순서는 [operating-proposal.md](operating-proposal.md)에 있다. 원본 PDF 내용·퀴즈·운영 DB·공유 링크·학습 기록을 이번 로컬 작업에서 변경하지 않았다.
