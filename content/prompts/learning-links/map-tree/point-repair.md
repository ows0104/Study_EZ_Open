실제 입력은 input.json이다. 원본 전용 최초 포인트(previous-exam-points.json)를 source-audit.json에서 검토한 실제 지적만 한 차례 보완한다. 지적된 원본 페이지를 읽고 overmerged 목표는 독립 회상 단위로 나누고, missing·scope·unsupported·duplicate는 실제 지적대로 고친다. importance_basis와 notebook_profile도 지적된 것만 고치고, 바꿀 때는 원본 쪽과 문장을 다시 확인한다. 확인된 지적 외의 선택 제안을 추가 확장으로 바꾸지 않는다. 수정이 필요 없는 목표의 ID·원문·근거는 그대로 복사한다. 분리할 때 기존 ID를 좁혀 유지하고 분리된 독립 목표에 새 P번호를 부여한다. 원본의 범위/충돌/제외/불확실성을 보존한다.
결과를 exam-points.json에 작성한다. title은 $title. 원본·입력·이전포인트·검수파일은 보존한다. 네트워크/다른세션/추가모델은 사용하지 않는다. 마지막 응답은 {"path":"exam-points.json","sha256":"실제SHA256"} 영수증만 반환한다.
