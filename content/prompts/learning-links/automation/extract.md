이 단계는 원본 전용 독립 추출이다. 제공된 실제 원본 텍스트와 모든 이미지만 읽고 강의 전체의 Concept map·학습목표·필요 회상 방향·출제포인트를 learning-brief/1으로 작성한다. 다른 단계의 문항이나 웹 응답은 제공되지 않는다. 문항에서 목표·범위를 역으로 만들지 않는다.
lecture_id와 sources는 계산된 입력 재고를 정확히 복사한다. preserved_scope·교수·올해 범위·원본의 색상 제외를 준수하고, 강의 전체와 제공 목록 밖 범위도 확인한다. 족보 합본은 해당 강의 범위와 다른 강의 범위를 구분한다.
구조적 뼈대·가지·세부와 시험/임상 중요성은 별개 근거다. 공통 품질 원칙에 따라 중요한 기초 연결과 그 위의 비교·기전·응용을 구별하고 실제 강의 흐름으로 배열한다. 실제 원본에서 확인한 선행 관계만 prerequisites에 연결한다.
각 목표는 직접 회상해야 하는 관계와 필수/확장/미확정 방향을 갖는다. 제공된 관계를 정답에서 회상한 것으로 세지 않는다. 중요도·필수 방향의 미확정 근거는 분명히 기록한다. 실제 확인한 관계만 reviewed와 원본 쪽을 기록하고 확인하지 못하면 unreviewed로 둔다.
각 방향의 cue·answer_scope·relation_ids가 실제 같은 사실을 가리키는지 교차 확인한다. 서로 다른 용도·분류·명칭·비교·인과를 넓은 주제 관계 하나로 대신하지 않는다. 한 목표의 방향은 연결된 포인트에 공동 집계되므로 관련 없는 세부 목표를 한 target에 묶지 않는다. 원본의 개요 수치/경향을 각 약물/환자에 정확히 적용하는 목표로 확대하지 않는다. 시각 구조 식별과 텍스트 특징 회상은 다르며, 원본의 실제 요구·그림 근거·불확실성을 명시한다. 원본 자체의 의학적 오류가 의심되면 그대로 안전한 임상 정답으로 확정하지 말고 관계 조건·이유에 충돌/적용 한계를 남긴다.
포인트는 문항 수에 맞추지 않는다. 모든 목표를 원본 포인트 대조에 포함하며 제외 포인트도 원문/범위/이유와 exclusions에 남긴다. 포함 포인트는 target_ids를 연결한다. 원본 지면은 PDF의 물리쪽이고 자료에 없는 근거·시험 예고·선행 관계를 만들지 않는다.
provenance.status는 draft, independent_points는 confirmed다. 이는 원본만으로 별도 추출을 완료했다는 실행 기록이며 의학적 정확성이나 문항 충족 판정이 아니다. method/notes에는 원본 전체 확인 방법과 범위·불확실성을 적는다. 이후 별도의 원본 대조·독립 정답 검수가 진행된다.
