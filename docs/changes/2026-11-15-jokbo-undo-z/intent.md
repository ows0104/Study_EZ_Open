# 족보 풀이 z 되돌리기

## 문제와 사용자 효과

사용자(2026-11-14): 「지금 족보 페이지에 뒤로가기 버튼이 있어? 족보 페이지에서도 다른 퀴즈처럼 z를 구현해줘.」

족보 풀이에는 「뒤로」(진입 화면으로)만 있고, 모르겠음·주의·괜찮음을 잘못 고르면 되돌릴 방법이 없었다.
예습 퀴즈·Main-Quiz·Quiz Bank는 `Z`·`Ctrl+Z`로 직전 평가를 되돌린다.

## 범위와 성공 기준

- 표시를 고른 뒤 `Z`(또는 `Ctrl`/`⌘`+`Z`)를 누르면 직전 문제의 답 화면으로 돌아간다. 고른 선지와 답은 그대로 보이고 표시를 다시 고른다.
- 오답노트 표시는 고르기 전 값으로 돌린다(틀린 문제는 서버가 붙인 모르겠음).
- 끝 화면에서도 된다. 회독은 끝 화면에 처음 닿을 때 한 번만 센다(이미 #170 동작).
- 한 단계만. 되돌린 뒤 다시 고르기 전에는 z를 받지 않는다. 답을 막 본(아직 표시 안 고른) 문제는 채점 기록이 이미 남아 되돌리지 않는다.
- 입력칸·열린 대화창에서는 동작하지 않는다.
- 범위 밖: 서버·DB(새 API 없음, 기존 `PUT …/mark`만 사용), 오답노트 화면.
