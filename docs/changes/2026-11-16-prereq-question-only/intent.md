# Main-Quiz 선행: 끌어오기·막기는 문항 사이 선행만

## 문제와 사용자 효과

신고(2026-11-15, 레지오넬라·리스테리아·바실루스 `감염과 면역/261109_02`, 판 `auto-2bcdcf1f…`):
「Essential만 골라서 푸는데 선행문제가 아닌 것 같은 Optional이 같이 나오고, 명시적 선행문제가 없음이라는 에러가 뜬다.」

운영 DB 읽기 전용 확인(2026-11-15):

- 판에는 문항 사이 선행(`bank_snapshot.questions[].prerequisites`, 17문항)과 목표 사이 선행(`document.prerequisites`, 10개)이 있다.
  목표 사이 선행은 지도 관계(`RP-C007-C022` 등, 예: 「균 형태와 염색」 → 「검사실 진단」)에서 왔다.
- `task_dependencies`는 목표 사이 선행 하나를 **앞 목표의 모든 과제가 뒤 목표의 모든 과제의 선행**으로 푼다.
  Essential `Q018`(계절 단서·흉부 소견)의 선행이 형태·배양 목표의 13과제(Optional `Q003` 염색법·`Q074`·`Q082` 포함)가 된다.
- Essential만 고른 오늘 세션 52과제 중 Essential은 17, 나머지 35(Optional 11)가 「명시적 선행 문항」으로 끌려왔다.
  풀이 화면은 그 이유를 보여 주지 않는다.
- 끌려온 과제를 「이 문제 제외」하면 `close_prerequisites`가 뒤 목표 과제 전부를 「명시적 선행 문항이 준비되지 않음」으로 막는다.
  `Q003` 하나를 제외하면 Essential `Q018`을 포함한 진단 목표 5과제가 막힌다. 실제로 한 학습자는 `Q084`·`Q087` 제외로
  `Q021`·`Q022`·`Q054`·`Q159`가 막혀 있다.

## 범위와 성공 기준

1. 목표 사이 선행은 고른 중요도 밖의 과제를 끌어오거나 막지 않는다. 오늘 목록에 있는 과제의 순서를 정하고,
   고른 중요도 안에서만 안 배운 앞 목표를 당겨 온다(기존 계획 규칙, spec R1). 필터 밖이어도 끌어오는 것은 문항 사이 선행과
   존재 목표 선행(#190, spec R1a)뿐.
2. 준비되지 않은 선행(개인 제외 등)은 뒤 과제를 막지 않는다. 그 선행만 건너뛴다.
3. 풀이 화면에서 선행이라 함께 나온 과제에 「선행 문항」 표시를 붙인다.

- 성공: 레지오넬라 판·운영 학습 기록 사본으로 Essential만 고른 계획에 목표 사이 선행으로 끌려온 과제가 없고,
  위 학습자의 막힌 4과제가 다시 준비됨. 학습 기록·DB 스키마 불변. 기존 검사 통과.
