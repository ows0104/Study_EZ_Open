# 관리자가 지금 프롬프트의 산출물을 반려했다 (2026-09-15)

기생충학을 지금 프롬프트로 돌린 결과가 마음에 안 든다는 판정이다. **전에 지적해서
고쳐졌다고 여겨진 것들이 계속 나온다**는 것이 요점이다.

> 충분히 cloze로 나와야할 것들이 긴 문장의 형태의 답인 기본으로 나왔고, 문제의
> 한국어가 이해가 되지 않았으며 답이 너무 길어 회상이 어렵고, 중요하지도 않고
> 단순번역인 문제도 나왔어.

넷으로 갈린다.

    ① cloze 로 낼 것을 basic 으로 낸다
    ② 질문의 한국어가 이해되지 않는다
    ③ 답이 너무 길어 회상이 안 된다
    ④ 중요하지 않은 **단순 번역** 문제가 나온다

## 짚은 카드 넷 — 어디 있는지

관리자가 Anki 화면을 캡처해 보냈고, 그 넷을 산출물에서 찾았다.

| | 편 / 판 / id | 형식 | 답 길이 | 무엇이 문제인가 |
|---|---|---|---|---|
| A | `260901_02/main/260902-0122` `c007` | basic | 58자 | **④ 단순번역.** 「장관내/조직내 선충증을 사는 자리로 바꿔 부르면?」 → Lumen dweller / Tissue invader. 한국어를 영어로 바꾼 것뿐이고 질문의 한국어도 어색하다(②) |
| B | `260901_01/main/260902-0122` `c037` | basic | 123자 | **③** 「장외 회충증에서 유발되는 합병증은?」 에 다섯 줄. 회상 단위가 아니다 |
| C | `260901_01/main/260902-0122` `c027` | basic | 105자 | **①③** 「어떤 방식으로 전파되며 무엇을 통해 감염되는가」 — **자료의 한 문장**이고 `fecal to oral`·`embryonated egg`·`식수 및 채소` 가 빈칸 자리다. cloze 로 났어야 한다. 겸사겸사 두 가지를 한 번에 묻는다 |

**D 가 가장 중요한 단서로 보인다.** cloze 규칙이 「빈칸마다 그 축을 남긴다」를 요구하는데,
그 요구가 **basic 의 질문에까지 번져** 축을 질문에 늘어놓는 문장을 만들고 있는 것처럼
읽힌다. **이것은 아직 확인되지 않은 가설이다** — 프롬프트를 고치기 전에 그것부터 봐라.

## 이 카드들은 지금 프롬프트가 낸 것이 맞다

빠져나갈 구멍이 없다는 것을 확인했다.

    ㉰ 가 선 시각         b2b4326  2026-09-06 15:41
    260901_01 의 ② 카드   09-06 16:19   ← 뒤다
    260901_02 의 ② 카드   09-08 21:57   ← 뒤다
    그 뒤 프롬프트 커밋     없다

**프롬프트 누락도 아니다.** 아홉 판을 재 보니 판마다 자기 폴더·자기 프롬프트였고 파트
수가 내내 같았다(`quizgen/CLAUDE.md` 「아홉 번에 프롬프트는 제대로 들어갔다」).

### 다만 판 폴더의 `prompt.cards.*.md` 를 믿지 마라

`260901_01/main/260902-0122/` 의 프롬프트 파일은 **09-08 16:21** 것인데 카드는
**09-06 16:19** 에 썼다. 그 뒤 실행이 다시 조립하면서 덮었고, ② 는 산출물이 있어
건너뛰었다. **그 폴더의 프롬프트는 그 카드를 만든 프롬프트가 아니다.**
카드를 만든 프롬프트를 알려면 원장(`usage.jsonl`)에서 ② 카드가 돈 시각을 찾고
그 시각의 `git` 상태를 봐야 한다.

## 실측 기준선 — ㉰ 가 낸 것 전부 (33편 · 2,766장)

09-06 15:41 이후에 카드를 쓴 판만 골랐다. **고친 뒤 이 값과 견주면 된다.**

    형식      basic 2,169 · image_basic 241 · cloze 211 · ox 143 · image_occlusion 2
    cloze 비율                     7.6%          편마다 0~24장으로 흔들린다
    basic 답 길이                  중앙 53자 · 상위10% 113자 · **최대 291자**
    질문 길이                      중앙 37자 · 상위10% 72자 · **최대 239자**
    **답이 80자 넘는 basic**        553장 (25%)      ← ③
    **질문이 60자 넘는 카드**        412장 (15%)      ← ②

    편마다 cloze 0장인 것도 있다 — 260907_05 · 260901_01 의 v9 판

다시 재는 법:

```bash
python scripts/prompt_baseline.py     # 위 표를 그대로 다시 뜬다
python scripts/attempts.py <run_id>   # 한 편의 판별 원값
```

**`prompt_baseline.py` 의 80자·60자 선은 근거가 있어서 그은 것이 아니다** — 지금
분포를 보려고 잡은 눈금이다. 규칙으로 굳히려면 관리자에게 먼저 물어라.

④(단순번역)는 **세는 법이 없다.** 사람이 짚어야 한다.

## 고치기 전에 읽을 것 — 이 저장소가 이미 실측한 제약

`quizgen/CLAUDE.md` 에 근거가 다 있다. 요약만 옮긴다.

**① 프롬프트를 고치고 한 편 돌려서 비교하지 마라.** 같은 편 같은 자료인데 판마다
cloze 6~16장 · 재현 78~91% 로 흔들린다. 관측 하나가 30분·$15 다. 2026-09-06 에
아홉 번 돌려 **실행끼리 비교한 주장이 하나도 안 남았다.**

**② 문구를 고를 때는 `quizgen.judge` 를 쓴다.** 이미 만들어 둔 카드를 판마다 뽑아
섞고 출처를 가린 채 한 세션에게 판정시킨다. 30초·$0.35.

```bash
python -m quizgen.judge cloze runs/260901_01/main/260906-1147 \
                              runs/260901_01/main/260902-0122
```

**다만 `judge` 는 지금 cloze 만 본다**(`RUBRICS`). 위 불만 넷 중 ①의 「형식을 잘못
골랐다」·②·③·④ 를 보려면 **잣대를 새로 써야 한다.** 그것이 이 일의 첫 걸음일 수 있다.

**③ 예시로 쓴 편으로 그 규칙을 재지 마라.** `domains/medical_ko.md` 의 실제 카드
예시가 어느 편에서 왔는지는 `prompting.py` 의 `DOMAINS` 위 주석에 있다. **`260901_01`
은 이미 예시로 쓰였다** — 그 편으로 「좋아졌다」를 재면 답을 쥐여 준 것이다.

**④ 지금 것은 v7 이 아니다.** v7 의 cloze 절을 되살리되 관리자가 뒤집은 넷을 걷어낸
조합이고(`b2b4326`), **그 조합은 아직 심판을 안 받았다.** v9 으로 바꾸는 것은 답이
아니다 — 첫 판정에서 v9 이 cloze 6장·83% 로 제일 낮았다(v7 16장·94%).

## D 의 가설은 재 봤다 — 안 맞는다 (2026-09-15)

**고치기 전에 그것부터 보라고 적어 둔 것을 봤다.** 결론은 **가설 D 가 안 받쳐진다**는
것이다. 프롬프트에서 cloze 의 「축을 남긴다」를 걷어내는 쪽으로 가지 마라.

```bash
python scripts/cloze_axis_probe.py           # 아래 표를 다시 뜬다
```

`260901_01` 은 판이 11개고 판마다 그때 쓴 `prompt.cards.*.md` 가 같이 있다. 그래서
**프롬프트에 그 규칙이 있었는가**와 **산출물이 어땠는가**를 맞댈 수 있다.

**「믿지 마라」를 세는 쪽에도 넣었다.** 프롬프트 파일 시각이 판 이름과 한 시간 넘게

적어 둔 것)과 `260906-1619`(**프롬프트 파일이 아예 0개다**. 이 문서에 없던 것이다).

### D 의 서명은 믿을 수 있는 판 아홉에서 0이다

D 는 「질문이 답의 구조를 ①②로 늘어놓는다」였다. 그 서명(`①②③④⑤`)을 basic 질문에서
세면 **아홉 판 모두 0장**이고, 나온 두 장은 규칙 칸을 못 채운 판 둘에 하나씩이다.
그중 하나가 이 문서가 짚은 카드 D(`c019`) 다 — **한 판의 basic 85장 중 1장**이다.

축 규칙이 있는 판과 없는 판을 갈라 평균을 내면 이렇다.

                   판  cloze%   a>80   ①②
    축 규칙 있음        5   13.2%   28.4  0.0
    축 규칙 없음        4    7.2%   34.5  0.0

**방향이 가설의 반대다.** 축 규칙이 있는 쪽이 cloze 가 많고(불만 ①) 긴 답이 적다(③).

### 그래도 이것을 근거로 규칙을 굳히지 마라

**한 편을 판마다 한 번씩 돌린 값이다.** 같은 편 같은 자료인데 판마다 cloze 6~16장으로
흔들린다는 것이 이 저장소의 실측이고(`quizgen/CLAUDE.md`), 위 차이는 그 폭 안에 있다.
게다가 **`260901_01` 은 이미 프롬프트의 예시로 쓰인 편이다**(이 문서 「고치기 전에 읽을
것」 ③). 여기서 말할 수 있는 것은 하나다 — **D 를 근거로 cloze 절을 건드릴 이유가 없다.**

### 그러면 무엇이 남는가

불만 ③(답이 길다)은 판을 가리지 않는다 — 믿을 수 있는 아홉 판에서 `a>80` 이 **19~45장**,
`a중앙` 이 48~83자다. 축 규칙이 있든 없든 난다. ②(긴 질문)도 9~23장으로 늘 있다.
**형식을 고르는 자리(제안 2)와 길이에 잣대가 없는 것(제안 3)이 그대로 남는다.**

## 어디서 시작할까 — 제안이지 결론이 아니다

1. ~~**D 의 가설부터 본다.**~~ **재 봤다 — 안 맞는다.** 위 절을 봐라
2. **형식을 고르는 자리를 본다.** C 같은 「자료의 한 문장」이 왜 basic 으로 가는지.
   지금 규칙은 *"자료의 문장을 앞면에 깔아 `cloze`로 닫는다"* 인데 7.6% 만 그리 간다
3. **길이에 잣대가 없다.** 답 80자·질문 60자를 넘는 것이 각각 25%·15% 인데
   프롬프트에도 검사에도 그 선이 없다. **선을 그으려면 관리자에게 물어라** —
   근거 없는 규칙을 문서에 박지 않는다(`quizgen/CLAUDE.md` 「규칙 문서를 쓰는 법」 ①)
4. 고친 뒤에는 **`judge` 로** 재고, 위 기준선과 견준다
