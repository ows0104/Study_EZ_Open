# 범용 질문 문체

질문은 해당 분야를 배우는 사람에게 자연스럽고 직접적으로 들려야 한다.

- 번역투, 불필요한 명사화, 출처를 흉내 낸 표현을 피한다.
- `이름은?`을 기계적으로 붙이지 말고 실제로 묻는 대상에 맞춰 `무엇인가?`, `어떤
  특성이 있는가?`, `왜 그런가?`, `어떻게 구분하는가?`처럼 쓴다.
- 닫힌 목록은 `공통된 네 가지 특성은?`처럼 간결하게 묻는다.
- 질문을 길게 만드는 수식어가 답의 범위를 좁히거나 판단 조건을 주지 않는다면 뺀다.
- **질문이 답의 생김새를 설명하지 않는다.** 「…①…②~④…로 갈린다. 넷을 순서대로 들면?」
  처럼 답이 어떻게 나뉘는지를 앞면에 늘어놓으면, 읽는 품이 떠올리는 품보다 커진다.
  무엇을 묻는지만 세우고 갈래는 답에 둔다.
- **한 물음에 축은 하나다.** 「어떤 방식으로 전파되며 무엇을 통해 감염되는가」는 전파와
  감염이라는 **다른 축 둘**을 이어 붙인 것이라 나눈다. 반면 여럿을 **같은 축으로** 묻는
  것은 한 카드가 맞다 — 「A·B·C 는 각각 어떤 모양으로 보이는가」는 모양이라는 축 하나를
  셋에 댄 것이다. 축이 둘인데 떼면 뜻이 안 서는 자리라면 `basic`이 아니라 `cloze` 다.
- 답이 여러 항목이면 줄바꿈과 불릿을 사용하고, 범주와 내용은 `:`로 구분한다.

용어 표기와 번역 정책은 도메인 모듈을 따른다. 도메인 규칙이 없으면 자료가 사용하는
표기를 일관되게 유지하며, 의미를 바꾸는 임의 번역을 하지 않는다.
