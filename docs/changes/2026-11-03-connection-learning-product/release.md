# 강의별 연결 학습 제품 통합 — 배포 준비

## 코드 리뷰·검증 결과
실제 제품 경로 /bank/:subject/:runId/connections와 BankStart/BankStudy 진입을 구현했다. 별도 connection_content/state/event 표를 사용하며 기존 은행/개인문항/복습 기록은 수정하지 않는다. 권한·비공개·불변 판·첫/후속 단계·부분 자기확인·재전달·revision 충돌·계정 분리·공개 중지 보존 API 검사, 경로 계약, 이용현황 2개 파일, 개인 문항 회귀 검사가 통과했다. 웹 타입 검사와 실제 제품 빌드도 통과했다. 실제 앱을 격리 API에 연결하여 답 공개와 후속 질문, 자기확인 저장 후 새로고침 복원을 확인했다. screenshot: screen.png. 루트 Python에서 서버 환경을 재호출할 때 stdlib 충돌이 있었고 서버 전용 Python으로 재검증했다.

## 배포 대상 버전·순서·데이터 변경
로컬 Build 완료, 운영 배포 미실행. 코드 지문은 state.json의 통과 검사에 고정한다. 운영 적용 순서: 백업 및 대상 DB 확인 → app.cli init-db로 신규 표/RLS 준비 → API 배포 → 웹 배포 → 관리자 자료 등록 → 내용 확인 후 해당 판 공개. 콘텐츠는 불변 판별로 보관한다. 로컬 확인용 콜린성 10묶음은 이전 대화 초안이며 비공개로 등록했다. 49문항 전체 재작성·의학 검수 완료나 독립 포인트 추출 완료를 주장하지 않는다.

## 배포 후 확인·롤백·필요한 사람 승인
운영 공개/DB 변경은 아직 실행하지 않았다. 배포 후보 및 중요 운영 승인 후 진행한다. 장애 시 새 진입을 내리고 이전 앱 버전을 복원하며 신규 표와 학습 사건은 보존한다. 미확인 요청은 계정/강의/판별 브라우저 outbox에 남고 같은 request ID로 재전송한다. 충돌 요청은 별도 conflict 키로 보존하고 서버 상태를 재조회한다. 자동 복습 간격·중요도 점수·첫 학습 전체 완료 정책은 합의되지 않은 값을 임의 구현하지 않았다. 현재 기능은 서버 저장을 갖춘 연결 학습·지도·근거·자료 등록이며 다음 단계는 전체 콘텐츠 확장과 운영 후보 준비다.

후속 2026-11-03: 현재 구현/빌드 요청으로 [저장 복구 보완](../2026-11-03-connection-save-recovery/release.md)을 완료했다. 기존 제품 change에서 시작한 제한 환경 서버 재검사는 중단·코드 변경으로 exit 2를 남겼으며, 현재 코드의 통과 검사와 리뷰는 후속 change의 state.json을 따른다. 운영 후보 승인으로 간주하지 않는다.
