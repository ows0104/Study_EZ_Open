## 배포 대상 버전·순서·데이터 변경
codex/chunked-main-quiz-review는 최신master7b96003f에서 생성하고 PR11 및 기존 복구 후보를 보존 통합했다. 실제 리뷰 runtime은 후속 runs/chunked/runtime에 코드·지문으로 보존한다. 서버 읽기 호환과 고정 jsonschema 의존성, 실제 검수완료 반입 모듈을 포함한다. DB migration 없음. 순서: 코드 검사/독립 검토 → 실제 검수·원본/PNG·격리UI 확인 → 같은 검증 후보의 API/웹 배포 확인 → 지정 강의 자료 반입 → 읽기 확인. 반입은 원래 packet/result와 원본 snapshot 매핑을 분리하고 입력 지문을 유지한다. 실제 요청을 위조하지 않으며 처음부터 done인 명시적 반입 job·정책 표식을 남긴다.

운영 사전 확인: 지정 원본 SHA 일치, 해당 강의 기존 은행/RootContent/RootControl/사람 RootEvent/RootSession 없음. 반입 시 재검사해 달라지면 멈춘다. 기존 은행/개인 상태는 쓰지 않는다. 시범 공개 범위는 관리자 전용이며 학생 전체 공개로 확장하지 않는다.

## 배포 후 확인·롤백·필요한 사람 승인
사용자의2026-11-07 명시 “검수가 끝나면 이미지 문제까지 확인하고 업로드까지 이어서” 승인을 해당 강의의 검증된 업로드에 적용한다. 일반 master 자동 코드 배포는 기존 협업 정책을 따르며 배포의 실제 SHA/검사/health를 확인한다. 게시 후 result/document/원본 snapshot 해시, 원본 링크·검수 의견 읽기, 기존 은행/학생 기록 보존을 확인한다. 새 업로드만 비활성화할 수 있으며 보존한 원래 파일/실패/학생 기록을 삭제하지 않는다. 기존 활성 판이 생겼다면 자동 대체하지 않는다. 사슬알균 실험은 범위 밖으로 미실행이다.
