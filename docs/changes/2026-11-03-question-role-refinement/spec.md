# 분류·나열 역할과 연결 회상 검토 기준 — 설계

## 요구사항과 수용 기준
분류는 기준에 따른 하위 집단·소속을, 나열은 연결된 항목의 범위를 묻는다. 질문 형태·뼈대/가지/세부·학습 단계 역할을 별도로 기록한다. 나열은 초기 조망과 후기 통합 모두에 쓸 수 있다. 답 단위·범위·부분 회상·도움 여부를 명시하며 전체 암기를 진입 조건으로 강제하지 않는다.

## 책임·입출력 계약·오류 상태
mapping-review.md에 검토 규칙, first-ten-review.md에 10묶음 역할과 후속 검토 기준을 기록한다. 기존 JSON 스키마에 새 필드를 넣지 않는다. 출처 맥락은 보존하되 발문의 불필요한 “강의에서”는 제거한다. 범위가 불명확해지면 발문 자체를 재설계한다.

## 호환성과 데이터 보존
기존 CLI 원문·은행·ID·검수 상한·학습 기록을 보존한다. 이번 산출물은 교육 설계 검토이며 의학적 답안 수정·검수 통과나 실제 학습 완료를 뜻하지 않는다.
