# Main-Quiz 「문제 수정·제보」에서 문항 형식 바꾸기

## 문제와 사용자 효과
사용자(2026-11-17): 「문제 수정할때 유형이 안바뀌어.」 「주관식 -> clozed. 유형을 바꾸는 선택지가 없었어.」
설계 확인에서: 「유형은 전부 다 바꿀 수 있도록. 다만 적당한 형식 제한이 걸리긴 하겠지」.
Main-Quiz 풀이 화면의 「문제 수정·제보」는 발문·정답 글만 내 수정본으로 저장한다(`bank_personal_edit`).
형식 칸이 없어 주관식을 빈칸으로(또는 다른 형식으로) 고칠 수 없다.

## 범위와 성공 기준
- Main-Quiz가 다루는 여섯 형식(주관식·나열·빈칸·OX·객관식·복수 선택) 사이를 수정창에서 바꿀 수 있다.
- 형식마다 최소 조건을 지켜야 저장된다: 나열 2항목 이상, 빈칸은 발문에 `{…}` 1개 이상, OX는 O/X,
  객관식은 보기 2개 이상·정답 1개, 복수 선택은 정답 1개 이상(전부는 아님).
- 바꾼 형식은 판 문항과 같은 모양으로 보인다(빈칸 채우기, OX 「X: 이유」, 보기 고르기).
- 내 계정에만 적용(지금 개인 수정과 같음). 「원본으로 되돌리기」는 형식도 되돌린다. 관리자 제보에 형식 변경이 적힌다.

범위 밖: 형식을 그대로 둔 채 보기·정답 ID만 고치기(지금처럼 글만), 기존 Quiz Bank 수정창, 「내 문제」, 관리자 공용 수정.
