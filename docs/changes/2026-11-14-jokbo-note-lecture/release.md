  - 노트가 있을 때 누르면 커서 자리에 들어감, 「시작」 뒤 풀이 화면에서도 버튼 유지.
  - 노트가 없을 때 누르면 새 노트에 저장은 되지만 개발 서버 화면에서는 빈 줄로 보임 — React StrictMode(개발에서만)가
    새로 붙은 글 칸의 mount effect를 다시 돌려 innerHTML을 처음 값으로 되돌리는 것(MutationObserver로 삽입 직후 제거 확인).
    운영 빌드는 StrictMode 이중 실행이 없다. 이번 변경과 무관한 기존 경로이며 운영 빌드에서는 따로 확인하지 못했다.
