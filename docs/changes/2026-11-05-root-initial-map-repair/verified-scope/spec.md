# 계약
초기 원본 추출의 실제 완료와 지도 의미/참조 유효성을 구분한다. 구조를 읽을 수 있는 원본 지도는 원문·사용량을 보존하고, 초기 지도 오류를 첫 문항 변환/지도 작성 호출에 함께 전달한다. 초기 지도 교정이 필요하면 이 호출 전에 총3회 중1회를 소비한다. 이후 문항 교정은 남은2회 이내다. 정상 초기 지도는 첫 작성에서 보존한다.
선행 관계는 초기 지도에서는 관계 종류·대상·순환을 검사하되 검수 전 상태를 허용한다. 최종 게시에서는 기존대로 실제 검수된 관계만 채택한다. 잘못된 일반 연결/비교·끝점·순환을 통과시키지 않는다.
초기 원문은 initialBrief로 보존하고 교정 뒤 문항을 본 지도는 derived다. 원본·범위·출제포인트 원문/ID는 보존한다. 최종 manifest는 초기 오류와 교정 비용, 전후 지도, 모든 검수 및 같은 총상한을 검증한다. 실패 native 호출은 재실행하지 않는다.
이미 모델 호출 자체는 끝났고 raw/input/usage가 보존된 failed normalize만 명시적 운영 복구 명령에서 증거를 확인해 재검증한다. 원래 failed ledger와 지문을 별도 보존하고 현재 실행 지문으로의 검증 이력을 결과에도 넣는다. 이 명령은 모델/서버/DB를 호출하지 않고 raw 내용을 고치지 않는다. 중단 호출·불일치·사용량 누락·후속 단계 존재·반복 복구는 차단한다.
