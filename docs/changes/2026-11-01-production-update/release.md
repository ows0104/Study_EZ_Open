# 검증된 최신 master 서버·웹 운영 배포 — 배포 준비

## 코드 리뷰·검증 결과
대상 코드는 master 35663e610ed003182e05fddfd828e871336fc389이다.
이전 세션의 Python 1,500개·서버 86파일·웹/확장 217개와 빌드가 통과했다.
이번 배포의 격리 서버 전체 검사·운영 웹 빌드·공통 계약 검사 결과는 state.json에 새로 연결한다.
후보에는 allowlist 서버 코드/공용 계약 또는 검증된 web/dist만 포함한다.
운영 DB 39개 모델의 누락 칼럼은 없고 보존·개인 정보 표 6개 모두 RLS가 켜져 있다.
이전 운영 후보와 DB 모델 변경이 없어 DB 변경을 실행하지 않는다.
웹 빌드는 테스트 토큰과 가짜 로그인 분기가 번들에 없는지도 검사했다.

## 배포 대상 버전·순서·데이터 변경
Cloud Run 서버를 새 release-attempt 버전으로 준비하고 Ready·정확한 버전·100% 트래픽을 확인한다.
그 뒤 고정 웹 후보를 Cloudflare Pages study-ez-open/master에 게시한다.
기존 운영 환경과 비밀 연결을 유지한다. 배포 스크립트의 기존 Secret Manager 동기화 외에 권한 범위·계정을 확대하지 않는다.
강의 원문·문항·학습/개인 기록·R2 자료 교체는 없다.

## 배포 후 확인·롤백·필요한 사람 승인
사용자의 “사이트에도 최신 버전으로 배포해줘”라는 현재 요청이 이 서버·웹 운영 배포의 승인 근거다.
후보별 실제 ID·승인·배포 영수증·사후 검사 결과를 state.json에 기록한다.
postcheck.py는 공개 HTTP·CORS·인증 차단, 기존 runner 권한의 읽기 전용 자료 조회,
웹 HTML·JS·CSS·정본 프롬프트의 SHA256을 운영 두 도메인과 배포 고유 주소에서 확인한다.
실제 로그인된 별도 확인 탭에서 시간표·학습 현황·문항 목록/답변 열람을 확인하며 평가 저장은 하지 않는다.
