# 공통 계약과 수용 기준
신규 요청은 source-assessment/2를 사용하고 legacy /1 요청·완료 자료는 기존 규칙으로 읽는다. 기존 실행의 입력/코드 지문과 모델 수정 상한을 초기화하지 않는다. 초기 웹 출제 규칙·범위·의학 내용의 CLI 전담을 보존한다.

1. 방향별 필수 회상 요소와 시각 입력 여부를 독립 지도에 기록한다. 원본 검수는 문항별 각 요소의 answer/provided/explanation/missing/unknown과 실제 answer_units 위치를 판단한다. 한 문항에서 전부 답하는 검토된 연결만 준비다. 여러 문항 합집합, 발문 제공·해설, 의심·오류 판정은 준비를 만들지 않는다. 의미 판단 자체의 정확성을 코드가 보증한다고 주장하지 않는다.
2. 한 수정 라운드는 model-authored brief+bank+그림 명세+임상 충돌 설명을 반환할 수 있다. 초기 독립 지도와 모든 전후 revision·이유를 보존한다. 원문 포인트·제외 범위는 보존하며 의미 변경은 새로운 검토와 중요도 근거 재확인을 요구한다. 질문을 본 지도 수정은 source-only 독립 추출로 재인증하지 않는다. 검수 전 관계 상태와 새 원본 관계 판정은 분리하고, 강의 ID/문항 ID로 특례 처리하지 않는다. 동등성 승계는 기존 보수적 hash 규칙과 빈 자동 equivalences를 유지한다.
3. 지적은 question_fix/map_fix/required_gap/optional_extension/limitation/confirmation으로 구조화한다. 수정 가능한 실제 오류·필수 누락만 반복 수정한다. 선택적 누락·자료 한계·긍정적 확인·doubt만 남으면 기록하며 종료한다. source+medical 검수와 총 3회 수정 상한은 유지한다.
4. 일반적인 PDF 원본 crop 명세를 렌더하고 출제·원본 검수·도구 없는 정답 검수·학생 질문 화면에 동일 PNG를 전달한다. source/page/bbox/bytes hash/크기를 검사한다. 교체 그림은 문항 지문에 포함하여 동일성 판정에 반영한다. 파일 경로·정답 주석·crop 이유를 학생에게 노출하지 않는다. 기본 크기·전체 용량 한도를 두고 잘린/위변조 그림은 거절한다.
5. 실제 model-authored 선행 관계의 존재·순환·필요성을 검토하고 첫 학습 순서와 서버 추천에 반영한다. 검토되지 않은 선행 연결과 준비되지 않은 선행 문항은 완료로 가정하지 않는다. 오답 후 다음 연결은 기존 정책대로 연다. 문항·정답은 순서 정리를 이유로 바꾸지 않는다.
6. 별도 임상 충돌 projection에는 의학적 충돌만 둔다. 원본 검수에서 원래 충돌과의 내용 일치/역사적 판정 분리를 확인한다. 독립 정답 검수는 실제 문항·답·해설·그림과 이 임상 충돌만 보며 과거 sourceAudit/medical/중요도/수정 요약을 받지 않는다. 원래 이력은 별도 보존한다.

모든 검사는 비의학 합성 자료/자체 생성 PDF와 격리된 로컬 DB/저장소를 사용한다. 운영 DB 접근·배포·실제 강의 재출제는 없다.
