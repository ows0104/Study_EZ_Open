# Main-Quiz 개념 지도 패널 옆 붙이기·확대 복원

## 문제와 사용자 효과
#51 배포 뒤 사용자(2026-11-09): 「오 좋은데? 뒤에 점점 격자를 없애고 움직이고 확대할 수 있게 하자. 그리고 좌우 공간을 더 써서 사이드 패널이 Map을 안 가리게 하자.」

#51에서는 고정 맞춤과 겹침 패널을 넣었는데, 두 가지가 문제였다.
- 패널이 지도의 한쪽을 가렸다.
- 크게 보고 싶을 때 확대할 수 없었다.

## 범위와 성공 기준
- 지도 바탕의 점 격자를 없앤다.
- 끌어 옮기기, 휠·두 손가락 확대, ＋/－/전체 버튼, +/−/0 키를 되살린다.
- 처음 화면은 전체 맞춤이다(#51처럼). 따로 움직이지 않았다면 창 크기나 패널이 바뀔 때 다시 맞춘다.
- 사이드 패널은 지도 옆에 붙는 열이다. 패널이 열리면 지도 영역이 그만큼 좁아질 뿐, 지도 위를 덮지 않는다.
  - 고른 주제는 패널 옆 남은 영역 안에 보인다.
- 좌우 여백을 줄여 지도가 가로로 더 넓게 쓴다. 지도 화면만 페이지 좌우 패딩을 줄이고 틀 테두리를 얇게 한다.
- #51의 정리(지도 위아래 요소 없음, 페이지 스크롤 없음)와 #50의 트리 규칙은 그대로 둔다.
- 서버·데이터는 바꾸지 않는다.
