# Main-Quiz 공개된 판 새로 출제(관리자 명시)

## 문제와 사용자 효과
공개된 Main-Quiz 판이 있는 강의는 새 요청이 409로 거절된다(판 교체 때 학습 기록 승계가 정해지지 않아서).
같은 구조·같은 자료의 판(리케치아 261110_03)은 공개를 닫아도 입력 지문이 같아 옛 요청을 돌려줄 뿐이라 다시 만들 길이 없었다.

## 범위와 성공 기준
- 사용자 결정(2026-11-12): 「학습기록 날려도 돼」, 리케치아 「고쳐서 재출제」.
- `restart: true` + `replacePublished: true` + 이유로, 공개된 판이 있는 강의에 새 요청을 만들 수 있다.
- 새 판이 게시될 때까지 학생은 옛 판을 그대로 본다. 게시되면 `put_result`가 새 판으로 바꾼다.
- 플래그가 없으면 지금처럼 거절한다.

## 근거·미정 사항
- 학습 기록은 새 판으로 옮기지 않는다(바뀐 문항은 처음부터). 옛 판·이벤트는 DB에 남는다.
- 화면 버튼은 만들지 않았다. 지금은 API 본문으로만 보낸다.
