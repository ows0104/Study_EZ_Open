# 앞 단계 은행 crop 형식

## 문제와 사용자 효과
2026-11-24 기본 모델을 gpt-6.2-sol로 바꾼 뒤(`08302578`) Main-Quiz 두 편이 「연결 자동출제 보류: 그림 원본/crop 불일치」로 멈췄다:
261124_03 혈관염(박진균)(그림 지정 14개)과 261124_01(8개). 둘 다 지정 **전부**를 `[x, y, 폭, 높이]`로 썼다.
렌더러(`quizbank/connection_visuals.py`)는 `[left, top, right, bottom]`을 읽는다. 11-23 앞 단계 은행 6건은 틀린 지정이 0개였다.
그림 영역 자체는 맞았다. 261124_03 VASC-Q019 `[0.662, 0.359, 0.314, 0.177]`을 x·y·폭·높이로 자르면 23쪽의 CT·조직 사진이다.

빈틈 둘:
1. 앞 단계 은행 과제문(`map-tree/bank-task.md`·`bank-task-v4.md`)에 crop 형식이 없다. v3/v4 add·fix 지시문에는 `crop[left,top,right,bottom]`이 있다.
2. 앞 단계 은행 검사는 「0~1 숫자 4개」만 본다. 모델에게 되돌아가지 않고 앞 단계 전체(약 15분)를 마친 뒤 렌더에서 편이 멈췄다.

## 범위와 성공 기준
- 과제문에 형식을 한 문장 넣고, 앞 단계 은행 검사가 `0<=left<right<=1`, `0<=top<bottom<=1`을 확인한다.
  거절은 기존 후속(같은 세션 한 번)으로 모델에게 되돌아간다.
- 자동 변환은 하지 않는다. 폭·높이로 쓴 값이 우연히 left<right를 만족하면 조용히 틀린 그림이 붙는다.
- 고친 뒤 두 편을 다시 돌린다.
- 넣지 않는 것: 렌더러, /4 단계, 서버·웹·DB.
