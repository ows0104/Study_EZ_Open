- 과제가 안 된 목표 22개의 이유: 지도 확인의 중요도 근거 판정(target) 9, 커버 문항 없음 6, 그림 판정 4, 선행 미준비(dependency) 4.
- 실제 재생은 프롬프트에 「reason은 한국어로」 한 줄을 넣기 전 판이다. 판정 이유가 영어로 왔다.

**리뷰에서 확인한 경계**
- /2: `medical_input` 정규식에 이름만 붙였다. /2 검사는 그대로 통과한다.
- 결과 검증은 새 manifest 칸 세 개를 요구한다. 서버에 반입된 /3 결과는 없다.
- 재사용된 검토 단계(판정 장부로 다시 묻지 않은 단계)는 ledger에 남는다. 처음 구현에서 이것까지 보관해 버리는 것을 사본 재생이 잡았다.

**남은 위험**
- 끝까지 돈 실제 강의는 하나다. 다른 강의의 새 멈춤은 단계 실패(이어 하기 대상)이거나, 여기서 못 본 강의 단위 관문이다.
- 실제 모델 판정의 흔들림은 재지 않았다.
- Windows 경로 한도까지 여유가 3자다(`.resume-99` 기준). 넘으면 시작할 때 멈춘다.
