# spec

운영 조회는 학습 기록을 바꾸지 않는 전체 문제·해설·상태 갱신만 사용한다. 비밀값·토큰을 수집하지 않는다. 과거 갱신 실패는 현재 정상과 원인 확정을 구분한다. 배포 도구는 기본 Python 경로를 실행 본문에서 결정하고 고정 후보 attempt에 대응하는 고유 revision을 생성한다. 정확한 새 revision의 컨테이너 준비 및 latestCreated를 확인한 뒤 명시적으로 100% 트래픽을 전환한다. 최종 latestCreated/latestReady/traffic이 모두 기대 revision과 맞아야 성공 기록을 허용한다. 다른 버전·생성/조회/전환 실패는 성공으로 처리하지 않는다. 이번 작업은 로컬 도구 보완과 운영 읽기 검사이며 새 운영 배포는 필요하지 않다. 원본 데이터·문항·기존 작업을 보존한다.
