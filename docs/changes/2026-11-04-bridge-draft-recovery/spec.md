# 기본 링크 버튼 및 GPT 브리지 이전 초안 충돌 복구 — 설계

## 요구사항과 수용 기준
1. 관리자가 작년 필기가 있는 강의의 예습 기본 링크 만들기 카드를 누르면 start("shared", false)를 통해 자료·최신 공통 예습 프롬프트를 담은 직접전송 요청을 연다. 별도의 자동전송 도구는 현재 자동전송 동작을 유지한다. 기존 링크 열기·교체 확인·학생 권한·필기 없음/진행 중 조건은 유지한다.
2. 직접전송은 자료와 프롬프트만 입력한다. 자동전송은 기존 동의와 업로드 확인을 거쳐 전송 버튼을 한 번만 누른다.
3. 브리지가 남긴 미전송 초안은 요청 식별자와 내용 지문으로 추적한다. 동일한 미변경 초안으로 확인된 경우에만 이전 첨부를 정리하고 현재 요청을 준비한다.
4. 기존 버전에서 남긴 초안 또는 출처를 확인할 수 없는 내용은 자동 삭제하지 않는다. 팝업에서 남은 초안·첨부의 존재와 복구 동작을 설명하고, 사용자가 명시적으로 입력창 정리를 선택하면 화면을 재확인한 뒤 이번 요청을 진행한다. 선택하지 않으면 내용은 유지한다.
5. 입력 수정·이동·취소·이미 전송됐을 가능성이 있는 상태에서는 자동 복구/재전송하지 않는다. 초안 복구는 전송 버튼을 누르기 전의 충돌에 한정한다.

## 책임·입출력 계약·오류 상태
예습 기본 링크 카드의 버튼과 권한·시작 모드는 PreviewAction의 책임이다. 초안 판정·첨부 확인·복구 UI는 ChatGPT 입력 브리지, 요청별 최소 상태 전달은 background의 책임이다. 기록에는 요청 식별자·지문·미전송 여부만 두고 프롬프트/파일 본문을 새 영구 저장소에 복제하지 않는다. 팝업 오류 원인을 구분해 기존 입력 내용, 알 수 없는 첨부, 사용자 수정, 업로드 실패를 서로 다른 상태로 표시한다.

## 호환성과 데이터 보존
기존 대화·공유 링크·완성 MD·확장 미저장 응답·서버 작업·문제은행·학습/검수 기록·출제 상한을 보존한다. 서버의 충돌 검사를 우회하거나 이전 작업을 일괄 취소하지 않는다. 예습·복습·Gemini·Claude의 기존 동의/직접전송 동작을 유지한다. 이번 변경은 로컬 코드·검사·패키지 생성까지이며 운영 배포와 실제 강의 자료의 GPT 자동전송은 포함하지 않는다.
