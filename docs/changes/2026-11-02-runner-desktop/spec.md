# 창 없는 러너 프로그램과 1분 자동 시작 — 설계

- 바탕화면 바로가기는 실제 pythonw.exe로 프로그램 창을 열며 명령창을 표시하지 않는다.
- 창을 연 뒤 단조 시계 기준 60초 동안 시작·취소 입력이 없으면 기존 runner agent를 숨김 실행한다.
- 시작은 즉시 실행, 자동 시작 취소는 해당 창의 자동 실행을 영구 해제한다. 창 닫기도 대기를 취소한다.
- 강의별 예습·복습 행을 따로 표시하고 시작·중지·취소를 적용한다. 중지는 재개 가능한 보류,
  취소는 자동 재등록 제외다. 예습·복습·다른 강의에 조작이 번지지 않는다.
- 예습 링크/복습 올해 필기를 준비 기준으로 표시한다. 복습은 현행 bank 경로를 사용하고
  저장된 웹 응답이 없으면 필수 자료 대기로 표시한다. 구형 main 경로와 CLI 최초 출제는 되살리지 않는다.
- 자동 시작은 현재 시간표 범위에서 준비되고 미완료인 신규 작업만 등록한다.
  완료·실패·중지·취소·전략 대기·일일 상한을 우회하지 않는다.
- 전체 일시정지는 로컬 러너와 실행 작업을 보존 가능한 상태로 멈추고 전체 재개 시 이어 간다.
- 이미 실행 중인 러너는 새로 만들지 않고 연결한다. 여러 창의 동시 조작은 파일 잠금으로 직렬화한다.
- 실행 여부 확인 실패 시 시작을 보류하고 오류를 보여 준다. 실패·종료 후 자동 재시작하지 않는다.
- 중지·취소는 로컬 제어 파일과 기존 서버 작업 상태에 연결한다. 러너가 해당 하위 프로세스만 종료하며
  상태가 확인되기 전에는 중지 완료로 표시하지 않는다. 전체 중지와 개별 중지를 구분해 재개한다.
- 창을 닫아도 시작된 러너는 계속 실행된다. 기존 상태 전용 창 동작은 유지한다.
- 로그는 runs/agent.log에 추가한다. 원본·문항·ID·검수·HOLD·CHOSEN·학습 기록은 삭제하지 않는다.
- 기존 시간표 범위, 동시성, 검수 상한과 서버 큐의 취소·재개 규칙을 유지한다.

수용 검증: 60초 직전/도달, 시작/취소/닫기, 실행 중 연결, 중복 시작, 조회·실행 실패,
강의·갈래 격리, 전체 일시정지/재개, 기존 취소 계약과 명령창 없는 실제 GUI 확인.
