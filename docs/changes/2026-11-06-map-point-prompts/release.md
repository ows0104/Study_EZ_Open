# Review · Map/포인트 프롬프트와 JSON 출력 형식

기준 revision a3f67d13, 작업 브랜치 codex/map-point-prompts. 현재 사용자 승인 범위의 두 원본 전용 프롬프트·JSON Schema·비의학 합성 예시·개발용 검증만 작성했다.

## 최종 변경

- Map: 중심 질문·개념·관계·큰 흐름에 집중한다. 문항·누락 판정·회상 평가·문항 순서를 지시하지 않는다. concepts/relations가 그래프이며 sections는 표시용 묶음이다. 여러 부모·교차 소속·비계층 관계의 실제 순환을 허용한다.
- 포인트: groups/points/directions로 독립 목표와 필요한 회상을 구별한다. 단서·답 범위·핵심 요소·조건·예외·그림 및 구조/시험/임상 중요성 근거를 기록한다. 심화 여부는 별도다.
- 각 JSON은 버전·원본·범위·근거·불확실성·추출 상태를 명시한다. 읽을 수 없는 자료는 빈 내용 목록과 한계로 표현한다. 두 결과의 ID 대응은 이후 별도 대조다.
- 프롬프트에 전체 필드 작성법과 JSON 예시를 포함했다. 반복 금지문 대신 작성 방향을 제시하는 문체를 유지했다. 기존 원본/내용 보존 정책과 공통 문항 품질 철학을 검토했다.

## 실제 검증

프로젝트 .venv의 jsonschema로 두 스키마의 메타 검증, 프롬프트의 JSON 예시와 별도 예시 파일 일치, 정상 예시 수용을 확인했다. 비정상 16사례(필수 항목/추가 키, 참조/중복 ID, 쪽수/위치, 방향/분류 순환, 답 요소/중요도 근거, 빈 성공/한계 없는 partial)를 거절했다. 여러 부모·교차 소속·인과 순환과 unreadable 두 사례는 수용했다. verify_formats.py는 개발 검증 전용이며 운영의 수신·저장 검증기로 연결되지 않았다.

최초 server/.venv에는 jsonschema가 없어 실행하지 못했다. 의존성이 있는 기존 프로젝트 .venv로 검증을 완료했으며 패키지/환경 변경은 없다. 실제 결과 요약은 prompt-review 로그와 state.json에 남긴다. git diff --check 및 신규 파일을 포함한 staged diff 검사도 수행한다.

JSON Schema만으로 교차 참조·원본 쪽수·의학적 정확성을 모두 확인할 수 없다. 개발 검증의 참조/구조 검사는 합성 자료에서 확인한 것이며 실제 모델의 추출 품질·전체 원본 열람·의학적 정확성을 인증하지 않는다.

작성 자산 안내에 따른 기존 회귀 검사도 실행했다. tests/quizbank/test_generate.py + test_runtime.py는 16개 통과, web/tests/bank-prompt-current.test.cjs는 7개 통과했다. 최초 Python 검사의 임시 폴더 권한 오류(7통과/9설정 오류)는 새 작업 폴더 내 임시 경로로 해결했다. 웹 검사의 누락된 TypeScript 의존성은 기존 설치 폴더를 worktree에 연결해 해결했다. 이 과정에서 테스트/운영 코드를 바꾸거나 새 패키지를 설치하지 않았다. 전체 웹 통합/모델 품질 검증으로 확대해 해석하지 않는다.

## 운영·보존

모델 호출/웹 전송/출제 재개/운영 배포 없음. 중단된 요청 548과 기존 문항·학습·원장·검수 상한은 변경하지 않았다. 현행 자동 생성기의 통합 추출 및 learning-brief/2/PLAN 계약은 유지한다. 실제 응답 수신·저장·화면·호출 분리·후속 대조의 연동은 별도 작업이다. 복원은 이 프롬프트·새 출력 형식·안내의 변경만 되돌린다.
