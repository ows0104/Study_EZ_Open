# 91문항 고정 분할 원본검수 및 이미지 확인·업로드 — 설계

## 요구사항과 수용 기준
원래91문항·brief·visual_stimuli·clinical_conflicts와 수정2/3을 불변으로 고정한다. 실제 CLI에서 문항15개씩 원본/설계/회상요소/선행/이미지 검수, 관계40개씩, 목표/방향24개씩 검수한다. 동일 전체 원본과 전체 기준/문항을 제공하며 할당된 ID만 출력한다. 전역 검수는 전체 원본·지도·문항·모든 묶음 결과를 대조해 목록 밖 누락·중복·임상충돌·전체 커버리지 지적을 남긴다. 의학 정답 검수는 과거 판정/원본을 제외한 기존 blind 입력으로 문항15개씩 별도 수행한다. 전체 ID/쌍의 정확한 포함과 기존 전체 compile/schema 검사를 통과해야 완료다. 콘텐츠/판정 수동 교정은 하지 않는다.

## 책임·입출력 계약·오류 상태
quizbank 분할 CLI와 runner 명시적 continuation이 새 출력 폴더에서 수행한다. 원래 전체 디렉터리 해시목록·실패 ledger·모델 timeout·partial usage unknown·runtime archive를 보존 연결한다. 완료 영수증·입력/스키마/자료/출력 지문·모델 사용량을 검증하며 중단/실패/다른 입력은 자동 반복하지 않는다. 전체 결과의 추가 continuation 증명은 공용 계약에서 검증한다. 원래 source-2 파일/ledger를 덮어쓰지 않는다.

## 호환성과 데이터 보존
예산을 초기화하거나 새 문항을 생성하지 않는다. 신규 검수 판정은 별도 기록이며 이전 판정을 지우지 않는다. 구조/원본/그림 검증 후 기존 게시 정책으로 업로드하고 실제 화면을 확인한다. 업로드 전 기존 운영 은행/자료/학습 영향과 수용 가능 여부를 확인하며 사람 학습 기록은 생성하지 않는다. 상한/판정 예외를 만들지 않는다. 실패하면 실제 상태를 보존하고 자동 재호출하지 않는다.
