# 좁은 화면 글씨 줄바꿈 — 설계

## 요구사항과 수용 기준

- R1 캘린더 칸: 강의명이 칸보다 긴 낱말이면 글자 사이에서 접는다(`overflow-wrap: anywhere`).
  칸 폭이 80px 이하(휴대폰)면 여백·글씨를 줄이고 음절 사이에서 접어, 안쪽 높이 62px 이상인
  칸은 제목 세 줄 + 교수 한 줄을 보인다. 학습 막대 칸은 66px 이상일 때만 세 줄이다.
- R2 강의 목록: 560px 이하에서 옆 칸을 좁혀 강의명 칸을 넓히고, 표가 640px 이하이면 강의명·
  교수 줄을 한 줄 말줄임 대신 두 줄까지 접는다. 머리줄 글자는 칸 안에서 접는다.
- R3 캘린더 머리: 제목과 오늘 할 일 카드가 한 줄에 안 들어가면 카드를 다음 줄로 내린다.

## 책임·입출력 계약·오류 상태

CSS만 바꾼다. 서버·API·데이터·문구는 바뀌지 않는다. 모든 규칙은 `responsive.css` 한 파일에
있고 main.tsx가 마지막에 부른다. 화면별 css가 늦게 붙어도 이기도록 `:root`를 붙인다.

## 호환성과 데이터 보존

데이터 변경 없음. 넓은 화면은 조건에 걸리지 않는다(R1의 `overflow-wrap`은 넘칠 때만 끊고,
R3의 줄바꿈은 안 들어갈 때만 일어난다). 파일을 빼면 이전 모양으로 돌아간다.
