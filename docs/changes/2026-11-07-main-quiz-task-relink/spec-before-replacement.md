# 검수통과28문항 보존형 과제재연결과 이미지 후속검수 — 설계

## 요구사항과 수용 기준
원래 result/packet/source/medical/manifest/bank 전체hash를 고정한다. 누락28문항과 누락6그림문항의 합집합에 대해 실제CLI가 새 회상목표·근거·단위/관계를 제안하고 다른 실제CLI가 원본PDF/정답/실제그림/한계/중요도를 독립 확인한다. 원래 판정은 불변이며 원래 통과28 외에는 새 원본·의학·시각 판정 모두 ok인 경우에만 추가한다. 기존 의심/오류를 삭제하거나 통과로 바꿔 쓰지 않는다.

## 책임·입출력 계약·오류 상태
순수 task-supplement 계약: 원래문서에 새 개념/관계/목표/포인트/매핑/검수근거/과제만 append. 기존49과제와 그 의미hash는 불변, 모든91문항/원본이미지 byte 불변. 파일/모델회차/보호입력/코드hash/실패를 보존한다. 실제CLI 미완료·명세변조·한계 미해결은 준비상태로 표시하지 않는다. 원래3/3은 유지하며 후속 모델호출을 별도 기록한다.

## 호환성과 데이터 보존
서버는 원래RootContent/RootGeneration/RootEvent/RootSession/QuizBank/BankState를 보존하고 새판/별도 supplement 영수증/관리자 publication 사건만 추가한다. 기존49방향의 direction_hash가 동일할 때만 명시적 equivalences로 원래 학습기록을 읽는다. 새과제는 미학습이며 사람 학습사건을 만들지 않는다. 기존세션은 원래판을 계속 읽는다. 원본링크/과거 검수노트와 새 후속 검수노트를 함께 제공하고 공개범위는 기존 관리자시범 그대로 유지한다.
