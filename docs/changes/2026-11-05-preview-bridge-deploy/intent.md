# 예습 기본 링크·GPT 초안 복구 운영 웹 배포

## 문제와 사용자 효과
사용자 2026-11-05 현재 채팅: “운영 사이트에도 배포해줘.” 이전 2026-11-04 승인·구현·검사한 예습 기본 링크 버튼과 GPT 이전 초안 복구를 실제 운영 사이트에 적용한다.

## 범위와 성공 기준

## 근거·미정 사항
원 구현 근거는 ../2026-11-04-bridge-draft-recovery/다. 현재 작업트리에는 다른 작업의 미커밋 변경이 있어 전체 빌드를 바로 배포하지 않는다. tmp/root-web의 운영 검증 사본에서 재빌드가 이전 운영 후보와 일치하는지 먼저 확인한 뒤 승인 범위만 적용한다.
