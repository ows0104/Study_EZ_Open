## 자세한 설명

StudyEZ 예습 브리지는 StudyEZ에서 선택한 작년 강의 필기와 예습 프롬프트를
ChatGPT의 새 대화에 준비합니다. 확인 화면에서 자료와 데이터 처리를 검토하고
동의하면 PDF가 첨부되고 프롬프트가 채워집니다. 메시지 전송은 사용자가 직접
누릅니다.

답변이 완성되면 개인 대화 주소를 해당 StudyEZ 강의에 연결합니다. 관리자가
기본 링크를 만드는 경우에는 링크를 가진 누구나 볼 수 있는 ChatGPT 공유 주소를
생성해 같은 강의를 보는 사용자들이 함께 이용할 수 있게 합니다.

주요 기능:

- 선택한 강의 PDF와 프롬프트를 ChatGPT에 준비
- 전송 전 파일 목록과 데이터 처리 내용을 확인하고 명시적으로 동의
- 완성된 개인 대화 주소를 StudyEZ 강의에 연결
- 관리자 기본 링크 모드에서 공개 공유 주소 생성 및 연결
- StudyEZ, ChatGPT, 지정된 Cloudflare R2 주소에서만 작동

## 단일 목적

사용자가 StudyEZ에서 선택한 강의 자료와 예습 프롬프트로 ChatGPT 예습 대화를
만들고, 완성된 대화 링크를 해당 강의에 연결하는 기능만 제공합니다.

## 권한 사유

### storage

진행 중인 강의 요청과 아직 StudyEZ에 저장되지 않은 대화 링크를 해당 브라우저
세션 동안 임시 보관합니다. 저장 확인을 받으면 삭제되며 장기 추적에 사용하지
않습니다.

### 호스트 권한

`study-ez-open.pages.dev`에서 사용자가 선택한 강의·파일 요청을 받고 완성된 링크를
돌려줍니다. `chatgpt.com`에서 사용자가 동의한 PDF와 프롬프트를 준비하고 대화
완료 및 링크를 확인합니다. 지정된 Cloudflare R2 origin에서는 사용자가 선택한
PDF를 임시 서명 URL로 내려받습니다. 다른 웹사이트를 읽거나 추적하지 않습니다.

### 원격 코드

**아니요.** 모든 실행 코드는 ZIP에 포함되어 있습니다. 외부에서는 사용자 선택
PDF와 서비스 API 응답만 받아오며 JavaScript 또는 WebAssembly를 내려받아
실행하지 않습니다.

## 개인정보 설문 선택값

수집/처리한다고 표시:

- 인증 정보
- 개인적인 커뮤니케이션
- 웹 기록
- 웹사이트 콘텐츠

그 밖의 카테고리는 선택하지 않음. 위 데이터는 핵심 기능 제공에만 사용하고 판매,
광고, 신용평가, 사용자 추적에 사용하지 않는다는 Limited Use 확인란에 동의합니다.

## 심사자 안내 초안

1. 제공된 StudyEZ 심사용 계정으로 로그인합니다.
2. 승인된 캘린더에서 필기가 연결된 강의를 누릅니다.
3. “개인 예습 시작”을 누르면 ChatGPT 새 탭과 확장 확인 카드가 열립니다.
4. 데이터 처리 설명을 읽고 동의 확인란을 선택한 뒤 자료 넣기 버튼을 누릅니다.
5. PDF와 프롬프트가 준비되는 것을 확인합니다. 확장은 전송 버튼을 누르지 않습니다.
6. 메시지를 직접 보내 답변이 끝나면 대화 링크가 StudyEZ 강의에 연결됩니다.

관리자 전용 “기본 링크 만들기”는 같은 흐름 뒤 공개 공유 주소도 생성합니다.
로그인 토큰은 ChatGPT 요청에 메모리에서만 사용하며 StudyEZ로 전송하거나 저장하지
않습니다.

> 제출 전 실제 심사용 계정 이메일·비밀번호와, 필기가 연결된 강의명을 이 절에
> 추가해야 합니다. 비밀번호는 저장소에 커밋하지 않습니다.

## 등록용 ZIP 만들기

PowerShell에서:

```powershell
.\chrome-extension\build-store-package.ps1
```

결과: `chrome-extension/release/studyez-preview-bridge-1.0.0-web-store.zip`

스토어 항목이 게시된 뒤 Cloudflare Pages 빌드 변수
`VITE_EXTENSION_STORE_URL`에 실제 스토어 URL을 넣으면 웹앱의 개발자 모드 설치
안내가 웹스토어 설치 버튼으로 바뀝니다.
