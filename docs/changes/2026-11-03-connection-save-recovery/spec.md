# 저장 복구 계약

- 사용자/강의/콘텐츠 판/요청 ID별로 미확인 요청을 따로 보관한다. 같은 요청의 재전달은 같은 ID와 본문을 사용하며 다른 탭의 요청을 덮어쓰거나 지우지 않는다.
- 기존 단일 outbox 입력을 보존하여 새 보관함으로 옮긴다. 충돌 요청도 별도 상태로 보관하고 화면에서 원래 응답을 확인할 수 있게 한다. 잘못된 보관 데이터는 삭제하지 않고 오류를 표시한다.
- 요청 성공 후 최신 GET을 확인한 다음 해당 요청만 보관함에서 제거한다. 과거 중복 요청의 응답 스냅샷을 최신 화면으로 확정하지 않는다. GET 실패 시 같은 요청을 유지한다.
- 작성 중 응답은 사용자/강의/판/질문/단계별로 로컬 보관하고 재개 시 복원한다. 로컬 보관 실패는 사용자에게 알리고 미확인 쓰기는 서버 전송 전에 멈춘다.
- 운영 DB/콘텐츠/기존 은행/학습 기록을 변경하지 않는다. 서버 API 중복 처리 계약을 유지한다.
