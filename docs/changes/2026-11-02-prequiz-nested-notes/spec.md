# 감염과 면역 예습의 하위 폴더 필기 탐색 누락 — 설계

현재 사용자의 명시적 수정·내일 예습 재실행 승인을 적용한다.

- 연도 아래 1차/2차 등 실제 강의 하위 폴더를 탐색하는 범위를 정의하고 보관본·충돌 사본·중복 판을 구분한다.
- 현재의 교수·회차·연도·최신 판·확정 매칭 규칙은 유지한다. 폴더 밖으로 연결된 링크는 무분별하게 따라가지 않는다.
- 예습 링크만으로 실행 준비가 끝났다고 표시하지 않고 실제 작년 자료 매칭 상태와 구분한다.
- 기존 원본의 이동·복사·삭제, 검수 상한 초기화, 자동 실패 재시도는 하지 않는다.
- 해당 강의에서 작년 251103_02를 찾는지, 다른 강의/블럭/갈래로 잘못 연결되지 않는지 검증한다.
- 준비 판정은 생성/대화 회수 없이 로컬 필기와 확정 매칭을 조회한다. 링크만 있거나 미확정이면 필요한 자료를 표시한다.
- 재실행은 2026-11-03 예습으로 한정하며 링크 없음·원본 미확정·기존 완료/실행·사용자 중지/취소를 구분한다.
  force 없이 보존한 단계를 재사용하고 기존 실패 기록을 남긴 새 요청으로 처리한다.
- 11월 3일 TBL의 네 주제를 다루는 작년 두 강의 PDF는 순서·페이지·그림을 바꾸지 않고 합본 입력으로만 묶는다.
  파생 입력의 출처·원본 해시·합본 해시·대상 강의를 기록하고 원본·기존 강의 ID·학습 기록은 바꾸지 않는다.
- 프로그램의 러너 실행 환경은 기존 agent.ps1과 일치시켜 하위 PDF 도구 실행 실패의 재발을 막는다.
  보안 설정이나 실행 권한을 해제하지 않는다. 완료된 prep와 기존 시도/검수 이력을 재사용한다.
