# 심내막염·CNS Map·포인트에서 생성·검수·풀이 E2E 실험 — 구현 계획

## 변경 범위·대상 파일·순서
docs/changes/2026-11-06-map-point-e2e에 입력 준비·증명·로컬 풀이 실행 도구와 intent/spec/plan/release 기록을 둔다. Windows 긴 파일명 제한으로 원본 저장소의 runs/_e2e/26110507에 읽기 전용 입력 사본·실행 ledger·모델 원문/사용량·검수·결과·격리DB·화면 증거를 저장한다. 긴 경로의 초기 준비본은 기존 작업 공간에 보존한다. 기존 프롬프트·생성기·공용 계약·운영 라우트는 수정하지 않고 기존 NativeJson/connection_generate를 호출한다. 두 강의는 별도 실행하되 같은 원본 범위/출처를 정확히 보존한다.

## 검사 명령과 성공 조건
input-preservation: 원본/Map/최종포인트 SHA와 초기 개수·범위를 확인한다. generation-contract: 완료 result를 validate_result/NativeJson.validate_all로 검증하고 포인트 원문 보존과 actual ledger/검수상한을 확인한다. solve-flow: 실제 서버·UI에서 강의별 시작·응답·답공개·평가·새로고침·지도/근거 확인을 별도 기술확인 계정으로 수행하고 저장 사건을 대조한다. 관련 엔진 회귀도 수행한다. 실패한 단계는 자동 재호출하지 않는다.

## 위험·복원·승인할 범위
현재 사용자의 문제 생성부터 풀이까지 E2E 실행 지시를 본 로컬 실험 범위의 승인으로 적용한다. 승인 전 메시지/자동 사건에 근거한 개발이 아니다. 별도 브랜치·대시보드 점유 완료. 중요한 운영 변경·공개·기존 콘텐츠 교체는 포함하지 않는다. 복원은 로컬 서버를 종료하고 실험 진입 링크만 거둔다. 원본·실패·결과·사용량·학습 사건은 보존한다.
