# Main-Quiz 관리자 출제 기본값을 새 구조 2로 — 설계

## 요구사항과 수용 기준
- `RootGenerationPanel`의 초기 `mode`는 `map-tree-v4`다. 이 값으로 요청하면 `pipeline: "map-tree/3"`이 전송된다.
- 기존 작업이 없거나, 파이프라인 정보가 없는 옛 원본 작업을 불러온 경우(`modeOf`의 마지막 경우)에도 기본은 `map-tree-v4`다.
- 「기존 Concept map·출제포인트 사용」 체크를 해제하면 `map-tree-v4`로 돌아간다.
- 라디오 순서와 라벨은 다음과 같다.
  1. 새 구조 2 (기본)
  2. 새 구조 (시범)
  3. 개념 지도·출제포인트부터 (이전 기본)
  4. 병렬 (옛 방식)

## 책임·입출력 계약·오류 상태
- API 계약은 바뀌지 않는다. 서버는 `map-tree/1|2|3|null`을 이전과 똑같이 검증한다.
- 승인 안내(호출 상한·공개 범위)는 고른 구조에 맞는 문구를 이전과 똑같이 표시한다.

## 호환성과 데이터 보존
- 이미 만든 판, 진행 중이거나 실패한 요청, 이어 하기, 학습 기록, DB는 모두 바뀌지 않는다.
- 이어 하기는 원래 요청의 `pipeline`을 그대로 다시 보낸다.
- 이미 공개된 판이 있는 강의는 이전처럼 서버가 새 요청을 거절한다.
