# Implementation Plan
EventPanel.tsx에 기존 useMainQuizEntry hook import/호출을 추가하고 복습퀴즈의 조건 한 곳을 bank.usable 또는 structured 진입 가능으로 바꾼다. 실제 CalendarPage/강의 패널에서 새 자료만 준비·옛 은행 준비·둘 다 없음의 버튼/href/클릭을 격리 브라우저로 확인하고 웹 타입/빌드를 실행한다. 사용자 현재 승인이 이 좁은 수정·확인·PR 병합·사이트 배포를 모두 포함한다. 검증/리뷰 후 일반 코드 자동 배포로 반영하고 동일 SHA의 서버/웹을 확인한다. 복원은 이 변경만 revert하며 자료/기록은 변경하지 않는다.
