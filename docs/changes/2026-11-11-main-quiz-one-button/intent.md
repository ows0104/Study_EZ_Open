# Main-Quiz 관리자 출제를 버튼 하나로

## 문제와 사용자 효과
관리자 강의 패널의 「Main Quiz 만들기」에는 「설정·기존 지도 사용」 아래에 구조 네 가지, 기존 지도·포인트 입력,
출제 범위, 시험일, 「우선 내 계정에서만 확인」이 있었다. 지금 쓰는 출제는 가장 최신인 「새 구조 2」
(map-tree/3, root-generation/4) 하나뿐이라 나머지 선택지는 고를 일이 없고 잘못 고를 위험만 남았다.
이번 변경 뒤에는 예습 퀴즈처럼 버튼 하나만 누르면 최신 구조로 요청되고, 공개 범위만 체크 하나로 정한다.

## 범위와 성공 기준
- 사용자 요청 원문(2026-11-11): 「사이트에서 Main-Quiz 출제 버튼도 훨씬 단순화하자. 예습퀴즈처럼 다 빼고 버튼 하나만 남겨줘.
  선택지는 지금 가장 최신 파이프라인으로. 기본 학생 공개. 체크하면 학생 비공개.」
- 새 요청은 언제나 `pipeline: map-tree/3`, `inputMode: source`, `authoring: cli`, `parallelAuthoring: false`,
  빈 지도·포인트·범위, `examDate: null`(서버가 시간표에서 확인)로 보낸다. 오늘 새 구조 2 기본 선택이 보내던 값과 같다.
- 체크박스 하나 「학생 비공개 (내 계정에서만 확인)」. 기본은 꺼짐 = `privatePilot: false`(학생 공개),
  켜면 `privatePilot: true`.
- 버튼 옆에 보낼 자료(올해 필기 S1·족보 S2 → OpenAI Codex CLI), 구조(새 구조 2), 공개 범위, 호출 상한을 적는다.
  버튼 누름이 그 강의의 자료 전송·공개 승인이다(2026-11-09 결정, `docs/development/README.md` 「사람에게 묻는 것」).
- 구조 선택, 기존 지도·포인트 입력, 출제 범위, 시험일 입력은 화면에서 없앤다.

## 근거·미정 사항
- 서버(`server/app/routes/root_generation.py`)는 바꾸지 않는다. 요청 검증은 지금도 map-tree/1·2·3과 옛 방식을 모두 받는다.
  화면이 보내는 값만 하나로 고정한다. 러너도 바꾸지 않는다.
- 이어 하기(resume)는 원래 요청을 그대로 되풀이해야 서버가 받는다. 그래서 실패한 옛 구조 요청도 그 구조·공개 범위로 이어 간다.
- PR #91(`claude/root-default-v4`, 병합됨)이 기본 선택을 새 구조 2로 바꾼 것 위에 쌓는다.
- 예습 퀴즈 버튼(`web/src/calendar/DeckSlot.tsx`)은 선택지 없이 「만들기」 하나, 진행·실패는 아래 한 줄로 말한다. 그 모양을 따른다.
