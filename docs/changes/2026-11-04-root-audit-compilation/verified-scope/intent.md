# 연결 검수의 의미 판단과 구조·집계 분리

원래 시범은 BANK88문항 구조를 통과했으나 source AUDIT의 방향 밖 tested 배정과 coverage 모순으로 중단됐다. 기존 모델 출력은 고정 CORE/문항 hash/관계 역할/방향 충족/포인트 충족까지 모두 복사·집계하게 하며, AUDIT 구조 오류를 고칠 수 없는 BANK 수정에 전달해 수정 상한을 낭비한다.

사용자의 현행 “예시이며 실제로 쓰이지 않으므로 원인을 해결” 요청에 따라 생성 프로토콜을 고친다. 기존 잘못된 연결을 버리고 게시하는 제안은 진행하지 않는다. 같은 원본의 의학 내용을 부모 에이전트가 직접 고치거나 과거 시범을 새 검수 횟수로 재시작하지 않는다.

성공 기준은 고정 입력 참조·관계 역할·방향 연결의 모순을 구조적으로 막고, coverage를 결정적으로 계산하며, 기술적 출력 실패는 문항 수정 횟수를 소비하지 않는 것이다. 독립 의미 판단/검수와 엄격한 최종 검증은 유지한다.
