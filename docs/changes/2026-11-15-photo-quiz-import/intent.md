# 사진 실습 Main-Quiz 수작업 반입 — Intent

## 사용자 요청 (2026-11-15, 원문)

1. 「감염 병리 통합실습 Main Quiz를 만드려고 해. 여기에서는 사진이 많고, 족보를 분석해보면 알겠지만, 사진을 보고 물어보는 문제가 많아서 사진을 외워야해. 그래서 출제유형을 사진 중심형으로 해주면 좋겠어. 또 발문에서 너무 많은 정보를 다 줘서 사진을 안 보고 풀수있는 문제는 지양해. 그래서 단서를 더 주고 싶으면 힌트로 주면 될듯. 그리고 해설을 쓸때 저 사진이 뭐고 어떤걸 근거로 판별했는지를 알려주면 좋을듯. 그리고 나온 사진들이 버려지지 않고 출제되면 좋겠어.」
2. 「사이트에도 올리고 싶은데 어떻게 하면 좋을까?」 → 선택지 중 「파이프라인에 사진 중심 모드 추가」로 진행 지시.
3. 진행 중 결정(질문 답):
   - 「그냥 이번에는 파이프라인 따로 돌리지 말고 사진실습은 직접 import하자. 그리고 문제를 훑어봤는데, 아직도 발문에서 부위나 염색법, 임상 힌트를 꽤 주는 거 같아. 힌트란으로 넘겨도 될듯.」
   - 그림 상한: 「사진 중심 판만 상향」
   - 전략 선택(파이프라인 작업 때): 「둘 다」(자동 판정 + 요청에서 덮어쓰기) — 이번 작업 범위 밖, 후속.
   - #154와의 겹침: 「지금 시작, 나중에 rebase」

## 문제

- 사진 실습 강의(261104_05 감염 병리 통합실습)는 시험이 「증례 + 사진 → 진단·원인균」 형식이라 사진 자체를 외워야 한다.
  현재 Main-Quiz 파이프라인은 사진 중심 출제 전략이 없고, 강의당 그림 64장·8 MB, PNG만 허용한다.
- 같은 세션에서 손으로 만든 사진 중심 문항(실습 86문항, 사진 140장, 힌트·판독 근거·감별 포함)이 있다.
  사이트에 올릴 정식 경로는 파이프라인 결과(`validate_result`)뿐이라 반입할 수 없다.

## 원하는 효과

- 261104_05 Main-Quiz로 손으로 만든 사진 중심 문항을 사이트에서 풀 수 있다.
- 발문에는 부위·염색·임상 단서를 두지 않고, 답을 보기 전에 펼쳐 볼 수 있는 「힌트」로 준다.
- 해설은 사진 판독 근거·감별을 담는다. 강의의 판독 가능한 사진을 모두 쓴다.

## 범위

- 포함: 수작업 반입 정책(검수 증명을 만들지 않고 「수작업·미검수」로 표시), 문항 힌트 칸(서버 공개·웹 표시),
  사진 반입 판에 한한 그림 상한 상향과 JPEG 허용, 반입 도구, 261104_05 반입(운영 DB 쓰기는 별도 확인).
- 제외: 파이프라인의 사진 중심 출제 전략(후속), 이론 강의(261104_02·03, 이미 공개 판 있음) 교체.
