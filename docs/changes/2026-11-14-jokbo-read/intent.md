# 족보 1회 풀이를 회독에 기록

## 문제와 사용자 효과
회독 줄(캘린더 칸 아래 점선, 강의 패널 「통계 › 회독」)에는 예습 퀴즈 완료와 강의록 회독만 있다.
족보 퀴즈를 끝까지 풀어도 회독에 남지 않아, 족보를 몇 번 돌렸는지 화면에서 볼 수 없다.

## 범위와 성공 기준
- 족보 진입 화면에서 고른 범위(같은 교수만 / 다른 교수까지 + 연도)를 끝까지 풀어 끝 화면에 닿으면 족보 1회독.
  끝 화면의 「다시 풀기」(같은 범위 전부)도 1회독. 「이 문제만 다시 풀기」(일부)는 세지 않는다.
  모든 교수 문항을 다 풀 필요는 없다.
- 캘린더 칸과 패널의 회독 줄에서 강의록 회독 뒤에 족보 회독 토막이 붙는다.
  색은 족보 칸 점(--ink-2) 계열로, 강의록 회독 회색보다 살짝 진한 회색.
- 족보 회독은 서버에 사람별로 남아 다른 기기에서도 같다.

## 근거·미정 사항
- 사용자 요청(2026-11-14 채팅): 「족보 1회 푼 것도 회독에 기록되게 변경해줘. 족보 색깔처럼 살짝 진한 회색으로 하면 될 거 같아.」
- 기준(2026-11-14 채팅): 「꼭 모든 교수 다 안 풀었어도 돼 그냥 첫 페이지에서 설정한 만큼 다 풀고 마무리 페이지에 도착했으면 1회독 한 걸로 해줘」
- 운영 DB 표 생성(2026-11-14 채팅): 「production DB 에서 뭘 실행해야 하는지만 정리해줘」, 「이 컴퓨터에서 할 수 있는 건 실행하고,
  러너 컴퓨터에서 실행해야 하는 게 있으면 정리해서 전달할 수 있게 알려줘」 — 표 생성은 러너 PC에서 사람이 실행한다.
- 족보 회독을 패널에서 지우는 기능은 없다(요청 없음). 잘못 생긴 회독은 DB에서만 지울 수 있다.
