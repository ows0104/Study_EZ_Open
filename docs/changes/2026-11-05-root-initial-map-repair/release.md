# 초기 지도 오류도 동일 교정 상한에서 처리 — 배포 준비

## 코드 리뷰·검증 결과
실제 시범45ba26d191dc468a800360a366c39a55/job544에서 모델의 초기 지도 추출은 완료됐으나 선행7개가 association/comparison을 참조했고2개 끝점도 맞지 않아 초기 수용 검사에서 실패했다. 실패 ledger와 input/raw/usage, 원본2개, 모델 사용량을 보존했다. 특정 강의의 관계를 직접 바꾸지 않았다.

공통 변경: 초기 지도 구조/의미 오류를 첫 문항 변환에 함께 전달하고 총3회 중1회를 호출 전에 소비한다. 정상 초기 지도는 첫 변환에서 보존한다. 초기 원문과 오류는 결과 manifest에 남고, 교정한 지도는 derived이며 원본/범위/포인트 text·scope·ID를 보존한다. 후속 교정에는 남은2회만 허용한다. 최초 선행 검증은 종류·끝점·순환을 검사하면서 unreviewed를 허용하고, 최종 게시의 reviewed 조건과 새 원본 판정 게이트는 유지한다.

명시적 connection_recovery_v2는 완료된 모델 호출의 archived input/raw/usage/실패 ledger와 원본 지문을 재검증한다. 모델·DB를 호출하거나 내용을 고치지 않는다. 이전 failed ledger와 origin runtime을 결과에 함께 보존하고, 중단/후속 단계/자료 변조/사용량 누락/반복 복구를 거절한다. 이 단계가 실제 지도 교정을 완료한 것으로 취급되지 않으며 이후 첫 변환이 같은상한을 소비한다.

회귀: 정상/미검수/잘못된 관계 종류·끝점·순환·목표 참조·중복 ID, 교정된 지도 독립성, 포인트 보존, 같은 총상한, 실패 호출 재실행 차단, 완료된 실패 수용 증거 재검증/변조 차단, JSON 키 순서 독립성 및 실제 격리 HTTP 게시를 확인한다. 신규21개 회귀를 포함해 contracts125/generator509/runner32와 서버19파일·브라우저1건·typecheck/build를 사용한다. 실제 명령/최종 지문/결과는 state.json과 runs/_development/2026-11-05-root-initial-map-repair 로그에 묶인다. 초기 제한 환경의 임시경로 오류와 추가 테스트 fixture 보완 기록도 보존한다.

리뷰에서 마지막으로 오류 메시지의 사전 키 순서 의존성과 dangling target/중복 ID의 진단 누락을 보완했다. 코드와 의학 내용을 구분하며, 새로운 모델 결과의 의미 정확성을 보증한다고 주장하지 않는다. 출제와 의학/원본 판정은 계속 모델이 담당한다.
