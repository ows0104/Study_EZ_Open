# 족보 풀이 플로팅 노트 강의명 버튼

## 문제와 사용자 효과
2026-11-14 사용자: 「족보 풀 때에도 복습퀴즈 풀 때처럼 똑같이 강의명 추가 버튼 좀 만들어줘」.
복습 퀴즈(RootLearning)·예습 퀴즈(QuizPage)는 `useNoteLecture`로 강의명을 알려 플로팅 노트 창에 「＋강의명」이 뜨지만,
족보 퀴즈(`/jokbo/:eventId`)는 알리지 않아 버튼이 없다.

## 범위와 성공 기준
- 족보 퀴즈 화면(진입·풀이·끝)에서 노트 창을 열면 「＋강의명」이 보이고, 누르면 본문 커서 자리에 강의명이 들어간다.
- 강의명은 족보 머리줄과 같은 `lectureTitle(doc)`(분야 머리 「미생물학) 」을 뗀 이름).

## 근거·미정 사항
- 같은 파일을 「족보 회독」(#170)이 마무리 화면에서 고친다. 사용자 「Go ahead」로 다른 블록에서 진행, 나중 병합 쪽이 rebase.
