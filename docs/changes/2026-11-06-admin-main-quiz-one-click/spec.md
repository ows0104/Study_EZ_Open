# Spec
Main Quiz 생성은 source 입력·웹 작성·본인 시범 공개를 기본으로 한다. 자료 자동 첨부/전송 후 기존 수신→CLI 원본 추출·통합·검수→러너 업로드를 사용한다. 현재 normalize 한 호출이 원본만으로 지도와 포인트를 함께 추출한다. 각각 별도 모델 호출로 변경하는 작업은 포함하지 않는다.
기존 문제은행 링크·구형 생성/재검수 패널을 사이드 패널에서 제거한다. 학습·문항 검토 링크는 보존한다. 수동 파일 전달은 복구 도구로 접는다. 진행 중 중복 클릭과 초기 조회 전 생성을 막는다. 실패/중지는 실패로 표시하고 동일 입력·남은 횟수로 재개한다. 강의 전환 시 이전 입력/작업을 초기화한다.
브리지와 러너는 필요하다. 원본·문항·학습 기록·수정 상한·공개 권한·서버 및 생성기 계약은 보존한다.
