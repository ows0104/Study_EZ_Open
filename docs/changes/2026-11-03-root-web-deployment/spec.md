# 계약

- 새 웹 요청은 원본/지도/포인트를 고정하고 held 상태에서 웹 응답을 기다린다. 자동전송 버튼만 ChatGPT 웹을 열고 자료·정본 프롬프트와 지도/포인트를 전달한다. 에이전트는 ChatGPT 탭을 선택·읽기·조작하지 않는다.
- 완성 MD 헤더의 generation_id로 결과를 전용 요청에 연결한다. 현재 확장의 파일 검증은 유지하며, 원문 파일·문항·정답·검수 기록을 보존한다. 기존 은행과 링크를 덮지 않는다. 자동전송 요청 기록을 먼저 저장하고 같은 전송을 자동 반복하지 않는다.
- 실제 MD·과목·강의·프롬프트 판·지문·generation ID와 취소를 검증한 뒤 같은 bank 작업을 queued로 바꾼다. 러너 입력 지문에 수신 파일 지문을 포함한다. CLI는 웹 원문을 정리하며 최초 문항을 대체 생성하지 않는다. 기존 CLI opt-in은 호환되며 UI 기본은 웹이다.
- 배포는 관련 기능/필수 의존성만 고정한 사본을 검사하고 DB 새 표/RLS→API→러너→웹 순서로 진행한다. 다른 작업의 미커밋 변경을 함께 배포하지 않는다. 기존 서비스/Pages 계정과 권한을 유지한다.
- 개인 시범은 이미 수신된 콜린성 약리학(1) Concept map·출제포인트와 해당 올해 PDF/족보를 사용한다. 실제 문항 내용과 검수 판정은 모델 파이프라인이 작성한다. 과거 은행의 수정 잔여 0회를 초기화하지 않으며 새 별도 생성 요청으로 보존한다.
