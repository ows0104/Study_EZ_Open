# 사용 현황 행동 구분 조사

## 문제와 사용자 효과
관리자가 첨부한 이용현황에서 예습 링크, 복습 풀이, 자료 받기를 구분하기 어렵다고 보고했다. 최초 요청의 읽기 전용 조사는 완료했다. 2026-11-01 후속 사용자 요청: “응, 개인 예습 대화 저장, 링크 열기, 퀴즈 풀이, 파일 요청 등을 한눈에 구분할 수 있게 이용현황 화면을 수정해줘. 자동 첨부를 직접 다운로드한 것처럼 표시하지 말고.” 이 발언을 아래 개선의 로컬 구현 승인으로 적용한다. 운영 배포/운영 스키마 적용은 포함하지 않는다.

## 범위와 성공 기준
운영 DB를 읽기 전용 트랜잭션으로 조회하고 관련 UI/API 경로를 추적한다. 화면의 18강의 기록과 과거 기록을 구분하고, 저장·클릭·평가·파일 요청이 각각 무엇을 증명하는지 설명한다. 이후 승인된 개선은 행동별 UI/API 및 파일 요청 목적 수집을 구현하고 과거 데이터와 학습 기록을 보존한다. 운영 데이터는 변경하지 않는다.

## 근거·미정 사항
2026-11-01 사용자 첨부 화면과 현재 채팅. 계정 주소·개인 대화 URL·인증정보는 이 기록에 복제하지 않는다. 조사 결과와 개선 제안은 spec.md에 보관한다. 후속 수정 요청의 승인은 plan.md의 로컬 구현 범위에 적용한다. 운영 스키마 적용과 배포는 고정 후보의 별도 중요 승인 대상이다.

## 운영 반영 및 확장성 승인
2026-11-01 사용자: “응, 기록용 DB 항목 추가하고 API·웹까지 운영 사이트에 반영해줘. 공용링크 열기/개인링크 만들기, 예습 퀴즈 풀기, 복습 퀴즈 풀기, 미상 등 중 무엇인지를 기록해줘. 이후 행동을 추가할때도 여기에도 반영되게 해줘.”
이 요청은 행동 분류의 확장성 보강과 기록용 칼럼 추가, 해당 기능의 운영 API/웹 배포까지 포함한다. 같은 범위 승인을 다시 요청하지 않는다.
