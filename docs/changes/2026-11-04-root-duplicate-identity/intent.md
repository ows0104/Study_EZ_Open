# 자동 시험일과 재개 요청의 동일 작업 보존

## 문제와 사용자 효과
콜린성(1) 시범의 시험일 원래 선택은 null, 시간표에서 확인된 시험일은 2026-10-20이다. 관리자 응답은 확인된 날짜를 원래 입력처럼 돌려주었고, 같은 화면의 재전송이 requestedExamDate만 다른 generation dbdbfaa349944893967c350116656cd7/job525를 만들었다. 기존 generation f0a8f3b68e3642598f85bbf462e1dc55/job524는 수정3/3회 후 검수 연결 계약 오류로 미게시다.

## 범위와 성공 기준
같은 자료·범위·확인된 시험일·소유자/공개 범위의 요청은 기존 generation과 검수 상한을 재사용한다. 원래 입력/요청 ID를 UI에 돌려주고 재개는 같은 requestId로 보낸다. 이미 전송된 중복 응답은 원문을 보관하되 자동 모델 대기열에 넣지 않는다. 기존69문항과 모든 원문·검수·실패 기록을 보존한다.

## 근거·미정 사항
현행 사용자 '그냥 누르면 알아서 작동하게', 배포/정확한 자료1건 실행, '다시 이어서 해봐' 승인의 필요한 중복 방지 수정이다. 부분 연결 채택 계획과는 독립이며 검수 수용 규칙이나 추가 모델 승인 변경이 없다. job525는 수신을 막지 않고 claim만 24시간 임시 지연했다. 배포 후 중복 보존 중복 요청 종료 상태로 확정해 자동 재시작되지 않게 한다.
