# 새 생성·학습 파이프라인을 Main Quiz에 통합 — 설계

## 요구사항과 수용 기준
기존 /bank/:subject/:runId와 /mainquiz/:subject/:runId 진입에서 서버가 새 검토 자료 접근 가능 여부를 판정한다. 새 자료가 허용되면 Main Quiz 화면으로 렌더하고 기존 자료 보기는 명시 query로 제공한다. 새 자료가 없거나 비공개/전역 중지면 기존 은행 진입을 유지한다. 초기 서버에 새 endpoint가 없으면404/405만 호환 처리하고 인증/서버 오류는 숨기지 않는다.

## 책임·입출력 계약·오류 상태
기존 root-learning 사건/API/정책/저장 충돌 복구를 재사용한다. 별도 UI 명칭만 Main Quiz로 바꾸고 실제 Main Quiz 문항/정답·표·선지·progress·답보기/자기평가 배치를 쓴다. 작성 응답은 선택적으로 펼치며 새로고침 후 보존한다. 키 반복/조합/입력 중 단축키를 차단하고 같은 task의 선지 선택도 보존한다. 회상 결과3등급의 의미를 유지하며 임의로 기존4등급에 대응하지 않는다. 지도 열람과 답만 보기는 독립 회상과 구별한다.

## 호환성과 데이터 보존
신규 DB 모델·migration 없음. 기존 문항/평가/비공개/전역 중지·검수 상한은 유지한다. 공개 관리와 생성 경로는 Main Quiz로 이름을 통일하되 endpoint/기록 코드는 호환 유지한다. Map/범위의 긴 검수 메모는 펼쳐서 보게 한다. recall-units788adb0c는 검증된 의존성으로 포함한다. 운영 콘텐츠 자동 등록이나 문제 교체는 수행하지 않는다.
