# 기본 링크 버튼 및 GPT 브리지 이전 초안 충돌 복구

## 문제와 사용자 효과
사용자 제보: “기본링크 만들기 버튼이 작동을 안해. 그리고 자동전송을 누르면 이전 기록이 남아서 충돌로 작동이 안돼.” 추가 확인: 충돌은 GPT 화면의 Bridge 팝업에 표시된다. 기본 링크 생성과 자동전송을 다시 사용할 수 있게 하고, 이전 실패 초안 때문에 같은 오류를 반복하지 않게 한다.

## 범위와 성공 기준
예습 기본 링크 생성 카드의 무응답과 ChatGPT 입력 브리지의 이전 미전송 초안 복구를 대상으로 한다. 기본 링크 카드를 누르면 직접전송용 새 요청이 열리고, 별도 자동전송 도구는 자동 첨부·전송을 유지한다. 이번 요청과 이전 초안을 구분하고, 안전하게 복구할 수 있는 경우 이번 요청을 한 번만 진행한다.

## 근거·미정 사항
추가 스크린샷에서 Study EZ 예습 자료/공개 공유 링크 모드임을 확인했다. 이번 요청은 [251106_07] 심내막염으로 시작하지만 GPT 입력창에는 [251106_06] 무산소성세균 프롬프트가 남아 있다. 오류는 “입력창에 작성 중인 다른 내용이 있어 자동 진행을 멈췄습니다. 새 대화로 다시 시작해 주세요.”다. PreviewAction.tsx의 기본 링크 만들기 카드는 button이 아닌 span이며 클릭 핸들러가 없다. chatgpt-bridge.js는 다른 초안이면 오류 후 confirm을 숨겨 복구 경로가 없다. 처음 조사한 BankPanel의 버전 비활성화 문제는 이번 스크린샷의 버튼 원인이 아니므로 구현 범위에서 제외한다. 스크린샷 제공은 구현 계획 승인으로 기록하지 않는다.
