# Spec
- 기존 자동 일괄 과목 제한·시간표 미확인 시 중단·개별/전체 중지·취소·동시 실행 제한은 유지한다.
- 인증된 서버 claim 응답에만, 실제 RootGeneration과 job ID/강의/소유자가 일치하고 미게시이며 웹 응답까지 수신한 버튼 bank 일감의 rootGenerationId를 추가한다. 일반 bank/자동/과거 작업에는 없다.
- 러너는 유효한 명시적 root ID가 있는 작업만 블럭 밖 과목이어도 처리한다. 현재 블럭 자체를 확인할 수 없는 경우는 계속 중단한다. CLI에 같은 root ID를 전달하여 최신 은행 조회로 다른 요청을 처리하지 않게 한다.
- 같은 generation/job/원본/응답/수정 상한을 이어 사용한다. 기존 69문항과 학습 데이터·전송/검수 이력을 유지한다. 재전송하지 않는다.
- 운영 API 고정 후보와 검증된 로컬 러너만 갱신한다. 기존 실행 중인 다른 작업을 중단하지 않는다. 웹/DB 변경 없음.
