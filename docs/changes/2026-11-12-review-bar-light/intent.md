# 캘린더 복습 막대 색 옅게

## 문제와 사용자 효과
같은 날 #129에서 캘린더 칸 아래 복습 학습률 막대를 진하게 했다(바탕 메인 색 30%, 테두리 72%, 채움 60–100%).
사용자 2026-11-12: 「바 색깔이 좀 진하다. 차라리 캘린더 화면 오른쪽 위에 예습 박스, 복습 박스 안의 색 정도로 하자.」
이어서 「둘 다 테두리가 있지?」 → 「오케이 그럼 PR하자」.

## 범위와 성공 기준
- 복습 막대: 「오늘 복습」 박스와 같은 바탕(`--accent-soft`)·테두리(`--accent-line`). 채움은 바탕보다 한 단계 진하게
  (메인 색 42%→28%, 학습률이 높을수록 옅다 — 「덜 채울수록 진하다」 규칙 유지).
- 예습 퀴즈 완료 토막: 「내일 예습」 박스와 같은 바탕(`--accent2-soft`)·테두리(`--accent2-line`).
- 범례 표본·사이드 패널 학습률 막대도 같은 함수(`reviewFill`)·같은 `.meter`로 맞춘다.
- 막대가 그려지는 조건(Main-Quiz 있을 때만)·높이 5px·강의록 회독 토막(회색)은 바꾸지 않는다.

## 근거·미정 사항
웹 표시만. 서버·DB·API 변경 없음.
