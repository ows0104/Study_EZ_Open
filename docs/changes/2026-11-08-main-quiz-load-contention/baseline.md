## 이 표가 바로잡는 것

앞서 이 엔드포인트를 "따뜻한 인스턴스에서도 2.0–6.3초"라고 적었다. 그것은 **261104_02에만**

즉 폴링 자체가 비싼 것이 아니라, **판이 쌓인 강의에서만** 비싸다.

261104_02는 대시보드 완료 기록의 PR #13·#14가 거듭 다시 만든 강의이고 과거 판을 보관한다.
`latest()`가 LIMIT 없이 질의하면 보관된 판 수만큼 `packet`·`result`·`web_dispatch`·
`web_response` JSON이 결과 집합에 들어오므로, 비용이 그 강의에서만 커지는 것과 맞는다.
이것은 일치하는 설명이며, 아직 증명은 아니다.
