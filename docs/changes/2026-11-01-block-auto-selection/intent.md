# 블록 자동 전환과 주간 기준 수정

## 문제와 사용자 효과
2026-11-01 KST 사용자는 원인 설명 후 “이전 블록 시험이 끝나면 퀴즈 준비 여부와 상관없이 다음 블록으로 자동 전환되게 고쳐줘”라고 명시적으로 구현을 요청했다. “토요일은 금요일이 포함된 이전주, 일요일은 다음날인 월요일이 있는 주간”이라는 기존 기준도 확인했다. 오늘 기본 선택은 감염과 면역이어야 한다.

## 범위와 성공 기준
학습 현황의 기본 블록 선택을 시간표·마지막 시험 종료 시각으로 바꾼다. 퀴즈·첨부 준비와 무관하게 예정 수업을 포함한다. 한국 시간, 일요일의 다음 월요일, 열린 화면의 시각 경과·탭 복귀·목록 갱신을 반영한다. 같은 자동 블록 안에서는 수동 선택과 전체 보기를 보존하고 자동 블록이 바뀔 때 새 기본값으로 전환한다.

## 근거·승인
위 사용자 발언은 원인 조사에서 제안한 같은 기능 수정 범위에 대한 직접 승인이다. 같은 범위를 다시 묻지 않는다. 운영 배포·운영 데이터·러너 큐 정책 변경은 포함하지 않는다. 앞선 조사 결과는 release.md에 보존한다.
