# 교수 변경 표시와 최근 5년 동일 교수 예습 필기 선택 — 설계

## 요구사항과 수용 기준
1. 올해 Y의 직전 5개 학년도 Y-1~Y-5를 검색한다. 2026년은 2025~2021이며 연도 안에서는 최신 판을 고른다.
2. 동일 강의 대응을 먼저 확인하고 교수 집합을 비교한다. 날짜/교시/교수만으로 다른 강의를 연결하지 않는다. 접힌 제목은 전체 제목·순번·기존 확인 대응으로 보완한다. 공동 담당 전체 일치 우선, 일부 일치는 별도 표시하며 자동 전체 일치로 취급하지 않는다.
3. 올해 교수는 실제 올해 필기 담당 우선, 없으면 시간표 기준 잠정. 필기자와 구별한다. 시간표와 다르면 출처와 차이를 보존한다.
4. 작년 대비 담당 집합이 다르면 캘린더에 ‘교수 변경’. 작년 자료/담당 미상은 비교 불가 또는 확인 필요. 공동 담당의 추가·제외도 변경이다.
5. 보유 최근 5년의 대응 강의에서 올해 교수 자료를 찾지 못하면 ‘신규 교수’. 상세/툴팁에 ‘보유한 최근 5년 동일 강의 필기 기준’, 검색 연도/미보유 연도를 명시한다. 실제 신규 임용·과거 담당 이력 전무를 주장하지 않는다. 일부 담당만 과거에 있었으면 전체를 신규로 묶지 않는다.
6. 검색 실패·교수 미상·관련 미해석 파일·대응 모호는 확인 필요로 둔다. 폴더 미보유와 읽기 실패는 구별한다. 미보유 연도를 실제 조사 완료로 위장하지 않는다.
7. 사용자 후속 승인(2026-11-05): 동일 교수 자료가 5년 이내 없으면 확인된 작년 강의를 예습 기본 자료로 사용하고 ‘신규 교수’ 및 ‘작년 자료 사용’을 표시한다. 작년 대응 자체가 없거나 불확실하면 확인 필요로 둔다. 기존 자료와 진도는 보존한다.
8. 예습 자료 표시는 ‘2023년 예습 필기’처럼 실제 연도를 사용한다. 캘린더 칸/모바일에서도 태그가 보이고 상세에는 과거→올해 교수·올해 담당 출처·선택 연도·참고 상태를 표시한다. 확장 첨부·프롬프트·Pre-Quiz가 같은 파일을 사용한다.

## 책임·입출력 계약·오류 상태
공통 순수 계약은 버전·올해 학년도/강의 식별·올해 담당/출처·작년 비교·검색 연도/누락/실패·선택 연도/교수/파일/해시·일치 상태·신규 여부·근거 지문/갱신 시각을 정의한다. 학생 API에는 요약만 보내며 로컬 경로/관리용 원문은 제외한다.

runner의 단일 선택기를 publish/readiness/prequeue가 공유한다. 작년 비교와 실제 예습 원본 연도를 분리하고 기존 `--prev` 비교 동작을 보존한다. 기존 `_pairs`는 강의 대응 근거로 남기고 새 예습 선택 provenance는 별도로 기록한다. 합본/분할은 범위 확인 전 자동 단일 파일 교체하지 않는다.

Lecture에 선택적 nullable JSON 메타데이터를 추가한다. 구형 클라이언트가 필드를 생략해도 새 메타데이터를 지우지 않는다. 시간표·담당·원본 지문 변경 시 낡은 판정은 재확인 상태다. 자료가 없는 시간표 자리도 메타데이터를 전달한다(현재 ahead는 짝을 찾은 자리만 반환하므로 보완 필요). 서버는 runner를 import하지 않는다.

## 호환성과 데이터 보존
[교수/첨부 정책](../../policies/jokbo-attachments.md) 및 [보존 지시](../../policies/pre-refactor-directions-2026-10-26.md)를 적용한다. 기존 강의/문항 ID·학습 기록·preview.md·수동 응답·공유 링크·HOLD/CHOSEN·검수 횟수는 보존한다. 원본 선택이 바뀌어도 옛 대화/덱을 새 자료 기반 결과처럼 재사용하지 않으며 출처 변경 상태로 남긴다. 자동 재출제/새 모델 호출/검수 상한 초기화는 하지 않는다.

운영 nullable JSON 추가 및 첨부 교체는 중요 운영 승인 대상이다. 교체 전 이전 파일·해시·연결을 보존한다. 로컬 구현/격리 검사 후 구체 운영 적용 목록과 복원안을 제시한다. 일반 코드 자동 배포 승인으로 운영 데이터 변경 권한을 대체하지 않는다.
