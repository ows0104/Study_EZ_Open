# 자유 노트 편집기 보완(들여쓰기·표·붙여넣기·토글)

## 문제와 사용자 효과
2026-11-14 사용자 보고(원문 요약): 자유 메모 기능에 문제가 많다.
1. 글머리 기호/번호 목록에서 Tab으로 한 단계 안쪽 들여쓰기가 안 된다.
2. 표를 넣을 수 없다.
3. 줄간격이 이상하다.
4. 맨 아래에 회색 칸이 자꾸 보인다(사진 첨부).
전반적으로 Notion을 참고해 보완해 달라는 요청. Notion 앱을 Ghidra로 분석해 기능을 가져오자는 제안은
받지 않았다(Notion 코드 복제 없음). 공개적으로 보이는 Notion 편집 동작을 기준으로 직접 구현한다.

## 범위와 성공 기준
- 목록·글 블록 Tab/Shift+Tab 들여쓰기(하위 블록 함께), 단계별 번호·기호.
- 표 블록(칸 편집, Tab 이동, 행·열 추가/삭제, 머리글 행).
- 여러 줄 붙여넣기를 줄마다 블록으로 나누고 md 기호·들여쓰기·표(TSV, md 표)를 인식. 줄간격 정리.
- 맨 아래 회색 칸 제거.
- 추가: 토글 블록, Ctrl+D 복제, Ctrl+Shift+↑/↓ 이동, 블록 단위 실행 취소/다시 실행.
- 기존 노트는 그대로 열리고 저장된다.

## 근거·미정 사항
- 회색 칸 원인: 편집기 끝의 「끝에 이어 쓰기」 영역(`.nb-append`, 높이 120px)이 `<button>`이라
  전역 `button:hover`/`:active` 배경(surface-2/3)이 `.notes-layout button` 초기화보다 우선해 회색으로 칠해졌다.
- 사진 블록 불러오기 중 회색 칸(`.nb-image.is-loading`)도 같은 모양이라 함께 정리한다.
