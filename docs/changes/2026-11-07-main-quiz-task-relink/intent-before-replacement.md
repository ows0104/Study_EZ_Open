# 검수통과28문항 보존형 과제재연결과 이미지 후속검수

## 문제와 사용자 효과
사용자 현재 지시: 검수 통과한28문항의 구조·연결을 고쳐 학습과제에 포함하고 이미지 누락을 보완한다. 기존91문항/정답/이미지/학습기록/원래검수 및 수정3/3은 보존한다. 현재 운영 Main Quiz UI도 확인한다. 원래47고유문항49과제에 대한 누락 분석을 후속 작업으로 연결한다.

## 범위와 성공 기준
指定261104_02만 처리한다. 원래 검수결과/은행을 바꾸지 않고 독립적으로 검수한 추가 회상 연결을 새 판에 더한다. 기존49과제/47고유문항 및 그 동일성 승계, 추가28고유문항 연결을 목표로 한다. 미해결 그림·의학 판정은 강제로 승인하지 않고 구체적 보류 이유를 보존한다. UI를 다시 디자인하지 않는다.

## 근거·미정 사항
사용자 현재 명시 승인과 앞선 지정PDF의 OpenAI 전송/실제CLI 시범/업로드 승인이 적용된다. 원래2/3→3/3 보완/실패/검수영수증을 수정하거나 제4회 문항 수정을 만들지 않는다. 추가 작업은 동일 문항의 목표·관계·그림 확인을 위한 별도 후속이며 기존 생성 예산과 구분한다.
