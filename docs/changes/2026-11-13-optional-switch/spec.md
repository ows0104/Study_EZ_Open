# Optional 제외 스위치 디자인 — 설계

## 요구사항과 수용 기준
- 「유형별/순서대로」 줄 맨 오른쪽, 라벨 `Optional 제외` 오른쪽에 스위치 트랙.
- 꺼짐: 회색 트랙(`--line-strong`), 손잡이 왼쪽, 라벨 흐린 색. 켜짐: 강조색 트랙(`--accent`), 손잡이 오른쪽, 라벨 진하게.
- Main-Quiz 타이머 스위치와 같은 모양. 설명 문구 없음.

## 책임·입출력 계약·오류 상태
- `role="switch"`·`aria-checked`. 값 읽기 전·저장 중에는 비활성. 저장 실패 시 앞 값으로 돌아감(#146 그대로).
