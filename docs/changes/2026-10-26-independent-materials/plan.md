# 구현 계획

1. 인벤토리와 활성 참조·프로세스·예약 작업을 확인하고 상세 목록을 고정한다.
2. 선정 manifest SHA-256: `5bd862dcdfa6b300929ecc57b50a6a62ce6a6b0d8e308fa5597430eef48a0ffe`. 대상 137개 폴더만 허용한다.
3. 독립 영역·보관 안내, 검색 제외, work/tmp 보관 색인을 작성한다.
4. 모든 파일을 압축 백업하고 별도 임시 폴더에 복원하여 해시를 대조한다.
5. 실제 이동 직전에 프로세스/예약 작업·원본 해시를 다시 검사하고
   원본과 보관 대상의 절대 경로를 고정된 두 루트 내부로 검증한다.
6. PowerShell Move-Item -LiteralPath로 폴더 단위 이동한다. 재귀 삭제를 사용하지 않는다.
7. 파일 수·해시·junction·보호 파일을 대조하고 공유 세션·개발 gate를 검사한다.
8. 이전 경로가 없을 때만 보관 폴더를 되돌릴 수 있도록 복원 방법과 매니페스트를 남긴다.

현재 사용자 요청은 이 로컬 비파괴 분리·보관 범위를 승인한다. 출제/배포/운영 재시작을 포함하지 않는다.
