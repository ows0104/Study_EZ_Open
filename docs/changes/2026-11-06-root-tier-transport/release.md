# 기존 Must-Know 등급 별칭의 Native 전송 복구 — 배포 준비

## 코드 리뷰·검증 결과
authored_json.to_bank의 기존 Must-Know→Essential 대응을 canonical_tier로 공용화했다. Native AUTHOR 전송은 그 tier 이름만 정규화하고 원본 파일 바이트/영수증과 실제 변경 question_id·원문/정규화 hash를 projection으로 보존한다. unknown tier·importance 수치·의학 문구는 자동 교정하지 않는다. 완료 파일의 명시 복구는 실제 provider 완료·원본/입력/파일·이전 실패/실행 지문과 기존 authoring recovery를 연결하며 모델 호출0회, 보완 소비 불변이다.

합성 계약·기존 생성/파일/복구 회귀263개 통과. 11개 전용 검사는 원문 바이트 유지·별칭 외 불변·중요도 수치 불변·이전 구조 복구 뒤 예산3회 유지 및 변조/중단/거절/unknown tier/재복구 거절을 검증한다. 초기 합성 fixture가 Must-Know인데 importance=2로 남아 있던 오류를 실제 사례와 같은5로 맞췄고, 이전 복구의 실행 지문을 새 형식 복구를 통해 연결하는 검사도 수정했다. 실제 원본/검수 결과는 수정하지 않았다. 최종 필수 검사와 실제 회수는 후속 기록에 남긴다.

## 배포 대상 버전·순서·데이터 변경
별도 codex/root-tier-transport 후보다. CNS가 실행 중인 root-authoring-recovery 코드는 변경하지 않는다. 기존 승인 복구 의존성 de1fcf73만 최신 origin/master 위에 복사했다. 실제 심내막염 대상은 마지막 완료47문항의 Q010 tier 문자열 한 곳과 이미 같은 importance=5다. 원문/실패/사용량/3회 소비를 유지해 모델 재생성 없이 회수하고 source-2/medical-2를 실제 실행한다. 운영배포·548 재개·기존학습/은행/권한 변경 없음.

## 배포 후 확인·롤백·필요한 사람 승인
현재 사용자 E2E·완료 초안 복구 승인 범위의 정본 형식 대응 재사용이다. 실제 수용 전후 파일/검수/예산 검증을 필수로 한다. 복원해도 원래 실패나 이미 소비한 모델 호출은 지우지 않는다. 실제 파일의 다른 오류가 남으면 임의 교정하거나 상한을 늘리지 않는다.
