# 수선 — 걸린 카드만 다시 쓴다

아래 카드들이 검사에 걸렸다. **그 카드만** 고쳐서 아래 파일을 다시 써라.
나머지 카드는 그대로 두고, 카드의 순서도 바꾸지 마라.

```
{raw}
```

## 재현 검사에 걸린 카드

질문만 본 외부 풀이자가 네가 의도한 답에 이르지 못했다는 뜻이다.
**답을 바꾸는 것이 아니라 질문을 고치는 것이 대개 맞다.**

- `question_ambiguous` — 무엇을 묻는지 좁혀지지 않는다. 묻는 대상을 질문에 명시해라.
- `needs_options` — 선지가 있어야만 답이 정해진다. **하나의 진술로 세우거나
  성립 조건을 묻는 긍정문으로 바꿔라.** 선지를 카드에 넣지 마라.
- `answer_underspecified` — 답의 집합이 열려 있다. **범주로 닫아라.**
  「세 가지는?」보다 「A·B·C 각각에 적용하면?」이 낫다.
  개수만 밝히는 것으로는 부족하다.

> 답의 집합을 닫으려고 **출처를 가리키지 마라.** 「강의록이 드는 네 가지는?」은
> 닫히긴 하지만 원본 없이는 못 푸는 카드가 된다. 축·범주로 닫아라 —
> 「발현량·유전자 수·서열·염색체 위치의 네 축으로 나누면?」

## 계약을 어긴 것

- **카드 수가 범위를 벗어났다면** 장수를 맞춰라.
  넘치면 *가장 덜 '꼭 반드시'한 것*부터 덜어낸다 — 카드를 쪼개거나 합치지 마라.
  모자라면 `must_know` 항목 중 배정 장수를 못 채운 것을 채운다.
- **O/X 비율이 넘었다면** 일부를 `basic` 으로 바꿔라. 예습에서 O/X 는 회수량이 적다.

## 지키는 것

- 출력 계약(①에서 읽은 것)을 그대로 지킨다. 새 키를 만들지 마라.
- `id` 가 있는 카드는 **`id` 를 그대로 둔다.** 그것으로 짝을 맞춰 다시 검사한다.
- 고친 뒤 무엇을 어떻게 바꿨는지 한 줄씩만 보고해라.
