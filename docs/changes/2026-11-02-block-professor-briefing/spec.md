# 블록 시작 교수 변경 안내와 교수별 기출 스타일 — Spec

상태: 설계 초안. 사용자 확정 요구는 블록 시작 시 교수 변경 안내와 교수별 기출 기반 출제 스타일 제공이다.
아래 동작·데이터 계약은 구현 전에 검토할 제안이며, 구현 승인이나 실제 분석 결과가 아니다.

## 1. 블록 시작 안내

- 블록의 첫 진입에서 ‘교수 변경 강의’와 ‘교수별 출제 스타일’ 요약을 제시하고 블록 현황에서 다시 열 수 있게 하는 안이다. 학습 시작을 막는 필수 확인창은 두지 않는다.
- 블록 식별·기본 선택은 시간표 기반 현행 정책을 재사용한다. 퀴즈나 필기 준비 완료를 안내의 시작 조건으로 삼지 않는다. 현재 블록 전환과 사용자의 다른 블록 열람은 구별한다.
- 별도 푸시·이메일·외부 메시지 발송은 현재 범위가 아니다. 정확한 노출 시점·재노출·확인 상태 저장은 P10에서 확정한다.
- 올해 필기 전에는 시간표 기준의 잠정 안내임을 표시한다. 이후 실제 필기에 담당이 명시되면 재대조하여 바뀐 내용과 확인 시점을 보여준다.

## 2. 교수 변경 판정과 근거

기본 비교 후보는 동일 블록·대응 강의의 **직전 학년도 담당 대 올해 담당**이다.
직전 학년도 자료가 없으면 ‘비교 불가’로 남긴다. 더 오래된 자료가 있으면 해당 연도를 명시한 참고 비교만 제공한다.
‘올해 교수 기출 없음’은 신규 임용·교수 변경의 증거가 아니다.

| 항목 | 제안 계약 |
|---|---|
| 강의 대응 | 안정 식별자·제목·단원·합본/분반 근거를 사용하고 날짜·교시·순번만으로 동일 강의를 확정하지 않음 |
| 올해 담당 | 실제 올해 필기 파일명/자료의 명시된 담당을 확인. 필기자 이름과 구별. 필기 전에는 시간표를 사용하고 잠정 표시 |
| 과거 담당 | 해당 연도의 원본 교수표·보존된 교수 이력과 출처 위치를 사용. 작년 필기 담당을 올해 담당으로 대체하지 않음 |
| 상태 | 변경 확인 / 동일 확인 / 확인 필요 / 비교 불가. 미상이나 충돌을 ‘동일’ 또는 ‘변경’으로 강제 분류하지 않음 |
| 공동 담당 | 교수 집합의 추가·제외를 표시하고 전체 이름을 보존. 일부가 같아도 구성 변경은 표시 |
| 출처 충돌 | 올해 실제 필기 우선 원칙을 적용하되 원래 시간표 값과 차이를 남김. 이름·강의 대응이 모호하면 확인 필요 |
| 표시 정보 | 강의, 비교 연도·과거 담당, 올해 담당, 변경/잠정 상태, 근거 자료·위치, 확인 시점 |

이름의 공백 등 표기 정규화와 동일인 확인은 구별한다. 동명이인·별칭을 문자열 유사도만으로 자동 합치지 않는다.
강의 분할·통합 또는 같은 단원에 여러 담당이 있는 경우 명시된 범위 밖으로 교수 변경을 확대하지 않는다.

## 3. 교수별 기출 기반 출제 스타일

- 올해 블록 담당 교수를 중심으로 **교수 × 과목/블록 × 강의 범위 × 분석 연도**를 명시한다. 같은 교수의 다른 과목 자료는 별도 참고로 표시한다.
- 해당 교수 귀속이 확인된 기출을 먼저 분석한다. 공동 담당만 확인되는 문항은 공동 담당 자료로 따로 제시하며 특정 교수 단독 출제로 계산하지 않는다. 교수 미상 문항도 별도 참고로 남긴다.
- 분석에 실제 포함한 연도·시험 회차·고유 문항 수와 제외/확인 필요 범위를 보여준다. 같은 원문이 여러 첨부에 복제된 경우 분석 집계만 중복을 제거하고 원본은 보존한다. 연도별 실제 재출제는 별개 출제 사례로 센다.
- 관찰 항목 후보: 반복 주제·개념, 직접 회상/비교/기전/증례·적용, 사진·표·도식 해석, 보기 구성·헷갈리기 쉬운 구별점, 동일·변형 기출 반복. 항목은 겹칠 수 있으므로 비율 합을 100%로 강제하지 않는다.
- 경향마다 대표 기출의 연도·회차·문항 식별자·원본 쪽을 연결한다. 비율·빈도를 쓰면 분모와 산정 범위도 제공한다. 텍스트 추출만으로 이미지 문제 여부를 확정하지 않는다.
- ‘관찰된 경향 → 실제 사례 → 올해 준비할 점’ 순으로 간결하게 설명한다. 준비 조언은 과거 관찰에서 도출한 해석임을 구별하고 올해 명시된 출제 예고·강조와 섞지 않는다.
- 표본 부족이면 ‘자료 부족/제한적 관찰’로 표시한다. 분석할 기출 없음, 자료 준비 중, 분석 실패, 담당 확인 필요를 구별한다. 최소 표본·검토 절차·갱신 기준은 P10에서 확정하며 임의 확률이나 확신 점수를 만들지 않는다.
- 기존 족보형·족집게형·신규·일반형 기준(S7/P04)과 연결하되 기출만으로 수업 중 강조 중심 성향을 확정하거나 교수에게 고정 유형을 부여하지 않는다.

## 4. 자료·게시·버전 계약

분석 결과 후보는 블록/강의 식별자, 교수 식별·표시명, 비교 연도, 담당 출처, 입력 자료 판·해시,
기출 참조와 집계, 관찰·해석·불확실성, 작성/검토/게시 상태·시각을 가진다. 최종 필드와 API는 P10에서 확정한다.
초안·검토 필요·게시 가능 상태를 구별하고 학생에게는 검토 후 공개한 요약과 허용된 근거만 전달하는 안이다.
공동 담당·미상·원본 정답/연결 확인 필요 상태를 유지한다. 개인 대화 주소·로컬 경로·관리용 원문 전체는 학생 응답에서 제외한다.
입력이 바뀌면 영향받은 변경 판정·스타일 결과를 재검토 대상으로 남기며 예전 결과를 최신 분석으로 표시하지 않는다.
새 분석은 기존 결과와 출처 이력을 남기고 갱신한다. 기존 퀴즈 생성·첨부·학습 상태를 덮어쓰지 않는다.

## 5. 수용 시나리오

| 상황 | 기대 결과 |
|---|---|
| 동일 강의가 작년 A → 올해 B | 비교 연도·두 담당·근거와 함께 변경 강의로 표시 |
| 작년 A+B → 올해 B+C | A 제외·C 추가와 공동 담당 전체를 표시 |
| 과거 담당 미상 또는 강의 대응 모호 | 변경으로 단정하지 않고 비교 불가/확인 필요 표시 |
| 올해 기출이 없고 다른 교수 기출만 있음 | 해당 교수 자료 부족과 참고 기출을 구분하고 ‘신규 교수’로 단정하지 않음 |
| 올해 필기 전 → 실제 필기 담당 갱신 | 시간표 잠정 안내를 다시 확인하고 변경 근거·갱신 시점 표시 |
| 같은 교수의 여러 과목·공동 담당 자료 | 분석 범위를 구분하고 개인 스타일로 부당 합산하지 않음 |
| 같은 문제가 여러 첨부에 있음 | 중복 첨부가 빈도를 부풀리지 않으며 연도별 재출제는 구별됨 |
| 이미지·증례 경향을 안내함 | 원본을 확인한 사례·문항 수·범위로 설명하고 올해 출제를 보장하지 않음 |
| 기출 원본 또는 교수 이력이 갱신됨 | 기존 분석의 판을 유지하고 재검토 필요 표시 |
| 안내를 읽거나 닫고 학습을 시작함 | 학습 진도·숙련도·기존 추천을 임의 변경하지 않음 |
| 조회 실패 또는 게시 취소 | 확인 실패/비공개를 표시하고 ‘교수 변경 없음’으로 대체하지 않음 |

실제 검사 결과는 아직 없다. 미정 결정은 [P10](../2026-10-27-learner-journey/open-design.md#p10-블록-시작-교수-변경과-출제-스타일)을 따른다.
