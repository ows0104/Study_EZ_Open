# 감염과 면역 2차 족보 풀이 자료

2026-11-23 사용자 요청: 「지금 감염과 면역 2차 기간인데 2차에 해당하는 족보도 정리해서 전부 다 넣어줘.
기존에 넣었던 족보 파일에 2차까지 같이 있으니까 거기에서 파싱해서 넣으면 돼」

1차 족보 풀이([2026-11-13-jokbo-solve](../2026-11-13-jokbo-solve/intent.md))는 「2차(49~)는 정리된 족보 세트가 아직 없다」로
끝났다. 1차 세트의 원천인 amgi 파서는 같은 책(`2025 감염과 면역 족보.pdf`, 표지 「감염과 면역 2026 족보」)의
1차 답 구획에서 멈춘다. 2차는 같은 책 119~183쪽에 같은 조판으로 실려 있다.

## 범위

- 시간표 「감염과 면역 49~66」 18강의. 1차와 같은 형식(jokbo-solve/1)·같은 풀이 화면·같은 해설 규칙.
- 원천을 만드는 일회성 스크립트는 이 폴더에, 산출물(문항 원문·그림·해설)은 git 밖
  `runs/_materials/감염과 면역/jokbo-solve/`(저장소가 공개라 족보 원문을 커밋하지 않는다).
- `runner/jokbo_solve.py`에 판 선택(`--edition 2026-2`)만 더한다. 1차 판의 산출은 바뀌지 않는다.
- 웹·서버·DB 변경 없음. 사이트 반영은 기존 업로드(R2 `jokbo-solve/<eventId>.json`).
