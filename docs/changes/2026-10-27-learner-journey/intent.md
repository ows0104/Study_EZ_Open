# 학습자 여정과 핵심 화면 구성

문서 역할 안내(2026-11-01): 이 파일은 이 설계 작업의 목적과 사용자 결정 이력을 보존한다.
사이트 제품의 목적·원칙은 [사이트 intent](../2026-10-27-site-intent/intent.md), 합의한 동작은 [spec](spec.md),
미확정 제안은 [open-design](open-design.md)을 현재 기준으로 읽는다. 아래 이력의 과거 제안을 최신 확정값으로 사용하지 않는다.

## 문제와 사용자 효과

[합의한 사이트 전체 intent](../2026-10-27-site-intent/intent.md)를 실제 이용 경험으로 구체화한다.
사용자가 전체 범위의 빈 곳과 현재 앎을 이해하고, 추천 학습을 시작하며, 오늘의 변화를 확인하는
대표 여정과 핵심 화면의 정보 우선순위를 함께 설계한다.

## 범위와 성공 기준

이번 범위는 여정·화면 역할·정보 구성·학습 상태 표현·중단/재개 등 주요 상황의 설계다.
검토용 화면은 예시 자료로만 만들고 실제 학습 기록을 변경하거나 학습을 완료 처리하지 않는다.
사용자가 정한 화면·여정의 방향은 spec의 핵심 합의에 모았다. 페이지 수·세부 배치·평가 버튼·계산법까지
일괄 확정한 것은 아니며, 합의한 구성과 후속 설계를 구분해 사용자 검토본으로 정리한다.

첫 화면에서 중요한 미학습 부분을 찾고, 추천 경로로 공부를 시작하고, 한 번 공부함과 실제 앎을
구분하고, 오늘 추천 분량의 완료와 학습 변화를 이해할 수 있으면 설계 목적에 부합한다.
구현용 계약·변경 파일·테스트 계획과 운영 배포는 후속 단계다.
