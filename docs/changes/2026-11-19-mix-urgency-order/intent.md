# 모아풀기 복습 주기 이전 문제도 보기

## 문제와 사용자 효과
모아풀기 시작 화면의 「기존 학습률 무시」(2026-11-18-mix-options)는 복습일이 아직인 문항까지 넣는다.
켜면 순서가 순서대로/섞어서만 따라서, 학습 기록을 정말 「무시」한다. 사용자가 원한 것은 다 풀 수 있게 하되 급한 것부터다.

사용자 원문(2026-11-19):
「학습률 무시 버튼을 좀 바꾸고 싶어. "복습 주기 이전 문제도 보기"로 바꿔줘. 한 마디로 학습률에 따라서 출제 순서가 바뀌긴 하는거야.
더 심각한 문제가 앞쪽에 오는거지. 그래도 복습주기가 아직 안 된 문제들까지 다 풀 수 있는 버튼이야.」

선택(같은 날, 질문에 답):
- 순서: 「Due first, rest by urgency」 — 복습 대상을 먼저(고른 순서대로/섞어서), 그 뒤 복습일 전 문항을 강의를 건너 급한 순으로.
- 미열람: 「After due, before not-yet-due」 — 복습 대상 → 미열람 → 복습일 전 문항.

## 범위와 성공 기준
- 체크 이름 「복습 주기 이전 문제도 보기」. 담는 문항은 지금 「기존 학습률 무시」와 같다.
- 모아풀기 출제 순서: ① 복습 대상(순서대로/섞어서) ② 미열람(미열람 문항 보기, 순서대로/섞어서) ③ 복습일 전 문항(강의 건너 급한 순).
- 새로고침·재개해도 같은 순서. 기록·복습일 계산은 바뀌지 않는다.

## 근거·미정 사항
- 「급한」 = 복습일이 가까운 것 먼저, 같은 날이면 지금 기억 확률(mastery)이 낮은 것 먼저. 복습일이 시험일·중요도별 목표로 이미 정해져 있어 「먼저 잊을 것」에 가장 가깝다.
- 선행 문항 포함(#228)으로 끌려온 선행은 묶음과 상관없이 그 뒤 문항보다 앞이다.
