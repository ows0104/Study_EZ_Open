# 콜린성 예시의 20개 검수 기록과 3개 미준비 방향 원인 교정 — 설계

## 요구사항과 수용 기준
- tested 관계가 기존 direction의 어느 cue에도 맞지 않으면 direction_ids=[]를 허용한다. 원문 판단·이유는 보존하고 어느 방향에도 충족 점수를 주지 않는다. provided/explanation 방향 참조 금지는 유지한다.
- 원본 전용 지도 교정 및 표적 보완 총2회: 최초 교정 후 실제 source1이 원래20개 안의 기초 명칭 관계 누락·복합 관계 과대 집계를 확인하여 표적 보완1회를 추가한다. 사용자 현재20개 교정 승인 범위의 실제 원인 해결이며 원래 실행/소비 횟수를 초기화하지 않는다. 원본 PDF35쪽/족보, 기존 독립 brief와 일반적 지도 완전성 진단만 제공한다. BANK/웹 응답/문항별 검수는 제공하지 않는다. 실제 회상 사실별 관계와 조건을 표현하고 동일 의미ID/제외 범위와 변경 이력을 보존한다.
- 별도 내용 CLI가 교정 brief/기존88/20개 원문/정식 의약품 문서 등 1차 자료로 BANK를 교정한다. 부모는 임상 문항·정답·판정을 직접 작성하지 않는다. 원본 오류를 복원하거나 외부 세부 용량을 임의 필수 목표로 확대하지 않는다.
- source2가 확인한 D24의 참조 불일치만 마지막3차 내용 수정에서 모델이 교정할 수 있다. cue/answer_scope/필수성·관계 조건·원본 포인트·범위는 바꾸지 않고 실제로 요구되지 않는 관계 참조만 정리한다. 제거되는 사실은 다른 필수 방향에 계속 남아 있어야 한다. 독립 포인트 추출의 이력과 이 후속 모델 작성 참조 교정은 별도로 표시하고 source3에서 재검수한다. 추가 지도 추출 호출은 없다.
- 원본 지도 교정에서 실제 기출의 구조 그림 식별 필수가 확인됐다. 동일 교정 범위 안에서 모델이 문항별 원본 쪽·정규화 crop을 작성하고 코드는 그대로 렌더한다. 예시에 실제 그림을 표시하며 독립 원본 검수와 도구 없는 blind medical도 동일 문항 그림을 본다. 완료 호출·예산과 실행도구 전환은 모두 보존한다. 지도 표적 보완은 위 실제 진단에 따른1회만 추가하고 문항 수정 상한은 늘리지 않는다.

## 책임·입출력 계약·오류 상태
이번 명시적 후속 범위 예산: 지도 호출 총2회(최초1+표적 보완1), BANK최대3회, 전체 source/blind medical 각각최대3회, 원래20개 처리 확인1회. map-2는 CLI2400초 시간초과였으나 조사 마지막에 완성된 assistant JSON과 task_complete·usage가 확인됐다. 재호출 방지 검사가 새 호출을 막았으며 추가 모델0회로 정확한 원문을 복구한다. failed stage는 바꾸지 않고 결정적 assembly-map2를 구분한다. 원문 조건·판정·포인트를 바꾸지 않는 classification 중복 역방향은 모델의 기존 부모 계층을 근거로 정규화하고, 계약상 근거가 없는 선행 연결은 원문 제안으로 보존하되 미채택한다. 의학 사실을 코드가 수정하지 않는다. 자동 재시도·상한 초기화·의심0 목적 반복은 없다.
