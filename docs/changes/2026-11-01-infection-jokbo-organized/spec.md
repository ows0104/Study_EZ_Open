# 자료 계약

정본은 직전 작업의 고정된 183쪽 2026 족보이며 강의 매핑 80칸/69개 단원을 유지한다.
정리 PDF는 단원 제목·교수 이력·연도·문항 번호·문제와 보기·그림·정답을 구분한다.
문항의 글자·그림·표는 원본 PDF 지면을 벡터 형태로 가져와 확대 배치한다. 그림 유무를 낱말로 추정하지 않는다.
정답은 동일 단원·연도·번호가 유일하게 일치할 때만 붙인다. 원본 정답표의 모순·중복·불명확은 확인 표시로 남기고 원본 정답 구간도 보존한다. 원문 오류를 임의 수정하거나 해설을 새로 쓰지 않는다.
현재 교수와 참고 문항 구분은 실제 시간표 교수 및 원본 교수표로 확인되는 범위만 적용한다. 교수표와 본문의 첫 두 단원 번호 차이는 제목으로 대조한다. CBL·합본처럼 대응이 불명확하면 출제자를 추정하지 않는다.
원본 구간은 연도·문항 경계로 빠짐없이 나눈다. 공용 보기·출제 없음·추가 그림·원문 안내는 별도 원문 자료로 남기며 각 문항의 원본 쪽수를 표시한다.
검증은 전체 구간의 연속 범위, 문항/정답 결합, 원본 텍스트·이미지·렌더 보존 및 페이지 넘침을 검사한다. 그림·표·긴 문항·연결형·CBL·2차·교수 변경 사례를 시각 검토한다.
자료 API의 jokbo만 교체한다. 직전 원격 목록과 로컬 보관본을 고정하고 게시 후 80개 첨부 해시, 기존 필기 71개와 강의·퀴즈 보존을 확인한다.
