# 블록 시작 교수 변경 안내와 교수별 기출 스타일 — Intent

상태: 요구 문서화 완료, 세부 설계 검토 전. 제품 구현·자료 분석 실행·운영 반영 승인은 아님.

## 사용자 요청과 문제

2026-11-02 KST, 현재 채팅의 사용자 요청:
“블럭 시작할때 교수님이 바뀐 강의들을 알려주고, 교수별 기출 문제를 보고 출제스타일을 알려줬으면 좋겠어. 이걸 intent, spec, plan 등에 적어줄래?”

블록 초기에 올해 담당 교수가 달라진 강의를 알지 못하면 이전 교수의 기출 경향을 그대로 적용하기 쉽다.
기출을 강의별로 따로 읽는 것만으로는 같은 교수의 반복 소재·질문 방식·이미지 활용 등을 한눈에 파악하기 어렵다.

## 원하는 사용자 결과

- 블록을 시작할 때 교수 변경 강의와 이전/올해 담당을 빠르게 확인한다.
- 교수별 실제 기출 근거와 함께 출제 스타일, 올해 공부에서 주의할 점을 이해한다.
- 올해 교수의 기출과 다른 교수의 참고 기출을 구별해 준비한다.
- 자료 부족·공동 담당·담당 미상은 불확실한 상태로 이해하고 잘못된 확신을 얻지 않는다.

## 범위와 원칙

블록 전체 안내와 강의별 상세를 연결한다. 강의별 독립 지도 원칙은 유지한다.
교수 변경 비교 기준, 안내 시점·배치, 분석 단위·표본 기준은 [Spec](spec.md)의 제안과 [결정 대기](../2026-10-27-learner-journey/open-design.md#p10-블록-시작-교수-변경과-출제-스타일)로 구분한다.
출제 스타일은 확보한 기출에서 관찰한 경향이며 올해 출제 보장이나 교수 개인에 대한 평가가 아니다.
분석 결과만으로 기존 문항·학습 순서·중요도·추천량을 자동 변경하지 않는다.
원본 기출·그림·정답·교수 이력·식별자·첨부·개인 수정·제외·학습 및 검수 기록을 보존한다.

## 성공 기준과 연결

사용자가 변경된 강의, 비교 연도, 올해 교수와 근거를 확인하고 해당 교수의 기출 사례로 출제 스타일을 이해할 수 있다.
자료가 없는 경우와 분석이 실패한 경우를 구분하며, 다른 교수의 경향을 올해 교수에게 잘못 귀속하지 않는다.
