# Concept Tree 학습 여정과 독립 추출 설계

상태: 사용자와 함께 작성 중인 intent 초안. 설계·구현 승인 전.
현재 논의 순서: [사이트 전체 intent](../2026-10-27-site-intent/intent.md)를 먼저 함께 정리한다.
아래 내용은 Concept Tree의 초기 기록이며, 후속 인터뷰의 합의는 사이트 전체 intent에 정리했다.
2026-10-27 KST: 사용자가 우선 강의별 뿌리만 진행하고 intent부터 함께 작성하도록 범위를 정했다.

## 문제와 사용자 효과

26필기와 족보를 바탕으로 각 강의의 Concept Tree·족보 경향·출제 포인트를 독립적으로 추출하고,
출제·누락 검증을 거쳐 뿌리부터 탐색하며 학습하는 구조를 구체화한다.
기존 문항에서 만든 개념 지도만으로 새 Tree의 범위를 정하지 않는다.

2026-10-29 KST 후속 명확화: 필기·족보에서 문제·출제 포인트·개념트리를 만들고 포인트별 문제의
누락·적절성을 검증하며 트리로 큰 흐름을 이해하는 문제 제공 순서를 구성한다.
현재 설계는 [학습자 여정 spec](../2026-10-27-learner-journey/spec.md)의 문제·출제 포인트·개념트리 연결 절에
구체화했다. 아래 초기 미정 사항은 이후 합의와 함께 읽으며 이미 합의한 여정을 다시 미정으로 취급하지 않는다.

학습자가 현재 겪는 핵심 어려움과 이 구조로 얻으려는 가장 중요한 효과는 다음 대화에서 함께 정한다.
그에 따라 학습자 여정과 완료 기준을 정하며, 아래 미정 사항을 확정된 요구로 취급하지 않는다.

## 범위와 성공 기준

### 확인된 범위

- 우선 강의별 뿌리에서 탐색하는 구조를 다룬다. 과목 전체 Tree와 강의 간 탐색은 이번 범위에 포함하지 않는다.
- 지금은 intent를 함께 작성한다. intent의 목표·여정·완료 기준을 논의한 뒤 spec과 plan을 작성한다.
- 기존 문항·ID·학습 기록·개인 수정·제외 상태·검수 이력과 원본을 보존한다.
- 구현은 구체화한 계획에 대한 사용자 승인 후 진행한다.

### intent 논의를 마칠 기준

사용자와 다음 항목을 합의해 이 문서에 기록한다.

1. 해결하려는 학습 문제와 기대 효과.
2. 한 강의에 진입해 뿌리에서 학습을 이어가는 대표 여정.
3. 학습자가 무엇을 했을 때 무엇을 완료했다고 표시할지.
4. 이번에 다룰 범위와 후속으로 남길 범위.

기능 자체의 성공 기준은 위 논의 후 작성한다. 문서 작성 완료를 기능 구현·학습 효과 검증 완료로 간주하지 않는다.

### 함께 정할 사항

- 가장 먼저 해결할 학습상의 어려움은 무엇인가?
- 뿌리는 강의의 큰 개념을 뜻하는가, 실제 회상에 필요한 기초 연결을 뜻하는가? 둘을 어떻게 연결할 것인가?
- 개념 설명·원본 탐색·문항 풀이를 어떤 흐름으로 경험하게 할 것인가?
- 탐색·첫 회상·목표 달성·오늘 학습 종료를 어떻게 구분할 것인가?
- Tree·족보 경향·출제 포인트의 독립 추출에서 각 원본의 역할은 무엇인가?
- 기존 문항으로 평가할 수 없는 개념과 미해결 누락을 어떻게 보여줄 것인가?

앞서 제안한 진입 방식·숙련도 완료 기준·세 가지 추출 입력 구성은 논의안이며 사용자 확정 사항이 아니다.
현재는 원본 추출 실행·문항 생성/수정·운영 데이터 변경·배포를 진행하지 않는다.
개발 기록의 검사 목록은 작업 생성 시의 잠정 목록이며, 이후 plan에서 실제 구현 범위와 맞춘다.
