# 과제 ② — 승인된 학습 목표를 카드로 만든다

승인된 계획 `{plan_in}`을 읽고 각 회수 목표를 필요한 카드로 옮긴다. 계획에 없는 내용을
분량을 채우기 위해 추가하지 않는다.

## 목표 충실도

- 각 목표의 중요한 `retrieval_targets`가 실제 질문에 반영되어야 한다.
- 목표의 가장 일반적이고 자명한 문장 하나로 나머지 핵심을 대신하지 않는다.
- 같은 회수 방향을 중복 카드로 만들지 않는다.
- 저가치 카드가 될 수밖에 없다면 억지로 만들지 말고 제외 근거를 남긴다.

## 형식 선택

| 회수 과제 | 형식 |
|---|---|
| 정의·기전·비교·적용 | `basic` |
| 문맥 안의 특정 요소 | `cloze` |
| 유용한 참·거짓 판단 | `ox` |
| 사진·조직·도표 자체의 판독 | `image_basic` |
| 그림 속 라벨·위치 회수 | `image_occlusion` |

### Cloze

빈칸 번호 하나가 카드 하나다. 같은 축의 항목은 같은 번호로 함께 가리고, 축이 다를 때만
번호를 나눈다. 정의문 전체를 옮겨 임의의 단어를 여러 개 뚫지 않는다. 가린 답이 같은
문장 다른 자리에 그대로 남지 않게 한다.

### O/X

오해를 교정하거나 방향을 판별하는 데 유용한 진술만 사용한다. 답 분포를 맞추기 위해
사실을 뒤집거나 새로 만들지 않는다. 한 덱에서 문장 길이·부정형·말끝이 정답의 단서가
되지 않게 한다.

### 이미지

사이드카의 figure ID와 occlusion candidate ID를 그대로 사용한다. 좌표를 직접 만들지 않는다.
Image Occlusion은 승인된 목표의 `retrieval_targets`에 직접 포함되는 핵심 라벨에만 쓴다.
선택한 후보의 라벨 자체를 `a`에 적고 질문에는 노출하지 않는다. 라벨을 가린 뒤 기능·기전
등 다른 답을 묻지 않는다. `label=null`인 영역과 강조 상자는 선택하지 않는다. 조건을
만족하는 후보가 없으면 억지로 박스를 만들지 말고 `image_basic` 또는 텍스트 형식을 쓴다.
가린 원문 라벨은 `a`에 반드시 포함한다. 자료가 한국어·영어 대응 표기를 모두 제공한
경우에는 도메인 정책의 고정된 병기로 답에 함께 적되, 질문에는 다른 쪽 표기를 노출하지 않는다.

## 출처 필드

- 강의 자료 목표는 `source_type=lecture`이며 `slide_no`가 필요하다.
- 과거 평가 목표는 해당 어댑터와 출력 계약이 지정한 `source_type`, `jokbo_ref` 규칙을 따른다.
- 강의 카드의 `exam_hit`은 같은 회수 목표를 과거 문항이 실제로 물었을 때만 사용한다.
