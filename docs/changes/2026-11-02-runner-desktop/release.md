# 창 없는 러너 프로그램과 1분 자동 시작 — 배포 준비

## Review와 Test

강의 식별자는 과목·run ID·예습/복습 갈래의 복합 키다. 현재 블럭 밖 작업, 기존 완료·실패·취소·중지,
수동 전략 대기와 자동 일일 상한을 우회하지 않는지 검토했다. 복습은 bank 후처리만 사용하며
필수 웹 응답이 없는 강의에는 필요한 자료를 표시한다. 기존 요청자 기록·산출물·검수 이력을 보존한다.

- runner: 전체 498개(488 + 화면 검사 8 + 기존 상태 창 2)를 검사한다. 최종 결과는 state.json 참조.
- desktop: 제어·타이머·버튼·중복 실행·파일 보존·한글 바로가기 설치 21개 통과.
- desktop-db: 격리 SQLite에서 자료 준비·강의/갈래 격리·상한·중지/재개·취소·중복 검사 통과.
- 한 프로세스에 Tk 창을 반복 생성한 검사는 Tcl 라이브러리 초기화 오류가 있어 화면 모듈을
  독립 프로세스로 실행했다. 화면 검사를 제외하지 않고 모두 실행한다.
- 서버 런타임 검사는 uv의 PYTHONHOME 환경을 제거하고 실행했다. 실제 JobClient도 같은 격리를 적용한다.

## 로컬 릴리스 대상

Git 기준 138f32dc432bbc54ed2e71604363782d28dd1014 + 현재 작업 트리.
검사·리뷰의 정본은 state.json의 revision-bound 근거이며 integration source hash는
2a91d24f0753a381325b818035d73d3f46e2cacfc0cfaad4c70148945c1e1c0e 이다.
사용자의 현재 구현·실행·바탕화면 프로그램 요청을 로컬 설치 승인으로 적용한다.
서버·웹 배포·DB 스키마·로그인 예약 작업은 변경하지 않는다. 다른 대화의 변경은 커밋/배포하지 않는다.

현재 작업이 없는 것을 확인하고 기존 러너를 새 제어 지원 러너로 교체했다.
실제 강의 162개 작업 행 조회, 새 러너 생존과 프로그램 창 생성, 오류 로그 부재를 확인했다.
시작할 신규 항목은 없으며 기존 실패 8건은 자동 재실행하지 않았다.
Computer Use는 해당 창을 찾았지만 화면 캡처 접근 확인이 시간 초과되어 시각 검증은 미완료다.
자동 GUI 검사에서 실제 Tk 버튼과 60초 경계·취소·창 닫기를 검증했다.
Windows PowerShell 5.1의 한글 파일명 해석 오류를 UTF-8 BOM으로 해결했고,
실제 Windows 바로가기 생성 회귀 검사도 통과했다.

## 설치·Maintain·복원

검사와 release gate 확인 뒤 scripts/install-runner-desktop.ps1로 바로가기를 설치한다.
프로그램은 현재 러너에 연결하며 창을 닫아도 러너가 유지된다. 전체 일시정지는 로컬 설정에 보존된다.
문제 발생 시 바로가기를 제거하고 기존 runner-status.ps1 상태 창을 사용한다.
원본 자료·생성물·학습 기록은 삭제하지 않는다. 설치 확인 결과는 local-verification.md에 남긴다.
