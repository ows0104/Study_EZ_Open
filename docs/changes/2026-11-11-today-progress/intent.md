# 캘린더 머리 두 칸 C안 · 「오늘 복습」 분모를 하루 학습 목표로

## Intent

사용자 2026-11-11: 「오늘 할 일 표시는 이걸(시험까지 오늘의 학습 목표, `daily_plan`) 사용할 거야. 이걸 분모로 두고 최초의 C안으로 진행해줘.」
C안 = 남은 양을 크게, 한 양은 칸 아래 막대(시안 2026-11-11). PR #97(내일 예습·새벽 4시) 위에 쌓는다.

## Spec

- 「내일 예습」: 큰 수 = 내일(학습일) 강의(실습 제외) 중 예습 퀴즈가 남은 강의 수. 막대 = 예습 퀴즈가 올라온 강의마다 한 칸, 끝낸 강의는 채운다.
- 「오늘 복습」: `/api/study-plan?target=<시험 목표>`의 가장 가까운 시험(`plans[0]`)을 쓴다. 큰 수 = `remainingGain`(%p),
  막대 = `progressPercent`. 시험 목표는 「시험까지 오늘의 학습 목표」 판의 선택값(`useStudyTarget`)과 같다.
  시험이 없거나 실패하면 「–」. 창으로 돌아올 때와 5분마다 다시 부른다.
- 다 하면(예습 남은 0, 복습 `met`) 칸이 회색으로 가라앉고 `✓ 전체`를 보인다.
- 이전 「오늘 복습 N문제」(이번 블록 `reviewDue` 합, `useTodayDue`)는 쓰지 않아 지운다.
- 서버·API 변경 없음. 이용 안내 1줄을 맞춘다.
