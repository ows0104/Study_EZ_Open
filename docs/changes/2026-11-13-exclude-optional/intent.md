# Optional 문항 계산 제외 토글

## 문제와 사용자 효과
사용자(2026-11-13): 「optional 문제가 상당히 지엽적으로 나와서 이번 블럭에서는 기본적으로 빼고 풀 거 같아.
근데 optional 문제가 계속 미열람 개수를 차지하고, 계산식에도 영향을 미쳐서 학습률이 너무 낮게 나와.
optional 문제를 없는 것처럼 하고 카드 수 및 학습률을 계산할 수 있는 토글 버튼이 … 있었으면 좋겠어.
그렇다고 사이트에서 optional을 아예 없애지는 말고, 그냥 계산할 때 고려하지 않게만 만들 수 있을까?」

위치·범위(같은 날 답변): 「강의별 풀기 화면에서 "유형별/순서대로" 토글과 같은 줄의 맨 오른쪽.
이걸 바꾸면 사이트 전역 (캘린더까지)에 적용되도록 해줘」

## 범위와 성공 기준
- 강의 목록의 「유형별/순서대로」 토글 줄 맨 오른쪽에 Optional 제외 토글 하나.
- 켜면 사이트 전체(강의 목록·캘린더·강의 패널·Main-Quiz 시작 화면·요약)의 Main-Quiz 카드 수·미열람 수·학습률이
  Optional 문항이 없는 것처럼 계산된다. 끄면 지금과 같다.
- Optional 문항·기록·지도는 지우거나 숨기지 않는다. 풀 수 있고 기록도 그대로 쌓인다.

## 근거·미정 사항
- 2026-11-12 오늘 학습 중요도 필터(#119)는 오늘 계획만 거르고 학습률·진척 분모는 그대로 두었다.
  이번 토글은 사용자가 고른 경우에 한해 분모에서도 뺀다.
- 저장 위치(브라우저/계정)와 서버·웹 계산 경계는 spec에서 정한다.
