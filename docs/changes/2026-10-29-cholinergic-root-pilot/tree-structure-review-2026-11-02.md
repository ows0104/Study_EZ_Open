# 첫 개념트리 수신·구조 검토

2026-11-02 사용자 첨부 텍스트를 `received/concept-tree-2026-11-02.txt`에 바이트 그대로 보존했다. 수동 전달이며 bridge 자동 수신 성공 근거가 아니다. 원본 PDF·독립 포인트·기존 69문항과의 대조는 아직 실행하지 않았다.

## 구조에서 확인한 점

- 제출본은 작용 표적 → 작용 방식 → 장기 반응 → 임상 활용 → 과도한 활성화의 다섯 큰 묶음을 제안하고 연결 이유·비교표를 함께 제공한다. 제목만 나열한 결과보다 학습 목표와 관계를 검토하기 좋다.
- 수용체·작용 방식·효소 결합·분포 특성을 서로 다른 분류 기준으로 드러낸다. 같은 약물이 여러 위치에서 반복 등장하므로 지도 위치와 학습목표 동일성을 구별할 실제 사례가 생겼다.
- (1)·(2) 합본 족보의 범위를 구별하려고 했으나 실제 제외/포함의 적절성은 원본 대조가 필요하다.

## 아직 확정하지 않을 것

- 다섯 묶음은 탐색 뼈대 후보이며 곧 학습목표 5개가 아니다. 실제 회상 질문·답 범위·필수 방향을 정하기 전 진행 막대의 분모를 만들지 않는다.
- 제출본의 다섯 단계는 설명 순서다. 의학적 선행관계나 강제 학습 순서로 자동 변환하지 않는다.
- 마지막 '어느 하나가 다른 하나의 하위 개념인 것은 아니다'라는 문장은 범위가 모호하다. 서로 교차하는 속성과 2-B에 제시한 기전 내부 분류를 구별해 표현할 필요가 있다. 이는 구조 표현 지적이며 의학 판정이 아니다.
- 파일명 인용과 일부 쪽/족보 번호가 있으나 각 주장·범위의 원본 근거를 확인한 것은 아니다. 강의 학습목표 5개라는 주장과 목록 밖 누락도 미검증이다.
- 뼈대 외 세부 내용을 첫 제품 범위에 자동 포함하지 않는다. 문항·정답·검수 판정·기존 학습 기록은 변경하지 않는다.

## 다음 단계

우선 이 큰 묶음을 구조 검토 후보로 두고, 별도 대화에 원본 필기·족보만 제공해 독립 출제 포인트를 받는다. 요청문은 기존 한 문장 '위 필기와 족보를 보고 출제 포인트를 추출해줘.'를 유지한다. 트리 결과를 포인트 추출 입력에 넣지 않는다.
