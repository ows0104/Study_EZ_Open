# Main Quiz 새 판 대체

현재 사용자 추가 지시: 학습한 사람이 없으므로 기존91문항·학습기록·수정3/3 보존 제약을 해제하고 새것으로 대체 가능. 기존 통과28의 목표/연결과 누락 그림을 보완해 학습 가능한 새 판을 게시한다. 정상 문항·원본 자료는 재사용하되 문항/그림/목표 수정과 문항 수 변경을 허용한다. 풀이UI는 현재 Main Quiz 그대로 유지한다.

원래3/3과 자료는 삭제할 필요 없이 과거판으로 보관하고, 새로운 생성ID와 별도0..3 수정 예산을 사용한다. 원래실패를 성공으로 덮거나 오래된 판정을 새 검수로 재사용하지 않는다. 새 실습 대상은261104_02뿐이다.
