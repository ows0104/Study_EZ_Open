# 복습 퀴즈 문항 타이머 — 설계

## 요구사항과 수용 기준
- 단계는 둘이다. **문제**(답을 펴기 전)와 **해설**(답을 편 뒤 평가 전).
  - 문제 시간: `format`이 `ox`면 20초, `matching`·`sequence`면 40초, 그 밖은 30초.
  - 해설 시간: 40초.
- 문제 단계 0초: 기존 「답 보기」와 같은 `reveal`(시도함, 고른 선지 포함)을 보낸다.
- 해설 단계 0초: 기존 Again 버튼과 같은 `rate('Again')`을 보낸다. 사용자 선택에 따른 것이며 학습 기록에 Again으로 남는다.
- 시간은 문항·단계가 바뀔 때마다 처음부터 센다(되돌리기로 돌아온 해설도 40초부터).
- 다음 동안은 시간이 흐르지 않는다: 타이머 꺼짐, Tab 일시정지, 저장·불러오는 중(`locked`),
  문제 이미지 준비 전, 문제 수정·제보 창이 열림, 브라우저 탭이 숨겨짐(`document.hidden`).
- 표시: 머리 오른쪽(`main-quiz-tools`)에 남은 초 숫자와 「타이머」 토글. 꺼지면 숫자를 숨긴다.
  일시정지면 숫자 앞에 「멈춤」 표시. 설명 문장은 넣지 않는다.
- 토글 상태는 `localStorage`의 `studyez:quiz-timer`(`on`/`off`), 읽기·쓰기 실패 시 켜짐으로 동작한다.
  꺼짐→켜짐이면 현재 단계 시간을 처음부터 센다.
- Tab(수정키 없음): 타이머가 켜져 있고 문항이 있을 때 일시정지/재개하며 기본 포커스 이동을 막는다.
  입력칸·열린 대화상자에 포커스가 있으면 처리하지 않는다. Shift+Tab은 그대로 둔다.
  일시정지는 그 문항·단계에만 적용되고 다음 단계는 다시 흐른다.

## 책임·입출력 계약·오류 상태
- 새 `web/src/bank/quizTimer.ts`: 형식별 초 계산과 `useQuizTimer` 훅(경과는 시각 차로 계산, 0에서 한 번만 만료 호출).
- `RootSolve.tsx`: 단계 판정, 만료 시 기존 `reveal`/`rate` 호출, Tab 처리, 머리 표시.
- 서버·API·`RootAction` 형태는 바꾸지 않는다. 시간 초과 여부는 따로 저장하지 않는다.

## 호환성과 데이터 보존
- DB·학습 기록 스키마 변경 없음. 자동 평가는 사용자가 누른 Again과 같은 경로로 저장된다.
- legacy `BankSolve`와 예습 퀴즈 화면은 바꾸지 않는다.
