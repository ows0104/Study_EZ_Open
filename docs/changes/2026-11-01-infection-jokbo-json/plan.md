# 실행 계획

1. 직전 answer-audit/upload-plan.json과 원본 PDF를 읽어 검증된 문항 경계/정답/강의 연결을 재사용한다.
2. 이 작업 기록의 일회성 빌더에서 원문 텍스트, 실제 이미지 및 벡터 영역·원문 대조 지면을 추출해 JSON으로 연결한다. 원본 압축 이미지도 보관한다.
3. JSON을 읽어 GPT용 MD·문항 ID 표시 그림·단원별 첨부 목록·사용 안내를 생성한다. 원본 PDF를 바이트 그대로 복사한다.
4. materials 검사와 대표 시각 검토 후 전체 ZIP을 만들고 package 검사로 내부 파일 해시·안전 경로·문항/그림/MD 연결을 확인한다.
5. 다운로드 경로와 실제 완료 수치, 정답 보류 유지 상태를 안내한다. 서비스 업로드 형식 변경이나 배포 없이 독립 자료를 제공한다.

현재 사용자가 설명한 JSON 관리 방식 적용을 명시적으로 요청했으므로 같은 제작 범위의 구현 승인을 기록한다. 기존 파일/원본/사이트 자료·개인 변경을 덮어쓰거나 삭제하지 않는다. 새 출력 폴더와 작업 기록만 작성한다.
