# 족보 모아풀기

## 문제와 사용자 효과
족보 퀴즈는 강의(시간표 칸)마다 따로 연다. 시험 전에 여러 강의의 족보를 한꺼번에 풀 길이 없다.
복습 퀴즈는 강의 목록에서 골라 모아풀기를 할 수 있게 됐다(#219·#220). 족보도 같은 자리에서 모아 풀고 싶다.

사용자 원문(2026-11-18):
「그리고 비슷하게 모든 족보를 묶어서 푸는 기능도 만들어줘. 지금 강의 여러개를 선택하면 하단에 모아풀기 버튼이 나오는데,
그걸 복습퀴즈 모아풀기랑 족보 모아풀기 버튼 두 개로 나눠줘. 족보 모아풀기의 경우에는 기존 학습률이나 미열람 문항,
주관식/객관식 선택 등이 없으니까 그냥 섞어풀기랑 모아풀기만 나눠줘. 대신 같은 교수만/다른 교수까지는 아까 중요도 선택처럼
전체 선택이 있고, 내려서 강의별로 선택할 수도 있게 만들어줘. 그리고 모아풀기를 아무 생각없이 모든 강의를 한 번씩 돌리는 걸로
하면 강의별로 족보 문제 개수가 안 맞아서 뒤로 가면 족보가 많은 단원만 계속 나올 테니까, 이렇게 되지 않도록 전체 개수를
고려해서 적절한 위치에 배분해줘.」

## 범위와 성공 기준
- 강의 목록에서 강의를 고르면 아래 막대에 「복습퀴즈 모아풀기」·「족보 모아풀기」 두 단추.
- 족보 모아풀기 시작 화면: 같은 교수만/다른 교수까지(전체 + 「강의별 ⌄」로 강의마다), 모아풀기/섞어풀기, 문항 수.
- 모아풀기는 강의마다 문항 수에 맞춰 전체에 고르게 배분한다 — 끝으로 갈수록 한 강의만 남지 않는다.
- 풀이·답·오답노트 표시(모르겠음·주의·괜찮음)·Z·끝 화면은 강의 하나 족보와 같다. 기록은 강의(시간표 칸)별로 쌓인다.

## 근거·미정 사항
- 「모아풀기」는 강의 안의 족보 순서(같은 교수 → 다른 교수 최신 연도)를 지키며 강의들을 번갈아 낸다. 「섞어풀기」는 강의 사이·안 모두 무작위.
- 같은 교수 문항이 없는 강의(교수가 바뀐 강의·CBL)는 강의 하나 화면처럼 「같은 교수만」을 고를 수 없고 「다른 교수까지」다.
- 고른 범위를 끝까지 풀면 그 범위에 든 강의마다 1회독(강의 하나 화면의 회독과 같은 규칙).
