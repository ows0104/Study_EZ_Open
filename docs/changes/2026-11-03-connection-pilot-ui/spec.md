# 설계

별도 로컬 React 진입점에서 대화의 첫 10묶음을 사용한다. AI/API 호출 없이 질문→답 공개→항목별 자기확인→후속 질문을 제공한다. 초기에는 답·후속 질문·지도·근거를 숨긴다. 검토 탭을 연 경우 노출 이력을 표시하고, 자기확인을 독립 회상·숙련으로 인증하지 않는다. 로컬 저장은 전용 revision 키를 사용하며 실패를 표시한다. 분류/나열, 구조적 역할, 학습 역할을 별도 표시한다. 지도·문항별 근거/미확인·남은 질문·결과와 피드백 내보내기를 제공한다. 전체 강의 완료로 표시하지 않는다.

기존 대화 초안을 시범 데이터로 옮기며 의학 검수 완료를 주장하지 않는다. 원본 CLI 결과·은행·ID·학습기록·검수 상한은 보존한다. 운영 라우트·인증·DB·생성 프롬프트를 수정하지 않고 별도 Vite 설정으로 빌드한다. 제품 이용현황 수집은 운영 기능 적용 시 연결하고 이번 로컬 행동은 서버 이용현황에 합치지 않는다.
