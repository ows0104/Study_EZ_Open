## 범위와 성공 기준
- Main-Quiz 개념 지도 화면만 바꾼다(`RootMap`). 기존 Quiz Bank 개념 지도(`ConceptMap`)는 범위 밖이다.
- 처음 화면에 강의 제목, 최상위 가지, 모든 하위 개념이 클릭 없이 읽히는 크기로 들어온다.
  감염병리1 기준 1600×900 데스크톱에서 그렇다.
- 개념을 누르면 다음이 보인다.
  - 위아래 계통과 다른 가지로 이어진 연결선이 강조된다.
  - 그 개념의 문항이 그 자리에서 펼쳐진다.
  - 옆 패널에 자세한 내용이 나온다.
- 학습 상태(미학습·학습 중·회상 가능·준비 전)와 현재 문제는 지금처럼 보인다.
- 서버·DB·출제 데이터·학습 기록은 바꾸지 않는다.

## 근거·미정 사항
- 데이터는 이미 계층을 가진다. map-tree-26110803의 개념 C 75개가 parent_ids를 가지며, 최상위는 7개다.
- 개념별 핵심 사실(core_facts)은 지도 API(`RootMapData`)에 없다. 넣으려면 서버 계약 변경이 필요해서 이번 범위에서 뺀다.
- 사용 안내(`GuidePage.tsx`)의 개념 지도 설명은 옛 동작을 말한다. 이 파일은 진행 중인 UI 개편 작업(claude/redesign-1107-feedback)의 범위라 여기서 고치지 않고 후속으로 남긴다.
