# 개인 수정한 Main-Quiz 문항의 선지 유지

## 문제와 사용자 효과
Main-Quiz에서 「문제 수정·제보」로 내 수정본을 저장하면 그 문항의 덧붙인 선지(객관식 모드·주관식 V 선지, `root_mcq`)가
사라졌다. 서버가 선지 짝을 문항 글 해시로 찾는데, 수정본은 글이 달라 짝이 없다고 판단했다.

## 범위와 성공 기준
- 발문만 고친 수정본: 수정 전과 같은 선지(같은 날 같은 조합·순서)와 같은 정답 ID.
- 단답(묶음 없음)의 정답을 고친 수정본: 고친 정답이 정답 선지, 오답 풀은 그대로(고친 정답과 같은 글은 뺌). 오답이 최소 수 미만이면 선지 없음.
- 나열·빈칸·순서·묶음 문항의 정답을 고친 수정본, v1 asset: 칸을 나눌 수 없어 지금처럼 선지 없음.

범위 밖: 뒤로 가기(되돌리기) 때 고른 선지를 남기는 것 — 사용자 2026-11-14 「무조건 과거 기록은 삭제되도록」 지시와
진행 중인 PR #137(RootSolve 선지 상태)과 겹쳐 따로 정한다.
