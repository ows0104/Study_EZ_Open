# Concept map·포인트 기반 자동출제·게시

사용자 2026-11-03: “Concept map·포인트를 받아 자동으로 출제하고 게시하는 연결을 진행하자.” 현재 뿌리 학습 입력을 문항 생성·원본/독립 정답 검수·방향 연결·게시까지 잇는 명시적 자동 경로를 만든다.

성공: 관리자 화면에서 개념도와 포인트 원문을 넣어 한 번 요청하면 기존 러너가 처리하고 검수 기록·포인트 충족/누락을 가진 새 뿌리 학습 판을 원자적으로 등록/활성화한다. 실제 강의 입력 없이 모델을 호출하거나 운영을 배포하지 않고 합성 원본과 가짜 모델 응답/격리 서버로 전체 연결을 검증한다.
