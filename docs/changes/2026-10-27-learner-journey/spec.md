# StudyEZ — Spec

상태: **합의한 동작을 정리한 설계 기준. 세부 계약 미완료.** 2026-11-01 재정리.
이 문서는 [intent](../2026-10-27-site-intent/intent.md)의 목적을 **화면·행동·상태·판정으로 어떻게 충족하는지**를 담는다.
계산 공식·버튼 문구 등 미확정안은 [open-design.md](open-design.md)에만 둔다. 아래 합의가 제품 구현·운영 승인이나 검사 통과를 뜻하지는 않는다.
이전 의사결정 발언은 [사용자 결정 기록](intent.md), 재배치와 원문 보존은 [정리 이력](reorganization-notes.md)을 따른다.

## S1. 대표 여정과 진입

전체 현황 → 오늘 추천 시작/재개 → 머릿속 회상 → 정답 확인 → 자기평가 → 다음 질문 → 오늘 완료·변화 확인 → 오늘은 여기까지.

- 지도 열람은 시작의 필수 단계가 아니다. 추천대로 바로 시작할 수 있고, 홈이나 학습 중 강의 지도를 선택해 볼 수 있다.
- 한 가지의 완벽한 숙련을 진입 조건으로 삼지 않는다. 오답·중간 평가에서도 다음 범위로 이동할 수 있다.
- 중단 후 재개 위치·저장 상태를 구별한다. 정답을 열었다는 사실만으로 회상 성공을 만들지 않는다.
- 경로의 종료, 오늘 분량 완료, 강의/전체 범위의 첫 학습 완료, 현재 앎은 서로 다른 상태다.

## S2. 학습 단위와 판정

| 단위 | 역할 |
|---|---|
| 개념 | 지도에서의 위치와 맥락 |
| 학습목표 | 공부하고 확인할 사실·관계·분류·순서·목적 |
| 회상 방향/과제 | 어떤 단서에서 어떤 답·판단 이유를 떠올려야 하는지 |
| 문항 | 해당 과제를 표현하고 확인하는 수단 |

같은 관계라도 필요한 방향별로 학습 상태를 따로 관리한다. 같은 목표를 여러 방향·문항으로 공부해도 목표 범위는 한 번만 센다.
구체 목표의 분할·동일성·필수 방향 선정은 실제 원본으로 검토할 미정 계약이다(P02). 강의 간 유사 목표를 자동 병합하지 않는다.

### 첫 학습과 현재 회상

- 유효한 과제에서 답을 떠올려 보고 정답까지 확인하면 틀렸어도 한 번 공부한 것으로 인정한다.
- 질문을 열기만 하거나 자료·지도만 둘러본 경우는 첫 학습이 아니다. 잊어도 첫 학습 사실은 유지한다.
- 기본 방식은 머릿속 회상·정답 확인·자기평가이며 매번 텍스트 답이나 이유 입력을 요구하지 않는다.
- 단답을 객관식으로 바꾼 문항에서 선지 없이는 떠올리지 못한 경우는 중간 상태다.
- 문장 OX를 객관식으로 바꾼 문항에서 왜 정답인지 설명하지 못하면 필요한 이해·판단이 갖춰지지 않은 상태다.
- 자기평가 전/보류를 회상 실패나 성공으로 임의 처리하지 않는다. 기록 시점·척도·기억 유지 기준은 P02에서 정한다.

### 목표 단위 집계

| 목표 상태 | 합의한 조건 | 범위 집계 |
|---|---|---|
| 미학습 | 유효한 방향 중 어느 것도 회상 시도·정답 확인을 마치지 않음 | 목표 1개 |
| 한 번 접함·보완 필요 | 한 방향 이상 공부했지만 모든 필수 방향이 현재 도움 없이 회상 가능한 상태는 아님 | 목표 1개 |
| 회상 가능 | 필요한 모든 필수 방향이 준비·평가되어 현재 도움 없이 회상 가능한 상태 | 목표 1개 |

필수 방향이 미정·누락·준비 전인 경우 회상 가능으로 통과시키지 않는다. 선택 확장 방향을 일괄 필수 조건으로 삼지 않는다.
내용의 첫 학습과 모든 필수 방향의 첫 학습은 구별한다. 지도에서 방향별 진행과 회상 상태를 확인하고, 추가 방향 미학습과 기억 부족을 구분해 보여준다.
필수 방향이 늘어도 내용 수를 중복 증가시키지 않는다. 범위/기준 변경과 실제 망각은 구분하며 기존 기록 연결 방식은 P07에서 정한다.

## S3. 전체 현황 홈

- 전체 시험 범위와 강의별 본 곳·빈 곳·현재 회상을 먼저 보여준다. 특히 중요한 미학습을 찾을 수 있어야 한다.
- 강의마다 **하나의 누적 막대**로 회상 가능 / 한 번 공부함·보완 필요 / 미학습을 표시한다.
- 회상 가능은 공부한 범위의 부분집합이다. 세 구간의 합은 해당 강의의 목표 범위이며 방향·문항·반복 횟수로 부풀리지 않는다.
- 중요한 내용 자체의 미학습과 이미 접한 내용의 추가 방향 미학습을 구별한다.
- 오늘 추천 학습을 바로 시작/재개할 수 있게 한다. 강의·분량·모드를 매번 계획하게 하지 않는다.
- 준비되지 않은 강의도 전체 목록에 남긴다. 모르는 세부 목표 수를 확정값으로 만들거나 준비된 범위의 완료를 전체 시험 범위 완료로 표시하지 않는다.
- 기존 카드별 StageBar는 표현의 참고다. 기존 '인지'는 열람만 포함할 수 있으므로 새 첫 학습 기준과 동일시하지 않는다. 기존 숙련도·기록을 그대로 새 목표에 복사하지 않는다.

정보 우선순위는 시험·범위 확인 → 강의별 현황·중요 미학습 → 오늘 추천과 시작 행동이다.
막대 색·무늬·배치·반응형 세부 표현은 P01에서 정한다.

## S4. 강의 지도

- 강의마다 독립 지도이며 처음에는 뼈대와 큰 가지만 보인다. 원하는 가지를 펼쳐 세부 지점을 본다.
- 접힌 가지에도 미학습·중요 미학습의 수를 남긴다. 접었다고 학습 범위에서 제외하지 않는다.
- 뼈대의 회상 성공이 하위 내용을 공부한 상태를 만들지 않는다. 가지 제목 자체를 별도 학습 범위로 중복 집계하지 않는다.
- 지점을 선택한 상태와 실제 풀이 중인 지점을 구별한다. 선택·펼침·접힘만으로 학습 기록을 만들지 않는다.
- 현재 위치와 해당 지점의 첫 학습·회상 상태를 확인하고 학습으로 진입할 수 있다.
- 분류/구조 연결선을 실제 의학적 선행관계·강제 학습 순서로 자동 해석하지 않는다.
- 학습 중 지도를 둘러본 뒤 같은 질문·정답 확인 여부·평가 단계·진행으로 돌아온다. 다른 곳을 살펴봤다는 이유만으로 현재 질문을 바꾸지 않는다.

관계 유형 표현·선택 상세 배치·미학습 0개의 표시·접힘 유지·답을 드러내는 명칭 처리 등 세부안은 P01이다.

## S5. 질문·자기평가·전환

- 질문을 중심으로 현재 강의·가지·학습 지점의 경로와 작은 위치 지도를 보여준다.
- 정답·해설·근거는 확인 행동 이후 보여준다. 지도 방문은 회상 성공의 증거가 아니다.
- 자기평가를 누르면 추가 '다음' 확인이나 대기 화면 없이 다음 질문으로 이동한다.
- 새 현재 위치와 방금 공부한 지점의 상태 변화를 짧게 보여준다. 이 표시는 추가 클릭이나 대기를 요구하지 않는다.
- 틀렸다고 같은 질문에 즉시 성공해야 다음으로 넘어가게 하지 않는다.
- 마지막 지점의 평가 후에는 해당 경로 결과로 이어진다. 이것만으로 오늘 추천 전체 완료를 자동 선언하지 않는다.

자기평가 버튼 개수·문구, '정답 확인' 한 행동으로 시도를 기록하는 안, 지도 단서를 본 경우의 판정·등급, 피드백 시간·표현, 저장 실패/중복/undo/복원 계약은 P01·P02·P07이다.

## S6. 오늘 완료와 변화

- 오늘 새로 공부한 범위, 회상 상태의 변화, 남은 중요한 미학습을 함께 보여준다.
- 기본 행동은 **오늘은 여기까지**이며 잔여 범위 확인·추가 학습은 선택이다.
- 잔여를 살펴봤다는 이유로 오늘 완료를 취소하거나 새 의무 분량을 만들지 않는다.
- 같은 목표를 여러 방향·문항으로 반복해도 오늘 새 범위가 중복 증가하지 않는다.
- 첫 학습 진전은 잊어도 지우지 않는다. 오늘 완료·전체 첫 학습 완료·현재 앎을 구분한다.
- 복습만 한 날에도 첫 학습 증가와 회상 보강을 구분할 수 있어야 한다. 중요한 잔여가 0이라고 전체 숙련을 선언하지 않는다.
- 전후 비교는 같은 범위·판정 기준으로 해야 한다. 기준이 없거나 바뀌었으면 변화량을 임의 생성하지 않는다. 자료/기준 변경은 학습 변화와 구분한다.

정확한 하루 기준 시점·복수 세션·날짜 경계·시간 경과·추가 학습·undo의 반영과 전후 막대 등 배치는 P06·P01이다.

## S7. 추천과 자료 추가

### 합의한 추천 동작

- 시간 설정 없이 시험일까지 남은 기간·준비된 범위·학습 기록으로 필요한 분량을 추천한다.
- 필요한 새 진도를 확보하면서 우선순위 높은 복습을 함께 배정한다. 새 내용과 이미 접한 목표의 새 방향을 구별하고 동일 목표 범위를 중복 집계하지 않는다.
- 평소에는 안 본 강의를 우선하고 복습을 섞는다. 시험이 가까워지면 중요한 미학습·반복 오답을 우선하되 아는 내용의 반복으로 새 범위를 막지 않는다.
- 고정 비율이나 보완 10개를 쓰지 않고 필요도와 실제 기록에 맞춰 조정한다.
- 필요한 새 진도와 급한 복습이 최근 학습량을 넘으면 **둘을 기본 추천에 포함해 분량을 늘린다.** 최근 기록을 강제 상한으로 삼거나 급한 복습을 선택 권장으로만 빼지 않는다. 증가 이유를 보여준다.
- 시험 2일 전까지 전체 첫 학습을 목표로 하고 마지막 이틀은 복습·약점 보완 중심이다. 늦은 필기·중요 미학습의 새 학습은 그때도 허용한다.
- 매일 실제 남은 기간·범위로 재계획한다. 전날 미완료 목록을 그대로 누적하거나 중요한 잔여를 숨기지 않는다.

계산식·급한 복습의 판정·초기 기록 부족·하루 기본량·간격 반복 모델·목표일 경계·오답 이후 세션 내 조정은 P03이다.

### 자료 유입과 준비 상태

시험 일정·전체 강의 목록은 미리 알 수 있고, 평일 강의는 하루 3~6개·평균 약 4개다. 이 수를 동일한 학습량이나 같은 날의 필기 도착으로 간주하지 않는다.
기존 예습 퀴즈를 쓰고, 새 지도 학습은 필기가 들어온 뒤 준비된 강의부터 시작한다.
필기·슬라이드가 추가되면 해당 강의 지도와 추천을 보정한다. 다른 강의와 통합한 지도를 만들지 않는다.
자료 대기·콘텐츠 준비/검증·사용자 학습을 구별하고 자료 추가를 곧 학습 완료로 처리하지 않는다.
자료 확인 절차·범위 확정·세션 도중 반영 시점과 변경된 목표의 기록 연결은 P05·P07이다.

### 중요도 판단에 사용할 교수별 기준

| 교수 유형 | 사용자가 제시한 기준 |
|---|---|
| 족보형 | 매년 반복되는 해당 교수의 기출 중심 |
| 족집게형 | 수업 중 짚은 부분 중심 |
| 신규 | 정보가 없으므로 다른 교수의 작년 기출·올해 설명 등을 포함해 넓게 준비 |
| 일반형 | 출제 예고 > 같은 교수 족보 > 교수 설명(학생 필기) = 올해 슬라이드 > 다른 교수 족보 |

유형별 순서를 고정된 전 교수 공통 점수로 바꾸지 않는다. 유형 판별·변경·출처 충돌·정량화는 P04이다.

## S8. 콘텐츠 준비·검증·학습 연결

| 결과물 | 학습에서 맡는 역할 |
|---|---|
| 문제 | 실제 회상·판단 연습 |
| 독립 출제 포인트·족보 경향 | 필요한 목표·방향·시험 근거와 누락을 살필 기준 |
| 독립 개념트리 | 강의 전체의 목적·분류·순서·관계와 학습 위치 |

- 세 결과물은 원본에서 각각 작성한 뒤 대조한다. 앞의 목록이나 기존 문항만으로 다음 결과의 전체 범위를 정의하지 않는다.
- 포인트마다 필요한 사실·관계·방향을 실제 문항이 충분히 묻는지, 정답·해설이 원본과 맞는지 본다. 포인트 목록과 트리 자체의 범위 오류·목록 밖 누락도 본다.
- 포인트·문제의 개수를 일대일로 맞추거나 한 문제의 부분 충족을 전체 충족으로 보지 않는다.
- 검증 결과와 학습자의 미학습·첫 학습·회상 가능은 별도 상태다.
- 실제 학습 목표로 묶고 관계의 의미를 드러내되 모든 연결을 선행관계나 새 문제로 만들지 않는다.
- 원본 전체 맥락에서 뿌리를 선정하고 기존 충분한 문항은 재사용한다. 뿌리→가지→세부, 비교·필요한 방향·혼합 복습에 활용한다.
- 이번 제품의 첫 범위는 강의별 뿌리다. 전체 원본을 읽거나 결과에 세부가 포함되어도 세부 Tree 전체 구현·전 강의 재출제로 범위를 확대하지 않는다.

### 원본 crop 기반 이미지 문항

2026-11-01 후속 합의: 이미지로 확인해야 할 내용을 필기·족보의 필요한 원본 영역을 crop해 문제에 사용한다.
해설의 근거 이미지 표시와 이미지 자체를 보고 푸는 과제를 구분한다. 원본은 보존한다.
실제 추출 영역·단서 처리·출처/좌표 계약·파일 전달·화질·검수·학습 상태 기준은 P09에서 정한다.
이 방향 합의는 이미지 추출 실행·기능 구현·운영 반영 승인이나 첫 적용 범위의 자동 확대가 아니다.

추적 표의 필드·충족/부분/누락 등 판정 명칭·통과 조건·실제 목표/필수 방향 선정은 P04·P02다.
웹/CLI 배치·파일 회수는 [시범 파이프라인](../2026-10-29-cholinergic-root-pilot/pipeline.md)의 실행 설계이며 현재 bridge의 세 종류 수신 지원을 뜻하지 않는다.

## S9. 보존·불확실성·기술 계약 경계

- 기존 문항·ID·원본·개인 수정·제외·학습 기록·검수 이력을 보존한다. ID만 같다고 새 목표로 상태를 자동 승계하지 않는다.
- 준비되지 않았거나 평가 자료가 없는 범위를 분모에서 지워 완료율을 높이지 않는다. 아직 모르는 범위 수를 확정값으로 꾸미지 않는다.
- 자료 부족·조회/저장 실패·평가 미확인을 회상 실패·0점·완료로 대체하지 않는다.
- 이전 카드별 인지/인출/기억 유지 지표를 새 목표의 상태로 자동 복사하지 않는다.
- 현재 화면안은 예시 자료이며 실제 원본 추출·API/DB 저장·제품 검사 통과의 증거가 아니다.
- 서버/웹의 구체 API·DB·추천/평가/저장 책임과 실패·재시도·중복·복원·권한은 P07에서 정리한 뒤 구현 계획으로 연결한다.
- UI 예시의 약물·문항·수치와 임의 숙련도를 의학적 검수 결과나 실제 기억 확률/시험 점수로 표현하지 않는다.

## S10. 수용 시나리오

| 상황 | 기대되는 관찰 결과 |
|---|---|
| 전체 범위를 처음 봄 | 강의별 빈 곳·중요 미학습을 찾고 추천을 바로 시작할 수 있음 |
| 틀렸지만 시도하고 답을 확인함 | 첫 학습 진전은 남고 현재 회상 부족은 구분되며 다음 범위로 진행 가능 |
| 같은 목표를 여러 방향/문제로 공부함 | 목표 범위는 한 번만 세고 방향별 상태는 따로 보임 |
| 방향이 미정·준비 전임 | 회상 가능으로 자동 통과하지 않고 준비 상태가 남음 |
| 가지를 접음 | 중요한 미학습이 사라지거나 범위가 줄지 않음 |
| 지도에 들렀다 복귀함 | 현재 질문·정답 확인·평가 단계가 유지되고 탐색만으로 학습 기록이 생기지 않음 |
| 자기평가를 선택함 | 추가 확인 없이 다음 질문·새 위치와 직전 상태의 짧은 변화가 보임 |
| 오늘 추천을 마침 | 오늘의 범위/회상 변화·중요 잔여를 보고 오늘은 여기까지로 종료 가능 |
| 추천을 못 마침 | 다음 날 남은 범위로 재계획하고 중요한 잔여는 계속 보임 |
| 필기가 늦게 도착함 | 해당 강의와 추천을 보정하되 과거 기록을 일괄 초기화하거나 새 내용을 완료로 만들지 않음 |
| 자료·평가·저장 정보가 부족함 | 불확실성이 표시되고 앎이나 완료로 꾸며지지 않음 |

이 표는 앞으로 검증할 수용 기준이다. 실제 자동 검사 결과가 아니다.

## S11. 블록 시작 교수 변경과 출제 스타일

2026-11-02 사용자 추가 요구: 블록 시작 시 담당 교수가 바뀐 강의를 알려주고 교수별 기출을 보고 출제 스타일을 안내한다.
블록 현황에서 올해 담당 변화와 준비 방향을 먼저 이해하고, 필요한 강의·교수의 근거 기출로 이어지는 역할이다.
기존 S7의 교수별 중요도 원칙과 연결하며, 과거 기출 관찰과 올해의 명시된 출제 예고·강조를 구별한다.

- 변경 강의에는 비교 연도·이전/올해 담당과 근거를 확인할 수 있어야 한다.
- 교수별 출제 스타일은 실제 기출 사례와 분석 범위를 바탕으로 설명하고 자료 부족·공동 담당·미상을 구별한다.
- 블록 시작에는 시간표만 있고 올해 필기가 늦게 들어올 수 있다는 기존 여정을 반영한다. 필기 전 잠정 안내와 이후 담당 재확인 방식은 설계 제안이다.
- 강의별 지도·범위와 기존 문항·첨부·학습 기록을 유지한다. 이 요구만으로 교수 유형·추천량·문항 순서를 자동 변경하지 않는다.

요구의 채택과 세부안 승인은 구별한다. 직전 학년도 비교·첫 진입 요약·스타일 분석 항목·검토/공개·갱신 방식은
[기능 Spec 초안](../2026-11-02-block-professor-briefing/spec.md)과 [P10](open-design.md#p10-블록-시작-교수-변경과-출제-스타일)에서 검토한다.
변경 파일·검사·복원은 [기능 Implementation Plan](../2026-11-02-block-professor-briefing/plan.md)에 분리했다. 현재는 문서화 단계다.
