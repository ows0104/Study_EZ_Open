# 강의 패널 개념 지도 버튼·지도 좌측 상단 뒤로 — 설계

## 요구사항과 수용 기준
- `links.ts` `mapHref(lecture)` = `bankHref(lecture)?map=1`.
- `EventPanel` 복습 줄 trailing: 복습 퀴즈 + 개념 지도(보조 버튼, 복습 퀴즈보다 가볍게).
- `RootLearning`: `?map=1`이면 첫 개요를 받은 뒤 기존 `showMap()`을 한 번 호출한다. 이 진입에서는 뒤로가 `leave()`(같은 탭 기록 뒤로, 없으면 캘린더).
- `RootMap`: 뒤로 버튼을 도구 줄에서 빼 지도 틀 좌측 상단에 둔다. `backTo='back'`이면 글자 「뒤로」, 기존 'question'/'today'는 「문제」/「오늘」과 기존 aria-label 유지.

## 책임·입출력 계약·오류 상태
- 서버 API·요청 형식 변경 없음. 지도 읽기는 기존 `showMap()` 경로(세션이 있으면 세션 지도, 없으면 강의 지도)를 그대로 쓴다.
- 지도 읽기 실패 시 기존처럼 오류를 보이고 시작 화면으로 돌아간다.

## 호환성과 데이터 보존
- 학습 기록·세션·DB 변경 없음. 진행 중 회차가 있으면 기존 「지도」와 같이 그 회차의 지도로 열린다(mapSeen 표시 동작 동일).
