실제 입력은 input.json이다. 위 사각형 예시는 출력 구조 예시이며 실제 대상은 「$title」이다. input.json의 scope를 지키고, material/*.md 전체와 모든 material/*.png의 표·그림·필기를 확인해 실제 강의 전체 결과를 작성한다. title은 $title로 적는다. ID는 $first_id부터 부여한다.
실행 환경의 전달 방법: request.md의 실제 JSON 파일 작성 요구를 수행한다. 다운로드 링크 대신 마지막 응답은 파일 영수증만 반환한다. 내용은 지정 JSON 파일에 모두 담고 마지막 응답에서 반복하지 않는다. acceptance.schema.json은 파일의 형식 계약이다. 다른 결과·은행·브라우저·네트워크·추가 모델에 접근하지 않고 제공한 자료만 사용한다. 입력·원본·프롬프트·스키마는 보존한다. 최종 응답은 {"path":"$filename","sha256":"실제 UTF-8 파일의 소문자 SHA256"}만 반환한다.
