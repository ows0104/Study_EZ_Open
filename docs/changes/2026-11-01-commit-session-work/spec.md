# Spec

기존 수정·삭제와 필요한 새 소스·테스트·프롬프트·가이드를 함께 반영한다. 코드 간 의존성을 보존하고 작업 성격별 커밋으로 정리한다.
PDF·이미지·학생 데이터·실행 캐시·개인 작업 폴더·비밀 설정은 로컬 보존한다. docs/changes의 생성 자료와 운영 스냅샷은 제외하고 코드/정책/검토 문서는 선택한다.
실제 루트 테스트, 서버 파일별 독립 테스트, 웹 타입/빌드와 관련 Node 검사를 실행한다. 스테이징 파일의 비밀 패턴·대용량·충돌 표시·누락 의존성을 검사한다. 원격 현황을 fetch 후 비교하여 비파괴 방식으로 푸시하고 원격 커밋 일치를 확인한다.
