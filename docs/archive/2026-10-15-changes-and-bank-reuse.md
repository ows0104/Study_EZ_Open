## 재사용 판단

**사용자 정정(2026-10-15):** 약력학(2), 약물대사, 콜린성 약리학(1), 중추신경계
약리 기초·질환 약리 5강의는 구식 프롬프트로만 출제한 상태였다. 이 5강의에 대한
아래의 국소 수정 우선 권고는 철회한다. 최신 프롬프트로 웹에서 처음부터 출제한 뒤
CLI 후처리·검수 결과를 기준으로 판단해야 한다. 옛 은행의 wrong 수치는 과거 상태
기록이며 최신 출제의 품질 근거가 아니다. 새 결과가 완료되기 전에는 해결 여부를 단정하지 않는다.

점검 당시 24강의 2,073문항이 있었으며, 위 5강의는 최신 웹 재출제 대상으로 정정했다.
나머지 강의는 기존 은행을 유지하면서 개별 검토·수정 필요성을 확인한다.
13강의는 원래 프롬프트가 1.10~1.29이고 나머지는 1.53~1.54다. 프롬프트 버전은
저장된 응답의 버전이며, 현재 게시 은행이 그 응답의 가장 최근 처리 결과라는 뜻은 아니다.
예를 들어 약력학(1)은 새 처리 111문항이 실패했지만 기존 63문항은 계속 게시되어 있다.

24개 현재 은행 모두 JSON 3.2 구조 검증을 통과하고 게시 가능한 상태다. 오늘 원본
868쪽을 대조한 중요도 후처리가 현재 은행 hash와 모두 일치한다. 현재 분포는
Core 617 / Important 965 / Optional 491, 별도 심화 113문항이다. 후처리는 문항·정답·
ID·build ID와 의학 판정을 보존했다. **중요도 재분류 성공을 내용 오류 수정·누락 보완
완료로 해석하면 안 된다.**

점검은 자동 구조 검사와 저장된 CLI 검수 기록을 대조한 것이다. 이 문서의 작성 에이전트가
의학 내용을 새로 판정한 결과가 아니다. 새 프롬프트와 완전히 같은 문항 설계가 되었다는
보장도 없다. 원본·응답이 손실되거나 잘못된 강의/판본을 전제로 만들어 국소 복구가
불가능한 사례는 이번 조사에서 확인하지 못했다. 다만 이것만으로 최신 웹 재출제의 필요성을
부정할 수는 없다. 위 5강의는 사용자 정정에 따라 최신 웹 생성부터 다시 평가한다.
