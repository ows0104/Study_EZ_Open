# Main-Quiz 참고슬라이드 복구·트리형 개념지도 — 설계

## 요구사항과 수용 기준
- 참고슬라이드: `pdfSlides[].url`을 R2 서명 URL 대신 API 경유 주소로 준다. PDF.js는 로그인 토큰을 헤더로 실어 이 주소를 읽고, 서버는 Range 요청이면 206과 해당 바이트만, 아니면 전체를 흘려 보낸다. 실패 시 기존 "원본 열기"(서명 URL, `<a>`는 CORS 무관)로 대체할 수 있다.
- 개념지도: 강의(뿌리) → 주제 → 문항 3단 트리를 좌→우로 배치한다. 기본 시야는 주제까지, 확대(배율 임계) 또는 주제 클릭으로 해당 문항이 펼쳐진다. 휠·핀치·끌기·＋/－/전체 버튼·키(0 전체, Esc 닫기)를 지원한다. 노드 클릭 시 옆 패널: 주제는 하위 문항 목록·상태, 문항은 질문·쪽·학습 상태·중요도 근거·"답 보기"(접힘). 검색은 주제/질문 텍스트로 찾아 이동한다. 현재 문제 노드와 그 주제를 처음부터 강조·중심에 둔다. 상태 색(미학습/학습 중/회상 가능/준비 전)은 기존 계산을 그대로 쓴다. 모바일 폭에서는 패널이 아래에서 올라온다.
- 주제 개념이 없는 판(다른 강의)도 깨지지 않는다: 연결 없는 개념은 "기타" 주제로 모으고, 기존 자료 범위·출제포인트 접기는 유지한다.

## 책임·입출력 계약·오류 상태
- 새 읽기 전용 API: `GET /api/root-learning/sessions/{session_id}/sources/{source_id}` — 본인 세션이고 활성 판이며(`checked_session`), 출처가 판의 review.sources와 생성 보존본에서 SHA가 일치하는 PDF일 때만. 아니면 404. `Range: bytes=a-b` 지원(206, Content-Range, Accept-Ranges), 잘못된 범위 416. `Cache-Control: private, max-age=3600`. 쓰기·사건 기록 없음.
- `evidence.attach_evidence`의 pdfSlides url만 경유 주소로 바뀐다. sourceLinks(원본 열기)는 서명 URL 그대로.
- `storage`에 범위 읽기(`open_stream`에 선택적 byte range) 추가. 로컬 저장소도 같은 동작.
- 지도 API 응답 형식은 바꾸지 않는다(트리는 웹에서 targets·concepts로 구성). 지도 열람 사건(mapSeen/helped) 의미 그대로.

## 호환성과 데이터 보존
문항·정답·검수·은행·학습 사건·공개 범위·DB 스키마를 바꾸지 않는다. 새 표·칼럼 없음. 기존 Quiz Bank 슬라이드(`slides`, 이미지)는 그대로. 답 공개 경계 유지: 슬라이드 주소는 답 공개 응답에만 실리며, 경유 API는 세션 소유자만 읽는다(서명 URL을 이미 받던 사용자와 같은 범위).
