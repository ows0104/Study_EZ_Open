## 6. 파일 저장과 전달

실제 UTF-8 JSON 파일 `study-ez-{{run_id}}-bank.json` 하나를 작성한다. 최상위 subject는 "{{subject}}", run_id는 "{{run_id}}", prompt_version은 "{{prompt_version}}"이다.

파일에는 확정된 전체 문항·선지·정답·해설·근거·출처 충돌을 저장한다. 여러 번 나눠 기록해도 되지만 저장 중 새 문항을 생성하거나 확정된 ID·정답·보기를 바꾸지 않는다. 파일 길이 때문에 범위나 필요한 내용을 생략하지 않는다.

저장한 파일을 도구로 다시 읽고 JSON 파싱, 과목·강의·판·요청 ID, 실제 문항 수와 ID 목록의 순서·누락·중복, 필수 필드·형식별 정답·보기 참조·cloze 빈칸·근거·충돌 정의와 참조를 확인한다. 오류가 있으면 수정 후 다시 읽는다. 전체 확인이 끝난 완성 파일에만 "complete": true를 기록한다.

파일을 만들 수 없으면 생성 불가를 알리고 완료로 처리하지 않는다. 검증 완료 후 채팅에는 전체 문항 수와 실제 .json 다운로드 링크만 짧게 제공한다.
