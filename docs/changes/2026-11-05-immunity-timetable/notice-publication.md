# 시간표 변경 공지 게시

Intent: 사용자의 후속 요청 “공지사항에도 써줄래?”에 따라 완료한 시간표 변경을 공지한다.
Spec: notice.json의 제목·본문을 기존 공지사항에 새 글 1개로 게시한다. 수정 일정 12개와 담당 변경, 기존 자료·링크·학습 기록 유지 사실을 안내한다.
Implementation Plan: 기존 공지 중복 확인 → 실제 반영 시간표와 본문 대조 → NoticeIn 입력 검증 → 중복 없는 새 공지 저장 → 새 DB 세션에서 공지 조회 경로의 목록에 존재하는지 확인.
Authorization: 현재 사용자의 직접 게시 요청을 이 공지 1개의 작성·게시 승인으로 적용한다.
Review: 기존 일반 텍스트 공지 형식에 맞췄으며 내부 ID·운영 구조·개인 정보는 싣지 않는다. 고정 여부는 기본값(False), 기존 공지는 수정/삭제하지 않는다.
본 작업은 기존 공지 기능으로 운영 안내문을 게시하는 후속 작업이며 앱 기능/코드 변경·재배포는 없다.
결과는 notice-receipt.json에 기록한다.
