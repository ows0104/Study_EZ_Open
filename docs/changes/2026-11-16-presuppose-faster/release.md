## 로컬 시범 (콜레라 편 공개판 de7da04c 재보강, 운영 쓰기 없음)

출력은 `C:\sez\pre7`에만 썼다. 기준은 같은 꾸러미로 돌린 2차 시범(`C:\sez\pre6`, 단계 줄이기 전)이다.

| | 2차(줄이기 전) | 3차(줄이기 후) |
|---|---|---|
| 보강에 걸린 시간 | 약 27분 30초 | **18분 24초** (13:06:06 → 13:24:30) |
| add 라운드 | 2 | 1 |
| 범위 확인·지도 점검 | 차례로(10:16:35 → 10:18:56) | 동시에(13:12:12 · 13:12:47) |
| 새 문항 | 23 | 24 |
| 존재 목표 | 23 | 24 |
| 끝까지 아무 문항도 답하지 않은 전제 | 3 | 2 |
| 과제가 되지 못한 새 문항 | 2 | 1 (Q240, 검토가 관계를 안 적음) |

- 한 편에 약 9분이 줄었다. 줄인 단계는 add 둘째 라운드(약 3분)와 지도 점검 대기(약 2분)이고, 나머지는 호출마다의 응답 시간 차이다.
- 문항은 줄지 않았다. 「P. aeruginosa의 주요 조직 손상 효소는? (4가지)」가 그대로 나왔고, 목표도 하나 더 생겼다.
- 검토 → 수정은 2라운드까지 그대로 돈다(FIX_LIMIT). 줄이지 않았다.
- 동시 4편은 이 시범으로 확인한 것이 아니다. 27편을 돌릴 때 실제로 재야 한다(추정 약 3.5시간).
