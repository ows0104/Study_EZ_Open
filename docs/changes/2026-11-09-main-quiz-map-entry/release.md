## 코드 리뷰·검증 결과

### 변경
- `RootLearning.tsx`
  - 「개념 지도」를 누르면 지도 탭을 먼저 고른다. 시작 화면이면 세션은 밑에서 열고, 문제 화면은 그리지 않는다.
  - 지도가 오기 전에는 「개념 지도를 불러오는 중…」 한 줄만 보인다. 실패하면 이전 화면으로 돌아간다.
  - 지도 위 「← 문제로 돌아가기」 줄은 없앴다.
- `RootMap.tsx`
  - 도구 줄 첫 버튼으로 「← 문제」(이름 「문제로 돌아가기」)를 넣었다.
  - 틀 아래 여백을 0으로 했고, 쓰지 않던 `position` prop을 없앴다.
- `main-quiz.css`
  - 지도 화면에서는 앱 본문 여백(28·36·40px)과 Main-Quiz 1100px 폭 제한을 없앤다.
  - 틀 테두리와 둥근 모서리를 없앴다. 크게 보기는 창 전체(inset 0)다.
- 회귀 검사 페이지
  - 사이트와 같은 앱 틀(좌측 메뉴 + `.app-main`)에서 그린다. #52까지는 앱 틀이 없어 1100px 제한을 못 잡았다.
  - 네 변 여백 0과 「시작 화면 → 지도에서 문제 문장이 한 번도 안 보임」을 단언한다. 옛 `RootLearning`으로 돌리면 이 단언이 실패하는 것을 확인했다.
