# 분류·나열 역할과 연결 회상 검토 기준 — 배포 준비

## 코드 리뷰·검증 결과
document-review 통과: 10묶음 행 수, 구분 기준, 문서 링크, 기존 CLI 원문 SHA256 보존 확인. 역할 표를 검토했으며 의학 내용이나 학습 효과를 검증한 것은 아니다.

## 배포 대상 버전·순서·데이터 변경
로컬 설계 문서와 mapping-review 안내만 반영. 운영 배포·은행·학습 기록·DB·JSON 계약 변경 없음. revision-bound 검사 근거는 state.json에 기록한다.

## 배포 후 확인·롤백·필요한 사람 승인
현재 사용자 반영 요청 범위의 로컬 문서 작업 완료. 운영 배포는 실행하지 않는다. 복원 시 이번 추가 문서·단락만 되돌리고 다른 변경과 기존 원문을 보존한다.
