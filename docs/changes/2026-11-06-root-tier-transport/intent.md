# 기존 Must-Know 등급 별칭의 Native 전송 복구

## 문제와 사용자 효과
승인된 E2E 완료 작성 복구 중 심내막염 마지막 보완이 완료됐으나 tier=Must-Know 하나가 BANK의 Essential 이름과 달라 전송 수용이 실패했다. 같은 의미의 대응은 이미 authored_json.to_bank에 있다. 해당 정본 대응만 재사용해 새 모델 호출 없이 실제 완료 파일을 회수하고 원본/독립 정답검수·풀이를 이어간다.

## 범위와 성공 기준
문항·정답·선지·근거·중요도 수치·보완3회 소비는 변경하지 않는다. 실제 provider 파일과 SHA 영수증·완료 사용량·보호 입력/원본을 검증하고 원본 JSON과 별칭 정규화의 차이를 명시 증명한다. 기존 실패와 이전 복구 증명·실행 지문을 보존한다. 알 수 없는 등급·불명확/중단/거절 호출은 수용하지 않는다.

## 근거·미정 사항
현재 사용자 “복구 경로까지 수정해 이어가기” 승인과 동일 두강의 E2E/자료 전송·최대3회 보완 승인에 적용하는 기술 형식 복구다. 새로운 내용 판단·등급 재평가·추가 보완 호출이 아니다. 실행 중 CNS의 후보 de1fcf73는 바꾸지 않도록 별도 worktree에 기존 승인 복구 의존성만 cherry-pick했다. 운영/548/기존학습 데이터 변경은 없다.
