# UI/UX 개편: 좌측 메뉴·흰색 바탕·캘린더 — 설계

정본 화면은 프로토타입 `web/src/redesign-prototype/`(2026-11-06 사용자 확정, intent.md의 지시 이력)다.
이 문서는 그 화면을 운영 웹에 옮길 때의 계약과 수용 기준이다. 화면에 설명 문장을 넣지 않는다(사용자 지시).

## 요구사항과 수용 기준

### 1. 앱 틀
- 상단 `app-bar`를 없애고 좌측 메뉴로 바꾼다. 순서: 브랜드·접기 / 학습(캘린더 `/`, 강의 목록 `/study`, 2단계에 자유 노트 `/notes`) /
  커뮤니티(공지사항 `/notices`) / 하단(이용방법 `/guide`, 문의하기 = 기존 피드백, 관리자만 관리 `/admin`) / 프로필(이메일·이름, 메뉴: 설정·로그아웃).
- 아직 없는 화면(통합 퀴즈·오류 토의·진탐 공유·결제)은 메뉴에 넣지 않는다. 검색 없음.
- 접으면 아이콘만, 상태는 localStorage. 900px 미만은 자동으로 접힌 아이콘 줄, 휴대폰(≤640px)은 상단 얇은 줄 + 펼침 서랍.
- 풀이 화면(`/lectures`, `/prequiz`, `/mainquiz`, `/bank`, `/legacy-mainquiz`)의 bare 모드와 `StudyNav`는 유지한다(좌측 메뉴 없이 풀이에 집중).
- 공지 새 글 점, 관리자 판정(`me.isAdmin`), 승인 대기·로그인·개인정보 화면 흐름은 그대로.

### 2. 색과 토큰
- 흰 바탕, 회색 단계(프로토타입 `--side/--hover/--active/--fill/--line/--line-strong/--chip-line/--ink-2/--ink-3` 값).
- 강조색 다섯 조합(인디고+앰버 기본, 블루+민트, 클레이+슬레이트 블루, 토마토+바이올렛, 그린+머스터드)을 사용자가 고른다.
  역할: 메인 = 지금·복습·주요 선택, 두 번째 = 예습. 시험·D-day·신규 교수 N = 빨강 `--exam`.
- 이 역할은 2026-08-31 관리자 지시의 갈래 색(`--fam-*`: 예습 violet · Pre-Quiz teal · Main-Quiz indigo, "바꾸지 않는다")을
  대체한다. 2026-11-06 사용자 결정으로 대체한다(plan 결정 1).
- 다크 모드(`prefers-color-scheme`)는 새 토큰의 어두운 값으로 유지한다.

### 3. 캘린더(`/`)
- 머리: 「YYYY년 M월」 + 「블럭 n주차 · 기간」, 오른쪽에 다음 시험 D-day(옅은 바탕, 숫자만 빨강).
- 「오늘」 줄: 「미열람 예습 n강의」(오늘 날짜의 강의·실습 중 예습 퀴즈 미완료), 「미열람 복습 퀴즈 n문제」(이번 블럭 오늘 복습 대기 합),
  오른쪽 끝에 오늘·‹ ›·주/월. URL 상태(`view`, `date`, `event`)는 유지한다.
- 회독·학습률은 항상 표시, 토글 없음. 첫 화면 요청(`/api/me`, `/api/timetable?include_study=false`)은 그대로 두고,
  첫 그림 뒤 학습 정보를 자동으로 이어 받는다(실패 시 기존 「학습률 조회 실패 · 다시 시도」).
- 칸: 강의·실습·TBL·CBL은 같은 모양(흰 바탕, 진한 테두리). 시험 = 빨강, 임상의학입문처럼 같은 시간의 다른 과목은 점선.
  제목 앞 번호는 흐린 회색. 아래 줄 「교수 + 변경 표시 · 분야」(날짜·시각 없음).
- 교수 변경 표시는 `previewSource`로 계산: 작년과 같음 = 없음, `selected.match='same'`이고 작년이 아니면 두 자리 연도(흐린 회색),
  `newProfessor=true` = 빨간 N. `needs_review`는 표시하지 않는다(상세 정보는 기존 `title`/툴팁 유지).
- 학습 표시: 위 = 회독 점선(예습 퀴즈 완료 토막 1개 + 강의록 회독 토막), 아래 = 복습 학습률 막대(0%도 바탕이 보이고 덜 채울수록 진함,
  아직 복습이 열리지 않으면 회색 바탕). 예습 학습률 막대는 없앤다.
- 범례: 강의·실습·TBL·CBL / 시험 / 다른 과목 / 예습 퀴즈 / 강의록 회독 / 복습 학습률.

### 4. 갈래·번호(웹에서 계산, DB 불변)
- 갈래: 시간표 `category` + 제목·세부로 표시 갈래를 정한다. 제목에 TBL → TBL, CBL → CBL, 세부가 「<동영상 강의 시청>」 → TBL 영상
  (같은 주제의 TBL 번호를 붙임: 「TBL n 영상」), 그 밖 lecture → 강의, practice → 실습, exam → 시험.
- 번호: 블럭 안에서 갈래별로 날짜·시작 순서대로 1부터. 강의는 영상을 뺀 뒤 빈칸 없이 센다. 블럭이 나뉘면 블럭마다 1부터.
- 블럭: 감염과 면역만 1차 시험에서 「감염과 면역 1차」·「2차」로 나눈다(2026-11-06 사용자 결정 4). 일반 규칙(중간시험 뒤 수업이 남으면 끝내지 않음)은 그대로.

### 5. 강의 상세 패널
- 머리: 번호 태그(강의 n), 블럭 이름, 닫기. 제목. 「교수 이름 + 변경 표시」만(일시·분야 없음).
- 예습: 「공통 대화」(기존 기본 링크), 「개인 대화」(기존 개인 링크), 「예습 퀴즈」. 복습: 「개인 대화」(기존 복습 개인 링크), 「복습 퀴즈 n」(Quiz Bank 공부하기).
  짧은 버튼, 예습·복습 퀴즈 버튼은 같은 모양(옅은 제 색 바탕·제 색 테두리·굵은 글자). 링크가 없으면 기존처럼 만들기 흐름으로.
- 통계: 회독(예습 퀴즈 완료면 맨 앞 토막, 강의록 회독 토막, + 추가, 토막을 누르면 삭제 + 4초 「되돌리기」), 학습률(25% 구간 색 숫자 + 막대),
  카드(미열람·인지·인출·저장 범례·막대).
- 맨 아래 작게 「덱 다운로드 예습 · 복습」(pre_apkg·main_apkg), 오류 토의·제보(기존 피드백).
- 빼는 것: 강의록·족보 행, 「기존 Main-Quiz 자료」, 「내 강의 학습도」, 사실 목록, 「강의 화면 전체 보기」 링크.
  관리자 도구(덱 작업, 문제은행 링크, Main-Quiz 관리, 뿌리 생성 패널, 카드 수정 링크, 블럭 덱 받기, 링크 만들기 관리자 버튼)는
  「관리자」 접힘 묶음으로 그대로 둔다.
- Esc 닫기·포커스 복귀·휴대폰 하단 시트·지연 로딩(`EventPanel` lazy)·확장 링크 수신(`useBankLink`, `usePreviewLink`)을 유지한다.

### 6. 강의 목록(`/study`, 학습 현황 + 모아풀기)
- 제목 「강의 목록」, 소제목 블럭·기간, 오른쪽 위 블럭 선택(이번 블럭 기본·다음 블럭 표시, 기본 블럭 선택 규칙은 `studyBlocks.ts` 그대로).
- 통계 3칸(오늘 복습 보라 #6e62d9, 학습률 평균, 전체 카드) + 카드 단계 카드(범례·막대, 복습이 열린 강의만 집계, 설명 문구 없음).
- 표: 강의 / 실습 / TBL·CBL 묶음(주차 구분·필터·검색·정렬 없음). 칸: 선택, 번호, 강의(제목 + 「교수 · 분야」),
  전체·미열람·인지·인출·저장(굵게, 단계 색)·복습(보라)·학습률(25% 구간 색). 퀴즈 없는 행은 「퀴즈 없음」, 복습 전 행은 회색 숫자.
- 체크하면 아래 떠 있는 막대 「n개 강의 선택 · 오늘 복습 n장 · 선택 해제 · 모아풀기」 → 기존 `BankBatch` 흐름.
- 단계 색: 미열람 #f07167/#ef5f55, 인지 #f6b54d/#f29b1d, 인출 #5aa9e6/#3d9be9, 저장 #34a77f/#1fae7a(막대/글자).
  「기억 유지」는 「저장」으로 이름을 바꾼다(정의는 그대로).
- 기존 기능 보존: 숨기기·복원, 관리자 퀴즈 삭제·관리 묶음, 약리학 퀴즈 준비 현황 칸, 「시험까지 · 오늘의 목표」(StudyPlanBoard),
  뿌리 학습 개요(`RootOverviewPanel`)는 표 아래 「더 보기」 접힘 영역으로 옮긴다(동작 불변).

### 7. 설정(`/settings`)
- 프로필 메뉴에서 연다. 색 조합 다섯 개 중 선택(즉시 반영, localStorage `studyez-accent`). 이름·이메일 표시.

### 8. 자유 노트(`/notes`) — 2단계(plan 결정 2)
- 노트 목록 + 블록 편집기(프로토타입 `notes.tsx`): 줄머리·글 안 md, `/` 메뉴, 서식 막대(글자색 10·배경색 10), 블록 손잡이(추가·이동·삭제·복제·전환), 할 일.
- 서버 저장(새 표·API)과 함께 2단계에서 연다.

### 9. 회독 기록 — 강의록 회독은 2단계(plan 결정 2)
- 예습 퀴즈 완료 = 기존 `prequizProgress.answered >= total`(또는 상세의 `prequiz.answered >= itemCount`). 새 저장 없음.
- 강의록 회독(자가 기록)은 새 서버 저장이 필요하다: 사용자·강의(subject, run_id)별 기록 행(생성 시각), 추가·삭제 API.
  학생 응답에는 자기 기록만. 기존 학습 기록과 별개라 학습률·SRS에 넣지 않는다.

### 10. 이용방법
- `GuidePage.tsx`의 버튼·화면 이름(학습 현황→강의 목록, 학습률 보기 제거, 기억 유지→저장, 패널 구성, 좌측 메뉴, 피드백 위치 등)을 새 화면에 맞춘다.

## 책임·입출력 계약·오류 상태
- web만 바꾸는 범위(1–7, 10)는 기존 API·응답 형식을 그대로 쓴다. 서버·러너·확장 계약 변경 없음.
- 강의 목록·「오늘」 줄의 카드 수는 기존 `POST /api/timetable/study-progress`(8강의씩)로 받는다. 실패는 기존 오류 표시·다시 시도.
- 회독(9)·노트(8)를 서버에 두면 새 표와 라우트(`/api/me/note-reads`, `/api/me/notes`)를 추가하고, 표는 API 배포 전에 만들며 RLS를 켠다.
  `tests/test_route_contract.py`에 등록한다.
- 출제(quizbank, quizgen, content/prompts, studyez_contracts/roots, runner)는 건드리지 않는다.

## 호환성과 데이터 보존
- 기존 문제·ID·학습 기록·숨긴 강의·개인 링크·프롬프트·교수 변경 메타데이터를 그대로 쓴다. 갈래·번호·블럭 분리는 표시 계산이며 DB를 바꾸지 않는다.
- 「기억 유지」→「저장」은 표시 이름만 바꾼다. 서버 필드(`retained`) 불변.
- 풀이 화면 경로·URL 상태·확장 연동(링크 저장 이벤트) 유지. 기존 경로 `/mastery` → `/study` 리다이렉트 유지.
- 프로토타입 폴더는 운영 빌드 입력이 아니지만 `tsc` 대상이다. 운영 적용 후에도 비교용으로 남기거나 별도 결정으로 지운다.
