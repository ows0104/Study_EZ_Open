# 콜린성 예시 핵심 보완 1회 예외 — 설계

## 요구사항과 수용 기준
이전 3차 결과와 원래 실행/자료/검수/상한은 불변이다. 새 예시 폴더에 이전 결과 hash와 예외 승인 범위를 고정한다. 내용 교정은 별도 Codex CLI 1회뿐이며 이후 원본 대조 1회, 도구 없는 독립 정답 검수 1회, 최종 의미 대조 1회로 끝낸다. 실패도 호출을 소비한다. 부모 에이전트는 의학 내용이나 판정을 직접 작성하지 않는다.

기존 문항을 우선 사용한다. 직접 교정 ID는 Q077/Q101/Q142/Q092/Q109/Q130/Q066, 필요한 일관성 점검은 Q118/Q136까지 허용한다. Q130/Q066는 선행 조건만 수정한다. D10와 R35만 비교 목표 재정의가 가능하며 전후 의미 및 비동등성을 기록한다. D21/D61의 기존 전체 목표를 축소해 누락을 숨기지 않는다. 원본 그림 교체는 실제 원본 crop과 정답의 방향 일치까지 검증한다. 다른 목표·포인트·원문·제외 기록은 그대로 둔다.

새 원본·정답 판정과 최종 의미 검토에서 보류된 방향은 화면의 준비 수에 포함하지 않는다. 불확실성을 숨기거나 의심 0을 완료 기준으로 삼지 않는다. 운영 DB/게시/배포/학습 기록 쓰기와 ChatGPT 직접 접속은 없다.

## 책임·입출력 계약·오류 상태
새 실행기는 기존 delta와 source-assessment/1, BANK 및 roots 계약을 사용한다. 실패는 ledger에 보존하고 자동 재호출하지 않는다. 임상 판정은 별도 내용 모델의 출력만 채택한다.

## 호환성과 데이터 보존
이전 예시 폴더 전체와 원본 생성 ledger를 보존한다. 의미가 달라진 D10은 동등한 숙련도 승계를 금지한다. 새 결과는 읽기 전용이며 운영 호환 구조를 검증해도 운영 준비 완료를 뜻하지 않는다.
