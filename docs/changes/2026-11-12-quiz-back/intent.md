# 퀴즈 풀이 중 뒤로가기

## 문제와 사용자 효과

사용자(2026-11-12): 「복습퀴즈나 예습퀴즈를 풀다가 중간에 나갈 수가 없어. 홈 버튼으로 나갈 수 있긴 한데 너무 불편해.
퀴즈 도중에 뒤로가기 버튼을 추가해서 이 첫 페이지로 나갈 수 있게 해줘.」

Main-Quiz는 「더 보기」 메뉴 안의 「오늘 현황 보기」로만 시작 화면에 돌아갈 수 있었다. Pre-Quiz는 풀이 중 나가는 버튼이 없었다.

## 범위와 성공 기준

- Main-Quiz 풀이 머리줄 맨 왼쪽 「뒤로」 → 시작 화면(오늘 현황). 기존 `onToday`와 같은 동작.
- Pre-Quiz 머리줄 맨 왼쪽 「뒤로」 → 들어온 화면(앱 안 기록이 있으면 history back, 없으면 홈 `/`).
- 기록·서버·DB는 바꾸지 않는다. Main-Quiz는 평가마다 이벤트를, Pre-Quiz는 「이해 확인」마다 `/check`를 이미 저장한다.
