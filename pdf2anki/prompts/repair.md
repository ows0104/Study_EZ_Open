# 과제 — 재현되지 않은 카드를 고친다

아래 카드들은 **질문만 보고 다시 풀었을 때 원래 답이 나오지 않았다.** 카드 결함이다.
`{raw}` 안의 해당 카드를 고쳐라. 다른 카드는 건드리지 마라.

## 무엇이 문제인가

| 이유 | 뜻 | 고치는 방향 |
|---|---|---|
| `question_ambiguous` | 무엇을 묻는지 좁혀지지 않는다 | 묻는 대상을 질문 안에서 특정한다 |
| `needs_options` | 선지가 있어야만 답이 정해진다 | 기전을 묻거나, 하나의 진술로 세워 O/X 로 바꾼다 |
| `answer_underspecified` | 답의 집합이 열려 있다 | 아래를 보라 |

## 열거형은 개수를 밝히는 것으로 부족하다

`answer_underspecified` 로 갈린 카드는 거의 다 "N가지는?" 형태다.
개수만 밝히면 외부 풀이자는 **다른 N개**를 댈 수 있다. 답의 집합을 닫아야 한다.

```
나쁨   Q. 중간엽 기원 양성종양 다섯 가지는?
       → 풀이자가 angioma, myxoma 를 댄다. 재현되지 않는다.

좋음   Q. 양성종양 명명 규칙을 근육·섬유모세포·연골·뼈·지방 기원에 각각 적용하면?
       → 기원을 질문이 지정하므로 답이 하나로 닫힌다.
```

기원·범주·축을 질문에 지정하거나, 아예 **변별형**으로 바꿔라 —
"A와 B를 가르는 기준은?", "이 조건에서 가장 확실한 것은?".

## 지켜야 할 것

- 회수 목표 자체를 버리지 마라. **묻는 방식만 바꾼다.**
- 답을 질문에 노출하지 마라. 고치다가 단서를 흘리면 그 카드는 무의미해진다.
- 시험 푸는 요령("선지를 먼저 지운다")은 답이 될 수 없다. 개념 진술로 바꿔라.
- 근거는 그대로여야 한다. `slide_no`·`evidence_type`·`jokbo_ref` 를 바꿔 달지 마라.
- 스키마를 지켜라. 키를 추가하거나 빼지 마라.

## 방법

`{raw}` 를 Read 하고, 해당 카드의 `q`(필요하면 `a`·`explanation`·`card_type`)만 고쳐
같은 경로에 Write 한다. 끝나면 무엇을 어떻게 고쳤는지 **한 줄씩만** 보고해라.
