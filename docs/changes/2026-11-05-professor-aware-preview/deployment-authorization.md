# 운영 반영 승인

2026-11-05 현재 채팅에서 사용자가 로컬 구현·검증 결과와 운영 미반영 상태를 확인한 뒤 “반영해줘.”라고 요청했다. 기존 승인 기준(최근 5년 동일 교수 최신 필기, 없으면 작년 필기와 신규 교수 태그)의 실제 운영 반영 승인으로 적용한다.

범위는 이 변경의 검사된 코드, `lecture.preview_source` nullable JSON 한 칼럼, 캘린더 교수 표시 및 예습 필기 선택/첨부 전환, 이전 자료·대화·학습 기록 보존, 필요한 일시정지/원상 재개와 사후 확인이다. 은행/문항 재작성·검수 상한 초기화·학습 기록 변경·비밀값/권한 변경은 포함하지 않는다.

[운영 적용 제안](operating-proposal.md)에 따라 운영 직전 연결/자료를 읽기 전용으로 대조하고 기존 강의 ID와 수동 예외를 보존한다. 실운영에 대응하지 않는 중복 로컬 파일은 새 강의로 자동 생성하지 않는다. 같은 승인 범위의 허락을 다시 요청하지 않는다.
