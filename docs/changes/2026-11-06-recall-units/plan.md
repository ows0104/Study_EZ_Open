최신 origin/master a3f67d13의 codex/recall-units에서 extract/author/source 추가 지시를 수정하고 bankPrompt1.82는 보존한다. recall_units.py와 generation_v2.py에 opt-in 스키마·명시 leaf 투영·부모 충족 집계·설계 검수를 연결한다. BankStem.tsx의 표/cloze 최소 확장과 관련 테스트를 추가하고 docs 전용 Main Quiz 비교 도구를 작성한다.

## 검사 명령과 성공 조건
recall-contract: 분할/부분/해설/제공/통합/설계·의학 판정·변조 방어. pipeline-regression: 기존 공용 계약·연결 생성·관련 서버. main-quiz-ui: 표/cloze·웹 타입. live-comparison: 실제 새 문항/검수·원본 보존·Main Quiz 비교 화면. 원본 세 문항과 관련 목표·페이지를 새 시범에 동결한 뒤 저작1회·별도 원본/설계·독립 의학 검수를 실행한다.

## 위험·복원·승인할 범위
현재 사용자가 제안 문안 구현·Main Quiz 기준 세 문항 재생성 비교를 명시 승인했다. 같은 승인을 재요청하지 않는다. 기존 강의/학습/실패/소비를 보존하며 운영배포·은행교체·기존 동일 ID 학습 승계 없음. 새 시범 결과는 별도 ID·호출 기록으로 제공한다.
