# StudyEZ 사이트 전체 학습 의도

상태: 사용자와 사이트 전체 intent의 방향을 합의함. 후속 여정·화면 설계 진행 중.
기록 기준: 2026-10-27 KST부터 이 채팅의 사용자 발언. 파이프라인 핵심 정리: 2026-11-01 KST.
현재 승인 범위: 사이트 전체 intent의 방향, 이를 바탕으로 한 학습자 여정·핵심 화면의 공동 설계.
구현·운영 변경 승인을 포함하지 않는다.

## 문제와 사용자 효과

**전체 시험 범위에서 공부한 곳·빈 곳·실제로 아는 곳을 한눈에 확인하고, 계획 부담 없이 추천 학습을
시작해 뼈대에서 세부로 범위를 넓히며, 회상과 복습으로 기억을 쌓고 그 변화를 느끼게 한다.**

의대 블럭 강의에서는 약 2~3주마다 시험을 준비해야 한다. 일부 내용을 완벽하게 익히는 동안
다른 강의나 개념을 한 번도 공부하지 못하는 일이 없어야 한다. 지엽적인 암기 내용도 시험에
나오므로 중요한 부분부터 시작하되 올해 시험 범위 전체를 최소 한 번 공부하는 것이 목표다.

StudyEZ는 사용자가 전체 범위에서 어디까지 공부했고 어디가 비어 있는지 한눈에 파악하고,
무엇을 공부할지 매번 직접 계획하지 않아도 오늘 추천 학습을 바로 시작할 수 있게 한다.
한 번 공부한 사실과 실제 회상·이해할 수 있는 상태를 구분하며, 뼈대를 잡고 가지를 탐험하면서
깊이를 늘리고 비교·양방향 회상·복습으로 연결과 기억을 보강한다.

사용자는 범위를 넓힌 진전과 실제로 알게 된 진전을 모두 알아볼 수 있어야 한다.
시험 준비를 이어가면서 공부의 재미·보람·효능감을 느끼는 것이 목표다.

## 파이프라인의 핵심

**문제로 회상하고, 출제 포인트로 누락을 검증하며, 개념트리로 강의의 흐름을 잡는다.**

필기·족보 → 세 결과물의 독립 작성 → 원본과 상호 대조 → 트리 기반 학습 → 학습 현황·추천 갱신.

1. **강의별 원본에서 세 결과물을 만든다.** 올해 필기와 족보를 읽고 문제, 출제 포인트·족보 경향,
   개념트리를 각각 만든다. 문제는 회상·판단을 연습할 수단, 포인트는 무엇을 시험하고 공부해야 하는지
   확인할 기준, 트리는 강의 전체 구조와 개념의 위치를 보여줄 지도다. 교수와 올해 자료의 근거를 구별한다.
   서로의 결과에서 범위를 역으로 정하지 않고 원본에서 작성한 뒤 대조한다.
2. **빠짐없이, 제대로 묻는지 검증한다.** 포인트마다 실제로 필요한 사실·관계·회상 방향을 묻는 문제가
   있는지, 정답·해설이 원본과 맞는지 확인한다. 포인트 목록 자체와 트리도 원본에 대조해 목록 밖 누락과
   범위 오류를 살핀다. 문제의 존재나 지도에 이름이 있다는 것만으로 충족했다고 보지 않는다.
3. **문제를 지도에 연결해 학습 흐름을 만든다.** 실제 학습 목표에 따라 개념을 묶고 관련이 있다는
   이유만으로 무조건 연결하지 않는다. 강의의 뿌리·큰 구조를 먼저 회상하고 가지의 세부 내용으로
   확장하며 비교·관계 회상·혼합 복습으로 깊이를 늘린다. 한 가지의 완벽한 숙련을 다음 진입 조건으로 삼지 않는다.
4. **학습 기록을 현황과 다음 추천으로 돌려준다.** 회상 시도·정답 확인·자기평가를 기록하고,
   한 번 공부한 범위와 회상 가능한 범위를 구분해 보여준다. 같은 목표의 여러 회상 방향은 전체 범위에
   중복 집계하지 않는다. 시험 일정·남은 범위·학습 기록·추가 자료에 맞춰 새 진도와 필요한 복습을 조정한다.

콘텐츠가 준비·검증됐다는 상태와 사용자가 공부·회상할 수 있다는 상태는 구분한다.
기존 문항·학습 기록을 보존하며 충분한 문항은 재사용한다. 현재 첫 적용 범위는 강의별 뿌리이고,
각 강의 지도는 독립적으로 구성한다. 웹·CLI 배치, 파일 전달과 복구, 저장 계약은 별도 설계·계획에서
구체화한다. 이 의도 정리는 제품 구현·운영 변경 승인을 포함하지 않는다.

## 범위와 성공 기준

### 1. 첫 화면의 최우선 역할: 현재 위치를 직관적으로 보여준다

사용자는 전체 시험 범위에서 어디까지 한 번 공부했고 어떤 강의·개념이 비어 있는지 먼저
파악할 수 있어야 한다. 한 번 본 것과 실제로 아는 것을 구분하고, 특히 중요한데 아직 못 본 곳을
눈에 띄게 보여준다. 그 현황에서 바로 오늘 추천 학습을 시작할 수 있어야 한다.
사용자는 현재 상황의 시각적·직관적 파악을 사이트의 가장 중요한 요구사항으로 제시했다.
구체적인 도형·색·수치·화면 배치는 아직 정하지 않는다.

### 2. 첫 학습과 실제 앎을 구분한다

질문을 보고 답을 떠올려 본 다음 정답까지 확인하면, 틀렸어도 일단 한 번 공부한 것으로 본다.
설명이나 슬라이드를 열어본 것만으로 이 기준을 충족했다고 처리하지 않는다.
첫 학습 기록과 실제 앎을 따로 보여준다.

| 질문의 성격 | 정답을 맞혔어도 관찰한 상태 | 해석 |
|---|---|---|
| 단답형을 객관식으로 낸 경우 | 선지 없이는 답을 떠올리지 못함 | 중간 단계 |
| 문장 OX를 적절한 것/적절하지 않은 것을 고르는 객관식으로 낸 경우 | 왜 맞거나 틀린지 설명하지 못함 | 필요한 이해·판단이 갖춰지지 않은 상태 |

정답 여부만으로 모든 문항의 앎을 동일하게 판단하지 않는다. 첫 학습으로 인정된 사실은
회상·판단이 부족하다는 이유로 지우지 않는다.

기본 학습은 머릿속으로 답이나 판단 이유를 떠올리고, 정답을 확인한 뒤 스스로 평가하는 방식이다.
매번 답이나 이유를 입력하도록 요구하지 않는다. 앎의 표시는 이 자기평가를 근거로 하며,
자기평가 항목·척도와 유지 기준은 이후 설계한다.

### 3. 전체 범위를 만나되 순서와 반복량을 달리한다

- 올해 시험 범위라면 지엽적인 내용도 최소 한 번 답을 떠올리고 정답을 확인한다.
- 중요한 내용을 먼저 공부하고, 덜 중요한 내용은 반복 횟수를 줄인다.
- 평소에는 안 본 강의를 우선하면서 복습도 조금씩 섞는다.
- 시험이 가까워지면 중요한 미학습 내용과 반복해서 틀리는 내용을 우선한다.
- 이미 아는 내용의 반복 때문에 새로운 내용을 못 보는 상황을 피한다.
- 시간이 부족하면 중요한 내용 중 무엇을 아직 못 봤는지 명확히 보여준다.

필요한 단순 암기는 반복으로 익히고 시간이 지나 잊은 내용은 복습한다.
구체적인 배분 비율·간격·반복 상한은 아직 정하지 않는다.

사용자 후속 합의(2026-10-29 KST): 시험 2일 전까지 전체 범위를 한 번 공부하는 것을 목표로 한다.
마지막 이틀은 복습·약점 보완 중심으로 하되 늦게 들어온 필기와 중요한 미학습은 그때도 공부할 수 있다.
목표일은 새 학습을 잠그거나 아직 못 본 범위를 완료로 처리하는 기준이 아니다.
추천 구성은 고정 비율보다 필요한 새 진도와 우선순위 높은 복습을 함께 배정하는 방향으로 합의했다.
복습 후보가 많아져도 새 범위를 계속 못 보는 일을 막으며, 구체적인 일일량과 보완 한도는 후속 설계한다.

### 4. 중요도는 교수와 올해의 근거에 맞춘다

| 유형 | 사용자가 제시한 준비 기준 |
|---|---|
| 족보형 | 매년 반복되는 해당 교수님의 족보 출제를 중심으로 준비 |
| 족집게형 | 수업시간에 짚어준 부분을 중심으로 준비 |
| 신규 | 정보가 없으므로 작년 다른 교수님의 족보, 올해 수업에서 설명한 부분 등을 포함해 넓게 준비 |
| 일반형 | 교수님의 출제 예고 > 같은 교수님의 족보 > 교수님 설명(학생의 필기) = 올해 슬라이드 내용 > 다른 교수님의 족보 |

사이트 전체에 하나의 고정 순위를 적용하지 않는다. 중요도는 순서와 반복량에 반영하며,
올해 시험 범위를 임의로 생략하는 근거로 쓰지 않는다. 교수 유형의 판별·변경과 근거 충돌 처리는 미정이다.

### 5. 뼈대를 먼저 회상하고 가지를 탐험하며 깊이를 늘린다

사용자가 전체 방향에 동의한 흐름은 다음과 같다.

1. 전체 뼈대 파악: 강의의 큰 분류·변화의 축·순서·목적·핵심 질문을 먼저 회상한다.
2. 가지별 깊이 확장: 뼈대의 어느 위치에 붙는 내용인지 알면서 세부 개념과 기전을 공부한다.
3. 관계 회상: 유사 개념을 비교하고, 상위에서 하위뿐 아니라 하위에서 상위로도 회상한다.
4. 혼합 복습: 학습한 내용을 섞어 익숙한 순서나 위치에만 의존하지 않고 회상한다.

한 가지를 완벽하게 알아야 다음으로 넘어갈 수 있게 만들지 않는다.
새로운 범위를 만나면서 이전에 공부한 곳을 다시 방문해 깊이를 늘릴 수 있어야 한다.
고정 BFS/DFS 순서·깊이·비율·단계 전환의 수치 조건까지 승인한 것은 아니다.

뼈대는 강의 전체 맥락을 보고 선정해야 하며 기존 문항 목록만으로 정하지 않는다.
사용자가 든 사례는 콜린성 약리학의 큰 분류, 유전자 표적항암약리의 변화 기준,
약물 대사의 단계별 역할과 전체 목적, 지혈의 주요 사건 순서다.
이 사례는 구조적 역할을 설명하는 인터뷰 자료이며 실제 출제 내용은 원본 대조가 필요하다.

현재 Concept Tree의 첫 범위는 강의별 뿌리다. 각 강의의 지도는 독립적으로 구성하며,
블록 전체 현황은 강의별 진행을 모아 보여준다. 블록 전체를 하나의 지도로 통합하지 않는다.
사이트 전체의 장기 의도에는 여러 강의를 함께 보며 개념의 출처·맥락과 연결을 되찾는 학습도
포함하지만 강의 간 지도 연결·목표 통합은 현재 범위에 포함하지 않는다.

#### 참고 대화에서 구체화한 학습 의도 — 2026-11-01

아래는 참고 대화를 다시 읽고, 이 채팅에서 합의한 방향에 맞춰 풀어쓴 내용이다.
링크를 열지 않아도 학습 의도를 이해할 수 있게 기록한다. 참고 대화는 설계 아이디어이며,
그 안의 알고리즘 명칭·수치·예시를 검증된 학습 이론이나 확정 구현으로 취급하지 않는다.

| 핵심 | StudyEZ에서의 의미 |
|---|---|
| 개념 이름과 함께 관계를 회상한다 | 무엇이 있는지만 외우는 데서 그치지 않고 어디에 속하는지, 왜 연결되는지, 무엇이 다른지 확인한다. 연결선만 그려져 있다고 학습된 것으로 보지 않는다 |
| 같은 지도를 다시 방문하며 깊이를 늘린다 | 처음에는 뼈대와 큰 가지를 만나고 이후 세부·기전·비교를 더한다. 한 가지를 끝내고 영원히 떠나는 흐름이 아니며 완벽한 숙련을 이동 조건으로 삼지 않는다 |
| 가까운 개념을 구별한다 | 각 개념을 따로 기억해도 서로 혼동할 수 있으므로 공통점·차이·구별 조건을 묻는 학습을 포함한다 |
| 한 방향의 성공을 다른 방향의 성공으로 보지 않는다 | 상위 분류에서 사례를 떠올리는 것, 사례에서 상위 분류와 이유를 복원하는 것, 유사 사례를 비교하는 것은 필요한 경우 별도로 확인한다. 모든 관계의 모든 방향을 의무화하지는 않는다 |
| 처음 배울 때와 복습할 때의 순서를 달리한다 | 처음에는 강의 구조와 실제 필요한 기초를 따라 맥락을 잡고, 복습에서는 이미 배운 내용을 섞어 지도 위치·직전 문제·고정 순서에만 기대지 않고 회상한다 |
| 학습 상태에 따라 다음 질문의 역할을 바꾼다 | 새 범위를 만날 필요, 약한 관계, 혼동하는 개념, 복습 시점, 출제 중요도를 함께 고려한다. 가장 약한 문제만 반복해 새 범위를 못 보는 상황을 피한다 |
| 지도·문제·추천을 구분한다 | 지도는 무엇을 배울지와 관계를 조직하고, 문제는 회상·판단을 확인하며, 추천은 지금 무엇을 공부할지 정한다. 같은 지도를 첫 학습·비교·복습에 재사용할 수 있다 |
| 모든 연결선을 별도 문제로 늘리지 않는다 | 필요한 목표와 회상 방향을 실제로 충족하는지 검증하고 충분한 기존 문항은 재사용한다. 중복 문제를 줄이는 것과 올해 범위의 지엽적인 내용을 생략하는 것은 구별한다 |

관계를 묻는 질문은 다음처럼 구분할 수 있다. 이는 질문의 역할을 설명하는 예시이며 실제 출제 내용은 원본에서 정한다.

- **위에서 아래로:** 이 분류에는 무엇이 속하며 어떻게 나뉘는가?
- **아래에서 위로:** 이 사례는 어느 분류에 속하며 그 이유는 무엇인가?
- **옆으로 비교:** 비슷한 두 개념은 어떤 조건에서 구별되는가?

구체 설계 후보로는 처음에는 같은 가지 안에서 섞고 이후 배운 다른 가지까지 혼합하는 방식,
분류·비교·인과·선행 관계를 구별해 표현하는 방식이 있다. 적용 시점과 표현은 아직 정하지 않는다.
학습에 필요한 기초를 먼저 제시하는 것과 정답을 맞혀야 다음 노드를 여는 것은 구별한다.
참고 대화의 정답/숙련도 기반 잠금은 채택하지 않는다. 고정 BFS/DFS 비율·깊이, 예시 우선순위 가중치,
Anki/FSRS 도입·연동도 확정하지 않는다. 이번 정리로 강의 간 연결이나 첫 구현 범위를 확대하지 않는다.

참고 대화의 읽기용 정리와 적용 구분은 [참고 대화 정리](reference-learning-principles.md)에 보관했다.

### 6. 계획 부담을 줄이고 바로 시작하게 한다

기본은 추천대로 바로 시작하는 경험이다. 매번 무엇을 공부할지 직접 계획하는 부담을 줄인다.
시험일까지 남은 범위를 고려해 하루 분량을 추천한다.
매일 시험일까지 남은 기간과 실제 남은 범위를 보고 하루 추천 분량을 다시 조정한다.
못한 분량을 매일의 숙제처럼 단순 누적해 부담을 주지 않는다. 재계획하더라도 중요한 미학습 내용은
전체 범위와 현황에 계속 남아 눈에 띄어야 한다. 계획을 조정한 사실만으로 학습을 완료 처리하거나
남은 범위를 숨기지 않는다. 사용자는 시간 설정 없이 필요한 분량을 추천받도록 선택했다(2026-10-29 KST).
시간 입력을 시작 조건으로 요구하지 않는다. 실제 학습 속도·완료 기록을 보조 근거로 활용하는 계산 방식은 이후 설계한다.
보완량은 고정 10개로 두지 않고 필요한 새 진도를 확보하면서 복습 필요도와 실제 학습 기록에 따라
자동 조정하는 방향으로 합의했다. 필요한 새 진도와 급한 복습이 최근 학습량을 넘으면 둘을 기본
추천에 포함해 분량을 늘린다. 최근 학습량은 강제 상한으로 쓰지 않는다. 증가 이유를 보여주고,
기본 분량·급한 복습 판정·초기 추정의 세부 계산은 후속 설계한다.

블록 운영에 대한 후속 확인(2026-10-29 KST): 시험 일정과 전체 강의 목록은 미리 알 수 있다.
강의는 평일 하루 3~6개, 평균 약 4개가 들어온다. 강의 수가 곧 동일한 학습 분량이라는 뜻은 아니다.
슬라이드와 필기는 블록 진행 중 계속 추가된다. 준비된 강의부터 공부하고 새 자료가 들어오면
지도와 추천 분량을 보정한다. 아직 자료가 없는 강의도 전체 시험 범위의 일부로 남긴다.
자료가 추가되어 범위가 구체화되는 변화와 사용자의 학습·회상 변화를 구분한다.
후속 선택(2026-10-29 KST): 예습은 현재 예습 퀴즈를 이용하고 새 강의 지도 학습은 필기가 들어온 뒤
시작한다. 슬라이드만으로 새 지도 학습을 먼저 시작하는 흐름은 채택하지 않는다.
필기 도착 후 자료 확인·학습 준비의 구체 조건, 보정의 적용 시점과 기록 연결은 후속 설계한다.

### 7. 실제 학습 변화에서 보람을 느낀다

공부가 재미있고 보람차며, 자신이 무엇을 알고 무엇을 모르는지 알아보고 효능감을 느끼기를 원한다.
보람을 주는 변화로 사용자가 선택한 것은 다음과 같다.

- 빈 영역이 줄고 학습 지도가 채워지는 모습.
- 한 번 공부한 영역과 실제로 아는 영역이 구분되어 늘어나는 모습.
- 오늘의 공부로 학습 범위와 앎이 얼마나 달라졌는지 확인하는 경험.
- 오늘 추천 분량을 마쳤다는 표시를 통해 하루 공부를 시작하고 완료할 동기를 얻는 경험.
- 약했던 개념을 다시 회상할 수 있게 된 변화.

오늘 분량 완료와 전체 범위의 첫 학습 완료, 실제 앎은 각각 구분한다.
객관식 시험 준비를 돕되 문항·선지 자체를 외워서 아는 것처럼 보이는 상황을 줄여야 한다.
사용자가 제시한 방법 후보는 게임 같은 선택 경험과 특정 슬라이드 암기를 위한 미니 퀴즈다.
선택 빈도·구체적인 시각 표현·미니 퀴즈의 형태는 아직 확정하지 않았다. 기본 추천 흐름을 방해하지 않아야 한다.
점수·레벨·배지의 도입 여부에 대한 사용자 선호는 아직 확인하지 않았다.

### 대표 학습자 여정

1. 사이트를 열어 전체 시험 범위의 본 곳·빈 곳·실제 앎을 파악하고 중요한 미학습 부분을 발견한다.
2. 시험일까지 남은 기간과 범위에 맞춰 조정된 오늘의 추천 학습을 바로 시작한다.
3. 처음 배우는 범위는 뼈대에서 가지로 확장하고, 학습 상태에 따라 비교·양방향 회상·혼합 복습을 이어간다.
4. 머릿속으로 답을 떠올리고 정답을 확인한 뒤 자기평가하며, 완벽하게 알지 못해도 새로운 범위를 만난다.
5. 오늘 지도의 빈 곳이 얼마나 줄었고 앎이 어떻게 달라졌는지 확인하며, 추천 분량 완료를 알아본다.

오늘 분량을 마치지 못했으면 다음 날 남은 기간·범위에 맞춰 다시 조정한다.
그 과정에서도 중요한 미학습 내용은 전체 현황에 계속 드러나야 한다.

### 의도 충족 여부를 검토할 대표 상황

| 상황 | 사용자가 할 수 있어야 하는 일 |
|---|---|
| 시험 범위가 여러 강의에 걸쳐 있음 | 본 곳과 빈 곳을 구분하고 중요한 미학습 범위를 발견한다 |
| 첫 질문에 틀렸지만 답을 생각하고 정답까지 확인함 | 첫 학습의 진전을 확인하며 실제 앎은 부족한 상태로 구분한다 |
| 한 가지의 세부 내용에서 계속 틀림 | 완벽한 숙련을 강요받지 않고 다른 범위도 공부하며 이후 복습한다 |
| 시험이 가까운데 못 본 내용이 남음 | 중요한 미학습·반복 오답을 먼저 공부하고 남은 빈 곳을 확인한다 |
| 무엇부터 할지 직접 계획하기 어려움 | 현황에서 오늘 추천 학습을 바로 시작한다 |
| 오늘 추천 분량을 다 못 마침 | 다음 날 남은 기간·범위에 맞춘 추천을 받으며 중요한 미학습 내용도 계속 확인한다 |
| 오늘 추천 분량을 마침 | 오늘 분량 완료와 오늘 새로 공부한 범위·앎의 변화를 확인한다 |
| 약했던 개념을 다시 회상하게 됨 | 그 변화를 학습 현황에서 알아보고 성취감을 느낀다 |
| 객관식에 맞혔지만 회상 또는 판단 근거가 부족함 | 문항의 성격에 맞춰 실제 앎이 충분하지 않음을 구분한다 |

- 자료나 연결 문항이 부족해 아직 평가할 수 없는 범위의 표시.
