# 미정 CBL 3개 작년 필기 확인과 연결 — 설계

## 요구사항과 수용 기준
2025년 원본 PDF의 표지·본문·관련 사례/목표를 올해 시간표와 직접 대조한다. CBL 전용 자료가 없고 해당 주제 일반 강의 필기만 있으면 그 사실을 기록하고 예습 참고 원본으로 연결한다. 동일 원본이 올해 일반 강의에 이미 연결됐더라도 기존 연결은 유지한다. 세 CBL에만 명시적 수동 매핑과 바이트를 보존한 별도 입력 사본/원본 해시 기록을 사용한다. ‘작년 CBL’로 자료의 성격을 지어내지 않는다.

## 책임·입출력 계약·오류 상태
기존 강의 ID·제목·담당·시간표 연결·예습 대화·문항·은행·학습 기록 및 모든 기존 _pairs 키를 보존한다. 원본/기존 첨부를 삭제하거나 덮어쓰지 않는다. 새 PDF 첨부와 preview_source만 승인 범위다. 재출제·ChatGPT 전송·학습도 승계는 실행하지 않는다. 필요시 러너를 일시정지하고 원상 복원한다.

## 호환성과 데이터 보존
기존 packet_sources와 _pairs 계약을 사용한다. 원본이 일반 강의에 이미 사용된 경우 원본 해시가 같은 CBL 예습참고 사본을 별도 파생 입력 ID로 등록해 기존 소유·범위 판정을 우회하지 않는다. 이름·사본·manifest·원본 해시 및 세 대상의 승인 근거를 함께 보존한다. 연결 성격은 이유 문구/파일명에서 분명하게 알 수 있게 한다. 다른 교수 선택 규칙은 바꾸지 않는다.
