# 로컬 보관 완료

현재 사용자 요청에 따라 완료 배포 사본 12개와 확인된 테스트 DB 폴더 125개를
Study_EZ_Archive/2026-10-26-independent-materials/tree/로 이동했다.
파일 백업·전체 복원·해시·링크·실제 이동 결과 검증을 통과했다. 사이트 실행 코드는 변경하지 않았다.
Spotter는 현역 경로에 유지하며 검색 범위만 분리한다. 기능과 DB 변경·마이그레이션은 없다.

복원은 보관함 restore.ps1로 한 항목씩 검증하고 원위치가 없을 때만 수행한다.
부모 작업 파일·운영 runs·검수/복구 기록·최신 사본을 보존했다. 남은 항목은 classification.json 참고.
로컬 작업 완료이며 운영 배포 승인이나 외부 업로드를 요청하지 않는다.
