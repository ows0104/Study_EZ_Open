# Main-Quiz 중요도 필터 강의별 저장·범위 슬라이더

## 문제와 사용자 효과

사용자 요청(2026-11-25 채팅): 「강의마다 따로 저장되게 바꿔줘. 그리고 가격대 선택처럼 해줘. 중요도 선이 있고
양쪽에 동그라미가 있어서 범위를 선택할 수 있게.」

- 지금(2026-11-12-tier-filter R4)은 오늘 학습 중요도 선택이 **과목(subject)마다** 하나다. 한 강의에서 칩을 바꾸면
  같은 과목의 모든 강의 오늘 추천이 같이 바뀐다. 강의마다 따로 남아야 한다.
- 칩 4개를 따로 켜고 끄는 대신, Essential → Optional 한 줄 위에 양 끝 손잡이 두 개로 연속 범위를 고른다.

## 범위와 성공 기준

- 강의 A에서 범위를 바꿔도 같은 과목 강의 B의 선택·오늘 계획·카드 수는 그대로다.
- 오늘 추천 카드 안에 선분 4개(중요도마다 하나, 이름·카드 수는 선분 위)와 경계 점 5개, 점 위의 손잡이 둘. 두 손잡이를 이웃 점에 두면 그 중요도 하나.
- 끌기·키보드(화살표)로 움직이고, 놓을 때 한 번 저장한다. 저장 뒤 오늘 추천 숫자를 다시 그린다(지금과 같음).
- 선행 문항 버튼은 그대로 범위 옆에 둔다. 선행 문항 선택도 강의마다 남는다(같은 저장값).
- 오늘 계획만 거른다. 학습 목표·진척·기록·복습 일정·「내 중요도」·모아풀기·전체 문항 필터는 바꾸지 않는다.

## 근거·미정 사항

- 저장 행(root_event kind='focus')은 처음부터 run_id를 적고 있다. 읽을 때만 과목으로 모았다. 표·migration 없음.
- 처음 값(사용자 11-25 답): 자기 선택이 없는 강의는 Essential~Important.
