# 강의록 회독 기록과 강의별 짧은 메모

## 문제와 사용자 효과
- 강의 패널 「통계」의 회독 옆에 강의록 회독을 더하는 버튼이 없다. UI/UX 개편 2단계(서버 저장)로 미뤄 둔 것이다
  (`docs/changes/2026-11-05-ui-ux-redesign/` plan 결정 2, spec 「강의록 회독」).
- 강의마다 각자 적어 둘 2~3줄 메모 칸이 없다.

사용자 요청(2026-11-10, 채팅): 「회독 작업 시작해. 그리고 이 페이지에서 회독 아래에 간단하게 각자 그 단원에 대해
적고 싶은 걸 적을 수 있는 아주 간단한, 2~3줄짜리 메모 칸을 추가하고 싶어. 이것도 추가하는 거 작업해줘.」

## 범위와 성공 기준
- 패널 회독 줄: 예습 퀴즈 완료 토막 → 강의록 회독 토막(하나에 하나) → 「+」. 토막을 누르면 최근 1회독을 지우고 4초간 「되돌리기」.
  둘 다 없으면 예습 빈 칸 하나(앞에서부터 채우기, 2026-11-07 지시 6).
- 캘린더 칸 회독 줄에도 강의록 토막이 붙는다. 패널에서 바꾸면 칸도 바로 바뀐다.
- 회독 아래 「메모」: 3줄 입력칸, 300자, 입력을 멈추거나 칸을 떠나면 저장. 본인만 본다.
- 학습률·복습 간격에는 섞지 않는다. 강의 목록 행의 「+」는 이번 범위가 아니다(11-06 개편에서 목록의 회독을 뺐다).

## 근거·미정 사항
- 새 표 두 개(`note_read`, `lecture_memo`)가 필요하다 → 운영 DB 표 생성은 별도 승인.
- 설명 문구는 넣지 않는다(라벨만).
