# Main-Quiz 같은 문항 반복 제거: 목표 전체 중복 판정·채울 수 없는 목표·같은 개념 띄우기

## 문제와 사용자 효과

사용자 제보(2026-11-12): 피코르나바이러스(261111_02) Main-Quiz에서 「RNA 바이러스는 proofreading이 부족해 변이가 많다」를
묻는 문항이 연달아 여러 번 나온다. 게시된 결과(`runs/_root-generation/cf4d5917…/generation/result.json`)에서 확인한 사실:

- 같은 사실을 묻는 과제가 3개다(P001·Q002·Q068, 모두 목표 D077). 첫 목표(T001)라 퀴즈 시작 5문항 안에 다 나온다.
- 목표 D077의 component가 「RNA 중합효소의 교정 기능 부족. 모든 바이러스에 예외 없는 법칙은 아니다.」 한 덩어리다.
  뒤 문장은 답으로 회상할 내용이 아니어서 커버 판정이 세 번 모두 missing이었다(「proofreading은 회상하지만 예외 단서는 안 묻는다」).
- 그래서 추가 출제 1차가 Q002를, 2차가 Q068을 썼다. 추가 출제 입력의 `existing`에 P001이 있었지만 같은 답을 다시 썼다.
- 추가 출제 뒤 커버 재확인은 그 회차에 새로 쓴 문항만 받는다(`v3.coverage_input(brief, bank, part, added)`).
  기존 문항과 같은지는 한 번도 비교되지 않았고, 이 강의에서 합쳐진 중복은 1건이다.
- 풀이 순서(`plan_tasks`)는 새 목표의 과제를 전부 이어서 낸다.

같은 강의에서 답이 사실상 같은 묶음이 8곳 더 보인다(읽어서 본 것, intent 작성 시점의 판단).

원하는 효과: 새로 출제하는 강의에서 같은 답을 같은 방향으로 묻는 문항은 하나만 과제가 되고, 같은 개념을 다른 방향으로
묻는 문항은 남기되 연달아 나오지 않는다.

## 범위와 성공 기준

사용자 지시(2026-11-12 채팅): 「생성기 중복 합치고, 러너는 지금 도는 거까지만 마무리하고 다시 돌려줄래? 얘네도 고쳐줘.
(채울 수 없는 목표 · 추가 출제가 같은 문항을 다시 씀 · 중복 판정이 셋을 같이 못 봄) 그리고 다른 방향에서 같은 개념을 묻는 문제는 띄워줘.」

1. 채울 수 없는 목표: 해석상 주의가 component에 섞여도 커버 판정이 회상할 내용만 본다. 정규화 지시도 같은 사례로 보강한다.
2. 추가 출제: 그 목표를 이미 묻는 문항과 무엇이 빠졌는지를 받고, 같은 답을 발문만 바꿔 다시 쓰지 않는다.
3. 중복 판정: 추가 출제 뒤 재확인이 그 목표의 기존 문항까지 함께 보고 중복 묶음을 적는다. 답을 온전히 못 채운 문항끼리도 합친다.
4. 풀이 순서: 한 목표 방향에 과제가 여럿이면 한 회차 안에서 서로 띄운다.
5. 병합 뒤 러너를 새 코드로 재설치한다. 그때 도는 강의가 끝난 다음에 한다.

성공 기준: 피코르나 결과의 저장된 판정에 「세 문항이 같다」는 묶음을 넣어 조립하면 과제가 하나만 남는다(모델 없이 재생).
새 검사와 기존 회귀가 통과한다. 실제 모델 효과(지시문)는 재설치 뒤 첫 강의에서 본다.

범위 밖: 이미 공개된 판의 교체·재출제(따로 묻는다), DB 변경, /2·/3 실행.

## 근거·미정 사항

- 정규화 지시에는 이미 「해석상 주의는 component에 넣지 않는다」가 있다(2026-11-11-v4-normalize-components). 피코르나 실행은
  그 지시가 있는 러너로 돌았는데도 주의가 들어갔다. 그래서 판정 쪽에서도 막는다.
- 「띄운다」의 뜻은 사용자가 정하지 않았다. 여기서는 같은 회차 안에서 순서만 바꾼다(다른 날로 미루지 않는다). 과제·학습 상태·
  목표 완료 조건은 그대로다. 다른 날로 미루기를 원하면 별도 작업이다.
- 지시문 변경의 실제 효과는 모델 실행 없이는 확인할 수 없다. 이 작업은 모델을 부르지 않는다.
