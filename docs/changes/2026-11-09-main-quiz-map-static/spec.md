# Main-Quiz 개념 지도 화면 정리 — 설계

## 요구사항과 수용 기준
- `RootMap`은 지도 틀 하나만 그린다. 틀 안에 들어가는 것은 다음과 같다.
  - 지도(강의 카드·열·주제·문항 줄·연결선)
  - 아래 도구 막대: 범례 점들, 현재 문제, 문항 펼치기/접기, 연결선 전체/숨기기, 크게 보기
  - 겹침 패널
- 틀 높이는 `100dvh − 틀의 문서상 top − 12px`(최소 360px)이고, 마운트·창 크기 변경 때 잰다.
- 확대·이동 입력은 없다.
  - 배율은 `min(틀폭/지도폭, 틀높이/지도높이, 1.2)`이다.
  - 그 값이 0.5 미만이면 배율은 `max(0.5, 틀폭/지도폭)`이고, 틀은 세로 스크롤된다.
  - 다시 맞추는 때: 지도 크기 변경(문항 펼침·연결선), 틀 크기 변경(창·크게 보기).
- 패널은 틀 안 절대 위치로 지도 위에 겹친다. 고른 노드의 화면 x 중심이 틀 가운데보다 오른쪽이면 왼쪽에 연다.
- Esc는 크게 보기를 닫거나 선택을 푼다.
- 좁은 화면(760px 미만)은 기존 세로 목록이다.

수용 기준
- 1600×900에서 지도 틀 위에 문구가 없다(돌아가기 버튼만 남는다).
- 틀 아래가 화면 아래 12px 안에 있고, 문서 높이가 화면을 넘지 않는다.
- 주제를 누르기 전과 후에 지도 transform이 같다.
- 휠을 굴려도 transform이 그대로다.
- 기존 흐름 검사(지도 왕복·평가·새로고침 재개)가 통과한다.

## 책임·입출력 계약·오류 상태
입력(`RootMapData`·`RootSummary`), `buildTree`, 지도 열람 이벤트는 그대로다.

## 호환성과 데이터 보존
화면만 바뀐다. 서버·DB·학습 기록은 바뀌지 않는다. 되돌리기는 병합 커밋 revert다.
