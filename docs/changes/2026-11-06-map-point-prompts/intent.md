# Map와 독립 출제포인트 추출 지침 정리

## 문제와 사용자 효과
지도는 고정 트리일 필요가 없다. 최종적으로 문항 구조·누락·학습 순서를 대조하는 데 쓰지만, Map 추출 지시문에는 그 최종 용도를 넣지 않고 원본의 개념·분류·관계·흐름 구성에 집중한다.

## 범위와 성공 기준
원본 전용 Map과 포인트 요청문 및 읽기 쉬운 출력 형식을 작성한다. 실행 코드·모델 호출·출제 재개·배포는 포함하지 않는다.

## 근거·미정 사항
사용자 2026-11-06: “Map은 그렇게 정리해줘. 필요하다면 이전 프롬프트의 형식을 참고해도 될듯. 더 좋은 형식이 있으면 그걸로 가고. 출제포인트는 이전 프롬프트를 우리의 철학에 맞게 해줘.”

후속 교정: “Map을 뽑을때의 프롬프트는 문제와는 무관하게 강의와 족보에서 개념 Map으로 만드는데 집중하는게 좋을듯.” 이는 동일 작성 범위의 명확화다.
