# Bridge 파일 수신 동작 점검

## 문제와 사용자 효과
사용자는 출력 잘림 때문에 문제은행을 파일로 받기로 했으나 bridge의 실제 파일 수신이 동작하는지 확신하지 못한다. 현행 소스·기존 검사·저장된 수신 기록을 확인해 자동 회수, 직접 파일 선택, 서버 저장의 확인 범위를 구분한다.

## 범위와 성공 기준
읽기 전용 조사와 기존 격리 검사 실행, 문서 기록만 수행한다. 제품 코드·프롬프트·확장 패키지·은행·운영 DB를 변경하거나 새 웹 생성·모델 검수를 실행하지 않는다. 실제 운영 연결 성공 여부와 로컬 테스트 통과를 구별해 보고하면 조사 완료다.
