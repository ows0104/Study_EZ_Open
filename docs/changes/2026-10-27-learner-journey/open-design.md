## P01. 화면 표현·탐색 세부

**합의 유지:** 강의별 단일 막대, 뼈대·큰 가지부터 펼침, 접힌 곳의 잔여 표시, 현재 위치, 자기평가 즉시 이동, 오늘은 여기까지.
**후보/미정:** 정확한 색·무늬·체크/빈 원, 노드의 이름/질문 비중, 0개 표시, 반응형 선택 상세 배치, 키보드 탐색·초점·접힘 상태 유지, 전후 막대 배치, 추가 클릭 위치, 피드백 초 수와 레이아웃 안정성.
지도에 답이 드러나는 명칭을 접거나 중립적으로 바꾸는 방식도 후보다. 표현 규칙과 접근성 검사는 구현 계획에서 확정한다.
같은 가지 안의 혼합에서 배운 다른 가지의 혼합으로 넓히는 시점, 분류·비교·인과·선행 관계의 구별 표현도 후속 후보다.
관계 선을 늘리거나 강의 간 지도를 합치기로 결정한 것은 아니다.

## P02. 목표·필수 방향·자기평가

**합의 유지:** 목표 중복 집계 금지, 방향별 상태, 시도+정답 확인은 첫 학습, 선지 도움은 중간, OX 이유를 못 설명하면 이해 부족, 모든 필수 방향을 도움 없이 회상해야 목표 회상 가능.
**미정:** 실제 목표의 분할·동일성, 필수/선택 방향 선정 기준, 문항 없는 목표·복합 목표 판정, 자기평가 전/보류 상태의 저장 시점, 도움 받은 회상의 판정과 점수, 숙련도 임계값·시간 경과·기억 유지 기준.
**후보:** “못 떠올림 / 도움 필요 / 스스로 회상” 세 버튼, “떠올려본 뒤 정답 확인” 단일 행동으로 시도까지 기록하기, 지도로 답을 본 경우 도움 받은 회상으로 표시하기.
예시 버튼을 모든 문항 형식의 확정 척도로 쓰거나 Anki Hard와 실패를 동일시하지 않는다.

## P03. 오늘 추천의 계산·복습 모델

**합의 유지:** 시간 입력 없음, 고정 비율/보완 10개 없음, 새 진도 보호, 필요한 새 진도+급한 복습이 최근 기록을 넘으면 기본 분량 증가, 매일 재계획, 시험 2일 전 목표와 마지막 이틀의 늦은/중요 새 학습 허용.
이 합의를 다음의 미확정 계산안과 섞지 않는다.

### 계산 후보

- 준비된 미학습 목표 U와 첫 학습 목표일까지 오늘을 포함한 학습일 D에 대해, D>0일 때 새 목표 N=ceil(U/D), U=0이면 N=0을 참고값으로 삼는 안.
- 이는 현재 준비 범위만 나누는 값이다. 앞으로 올 강의 일정과 실제 관측한 강의별 목표량으로 유입을 예측해 준비된 범위를 미리 공부하도록 보정하는 안을 검토한다.
- 평균 4강은 고정 일일 진도나 같은 날 필기 도착량이 아니다. 정확한 일정이 있으면 우선하고 주말을 자동 제외하지 않는다.
- 미준비 목표의 추정치는 계획용이며 확정 진행 막대 분모에 넣지 않는다. 준비 범위보다 많은 새 진도를 배정하지 않는다.
- 최근 의미 있는 학습 기록의 대표값 H를 참고하는 안. 기록 기간·과제별 부담 가중치·조정 폭은 미정이다. 클릭/즉시 반복, 미접속, 자료 대기, 저장 실패를 실제 학습 부담과 구분한다.
- 일반 보완량 K는 새 진도와 급한 복습 배정 후 H 안의 여유와 실제 필요량을 참고하되, H를 넘어도 합의대로 새 진도와 급한 복습은 확보하는 안이다. 급한 복습은 하한으로 고려하고 같은 후보를 중복 배정하지 않는다.
- 급하지 않거나 복습이 불필요한 항목으로 양을 채우지 않고, 하루 몰아공부·분량 증가일 때문에 다음 날 H를 즉시 올리지 않는 안.
- 오답 때문에 세션 목표가 끝없이 늘지 않도록 하루 범위를 유한하게 제시하는 안. 세션 중 재계획·새 자료 반영과의 정확한 경계는 미정이다.

D<=0 또는 마지막 이틀에 위 공식을 그대로 연장하지 않는다. 목표일 날짜/시각·초기 기록 부족·급한 복습 기준·유입 예측·반복 상한·준비된 새 내용이 없는 날·복습 후보가 없는 날의 정확한 계산은 아직 결정하지 않았다.
최근 기록으로 가용 시간·능력이나 시험 준비의 충분함/불가능함을 단정하지 않는다.

### 모델 후보

FSRS는 복습 시점을 정할 후보이며 도입·등급 매핑·초기화·목표 유지율은 미정이다.
범위 계획과 복습 시점을 분리하되 구체 우선순위 함수·가중치·일일 최소/최대량은 확정하지 않았다.
회상 확률 추정을 실제 앎·시험 정답률의 보증으로 표시하지 않는다.
Anki/인출·간격·교차 학습 자료의 출처와 해석 범위는 [review-notes.md](review-notes.md)에 있다.

## P09. 이미지 기반 문제와 학습

**사용자 추가 요구:** 현재 감염과 면역 블록에 이미지 문제가 자주 나오고 다른 블록에도 중요하다. 처리 방식은 미정이다.
**후속 방향 합의:** 사용자는 필기·족보의 필요한 이미지 영역을 crop해 출제하기를 원한다. 이 방향은 spec/S8에 반영했다.
아래의 세부 방식은 설계 후보이며 상태 기준·파일 계약·첫 구현 범위를 확정한 것이 아니다.

### 구별할 역할

- 해설/근거 이미지: 답 확인 후 원본을 설명하거나 근거를 보여주는 자료.
- 문제 이미지: 그 이미지를 실제로 보고 특징을 식별·구별·해석해야 풀 수 있는 자료.
- 암기용 시각 자료: 구조·표·경로 등을 회상하거나 일부를 가리는 학습 후보. 모든 이미지를 이 유형으로 처리하지 않는다.

텍스트 문제에 근거 이미지가 붙었다는 사실만으로 이미지 해석 목표까지 충족했다고 보지 않는 방향을 제안한다.

### 최소 설계 후보

1. 포인트 추출에서 이미지로 확인해야 할 목표와 실제 원본 위치를 식별한다. Markdown 족보에 원래 그림이 없으면 원본 PDF 확인 필요로 남긴다.
2. 이미지는 관련 개념/목표의 지도 위치에 연결한다. 이미지를 텍스트로 설명한 답을 외우는 것과 이미지를 보고 회상하는 방향의 평가를 구별할 필요를 검토한다.
3. 첫 형태는 원본 이미지 제시 → 머릿속 답/판단 이유 회상 → 정답·특징 위치/근거 확인 → 자기평가를 후보로 한다. 매번 입력을 강요하지 않는 기존 원칙을 유지한다.
4. 원본의 답·라벨·캡션이 정답 단서가 되는 경우 질문용 표시와 해설용 표시를 구분하는 방식을 검토한다. 원본은 보존하고 자르기/가림 등 파생 자료는 출처·영역·변환 이력을 남기는 안이다.
5. 같은 사진 자체를 외우는 문제에 대비해 원본에서 확보한 다른 사례나 유사 이미지 비교를 검토한다. 동일 목표/방향인지와 대표 사례·변형의 충분성은 실제 자료로 판단한다. 새 의학 이미지를 임의 합성해 검증된 자료로 취급하지 않는다.
6. MD 링크만 전달했다고 이미지 파일까지 회수됐다고 보지 않는다. 실제 자산·원본 쪽·영역·판 연결과 화면 표시를 검증하는 계약이 필요하다. 이미지가 빠지거나 판독 불가능하면 검증 미완료로 남기는 안이다.

**결정 대기:** 이미지 유형별 목표, 기존 문항의 지원 범위, 이미지→대상/특징→이미지 방향의 필요와 집계,
첫 접촉·회상 기준, 답 가림·확대·표시 방식, 출처/파일 전달·정답 단서·해상도, 비교 사례 확보, 기존 기록 연결.
crop의 최소 영역과 주변 맥락, 원본 파일 판·물리쪽·영역 좌표의 표현, 라벨/캡션의 답 노출 여부,
문제용 crop과 해설용 원본/표시의 구분, 잘린 특징이나 판독 불가능한 화질을 검수할 기준도 정한다.
필요하면 이후 위치 클릭·영역 선택 같은 상호작용을 검토하되 처음부터 필수 구현으로 넣지 않는다.
실제 이미지 문제 1~2개를 보고 위 유형과 최소 흐름을 좁히는 것이 다음 설계 작업이다.
이는 콜린성 시범이나 강의별 뿌리의 첫 적용 범위를 자동 대체하지 않는다.

## 채택하지 않았거나 현재 범위에 없는 것

| 항목 | 상태 |
|---|---|
| 새 진도 70%·복습 30%, 참고 대화 BFS 60%·DFS 40% | 채택하지 않은 예시 비율 |
| 보완 10개 고정 | 사용자가 자동 조정을 선택하여 채택하지 않음 |
| 정답/완벽한 숙련을 다음 노드의 잠금 조건으로 사용 | 사용자 의도와 맞지 않아 채택하지 않음 |
| 모든 관계에 역방향·모든 연결에 별도 문제 생성 | 자동 의무화하지 않음 |
| 강의 간 지도·목표 자동 통합 | 현재 범위 밖 |
| Anki/FSRS 도입·연동, 점수·레벨·배지·슬라이드 미니 퀴즈 | 미확정 또는 후속 후보. 현재 첫 구현의 필수 항목 아님 |
| 원문의 탐색 알고리즘 이름·임의 숙련도·예시 코드 | 검증된 이론·실측치·구현 기준으로 채택하지 않음 |
