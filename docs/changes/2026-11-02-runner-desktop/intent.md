# 창 없는 러너 프로그램과 1분 자동 시작

명령창 없이 바탕화면 아이콘으로 실행하는 러너 프로그램과 강의별·예습/복습별 시작·중지·취소 제어를 제공한다.
2026-11-02 현재 대화의 사용자: “어 그렇게 만들어줘. 올라가고 사용자 입력(시작, 취소)이 1분 간 없으면 자동으로 시작해줘.”
이 명시적 구현 승인을 현재 로컬 프로그램 범위에 적용한다.

후속 사용자 정정: 전체 프로그램 제어가 아니라 강의별·예습/복습별 시작·중지·취소를 뜻한다.
자동 시작은 예습 링크·올해 필기 등 실행 자료가 준비된 작업이며 전체 러너 일시정지 버튼도 요청했다.
기존 러너·진행 표시를 재사용한다. 서버 배포·콘텐츠·검수 규칙과 로그인 예약 작업 변경은 제외한다.
