# 족보 풀이 Z 무제한·답 선택 취소

## 문제와 사용자 효과

사용자(2026-11-24): 「족보 페이지에서는 왜 최대 한 문제까지만 뒤로 갈 수 있어? 내가 체크한 답은 절대 취소할 수 없어서
너무 불편해. 일반 복습 강의처럼 체크한 답도 취소할 수 있게 해줘.」

#175(2026-11-15)의 족보 Z는 직전 표시(모르겠음·주의·괜찮음) 한 단계만 되돌렸다. 고른 답은 서버 풀이 기록이 남아
취소하지 않았다. 복습 퀴즈(Main-Quiz, #109)는 답 보기·평가를 회차 처음까지 한 단계씩 되돌린다.

## 범위와 성공 기준

- Z(또는 Ctrl/⌘+Z)마다 한 칸: 표시를 고른 상태 → 그 문제 답 화면(표시는 고르기 전 값) → 고르기 전 문제 화면 →
  이전 문제 답 화면 … 이번 판 처음 문제까지. 끝 화면에서도 시작할 수 있다.
- 답 취소 시 서버 풀이 기록도 되돌린다: 맞힘·틀림 횟수 1 감소, 틀려서 자동으로 붙은 「모르겠음」은 원래 값,
  마지막 결과·풀이 시각도 이전 값. 처음 푼 문항이면 기록 줄이 없던 상태로 돌아간다.
- 강의 하나 족보와 족보 모아풀기 모두.
- 회독은 끝 화면에 처음 닿을 때 한 번만 센다(그대로). 되돌려도 줄지 않는다.
- 범위 밖: 오답노트 화면, DB 표·칼럼.
