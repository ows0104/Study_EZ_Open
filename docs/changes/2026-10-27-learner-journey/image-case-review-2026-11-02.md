**아직 판단하지 않은 것:** 기존 문항에 정답을 맞힌 사실이 사진 특징을 실제로 읽은 증거인지. 텍스트 단서만으로 답을 떠올렸을 수도 있으므로 문항 연결만으로 시각 방향의 회상 가능 상태를 부여하는 것은 검토가 필요하다.

**설계 제안:** 원래 문항을 재사용할 때는 두 사진의 관계와 원본 표식을 보존한다. 표식을 보고 해석하는 과제와 표시 없이 위치까지 찾아야 하는 과제를 구별한다. 표시 없는 원본을 확보하지 못한 경우 임의 복원·합성으로 후자를 준비 완료 처리하지 않는다.

**아직 판단하지 않은 것:** 점선을 유지할 과제의 목표, 다른 이미지로 일반화 확인이 필요한지, 확대 시 실제 판독 가능한지. 이번 렌더와 파일 크기는 의학적 판독 품질 검수 통과가 아니다.
