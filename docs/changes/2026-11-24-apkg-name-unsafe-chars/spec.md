# 예습 덱 파일 이름에서 Windows 금지 글자를 뺀다 — 설계

## 요구사항과 수용 기준
- R1 `deck.apkg_name(node, kind)`가 돌려주는 이름에는 `RE_FS_UNSAFE`(`\ / : * ? " < > |`) 글자가 없다. 글자를 뺀 자리의 연속 공백은 하나로 줄인다.
- R2 `deck_node`·`calendar_node`·`calendar_deck`(덱 이름)은 그대로다. 「(분반) A: 김태민」의 `:`도 덱 이름에는 남는다.
- R3 금지 글자가 없는 마디는 지금과 같은 파일 이름을 받는다.
- R4 이미 나간 덱의 마디(`pinned_node`)에 `:`가 있어도 파일 이름은 걸러진다(251104_01을 다시 구울 때).

## 책임·입출력 계약·오류 상태
- 파일 이름의 주인은 `apkg_name` 하나다. `calendar_name` → `run_pre`/`rebuild`가 `--apkg-name`으로 quizgen에 넘긴다.
- 빌드된 덱은 이름이 아니라 `*.apkg` 글롭으로 찾는다(`apkg_of`, `chosen`, `rebuild`의 옛 파일 지우기). 그래서 파일 이름과 덱 이름이 글자 몇 개 달라도 찾는 쪽은 그대로다.
- 메타의 `deck_file`은 실제로 쓴 파일 이름을 적는다.

## 호환성과 데이터 보존
- 덱 이름을 바꾸지 않는 까닭:
  - Anki는 `::`로만 덱을 나눈다. 홑 `:`는 덱 이름에 들어가도 된다.
  - 이미 나간 251104_01의 마디에 `:`가 있다. 덱 이름이 바뀌면 학생 Anki에 새 마디가 옆에 하나 더 선다.
  - `prequeue`는 `prequiz.config.json`의 `lecture`가 같을 때만 `--resume`한다. 덱 이름이 바뀌면 새 판을 열어 모델 단계를 처음부터 다시 돈다.
- guid 씨앗(`deck_id`)은 바뀌지 않는다.
