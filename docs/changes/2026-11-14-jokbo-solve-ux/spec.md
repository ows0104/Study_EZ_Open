# 명세

## 오답노트 표시 3단계

| 화면 | 저장 band | 뜻 |
|---|---|---|
| 모르겠음 | `high` | 오답노트에 담음 |
| 주의 | `mid` | 맞혔지만 나중에 볼 수도 있음 — 오답노트에 담음 |
| 괜찮음 | `NULL` | 오답노트에서 뺌 |

- 저장 값과 API(`PUT …/mark {band}`)는 그대로다. 서버는 여전히 `high|mid|low|null`을 받는다(이전 웹 호환).
- 기존 `low`(하 헷갈림) 줄은 고치지 않고 화면에서 **주의**로 보이고 센다. 사람이 주의를 다시 누르면 그때 `mid`로 바뀐다.
- 틀리면 서버가 `high`를 붙이는 동작은 그대로다. 답을 본 뒤 사람이 고른 값이 최종이다.

## 풀이 화면

예습 퀴즈와 같은 틀: 머리줄(뒤로 · 족보 배지 · 강의 제목) → 진행 줄(족보 n / N, 막대, 연도·교수·출제·변형) → 카드 → 아래에 떠 있는 독.

- 폭: 풀이·끝·오답노트 본문 최대 760px. 문제 18px·줄간격 1.8, 선지 16px·1.65, 선지 사이 10px, 해설은 옅은 상자.
- 독: 답 보기 전 「답 보기/확인 Enter」. 답 본 뒤 **모르겠음 1 · 주의 2 · 괜찮음 3**. 누르면 표시를 저장하고 다음 문제.
  `Enter`/`Space`는 기본값 — 틀렸으면 모르겠음, 그 밖은 괜찮음. 숫자 키는 답을 본 뒤에만 표시로 쓴다(그 전에는 선지).
- 답 영역 안의 상·중·하 버튼은 없앤다.

## 끝 화면

예습 퀴즈 완료 화면과 같은 구성.

- 머리줄 뒤로(들어온 곳으로).
- 요약 상자: 「족보 완료」, `N문항 · 맞힘 a · 모르겠음 b · 주의 c`(0은 생략), 버튼 다시 풀기 · 범위 다시 고르기 · **족보 마치기**(뒤로).
- 「오답노트에 넣은 문제 k」 + 「이 문제만 다시 풀기」. 이번 회차에 모르겠음·주의로 고른 문제를 푼 순서대로,
  선지(정답·내가 고른 것 표시)·선지별 해설·해설과 함께 펼친다. k가 0이면 이 칸이 없다.

## 오답노트

- 강의 칩: 전체 N + 강의마다(번호. 제목 k, 강의 날짜 순). 고르면 그 강의만.
- 목록은 강의별 묶음(머리에 강의 이름 — 누르면 그 강의 족보 퀴즈 — 과 수). 묶음 안은 모르겠음 → 주의 → 족보 순서.
- 표시 칩: 모르겠음 · 주의(수). 「풀기/정답 보기」 토글 삭제. **전체 정답 보기** 토글 하나(켜면 모든 카드의 답이 펴짐, 끄면 다시 가림).
- 카드 아래 모르겠음 · 주의 · 괜찮음. 괜찮음을 눌러도 줄은 이번 화면에 남고(테두리 초록), 다음에 들어오면 빠진다.

## 보존

DB·학습 기록·족보 문서 변경 없음. 기존 band 값은 읽기만 하고 사람이 누를 때만 바뀐다.
