# Main-Quiz 선지를 게시 직후 기본 실행

## 문제와 사용자 효과
단답·나열 「선지 보기」 선지는 2026-11-12에 출제 파이프라인 밖의 수동 명령(`python -m runner.root_choices`)으로 만들었다.
그날 공개된 감염과 면역 23강의에는 일괄로 올렸지만(대시보드 완료 기록 2026-11-12, 1,378문항), 그 뒤에 새로 게시된 판에는
누군가 명령을 돌리기 전까지 선지가 없다. 강의를 다시 출제해 판이 바뀐 경우도 같다.

원하는 효과: 새로 게시되는 Main-Quiz 판에는 따로 손대지 않아도 선지가 붙는다. 이미 게시됐는데 선지가 빠진 판은 한 번에 채운다.

## 범위와 성공 기준
- 러너가 Main-Quiz 판을 게시한 직후, 근거 보강 다음에 같은 실행 폴더에서 선지를 만들어 올린다. 실패해도 게시 결과·종료 코드는 그대로다.
- 중복 재판정(duplicates-only/1)으로 새 판이 나와도 선지를 붙인다.
- 수동 명령에 `--missing`: 현재 판에 선지를 올린 기록이 있는 강의는 건너뛴다. 이미 올린 강의에 모델을 다시 부르지 않는다.
- 선지 작성 규칙·지시문·의학 검토·서버·화면은 바꾸지 않는다.

범위 밖: 서버·웹·DB, 선지 지시문, 이미 올린 선지의 교체.

## 근거·미정 사항
사용자 발언(2026-11-14 채팅): 「최근 만들어진 퀴즈들도 선지 추가가 돌아갔나? 안 돌아갔으면 해줄래? 그리고 기본으로 설정해줘.」

- 2026-11-12 결정 「지금 파이프라인에 영향을 안 주고」(→ 수동 명령)를 이 발언이 바꾼다. 기본 실행은 게시 뒤 단계이고 게시 경로의 성패에는 영향이 없다.
- 이 작업은 클라우드 세션에서 했다. 운영 API(프록시 403)와 사용자 PC의 `runs/_root-generation`에 닿지 않아,
  어느 판에 선지가 있는지 직접 확인하지 못했고 빠진 강의 보강 실행도 하지 못했다. 보강은 사용자 PC에서 `--missing`으로 돌린다.
