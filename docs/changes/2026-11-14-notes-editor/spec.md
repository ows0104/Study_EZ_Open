# 자유 노트 편집기 보완(들여쓰기·표·붙여넣기·토글) — 설계

## 요구사항과 수용 기준
**블록 모양(저장 형식)**
- 모든 블록에 `indent`(0–6, 0이면 생략). 블록 목록은 평평한 배열 그대로이고, 한 블록 뒤에 이어지는
  더 깊은 `indent` 블록들이 그 블록의 하위다.
- 새 종류 `toggle`(`open` 참/거짓, 하위 블록을 접는다), `table`(`rows: string[][]` 칸별 HTML, `header` 첫 행 머리글).

**들여쓰기**
- Tab: 바로 위 블록보다 한 단계까지 깊게(맨 첫 블록은 불가). 하위 블록도 같이 한 단계 이동.
- Shift+Tab: 한 단계 얕게(하위 함께).
- 빈 목록 블록에서 Enter: 들여쓴 상태면 한 단계 얕게, 0단계면 글 블록으로.
- 들여쓴 글 블록 맨 앞 Backspace: 한 단계 얕게.
- 번호는 같은 단계·같은 부모 안에서 이어 센다. 단계별 1. → a. → i. 반복. 기호는 • → ◦ → ▪ 반복.
- 코드 블록 안 Tab은 공백 두 칸.

**표**
- `/표`로 3×3(첫 행 머리글). 칸은 글 서식(굵게·색) 가능.
- Tab/Shift+Tab 다음/이전 칸, 마지막 칸 Tab은 행 추가. Enter는 아래 칸(마지막 행이면 행 추가), Shift+Enter 칸 안 줄바꿈.
- 칸에 커서가 있으면 표 위에 작은 막대: 행 추가·열 추가·행 삭제·열 삭제·머리글 켜고 끄기. 최대 100행·20열.

**붙여넣기·줄간격**
- 여러 줄 글은 첫 줄을 커서 자리에, 나머지는 줄마다 새 블록. `# ## ### - * + 1. [] [x] >` 기호와 앞 공백/탭(2칸=1단계)을 인식.
  커서 뒤에 있던 글은 마지막 새 블록 끝에 붙는다.
- 모든 줄에 탭이 있는 여러 줄(엑셀·시트 복사) 또는 md 표(`| a | b |` + `|---|`)는 표 블록으로.
- 코드 블록 안에서는 그대로 붙인다. 표 칸 안에서는 줄바꿈을 공백으로.
- 본문 글 줄높이 1.5, 블록 사이 간격 일정(목록·인용·콜아웃·코드의 위아래 여백 통일).

**회색 칸**
- `.nb-append`는 가리키거나 눌러도 배경 없음. 사진 불러오는 동안 칸은 투명.

**토글·복제·이동·실행 취소**
- 토글은 `/` 메뉴(「토글」)와 블록 메뉴 전환으로 만든다. ▸를 누르면 하위 블록 접기/펴기.
  펼친 토글 끝에서 Enter는 첫 하위 블록을 만든다.
- Ctrl+D: 블록(하위 포함) 복제. Ctrl+Shift+↑/↓: 같은 단계의 앞/뒤 블록과 자리 바꾸기(하위 포함).
- Ctrl+Z / Ctrl+Shift+Z·Ctrl+Y: 블록 목록 기준 실행 취소/다시 실행(연속 입력은 묶음). 노트를 바꾸면 기록을 비운다.

## 책임·입출력 계약·오류 상태
- 서버 `/api/me/notes`: BlockType에 `toggle`·`table` 추가. 필드 `indent`(0–6), `open`(toggle), `rows`
  (table, 최대 100×20, 칸 HTML 각 5,000자), `header`(table). 해당 종류가 아니면 버린다. 표 블록의 `html`은 ""로 저장.
- 웹은 표 칸 HTML도 그리기 전에 `sanitizeNoteHtml`을 거친다(새 태그 허용 없음).
- 값이 없으면(이전 웹이 저장한 노트) 기본값: indent 0, open 참, header 참.

## 호환성과 데이터 보존
- DB 스키마 변경 없음(blocks는 JSON 열). 기존 노트 그대로.
- 배포 순서: API 먼저(기존 자동 배포). 이전 웹이 새 블록을 받으면 toggle/table은 빈 글 칸처럼 보이고,
  이전 웹이 그 노트를 저장하면 `indent`·`rows`가 빠질 수 있다 — 같은 SHA 웹이 곧 올라오므로 수용.
