# 감염병리1 Map 파이프라인 재구성(개념 트리·구조 문제)

## 문제와 사용자 효과
2026-11-07~08 사용자: 감염병리1(감염과 면역/261104_02) Main-Quiz 개념지도가 사실상 한 층이고 문항과 1:1이다. 강의록 전체 구조를 잡을 수 있는 개념 트리(엄격한 트리가 아니어도 됨)가 있고, 그 사이 연결을 구조 문제로 내고 싶다. 참고: 콜린성(아세틸콜린) 예시. "Map 파이프라인에 합류", "Codex 세션을 승계받아 진행". 이전에 미뤄 둔 문제 품질 보완(4번)도 여기서 함께 다룬다.

원인: 현 공개 판은 기존 문제은행 98문항을 옮긴 것으로 parent_ids 0, 관계는 주제→답 association 98, target은 전부 leaf. Codex Map 파이프라인(E2E)도 Map 형식에 상하 칸이 없어 CNS 결과의 Map 개념 26개가 모두 최상위였다.

## 범위와 성공 기준
- Map 추출 지시를 트리 중심(중심 주제 → 갈래 → 세부)으로 하고 개념마다 `parent_id`를 받는다(형식 concept-map-extract/3). 정규화가 Map의 부모를 그대로 보존하는지 기계적으로 검사한다.
- 입력: 올해 필기 S1(박준원v2, 37쪽) + 같은 교수 족보 S2(김지은 「감염성 질환의 병리 1·2」 2020–2025, 27쪽). 병리 2 범위 문항은 참고로만 쓰고 병리 1 범위로 한정한다.
- 결과: 다층 개념 트리(최상위 소수, 2층 이상), 분류·원인·비교·순서 등 관계, root/branch 구조 문제와 leaf 개별 문제, 원본 대조·독립 정답 검수(보완 최대 3회).
- 격리 로컬에서 트리·구조 문제를 사용자에게 보여 준다. 운영 등록·공개는 별도 승인.

## 근거·미정 사항
- 모델: Codex CLI gpt-6.1-sol (사용자 선택 2026-11-08). 하위 프로세스로 실행, 이 대화 컨텍스트로 생성하지 않는다.
- 트리 방식: Map에 부모 칸 추가 (사용자 선택 2026-11-08).
- 외부 전송·생성·검수는 단계별 명시 승인 후 실행한다(과거 승인은 다른 강의 자료라 적용하지 않는다).
