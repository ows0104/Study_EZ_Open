# 캘린더 회독 줄 색: 예습 연하게·복습 진하게·족보 연한 빨강

## 문제와 사용자 효과
사용자 2026-11-25: 「캘린더에서 예습 퀴즈 색깔을 조금만 연하게 하고, 복습 퀴즈 색깔을 조금만 진하게 하고,
족보 회독 색깔을 시험 표시하는 연한 빨간색으로 바꿔줘.」

## 범위와 성공 기준
- 예습 퀴즈 완료 토막(`.readline i.rl-pre.is-on`): 두 번째 색 100% → 75%.
- 복습 막대 채움(`.meter > span`): 메인 색 28%(`--accent-line`) → 42%.
- 족보 회독 토막(`.readline i.rl-jokbo`): 진한 회색 → 시험 칸 테두리색 `#f3b0b2`.
- 테두리·크기·그리는 조건은 그대로.

## 근거·미정 사항
웹 표시만. 서버·DB·API 변경 없음. 시험 칸 바탕색 `#fdeeee`는 5px 토막에서 거의 안 보여 테두리색을 썼다.
