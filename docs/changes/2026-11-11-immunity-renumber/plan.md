# 감염과 면역 이동 12강의 run ID를 현재 시간표 번호로 — Implementation Plan

## 순서

1. `scripts/immunity_renumber.py`(새 파일)를 만든다. 11-05 도구의 스냅샷·잠금·영수증 틀을 다시 쓴다.
   - 기본 실행은 읽기만 한다. 운영 DB와 R2의 현재 모양을 읽어 옮길 표를 출력한다.
     - 표마다 행 수, 미코·무산소 행별 판정, R2 복사 목록이다.
   - `--copy-r2`: R2 객체를 새 경로로 복사하고 해시를 확인한다. 지우기는 없다.
   - `--apply --database local|production`: R1을 한 트랜잭션으로 적용하고 영수증을 남긴다. dev gate가 필요하다.
   - `--reverse --previous-receipt`: 영수증으로 되돌린다.
   - `--local-runs`: R3의 로컬 파일을 옮긴다. 사본을 먼저 남긴다.
2. `data/timetable/identities/`에서 12강의를 지우고, `runner/filenames.py`·`runner/ahead.py`가 빈 별칭에서도 동작함을 검사한다.
3. 검사
   - `tests/scripts/test_immunity_renumber.py`: 격리 SQLite에 운영과 같은 모양의 데이터를 만들어 확인한다.
     - 맞바꾸기 결과, 다른 강의 불변, 왕복 바이트 동일
     - 진행 중인 작업이나 애매한 판정이 있을 때 멈춤, 키 겹침이 있을 때 멈춤
   - `tests/runner/test_timetable_identity.py` 갱신
4. review와 release를 쓴다. 데이터 전용 후보를 고정한다.
5. **적용(사람 승인 뒤)**
   1. 아데노 Main-Quiz가 끝나면 러너를 끈다.
   2. 운영 읽기 판정표를 사용자에게 보인다.
   3. R2를 복사하고 DB에 적용한다.
   4. 로컬 runs와 SQLite를 옮긴다.
   5. 러너를 다시 설치·실행한다.
   6. 화면을 확인한다.

## 위험·복원

- **DB**: 영수증으로 조건부 역적용한다. 다른 강의 314개의 지문은 사전·사후로 대조한다.
- **R2**: 옛 객체를 남기므로 키만 되돌리면 된다.
- **러너**: 적용하는 동안 꺼 둔다. 옛 별칭 파일을 가진 러너가 다시 돌면 맞바꾼 행을 덮어쓰기 때문이다.
- **학생**: 이미 받은 Anki 덱은 그대로다. 옛 번호 북마크는 상대 강의를 연다.

## 승인할 범위

- 코드·도구·검사 작성은 이번 승인으로 진행한다.
- 운영 DB와 R2 적용은 판정표를 보인 뒤 따로 승인받는다.
