# 목표 중요도 근거의 같은 쪽 중복 제거 — Spec

- `studyez_contracts/bank/importance.py` `target_axes`: 근거 한 줄(`evidence[]`)의 `refs`에서 정확히 같은 참조를 지운다. 같음은 정렬된 JSON으로 판단한다.
  - 쪽 목록이 다르면(`[23,35]`와 `[35]`) 둘 다 남긴다.
  - 포인트 표(/2·/3)와 문항 표(/4)가 같은 함수를 쓴다.
- 출제 출력의 검사는 바꾸지 않는다. 모델에게 다시 묻지 않으므로 시간이 늘지 않는다.
- 서버의 결과 검증도 같은 계약을 쓴다. 그래서 API가 먼저 배포되어야 새 러너 결과가 받아들여진다.
