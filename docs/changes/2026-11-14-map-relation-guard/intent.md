# Main-Quiz 지도 관계 누락 검사

## 문제와 사용자 효과
운영 Main-Quiz 「장내세균;기회감염균, 장병원성균(김동현)」(감염과 면역/261105_03, revision
`auto-2676085648a542a28b2b83f783f97865`)은 184문항 중 69문항만 과제다. 검수 `ok`인 107문항(최초 웹 출제 60, 추가 47)이
`no-relation`으로 지도에 못 붙어 학생에게 보이지 않는다. 운영판 28편의 나머지는 0~11%다(2026-11-14 운영 DB 읽기 전용 대조).

원인:
- `normalize`가 만든 지도의 관계 84개가 계층(`classification`, 제공 parent_id) 58개와 갈래 연결 26개뿐이다.
  정상 편에 있는 「제공 포인트와 원본의 해당 회상 사실을 연결」 관계가 0개다(같은 교수 261105 장내세균 일반편 112개).
- 방향 138개 중 37개는 계층 관계만, 75개는 4개 이상 방향과 똑같은 내용 관계 묶음을 가진다. 다른 33개 v4 실행은 각각 최대 3개, 0개.
- 배치 정책 `review-relations/1`은 문항 검토가 적은 관계로만 과제를 만든다. 예: D007 「Indole 검사의 확인 대상」에는
  RH005(계층)·R002(E. coli IMViC ++--)·R025(Proteus 감별)만 붙어, 같은 내용을 묻는 Q007의 검토가 관계를 고르지 못했다.
- `v4-brief-fix`는 기계적 결함이 없어 지도를 그대로 넘겼고, 조립 뒤에도 과제 0개만 멈추므로 58% 미배치가 게시됐다.

같은 구멍은 정상 편에도 있다. 운영판 나머지 27편에서 검수 `ok` 문항 125개가 같은 이유로 빠졌다.
배치는 문항 검토가 적은 관계로만 하고, 보충 단계(목표 밖 문항 → 새 포인트·목표)는 범위 점검이 한 번이라도 본 문항을
「검토가 붙일 것」이라며 건너뛴다. 검토가 관계를 적지 않으면 두 단계 사이로 빠진다. 이는 사용자 원칙
「포인트·방향 판정이 문항을 학습 경로에서 빼면 안 된다」(출제포인트는 누락 점검표)와 어긋난다.

## 범위와 성공 기준
- 검수 `ok`이고 중복 합침이 아닌 문항은 모두 과제가 된다. 붙일 곳이 끝내 없으면 게시 전에 멈추고 보고한다.
- normalize 직후 내용 관계가 없는 방향을 찾아 기존 `brief-fix`(1회)로 보낸다. 고친 뒤에도 많이 남으면 비싼 단계 전에 멈춘다.
- 정상 편(운영판 27편)의 지도·결과는 바뀌지 않는다. 기존 문항·학습 기록은 건드리지 않는다.
- 병합·러너 재설치 뒤 261105_03을 다시 요청해 새 판의 미배치가 기준 이하인지 확인한다(별도 승인).
