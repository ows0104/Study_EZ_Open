## 배포 후 확인·롤백·필요한 사람 승인
현재 명시적 구현 승인 범위의 로컬 UI. 코드 검증이 의학 검수나 학습 효과 검증은 아니다. 10묶음 밖 전체 강의 적용은 미완료. 운영 적용은 별도 작업이다. 복원 시 새 시범 파일과 추가 실행 명령·제외 규칙만 되돌린다. 실행 종료는 시범 Vite 프로세스만 대상으로 한다.
