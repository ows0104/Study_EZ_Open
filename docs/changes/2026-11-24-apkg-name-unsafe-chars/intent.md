# 예습 덱 파일 이름에서 Windows 금지 글자를 뺀다

## 문제와 사용자 효과
- 2026-11-23 23:10 예습 덱 261125_07 암면역(작년 짝 251126_15)이 덱 빌드에서 멈췄다.
  - 오류: `OSError: [Errno 22] Invalid argument: '…\[261125_07] 암면역((분반) A: 김태민 (분반) B: 김범석) 예습.apkg'`
  - 모델 단계(설명본·반드시 알 것·카드·재현 검사)는 모두 끝났고, 마지막 `.apkg` 쓰기만 실패했다.
- 원인은 CBL·TBL 시간표의 교수 칸이다.
  - 교수 칸은 「(분반) A: 김태민 (분반) B: 김범석」 꼴이다(서버 `naming.py`가 일부러 이 꼴로 둔다).
  - `runner/deck.py`의 `deck_node`는 제목만 `RE_FS_UNSAFE`로 거른다. 교수 꼬리는 그 뒤에 거르지 않고 붙인다.
  - 그 마디가 그대로 파일 이름(`apkg_name`)이 되어 `:`가 들어간다.
- 전에도 같은 일이 있었다. 251104_01(TBL)은 덱 이름에 `:`가 든 채로 나갔고, 파일 이름은 손으로 `[261103_01] TBL 예습.apkg`로 줄였다.

## 범위와 성공 기준
- `apkg_name`이 마디에서 `RE_FS_UNSAFE` 글자를 빼고 공백을 하나로 줄인다.
- 덱 이름(Anki 마디)은 바꾸지 않는다.
- 261125_07은 `--resume`으로 덱 빌드 단계만 다시 돌아 덱이 나온다. 모델 단계는 다시 돌지 않는다.
