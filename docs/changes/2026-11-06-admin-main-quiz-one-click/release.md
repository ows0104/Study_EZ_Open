# Review / release candidate
Main Quiz 사이드 패널에서 구형 문제은행 링크·재검수 패널을 제거했다. 학습과 문항 검토는 유지했다. 생성 주 버튼은 자동 웹 전송을 시작하고 기존 수신·CLI·업로드 경로를 사용한다. 실패 재개는 같은 requestId/input/authoring을 보존한다. 조회 전 실행·빠른 중복 클릭을 차단하고 조회 실패 재시도 및 강의별 keyed state를 적용했다. 수동 파일 전달은 복구 항목으로 접었다.

검사: web-build(타입 및 Vite 프로덕션) 성공, web-main-quiz 10/10 성공. 최초 build 뒤 검사 추가로 지문이 달라져 최종 동일 지문으로 재검증했다. git diff --check 통과. 기존 root-generation 브라우저 검사 버튼 선택자만 갱신했으며 해당 라이브 서버/모델 E2E는 이번에 실행하지 않았다. 실제 모델 호출·운영 콘텐츠 업로드는 실행하지 않았다.

검토: 서버 API/생성기/프롬프트/DB 변경 없음. 제거한 BankAdmin은 중복 UI였으며 원본/은행/학습 데이터는 수정하지 않았다. 기존 문항 검토 링크를 보존했다. 새 시범 공개 범위 및 최대3회 수정은 기존 정책대로다. 현재 지도·포인트 추출은 원본 전용 단일 CLI 호출이다. 각각 별도 호출·병렬 실행을 구현했다고 표시하지 않는다. GuidePage 수정은 Claude UI 세션에 버튼명 Main Quiz 만들기로 전달한다.
