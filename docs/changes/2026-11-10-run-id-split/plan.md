## 변경 범위·대상 파일·순서

## 검사 명령과 성공 조건
- `python -m pytest tests/runner/test_timetable_identity.py -q` 통과, 수정 전 코드에서는 새 검사 2개 실패.
- `python -m pytest tests/runner -q` 통과(로컬 `.venv`가 필요한 바로가기 검사 1개는 환경 사유).
- 실제 SynologyDrive 필기 전체 전후 run ID 대조: 바뀌는 것은 의도한 2개뿐.
