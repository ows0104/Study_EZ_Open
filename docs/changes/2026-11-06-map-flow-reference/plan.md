# Map 흐름 예시를 반영한 별도 프롬프트 복사본 — 구현 계획

## 변경 범위·대상 파일·순서
별도 worktree/브랜치 codex/map-flow-reference에서 고정 커밋 59b6b405의 Map 지시문을 읽어 map-extract-reference.md를 작성한다. 추출 본문과 title/core_facts/relation 작성 설명에 예시의 표현 방향을 간결하게 반영한다. 기존 시범이 쓰는 파일은 수정하지 않는다.

## 검사 명령과 성공 조건
prompt-review: 기존 /2 JSON 예시와 새 복사본의 예시 동일성, 고정 /2 스키마 유효성을 검사하고 git diff --check를 실행한다. 추출 지시의 개념 구성 역할·간결함·출제/점수 미혼입은 수동 검토한다. 별도 모델 호출/웹/서버 통합 검사는 없다.

## 위험·복원·승인할 범위
현재 사용자의 별도 복사본 작성 선택을 구체적 승인으로 적용한다. 기존 시범 입력과 공용 출력 형식은 유지한다. 복원은 새 복사본과 이 변경 기록만 대상으로 하며 시범 자료/원장은 보존한다. 자동 회수·운영 배포는 포함하지 않는다.

## 짧은 지시문 실험

개발용 short_map_experiment.py를 이 변경 폴더에 작성한다. prepare는 고정한 원본·SHA·텍스트/전체 페이지 PNG·짧은 요청문·원래 /2 스키마를 별도 실행 폴더에 보존하며 모델을 호출하지 않는다. run은 자료 선택 및 OpenAI Codex/GPT 전송 답변 후 명시적으로 1회 실행한다. started/실패 상태와 원문·사용량·파일 영수증·완료 여부를 보존하고 자동 재시도하지 않는다. 입력/원본 불변·출력SHA·JSON스키마·출처ID/쪽수/개념참조를 확인한다. 실제 JSON에서 결정적으로 로컬 미리보기를 생성한다. 검증 실패나 생물학 콘텐츠 제한은 보류하며 공급자 제한을 우회하지 않는다.

원본 준비와 실행의 사용자 승인 근거를 구별한다. 현재 실험 요청을 준비/도구 작성에 적용하고, 자료+전송 질문 답변 전에는 모델 호출을 시작하지 않는다. 기존 감염 강의 시범/서버 요청548/학습 상태는 변경하지 않는다.
