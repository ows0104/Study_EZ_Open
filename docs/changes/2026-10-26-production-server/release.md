운영과 후보의 OpenAPI 130경로/스키마 동일. 환경 일반값 및 비밀값 일치 확인(값은 기록하지 않음).
웹의 로컬 테스트 인증 분기를 DEV 전용으로 보완하며 서버 인증 정책은 변경하지 않는다.
DB 스키마·문항·학습 기록 변경 및 커밋/푸시 없음. 서버 다음 웹 순서로 고정 후보를 게시한다.
사후 확인: 실제 ready revision과 100% 트래픽, health/CORS/익명 및 잘못된 토큰 차단, 공개 웹 응답.

복원: release-config.json의 이전 서버 revision으로 트래픽 복원. 데이터 역변환은 없다.
현재 사용자의 실제 운영 배포 요청을 이 고정 후보에 적용한다.
