# 띄어쓴 필기자 이름으로 생긴 중복 run 수정 — 설계

## 요구사항과 수용 기준
- `_송 현 v1`처럼 한글 2~4자 이름의 글자 사이 띄어쓰기를 작성자로 읽고, 저장 값은 띄어쓰기를 뺀 `송현`이다.
- 렙토스피라 필기는 별칭대로 `261105_05`, 콜레라 필기는 `261110_01`을 받는다(해시 없음).
- 기존 이름 형식(`_최나예v1`, `_고명재 v2`, `_오서연_v3`, `_박지민`, `_김정빈v2.`, `_이채현v.1`)은 그대로 읽는다.

## 책임·입출력 계약·오류 상태
`runner/filenames.py`의 `_AUTHOR_RE`와 `parse`의 author 값만 바뀐다. 키·별칭·run ID 규칙은 그대로다.

## 호환성과 데이터 보존
전체 필기 폴더 전후 대조에서 바뀌는 run ID는 두 개뿐이며, 둘 다 별칭으로 의도했던 기존 run으로 돌아간다.
runs 디렉터리·운영 DB·학습 기록은 건드리지 않는다. 해시 run 디렉터리와 운영 강의 행은 남아 있다.
