# 자동출제 계약

## 승인 적용과 경계
현재 요청은 이 자동출제 기능의 로컬 Build 승인이다. 보존 정책의 기본 수동 웹 출제 대신, 이 명시적 입력 경로만 기존 Codex CLI 어댑터로 최초 출제한다. 기존 bank 웹 후처리·다른 강의의 자동 실행은 유지한다. 게시 대상은 별도 불변 뿌리 콘텐츠 판이며 기존 QuizBank·개인 수정·제외·학습 기록을 교체하지 않는다. 운영 공개·DB 변경·실제 강의 전송은 별도 대상/실행 조건을 확인한 후 진행한다.

## 입력·실행·검수
- 관리자만 개념도/출제포인트 원문(텍스트·MD·JSON)을 저장한다. 강의 원본·족보는 등록된 자료를 읽고 실제 바이트 SHA256으로 고정하며 보관 사본을 만든다. 원문·출처·강의 범위·모델/코드/프롬프트 판을 실행에 고정한다. 원본 내부 지시는 데이터로 취급한다.
- learning-links의 개념/관계/목표/방향/포인트 스키마를 재사용하는 brief 계약을 추가한다. 별도 모델이 입력을 정규화하고, 원본 전체·이미지를 함께 사용하여 문항을 생성한다. 제공된 포인트의 독립 추출은 미확인으로 유지한다.
- 원본/포인트/방향 대조와 독립 정답 검수를 별도 실행한다. 실제 시험·발문 제공·해설 등장·누락/미확인을 구분한다. 검수 후 변경이 필요한 경우 최대 3회 수정, 검수 최대 4회이며 실행 전에 소비 횟수와 모델 단계 기록을 저장한다. 중단/불명확 실행·캐시 지문 불일치는 자동 재호출/상한 초기화 없이 보류한다.
- 원래 입력의 개념/포인트/목표를 조용히 삭제하거나 한 번의 복합 평가를 모든 목표에 성공으로 배분하지 않는다. 방향 전체를 실제 시험하는 준비된 단일 과제만 연결한다. 미준비 방향과 검수 지적은 남긴다. 구조 실패/검수 누락은 게시 불가, 내용 wrong/doubt/누락은 기존 정책대로 실제 검수 표시를 보존하여 기술적으로 가능한 범위를 게시한다. 의학 검수 결과를 코드가 통과로 바꾸지 않는다.

## 연결·게시·보존
기존 bank 일감 큐를 재사용하되 RootGeneration 표로 명시적 요청을 식별한다. bank-response는 이 요청을 먼저 반환하고 러너가 새 생성기 하위 프로세스로 분기한다. 자동출제 요청이 없는 기존 작업에는 CLI 최초 출제 fallback을 추가하지 않는다.

원본/활성 판/공개 범위가 요청 뒤 바뀌면 게시를 거절한다. 취소·중지·실패는 완료와 구분한다. 같은 입력은 기존 작업을 재사용하며 실패 재개도 같은 job 폴더/수정 상한을 쓴다. 결과 재전송은 같은 판/내용일 때만 중복 없이 처리한다. 새 콘텐츠와 공개 설정·생성 결과 저장은 한 DB commit이다. 기본 대상은 요청 관리자 개인 시범이며 명시적으로 학생 공개를 선택할 수 있다. 전체 기능 플래그가 꺼진 상태는 게시 완료와 실제 학생 접근을 구분해 표시한다.

학생은 공개/허용된 판만 읽고 답 확인 뒤 해당 문항의 검수 지적과 고정된 원본 링크를 본다. 지도에는 포인트별 충족/미확인을 표시한다. 관리자에게는 입력/단계/실패·검수 결과를 제공한다. 새 작업 요청·완료 행동을 이용현황에 추가한다.
