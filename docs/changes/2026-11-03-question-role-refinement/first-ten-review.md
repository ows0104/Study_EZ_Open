# 첫 10묶음: 질문 역할 검토

2026-11-03 대화에서 수정한 첫 학습 10묶음 기준이다. 아래 번호는 원래 D01–D10이 아니다. 10번째는 D45이며, 복수 소문항이 있는 묶음을 원자 문항 10개로 세지 않는다. 의학 답안을 새로 작성하거나 원래 CLI 결과를 수정하지 않는 교육 설계 메모다.

| 묶음 | 원래 초안 참조 | 질문 형태 | 학습 역할 | 누설·범위 검토와 다음 작업 |
|---|---|---|---|---|
| 1 | D01·D03 | 수용체 계열 분류 → 기전 비교 | 방향 잡기 → 연결 확장 | 계열명·개수를 먼저 주지 않는다. 계열 회상과 신호 방식 회상을 분리해 기록한다. |
| 2 | D02 | 위치 나열 → 예외 연결 | 분포 조망 → 통합 | 처음부터 부위 목록을 주면 위치 회상은 시험하지 않는다. 대표 위치의 인정 범위를 정하고 누락별로 안내한다. |
| 3 | D03 | 부위→수용체 연결 → 작용 흐름 | 개별 연결 확장 | 탈분극·수축 경로를 발문에 미리 쓰지 않는다. 앞 문항에서 본 정답의 즉시 반복을 독립 회상으로 과대평가하지 않는다. |
| 4 | D04 | 개입 지점 나열 → 특정 물질의 위치 연결 | 과정 조망 → 연결 확장 | 단계 이름을 먼저 나열하지 않는다. “개입 지점”의 범위가 막연하므로 과정 재구성과 개입 위치 질문의 순서를 검토한다. |
| 5 | D05 | 작용 방식 분류 → 표적·인과 | 방향 잡기 → 연결 확장 | 직접형·간접형 이름을 주고 표적만 묻는 과제와, 방식 자체를 떠올리는 과제를 구별한다. |
| 6 | D06 | 화합물군 분류 → 대표 예 연결 | 방향 잡기 → 구체화 | 합의 발문: “직접형 콜린수용체 흥분제는 어떤 화합물군으로 나뉘는가?” 분류 기준은 남기고 “강의에서”와 답 개수는 뺀다. |
| 7 | D07 | 결합·가역성 기준의 분류 → 경계 판단 | 방향 잡기 → 구별 | 기준까지 숨겨 여러 분류가 가능한 모호한 질문으로 만들지 않는다. 집단 이름은 제공하지 않는다. |
| 8 | D08 및 초안 치료·진단 관련 부분 | 용도 나열 → 각 용도의 작용 연결 | 초기 범위 조망 / 후기 통합 회상 | 질환·상태와 생리 작용이 섞인 기존 답 범위를 먼저 정리해야 한다. “치료 또는 진단에 활용되는 질환·상태”라는 답 단위로 설계하되 인정 범위를 자료와 대조한 뒤 확정한다. 모든 콜린성 약물이 모든 용도에 쓰인다는 뜻으로 읽히지 않게 한다. |
| 9 | D09·D11·D12 | 비교할 특성 나열 → 구조·특성 연결 | 비교 틀 조망 → 세부 확장 | 선택성·분해라는 축을 주면 축의 존재 회상을 시험한 것이 아니다. 반대로 맥락을 모두 없애 무제한 특성을 요구하지 않는다. |
| 10 | D45 | 치료 약물 나열 → 표적 비교 | 치료 연결 회상 → 통합 | 약물 이름을 먼저 주면 치료제 존재 회상을 확인할 수 없다. 이 묶음에 포함되지 않은 중독 증상 등의 선수 연결을 전체 경로에서 확인한다. |

## 모든 묶음에 적용할 검토 순서

확인할 연결 → 출발 단서와 답 범위 → 발문·제목·앞 답에서 이미 제공한 연결 → 도움 없는 첫 질문 → 모를 때 설명 → 세부 후속 질문 → 항목별 확인/미확인.

설명은 학습을 위한 것이며 회상 성공이 아니다. 초기 목록 노출·초기 회상 시도·후기 통합 회상을 별도로 취급한다. 한 연결을 여러 단계에서 사용해도 필요 없는 중복 문제는 만들지 않는다.
