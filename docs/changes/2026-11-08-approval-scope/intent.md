# 사람 승인을 되돌릴 수 없는 작업으로 좁히기

## 문제와 사용자 효과
개발 루프가 모든 작업에서 구현 계획 승인과 배포 승인을 따로 묻게 되어 있어, 사용자가 같은 허락을 반복해서 내린다.
사용자 지시(2026-11-08 채팅): "저것도 정말정말 필요하고 비가역적인 것만 하자."
("저것"은 CLAUDE.md의 Implementation Plan(사람 승인)·Deploy(중요 승인) 단계를 가리킨다.)

## 범위와 성공 기준
- 사람에게 따로 묻는 작업을 한 목록(docs/development/README.md 「사람에게 묻는 것」)으로 정하고, 다른 문서는 그 목록을 가리킨다.
- 그 밖의 일(일반 구현, 격리 검사, 브랜치·PR, 되돌릴 수 있는 코드 배포)은 사용자의 작업 요청을 근거로 끝까지 진행한다.
- 문서만 바꾼다. development.py·deploy.ps1의 근거 기록·검사 장치는 그대로 둔다.

## 근거·미정 사항
- 목록의 항목은 CLAUDE.md 「보존·승인」과 collaboration.md 「별도 승인이 필요한 작업」에 이미 있던 것을 모았다.
- 함께 작업하는 HungryPotato01 세션들도 이 규칙을 따르게 된다.
