# Main-Quiz 강의 문항 전체 보기

## 문제와 사용자 효과
사용자 요청(2026-11-23 채팅): 「한 강의의 퀴즈문제를 쭉 한번에 볼 수 있는 곳이 있으면 좋겠어. 검색, 검토, 편집할때도
쓸 수 있게. 문제, 답, 유형, 중요도, 난이도, 참고슬라이드 등등. 참고슬라이드는 로딩이 오래걸릴 수 있으니까, 페이지 번호만
적어두고 누르면 불러오도록하면 될듯.」 이어서 「아 난이도는 뺴도 될듯」.

지금 Main-Quiz 문항은 풀이 화면에서 한 문항씩만 보인다. 옛 Quiz Bank에는 「전체 문제」(`/bank/:s/:r/all`)가 있었지만
Main-Quiz 판은 볼 곳이 없다.

## 범위와 성공 기준
- 공개된 Main-Quiz 강의마다 문항 전체를 한 화면에: 번호·문항 ID·형식·중요도·발문·정답(해설)·참고 쪽 번호.
- 검색(발문·정답·ID)과 거르기(형식·중요도·내 수정본).
- 참고 쪽은 번호만 보이고, 누르면 그 문항의 슬라이드(PDF.js, 기존 풀이 화면과 같은 부품)를 불러온다.
- 편집은 내 계정만: 기존 「개인 수정·제보」와 「내 중요도」를 그대로 쓴다. 문제은행 연결 판은 기존처럼 제보만.
- 쓰는 사람: 그 강의를 볼 수 있는 모든 학습자(사용자 선택 「모든 학습자」).
- 열람은 학습 기록·복습 일정을 바꾸지 않는다.

## 근거·미정 사항
- 사용자 선택(2026-11-23 질문 답): 사용자 「모든 학습자」, 편집 「내 계정만」, 난이도는 처음 「내 기록 기준」→ 뒤이어 「빼도 될듯」으로 뺀다.
- 공용 수정(모든 사용자 반영)은 새 판 + bank_retention이 필요해 이번 범위 밖.
- 내 문제(mine)는 이번 목록에 넣지 않는다(다음에 필요하면 추가).
