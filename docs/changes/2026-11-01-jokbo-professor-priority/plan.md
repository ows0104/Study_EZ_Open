# Implementation Plan

1. 관리 JSON 및 기존 PDF 계획을 읽고 실제 사이트의 해당 과목 강의·자산·은행을 읽기 전용 스냅샷으로 보존한다. 교체 대상의 기존 PDF 로컬 해시를 확인한다.
2. 이 변경 폴더에 독립 빌더·검증·업로드 스크립트를 작성한다. JSON 문항/교수/원본 영역을 기준으로 새 output/pdf/감염과 면역_2026_교수우선 폴더를 만든다. 기존 제작기의 검증된 지면 배치 함수를 재사용한다.
3. 원문·그림 영역 전수 대조, 문항 ID/정답/19개 확인 상태·교수 표기·순서·80개 연결을 검사하고 대표 PNG를 시각 검토한다. 관리 JSON과 이전 PDF는 덮어쓰지 않는다.
4. web/src/lecture/reviewPrompt.ts와 교수 파일명 해석용 작은 공통 모듈을 변경하고 content/prompts/bank/bankPrompt.md 버전을 갱신한다. 예습 경로는 그대로 둔다. 프롬프트 회귀, 웹 빌드, 공용 계약 검사를 실행한다.
5. 리뷰 및 release.md를 기록한다. 현재 사용자의 '정리하여 첨부해주자' 승인은 이 감염과 면역 PDF 제작·jokbo 교체 범위에 적용한다. 검증 후 해당 자산만 API로 교체하고 원격 바이트 및 나머지 기록 보존을 확인한다. 웹 서비스 배포는 별도 후보 검토 대상으로 남긴다.

현재 요청은 구체적인 기능 변경과 자료 첨부의 직접 지시다. 피드백/자동 사건으로부터 승인을 추정하지 않으며 위 범위에 한해 현재 발언을 구현 승인 근거로 기록한다. 복원은 이번 스냅샷의 이전 파일·해시와 기존 upload-plan.json을 사용한다.
