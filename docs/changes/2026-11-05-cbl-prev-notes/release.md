# 미정 CBL 3개 작년 필기 확인과 연결 — 운영 반영 완료

최신 실제 결과는 [운영 반영 기록](deployment.md)을 따른다. 세 첨부의 실제 해시·기존 학습 기록 보존·운영 화면 확인·러너 원상 복원까지 완료했다. 아래 적용 직전 기록은 당시 상태다.

## 코드 리뷰·검증 결과
실제 원본 3개(39/49/46쪽)의 표지·관련 CBL 페이지를 직접 확인했다. 세 사본은 원본과 SHA-256이 같다. 격리된 runs에서 publish/readiness가 모두 2025년 자료 3개를 동일하게 선택하고 나머지 선택·기존 매핑은 그대로인 것을 확인했다. 운영 변경 전 기존 강의 84개·첨부 459개·보호 테이블 10개 보존 검사 통과. 검사 로그는 runs/_development/2026-11-05-cbl-prev-notes에 보관한다. 공통 제품 코드·문항은 변경하지 않았다.

## 배포 대상 버전·순서·데이터 변경
운영 코드 c86e15fb의 기존 첨부 계약을 사용한다. 고정 자료 후보는 approved-plan.json의 세 원본 해시와 251119_15/251126_15/251124_15 입력이다. 사용자 요청에 따라 러너 일시정지 → 세 참고 사본/원본 provenance 및 _pairs 세 키 추가 → 세 강의 preview_source와 notes_prev만 반영 → 실제 바이트·공개 메타데이터·기존 연결/학습 기록 보존 확인 → 원상 재개 순서다. API/웹/스키마 재배포 없음.

## 배포 후 확인·롤백·필요한 사람 승인
‘작년 자료 연결이 미정인 CBL 3개도 확인해서 맞는 작년 필기로 연결해줘.’라는 현재 사용자 발언이 이 세 대상의 운영 자료 연결 승인이다. 같은 승인을 다시 요청하지 않는다. 기존 원본·강의 식별 필드·대화·은행·학습 기록은 보존한다. CBL 전용 필기라고 주장하지 않고 일반 강의+관련 CBL 기출의 예습참고 사본으로 표시한다. 실패 시 스냅샷으로 연결만 복원하고 원본/기록을 삭제하지 않는다. 현재는 적용 직전이며 실제 성공은 후속 영수증으로 기록한다.
