# Main-Quiz 사진 판: 시작할 때 「순서대로/랜덤」

## 사용자 요청 (2026-11-15)

「처음할 때 랜덤으로 섞어서 볼 수 있으면 좋겠어. 지금 순서대로라 맞추기가 쉬워.」
범위 질문에 「사진 문항 판만, 그리고 들어갈 때 순서대로 or 랜덤 선택할 수 있게」.

## 문제

사진 실습 판(261104_05, 141문항)은 시험일이 없어 오늘 계획이 준비된 새 목표 전부이고, 판 문서 순서(병리 1 → 병리 2 → 실습,
주제별로 이어짐)대로 나온다. 같은 주제 사진이 붙어 나와 앞 문항으로 다음 답을 짐작할 수 있다.

## 범위와 성공 기준

- 사진 반입 판(`photo-import/1`)이고 선행 연결이 없는 판에만 시작 화면에 「순서대로/랜덤」(이 기기에 기억).
- 랜덤: 사용자·판·학습일로 고정한 섞은 순서. 칩을 바꾸거나 다시 들어와도 같은 날은 같은 순서.
- 순서대로: 판 문서의 과제 순서.
- 이어 풀 때 바꾸면 아직 안 푼 뒷부분만 다시 놓는다(푼 앞부분·답을 연 지금 문항·되돌리기는 그대로).
- 다른 판: 선택이 보이지 않고 서버도 무시한다(개념 트리 순서 유지). 학습 기록·복습 간격·DB 표는 바뀌지 않는다.
