# 띄어쓴 필기자 이름으로 생긴 중복 run 수정

## 문제와 사용자 효과
캘린더 11 콜레라·캄필로박터·수도모나스 칸의 복습 막대가 둘로 갈라져 보였다.
칸 막대는 그 시간표 칸에 붙은 강의 행 수만큼 그려지는데, 운영 응답에서 이 칸에 강의가 둘 붙어 있었다.

- 11/05 콜레라 칸: `261110_01`(기존) + `261110_01-418f`
- 11/10 렙토스피라 칸: `261105_05`(기존) + `261110_01-a7a0`
- 11/02 감염병의 치료 원칙 칸: `261102_05`(기존) + `261102_05-464e`(김홍립) + `261102_05-e938`(김홍빈)

원인: 필기 `[261110_01]렙토스피라, 매독균, 보렐리아(김현제)_송 현 v1.pdf`의 필기자 이름 `송 현`의
띄어쓰기를 `runner/filenames.py`의 작성자 정규식이 받지 못해 제목에 `_송 현 v1`이 남았다.
그래서 2026-11-05 시간표 변경의 주제 별칭(`data/timetable/identities/2026-2-notes.json`)이 빗나가
날짜 키 `261110_01`이 그대로 쓰였고, 별칭으로 같은 키를 받은 콜레라와 겹쳐 `assign_run_ids`가
두 강의 모두에 해시를 붙인 새 run을 만들었다. 서버는 새 run을 새 강의 행으로 등록해 각 칸에 붙였다.
감염병의 치료 원칙은 같은 교시에 교수 이름이 다른 판(김홍립 오타·김홍빈)이 한때 같이 있어
같은 규칙으로 해시 run이 생겼다. 지금 폴더에는 김홍빈 v2 하나만 있어 새로 생기지는 않는다.

## 범위와 성공 기준
작성자 이름의 글자 사이 띄어쓰기를 받아 제목에서 떼어 낸다. 실제 필기 폴더 전체(4,973개)에서
run ID가 바뀌는 것은 위 두 파일(`-418f`→`261110_01`, `-a7a0`→`261105_05`)뿐이어야 한다.
운영 DB의 중복 강의 행 정리는 이 변경에 들어 있지 않다(사용자 승인 대상).

## 근거·미정 사항
사용자 요청(2026-11-10): "이 강의는 대체 왜 복습 퀴즈 칸이 두 개로 나뉘어져 있는 거야? 몇몇 강의가 이런데, 원인을 찾아서 해결해줘."
운영 중복 행 4개(`261110_01-418f`, `261110_01-a7a0`, `261102_05-464e`, `261102_05-e938`)는 예습 문항이 있는 행이 있어
학습 기록 보존 확인 후 연결 해제/삭제 여부를 사용자가 정한다.
