# 예습 연결 복구와 실패 안내 수정 — 로컬 적용 검토

- 변경: runner/prequeue.py는 해당 강의 매칭/시간표 실패를 보존하며 입력 부재를 단정하지 않는다. runner/ahead.py는 이미 명시 확인한 개별 실습 키만 인식하고 자동 범위와 날짜 경계를 유지한다.
- 검사: 해당 회귀/러너 판정 49개 통과. 전체 러너 557개 통과(실제 러너와 같은 Anaconda, 짧은 격리 tmp 경로). 첫 전체 검사 실패는 샌드박스 임시폴더 권한·Windows 긴 경로·uv Tk 설치 결함이었다. 상세 명령/지문/실패와 성공은 state.json 및 runs/_development 로그에 모두 보존했다.
- 리뷰: 원본 미수정, 정확한 과목/ID 경계, 다른 강의 경고 미전파, 명시 실습만 허용, 날짜 필터 유지와 독립 예습 입력의 충돌 방지를 검토했다. 매칭 임계값과 출제/검수 상한은 유지한다.
- 자료: 2026-11-01 검증표를 재사용해 21개 명시 연결을 추가했고, 정상 연결을 포함한 71강의의 세 소비자 계약을 확인했다. 이 중 동영상 2개는 기존 검증 PDF의 동일 바이트 사본을 독립 입력 ID로 사용하고 원본 출처/해시를 보존한다. 적용 전 감사표는 connection-audit.json이다.
- 승인: 현재 사용자가 계획 및 다른 강의의 동일 복구를 승인했다. 로컬 코드·메타데이터 적용 및 저장 응답 기반 미완료 예습 재실행 범위다. 서버/웹 코드 배포·DB 스키마 변경은 없다.
- 복원: 이 작업의 두 코드 변경과 추가한 pairs 키/입력 등록만 분리한다. 원본·기존 문항·학습/시도/검수 기록은 삭제하지 않는다.
- 운영 실행과 사후 확인은 actual-run.md에 이어 기록한다. 검사 통과와 덱 생성/게시 완료는 구분한다.
