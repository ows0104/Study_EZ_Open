# 러너 창 흐름 순서

## 문제와 사용자 효과
사용자 요청 원문(2026-11-14): 「지금 러너에서 선택 가능한 강의(접힌상태) -> 대기열 -> 현재 실행 중 -> 완료 혹은 실패(로그) 이런식으로 보이면 좋겠어.」

지금 바탕화면 러너(`pythonw -m runner.desktop`)는 위에서부터 실행 중 카드 → 이번 블럭 작업 표(모든 상태가 한 표에 섞임)
→ 접힌 「목록」 탭(하는 거/한 거/할 거/확인 필요/별도 러너 보류) → 접힌 상세 기록 순서다.
작업이 어디서 와서 어디로 가는지 한눈에 따라가기 어렵고, 끝난 작업의 로그는 따로 볼 곳이 없다.

## 범위와 성공 기준
- 창이 작업 흐름 순서로 위에서 아래로 나뉜다.
  1. **시작할 수 있는 강의** — 기본 접힘, 머리에 개수. 시작 가능·보류·중지됨·자료 대기.
  2. **대기열** — 차례 대기 작업을 서버 순서대로 번호와 함께.
  3. **실행 중** — 기존 카드(시간 비례 막대·구간·완료 예상) 그대로.
  4. **완료 · 실패** — 실패가 먼저, 행을 고르면 그 강의의 로그 끝부분이 아래에 보인다.
- 각 구역은 자기 상태에 맞는 버튼만 보인다(시작/재개 · 중지 · 취소 · 다시 시작).
- 이미 있는 기능(자동 시작 카운트다운·전체 일시정지·이전 블럭 기록·상세 기록)은 그대로 남는다.

## 근거·미정 사항
- 다른 세션이 등록한 일괄 작업(`runs/status-jobs`)과 별도 러너 보류는 이 창의 강의 작업이 아니므로 네 구역에 섞지 않고,
  기존 「목록」 탭을 상세 기록 옆 접힘으로 남긴다(2026-10-17 한 거/하는 거/할 거/확인 필요 지시 보존).
- 읽기 전용 상태 창(`scripts/runner-status.ps1`, `StatusWindow`)의 모양은 바꾸지 않는다.
