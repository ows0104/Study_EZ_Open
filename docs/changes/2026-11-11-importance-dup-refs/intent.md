# 목표 중요도 근거의 같은 쪽 중복 제거

## 문제와 사용자 효과
2026-11-11 감염과 면역 아데노·폭스(운영 261113_01, 생성 `6e5c581a…`)의 Main-Quiz 생성이 96분 동안 모든 단계를 마쳤다.
그런데 조립에서 `review.targets[24].importance.clinical.evidence[2].refs: duplicate entries`로 보류되어 공개되지 않았다.

원인은 출제 단계가 쓴 문항별 중요도 근거(`importance_basis`)다. 한 근거 안에 같은 참조를 두 번 적었다.
- 예: `{S1, [15]}`가 두 번, `{S1, [23,35]}, {S1, [35]}, {S1, [35]}`
- 저장 파일에서 4곳이다: v4-add-0, v4-fix-2-0, v4-fix-3-0, v4-fix-4-0
- `importance.target_axes`는 이 참조를 그대로 목표 중요도 근거로 옮기고, 검토 문서 검사는 반복 항목을 거절한다.

인용 쪽 맞춤(#92)과는 무관하다. 그 단계 바로 뒤라 같은 자리에서 보였다.

- `target_axes`가 목표 근거 한 줄의 참조를 처음 나온 순서대로 한 번씩만 남긴다.
