# 족보 풀이 화면 개편 — 예습 퀴즈처럼

## 사용자 요청 (2026-11-14 채팅 원문 요약)

- 「족보 푸는 페이지에서 문제 가독성이 너무 떨어져. 문제가 너무 가로로 길고 줄간격이 좁은 느낌? 한눈에 더 잘 들어올 수 있게 바꿔줘.」
- 「풀고 나서 도착하는 페이지가 좀 이상해. 뒤로가기 버튼도 없고 뭔가 막힌 느낌이야. 맨 마지막에 오답노트에 넣기로 표시한 문제를
  다 보여주면서 끝냈으면 좋겠어 (예습퀴즈처럼). 전체적으로 예습퀴즈의 느낌을 많이 따왔으면 좋겠어.」
- 「틀림/좁혀서 맞힘/헷갈림도 너무 과한 거 같아. … 괜찮음/모르겠음/주의 정도의 3단계로 해줘. 주의는 맞긴 했는데 혹시 나중에 볼 수도 있다 정도의 느낌이야.」
- 「오답노트 페이지에서도 강의별로 분류하는 기능이 아예 없어서, 만들어줬으면 좋겠어.」
- 「맨 위에 정답 보기 버튼은 왜 있는거야? 어차피 문제별로 정답 보기 버튼 따로 있잖아. 전체 정답 보기 버튼만 만들어주면 돼.」

## 범위

웹 족보 풀이(`/jokbo/:eventId`)와 오답노트(`/wrong-notes`), 이용방법 안내. 서버·DB·족보 문서는 그대로.

## 성공 기준

- 문제·선지가 좁은 폭(한 줄 40자 안팎)과 넉넉한 줄간격으로 보인다.
- 답을 본 뒤 모르겠음/주의/괜찮음 중 하나를 골라야 다음 문제로 넘어간다(예습 퀴즈의 헷갈려요/이해했어요 독).
- 끝 화면에 뒤로가기·다시 풀기·마치기가 있고, 이번에 오답노트에 넣은 문제가 답·해설과 함께 펼쳐져 있다.
- 오답노트를 강의별로 거른다. 풀기/정답 보기 토글이 없고 「전체 정답 보기」 하나만 있다.
