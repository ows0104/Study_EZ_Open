# 실행 계획

현재 요청을 새 콘텐츠 설계 초안 작성 승인으로 적용한다. 기존 원본 파일·렌더 지문을 확인하고 족보 원본의 관련 지면을 준비한다. 원본 우선으로 한 차례 별도 Codex CLI 의미 작성(기본 모델, 파일 읽기 전용)을 수행하고, 이후 옛 두 첨부/은행은 비교한다. 기존 15목표/69문항/8경로를 새 구조의 기준으로 삼지 않는다. 단일 작성 세션이므로 독립 포인트 검수 완료라 부르지 않는다. CLI 출력 원문과 로그를 보존하고 보고서·질문 ID·출처 및 입력 전후 지문을 확인한다. 기존 검수 잔여 0회를 유지하고 운영 코드/프롬프트/DB는 변경하지 않는다. 소요 자료는 원본 필기 PDF/렌더, 합본 족보 관련 지면과 텍스트, 기존 로컬 bank.json, 사용자 첨부 2개, 현재 합의 설계다. 이번 호출은 과거 단회 승인 재사용이 아니라 현재 새 작성 요청 범위다.

검사 source-preservation: 전용 check_inputs.py가 명시한 입력 지문과 출력/문항 참조 존재를 확인한다. 의학 검수 통과를 대신하지 않는다. 실패와 미확인은 그대로 남긴다.
