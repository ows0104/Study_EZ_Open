# Main-Quiz 강의별 Claude 출제 경로

## 문제와 사용자 효과

감염과 면역 261109_02 「레지오넬라, 리스테리아, 바실루스(석승혁)」 Main-Quiz(generation `d4b5c7e61ce04cff97feb77c89175728`)가
생성기 `normalize` 단계에서 OpenAI 콘텐츠 제한으로 세 번 연속 거절됐다(11-12 07:10·07:47, 11-14 13:58).
같은 강의의 앞 단계(지도·포인트·문제은행·대조·보완, Codex 세션 6개)는 통과했다. 조사 기록:
`runs/_development/2026-11-14-261109_02-normalize-retry/content-restriction-analysis.md`.

거절 원인 후보는 normalize 첫 입력에 모인 탄저 병원성·독소 기능·노출 경로 요약이다. 같은 입력을 다시 보내도
통과할 가능성이 낮다. 출제 파이프라인의 모델은 Codex(gpt-6.1-sol) 하나뿐이어서, 이 강의는 Main-Quiz를 만들 길이 없다.
웹 출제로 돌려도 후처리 검수가 Codex로 같은 필기를 읽어 같은 거절에 걸릴 수 있다.

원하는 효과: 관리자가 지정한 강의(generation)만 출제 단계 모델을 Claude Code CLI로 돌려, 같은 프롬프트·스키마·
검사·수정 상한으로 Main-Quiz를 완성한다. 다른 강의와 기본 동작은 그대로 Codex다.

## 범위와 성공 기준

범위
- `studyez_llm`에 Claude Code CLI 실행기를 추가하고, 모델 이름(`gpt-…`/`claude-…`)으로 Codex·Claude를 고른다.
- Main-Quiz 생성 경로(root_native_json 단계, root_front 앞 단계, 게시 뒤 근거 보강·선지)가 지정된 모델을 그대로 쓴다.
- 러너가 generation별 모델 지정(`runs/model-overrides.json`)을 읽어 그 작업에만 `--model`을 붙인다.
- 원장·영수증·사용량 기록에 실제 공급자·모델을 정직하게 남긴다. Codex 영수증을 꾸미지 않는다.
- 첫 적용 대상은 261109_02 하나다.

범위 밖
- 기본 모델 변경, 다른 강의 일괄 전환, 웹 화면에 모델 선택 버튼 추가.
- 복구 전용 도구(root_chunked_*, root_plan_repair, root_session_resume 등)의 Claude 지원. 이 도구들은 Claude 모델을 받으면 명시적으로 거절한다.
- 프롬프트·스키마·검수 기준·수정 상한 변경.

성공 기준
- 지정이 없는 작업의 실행 명령·결과·원장은 지금과 같다(기존 테스트 통과).
- 261109_02가 Claude로 normalize부터 게시까지 끝나고, 서버 검증을 통과해 게시된다. 원장·manifest의 model이 Claude 모델로 남는다.
- Claude가 거절하면 지금의 `model_content_restricted`와 같은 보류로 멈추고 자동 재시도하지 않는다.

## 근거·미정 사항

사용자 요청(2026-11-14 채팅, 이 세션):
- 「아니면 똑같은 작업을 네가 대신해줄 수 있어? 파일과 프롬프트 다 있으니까.」
- 두 방법(막힌 단계만 / 이 강의 전체를 Claude로) 제시 뒤 「2번으로 계획 세워줘」

사람에게 묻는 것(docs/development/README.md):
- 강의 자료(필기·족보 PDF 쪽 이미지·텍스트)를 정해진 자동 경로(Codex) 밖의 외부 모델(Anthropic)로 보내는 일이다.
  구현은 계획 승인으로 진행하되, **261109_02 실제 실행은 사용자가 이 강의·모델·호출 규모를 확인한 뒤** 시작한다.

미정
- 모델: `claude-opus-5-5`를 기본으로 제안한다. 사용자가 다른 모델을 고를 수 있다.

  거절되면 그대로 보류하고 보고한다.
- 사용량: 이 강의 한 판은 Codex 기준 단계 50~60회다. Claude 구독 사용량으로 처리하며, 사용 한도에 걸리면 기존처럼 재개 시각을 기록하고 기다린다.
