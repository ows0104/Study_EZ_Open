# 강의 패널 개념 지도 버튼·지도 좌측 상단 뒤로

## 문제와 사용자 효과
개념 지도는 Main-Quiz 화면 안에서만 열렸고, 지도의 뒤로 버튼은 좌측 하단 도구 줄 끝에 있어 잘 보이지 않았다.
지도의 뒤로는 문제(또는 오늘 추천)로만 갔다.
사용자 요청(2026-11-14): 「사이드바의 복습 구역에서 개념 지도도 따로 접근할 수 있는 버튼 만들어줘. 그리고 개념 지도만 뒤로가기 버튼이 문제로만 가고, 좌측 하단에 되게 눈에 안 보이게 있어서 개념 지도도 좌측 상단에 뒤로가기 버튼 만들어줘.」

## 범위와 성공 기준
- 강의 패널(캘린더 일정 패널) 「복습」 줄의 ▶ 복습 퀴즈 옆에 「개념 지도」 버튼. Main-Quiz가 열리지 않은 강의는 흐린 비활성.
- 버튼은 같은 Main-Quiz 화면을 지도부터 연다(`/mainquiz/<subject>/<runId>?map=1`). 이때 뒤로는 연 곳(패널)으로 돌아간다.
- 지도의 뒤로 버튼은 좌측 상단에 다른 학습 화면과 같은 모양(quiz-back)으로 둔다. 좁은 화면에서는 지도 위 첫 줄.
- 기존 진입(오늘 추천·풀이 중 「지도」)의 뒤로 동작은 그대로다(오늘 추천 / 문제).

## 근거·미정 사항
- 사용자가 말한 「사이드바의 복습 구역」은 강의 패널의 「복습」 그룹(`ReviewAction`)으로 해석했다. 좌측 주 메뉴에는 복습 구역이 없다.
