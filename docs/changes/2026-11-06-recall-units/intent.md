# 회상 단위별 문항 설계·검수·분산 충족과 Main Quiz 비교

## 문제와 사용자 효과
사용자는 CNS Q012/Q019/Q032의 과도한 회상량·메타 질문·답이 드러나는 한계 질문을 지적했고, 제안한 추가 지시/검수/충족 코드 동시 수정을 승인했다.

## 범위와 성공 기준
기존 Main Quiz UI를 기반으로 세 문항 범위만 새 기준으로 재생성하여 비교한다. 원래 강의 전체 실행·최대3회 소비·실제 풀이 기록은 보존한다.

## 근거·미정 사항
현재 사용자: “좋아. 그 방향으로 추가 지시랑 검수 기준, 코드의 충족 판정까지 같이 수정해줘. 기존 Main Quiz UI를 기준으로 하고, 수정한 기준으로 저 세 문제부터 다시 뽑아서 비교해보자.” 제안한 구체 문안의 구현 승인이다.
