# 새 생성·학습 파이프라인을 Main Quiz에 통합

## 문제와 사용자 효과
사용자는 비교 실험을 수용하고 새 생성·검수·학습 파이프라인을 기존 Main Quiz UI에 연결해 사이트 Main-Quiz를 대체하도록 요청했다. '뿌리 학습'을 별도 제품으로 노출하지 않는다.

## 범위와 성공 기준
기존 Main-Quiz URL에서 검토·공개·계정 범위를 통과한 새 자료를 우선 사용한다. 기존 은행/학습/개인 수정은 호환 진입으로 보존하며 자동 내용 교체·ID 학습 승계·일괄 재출제하지 않는다. 시작/풀이/맵/생성 UI를 Main Quiz로 통일한다.

## 근거·미정 사항
현재 사용자 사이트 대체 요청 및 담당 범위 답변 “그렇게 범위를 나눠 진행”. 다른 세션은 App/메뉴·캘린더·목록·이용안내/전역 스타일 담당이며 이 작업은 해당 파일을 수정하지 않는다.
