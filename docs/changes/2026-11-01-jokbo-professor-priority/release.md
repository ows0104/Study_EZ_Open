# 족보 핵심 표시·교수 우선순위와 복습 교수 확인

## 코드 리뷰·검증 결과
자료: 관리 JSON의 69단원·850문항에서 강의별 담당 교수 구성을 반영한 74 PDF / 80개 첨부를 생성했다. 전체 원본 영역 1,879곳의 연속성·문자·저장 후 픽셀을 대조했으며 최대 평균 픽셀 차이는 0.0833 미만이다. 원본 정답 831개와 연결 확인 필요 19개를 보존했다. 대표 9지면의 사진·공동 담당·이어지는 쪽·참고 구분·확인 표시를 직접 확인했다.

복습/Quiz Bank: 실제 올해 파일명 교수 확인·예정 담당과의 충돌·교수 미상·필기자 오인 방지·예습 유지 회귀를 포함한 Node 10검사, 공용 계약 6검사, 생성기 14검사와 웹 빌드 통과. 새 helper, reviewPrompt.ts, bankPrompt.md 및 회귀 검사만 수정했다. 은행의 문항·정답·학습 상태를 수정하지 않았다.

웹 후보는 현재 운영 기반 35663e610ed003182e05fddfd828e871336fc389를 별도 폴더에 추출하고 이 작업의 네 파일만 덧씌워 빌드했다. web-source-manifest.json/verify_prepared_web.py로 원본 바이트·변경 파일 및 산출물을 확인했다. 다른 작업의 미커밋 소스는 포함하지 않는다.

## 배포 대상 버전·순서·데이터 변경
자료 업로드는 감염과 면역의 jokbo 80개만 대상으로 한다. 변경 전 강의 80개, 필기 71개 및 은행 0개를 스냅샷으로 보존했다. 올해 필기가 아직 0개이므로 이번 PDF의 정렬은 시간표 기준이며 지면 하단에 명시한다. 자료 교체 전 모든 기존 원격 PDF가 로컬 복원본과 같은 해시인지 확인한다. 교체 후 저장된 바이트와 파일명·MIME·크기를 전수 확인하고, 그 외 자산·강의 속성·은행이 변경되지 않았음을 확인한다. 실제 결과는 upload-result.json 및 upload-verification.json에 기록한다.

웹 후보의 변경은 복습 프롬프트의 실제 파일명 교수 판정 및 Quiz Bank 정본 1.79다. Cloudflare Pages study-ez-open/master/studyez.kr만 대상이고 서버·DB 변경은 없다. 실제 웹 배포는 고정 후보의 중요 승인 이후 release_evidence.py publish-web으로만 한다. 후보의 prepare는 로컬 작업이며 운영 배포를 뜻하지 않는다.

## 배포 후 확인·롤백·필요한 사람 승인
현재 사용자의 “올해 같은 교수님 족보를 더 먼저 우선시하도록 정리하여 첨부해주자”는 이번 과목 PDF 제작·족보 첨부 교체의 승인으로 적용한다. 웹 서비스 배포 승인은 별도로 대기한다. 기존 정책 docs/policies/infection-immunity-materials-2026.md에 따라 관리 JSON·그림·원본·기존 PDF는 보존한다.

자료 복원은 remote-before.json의 80개 기존 PDF 로컬 경로·해시와 이전 answer-audit/upload-plan.json을 사용한다. 웹 복원은 web-release-config.json에 기록한 실제 이전 Pages 운영 배포를 복원한다. 웹 게시 후 postcheck.py가 후보의 HTML/JS/CSS/정본 프롬프트 바이트를 사이트·pages.dev·고유 배포 주소와 비교하고, 읽기 전용 공개/인증 경계 및 자료 조회를 확인한다. 학습 평가를 저장하는 검사는 하지 않는다.
