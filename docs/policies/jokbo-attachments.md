# 족보 정리·첨부의 기본 형식

2026-11-01 사용자 직접 지시: “ㅇㅋ 그럼 앞으로 족보도 이 형식으로 정리해서 첨부해줘.”
사용자가 확인한 감염과 면역 「감염병의 진단」 교수우선 PDF를 기본 형식으로 적용한다.
앞으로 새로 정리·갱신하여 첨부하는 족보에 적용하며, 이미 처리한 다른 과목을 일괄 교체하는 지시로 확대하지 않는다.

## 첨부와 관리 자료

- 실제 첨부는 검증된 PDF 정리본으로 한다. JSON·연결 그림·원본 PDF는 기준/관리 자료로 보존한다. JSON이 없으면 원본의 문항·연도·교수·정답·원본 영역을 보존하는 관리 자료부터 준비한다.
- 문제·보기·사진·표·도식은 원본 모습을 유지한다. 본문을 새로 쓰거나 그림을 텍스트로 대신하지 않는다. 기존 정답·오류 가능성·연결 확인 필요 상태와 중복 원문·문항 식별자를 보존한다.
- 전체 교수 목록 페이지와 별도 표지를 넣지 않는다. 단원명, 연도·해당 연도 교수·문항 번호, 우선/참고, 원본 쪽, 정답/연결 확인 상태만 간결하게 표시한다. 필요한 공용 자료·원본 정답표는 뒤에 보존한다.

## 교수 확인과 순서

- 과거 연도의 담당 교수는 JSON에 보존한 원본 교수 이력을 해당 연도 옆에 표시한다. 자료에 없으면 교수 미상으로 표시하고 추정하지 않는다.
- 올해 담당 교수와 겹치는 기출을 먼저, 다른/미상 교수 기출을 참고로 뒤에 둔다. 각 구분 안에서는 최신 연도부터 배열한다. 참고 기출도 제외하지 않는다.
- 공동 담당 연도는 모든 이름을 표시한다. 올해 교수와 한 명 이상 겹치면 우선하되, 개별 문항의 출제자를 단정하지 않는다. 같은 단원을 여러 강의가 공유해도 올해 교수 구성이 다르면 그에 맞는 순서의 PDF를 첨부한다.
- 복습 퀴즈는 필기자가 올린 실제 **올해 필기 파일명**의 교수로 한 번 더 확인한다. 시간표·족보의 올해 열과 다르면 실제 필기를 우선하고 필기자 이름과 구분한다. 파일명에 없으면 자료의 명시된 담당을 확인하고, 확인되지 않으면 미상으로 둔다.
- 올해 필기가 아직 없으면 시간표 기준으로 정렬했음을 명시한다. 이후 복습 시 실제 필기 교수와 대조해 우선순위를 다시 판단한다. 예습은 기존 올해 대상 교수 판정을 유지하고 작년 필기의 교수를 올해 교수로 대체하지 않는다.

## 첨부 전 확인과 보존

- 원본과 문항 수·식별자·연도·교수·정답/확인 상태·모든 원문/이미지 영역을 대조한다. 최종 저장한 PDF를 렌더해 사진·표·도식, 긴 문항의 이어지는 쪽과 공동 보기, 한글·여백·잘림을 확인한다.
- 사이트 첨부 교체 시 검증한 PDF와 실제 저장 파일의 바이트 해시·파일명·MIME·크기를 확인한다. 이전 PDF와 연결·해시, 관리 JSON·그림·원본, 기존 필기·퀴즈·개인 학습 기록을 보존한다.
- 이 정책은 앞으로의 자료 작업 지침이다. 기존 자동 경로가 이미 모두 이 PDF 형식을 생성한다고 간주하지 않는다. 웹의 복습 교수 확인 규칙은 2026-11-01 사용자의 후속 명시 승인으로 보류를 해제하여 배포했다. 실제 게시·사후 확인 근거는 [웹 배포 기록](../changes/2026-11-01-jokbo-web-deploy/post-deploy.md)에 보존한다.
