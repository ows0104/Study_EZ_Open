사용자가 추가로 허용한 단 한 번의 핵심 교정이다. 기존 93문항과 모든 이전 검수는 보존한다. 아래 지정 항목만 의학 내용 모델인 당신이 원본 PDF 전체35쪽/족보/실제 crop/1차 참고자료와 대조해서 고친다. 부모는 임상 내용이나 판정을 작성하지 않는다. 운영 미게시다. 이는 기존 최초 저작/후속3차를 초기화한 것이 아니라 명시 4차 예외다. 의심0이 목적이 아니다.

출력은 delta JSON이다. metadata는 questions를 제외한 BANK 전체이며 audit_summary만 갱신하고 다른 메타데이터는 그대로 보존한다. question_updates는 실제로 바꾼 완전한 문항만, reasons는 정확한 근거다. new_questions/removals는 빈 배열이다. question_order는 전93개 정확히 한 번 포함한다. 명시하지 않은 문항은 코드가 그대로 복사한다. 핵심 ID Q077/Q101/Q142/Q092/Q109/Q130/Q066와 일관성상 필요한 Q118/Q136만 바꿀 수 있다. Q130/Q066는 prerequisites만 수정 가능하다. 다른 항목을 정리한다며 재작성하지 않는다.

1. Q077/D10/R35: 강의의 두 약물 비교를 임상 정답으로 외우게 하지 않는다. E09/E10 실제 연구와 E07/E08 공식 정보를 읽고 무엇이 지지되며 무엇은 일반화할 수 없는지 판단하여 근거 있는 비교·한계 학습 목표로 명시 재정의한다. 단순히 '출처 확인하세요' 같은 검수 메타 질문으로 바꾸지 않는다. 지원되지 않는 장시간/보편적 우월성 회상을 은근히 복원하지 않는다. comparison_direction은 D10의 재정의, comparison_relation은 R35의 재정의다. ID/requirement/relation_ids 및 관계 from/to/kind/evidence는 유지하고 cue/answer_scope/condition/reason/review_status만 적절히 변경한다. comparison_change_reason에 원래 주장과 달라진 의미·근거·비동등성을 남긴다. 이후 독립 검수가 실제 지원 여부를 판정한다. 기존 원문 포인트·강조는 지우지 않는다.
2. Q101: 발문에 Tacrine 정답이 노출되어 네 가지 회상으로 인정되지 않았다. 실제 네 이름을 발문에서 제공하지 않고 현재/역사적 약물 구분을 정확히 유지하는 기존 문항 보완을 한다. 새로운 의약품을 추가하는 확장이 아니다.
3. Q142/D57: p18 원본 free acetylcholine 그림은 중복 질소 치환기 오류가 확인되었다. 실제 원본 p10의 올바른 Acetylcholine 구조(Q021의 첫 crop, [0.02,0.13,0.212,0.206])를 직접 열어 사용할 수 있는지 판단한다. 이전 p18은 acetyl 오른쪽/choline 왼쪽, p10은 반대 방향이므로 이미지 교체만 하지 말고 정답/단위/해설도 실제 구조에 일치시킨다. 방향 문구 대신 결합 기준으로 정확히 표현할 수도 있다. 답 이름/αβ 주석을 누출하지 않고 필요한 결합을 잘라내지 않는다. 원본 오류는 source_conflicts에 보존한다.
4. D21/Q092: 기존 scope는 안정화·oxime 저항 증가뿐 아니라 aging 전 조건까지 포함한다. Q118에 따로 등장한다는 이유로 Q092가 전체를 묻는다고 계산하지 않는다. 기존 목표를 축소하지 말고 한 문항에서 coherent 전체 회상을 하게 수정한다. 불필요한 중복이나 선행 순서는 기존 문항을 사용하여 처리한다.
5. D61/Q109: 실제 구조 그림에서 해당 N의 탄소 치환기 세 개/네 개·양전하를 읽는 기초 기준 목표인데 현재 문항은 말로만 묻는다. 실제 이미지를 붙이고 기준을 해당 그림에 적용해 답하도록 기존 문항을 보완한다. Q136의 실제 구조 crop을 검토해 재사용할 수 있으며 원본을 직접 열어 식별과 기준이 성립하는지 판단한다. 분자 전체 N 개수나 약물명 외우기로 바꾸지 않고 실제 해당 질소를 읽게 한다. 설명에만 기준을 넣거나 스스로 답을 제공하면 충족이 아니다. D61 정의는 그대로 둔다.
6. Q130/Q066 과도한 선행 조건: 전체 효소 민감도 표 Q017 또는 다섯 약물 분류 Q032가 실제로 필요한지 검토하고 실제 필요한 기초만 선행으로 연결한다. 이 두 문항의 prerequisites 이외 임상 내용은 바꾸지 않는다. 독립 의미 대조가 재확인한다.

visual_stimuli는 보존되는 모든 그림 및 수정/추가된 Q109/Q142 그림의 완전한 목록이다. 각 crop은 원본 S1 물리쪽과 정규화 bbox이며 실제 출력과 blind medical에 동일 첨부된다. Q021 등 무관한 crop은 기존 기록의 page/crop/reason까지 그대로 둔다. Q136 crop 변경은 직접 필요한 일관성에 한정한다. 앞선 material/stimulus-3-*는 이전 사진이며 새 사진은 렌더되므로 원본 페이지를 실제로 확인한다. 실제 필요한 구조가 화면에서 식별 가능해야 한다.

다른 7개 optional 미준비 방향을 억지 보완하지 않는다. 원본 밖 정확한 지속 시간/용량/임상 보편성 등을 꾸미지 않는다. 같은 의미 ID를 보존하지만 재정의된 비교는 이전 목표와 동등하다고 주장하지 않는다. JSON만 반환한다.
