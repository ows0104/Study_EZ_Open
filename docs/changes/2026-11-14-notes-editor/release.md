## 코드 리뷰·검증 결과
- `server -m tests test_notes` 통과(격리 sqlite): indent·toggle open·table rows/header 저장, 다른 종류 값은 버림,
  표 html 버림, 잘못된 표 모양(빈 표·행마다 칸 수 다름·21열·101행·5,001자 칸)·indent 7/-1은 422.
- `npm --prefix web run build`(tsc 포함) 통과.
- 로컬 미리보기(격리 API 8031 + server/local_test_data/notes-editor.db, 운영 DB 미사용)에서 확인:
  - `- ` 목록 → Enter → Tab 두 번 → 3단계 • ◦ ▪, Shift+Tab, 빈 목록 Enter로 한 단계씩 나오기, 0단계 빈 목록 Enter → 글 칸.
  - 번호 1. 아래 Tab → a. b., 다시 나와서 2. 로 이어 셈.
  - Ctrl+Z 두 번(입력 묶음 → 들여쓰기) · Ctrl+Shift+Z 두 번으로 원래대로.
  - Ctrl+D: 하위 포함 복제. Ctrl+Shift+↑: 같은 단계 앞 블록과 자리 바꿈(하위 함께), 커서 유지.
  - 여러 줄 붙여넣기: `##`·글·`- **굵게**`·2/4칸 들여쓴 `-`·`- [ ]`·빈 줄 3개(1개로)·`1)` → 제목·글·목록 3단계·할 일·빈 칸 1개·번호.
  - 시트 TSV 3×3 붙여넣기 → 표(첫 행 머리글). 칸 입력, 끝 칸 Tab → 행 추가 후 새 행 첫 칸.
  - `/toggle` → 토글, Enter → 하위 글 칸, ▸로 접기. 새로고침 뒤 서버 응답에 indent·rows·header·open 그대로.
  - 맨 아래 「끝에 이어 쓰기」 영역을 가리켜도 배경 투명·테두리 0(전에는 전역 button:hover의 surface-2 회색).
  - 좁은 폭(534px)에서 가로 넘침 없음, 어두운 화면에서 표·토글 표시.
- 확인 못 한 것: 실제 한글 IME 조합 중 Tab/Enter(자동화 입력은 조합을 거치지 않음 — 조합 중에는 기존처럼 처리하지 않음),
  플로팅 노트 창 안 동작은 같은 편집기라 따로 열어 보지 않음, 엑셀 HTML 서식은 쓰지 않고 글(TSV)만 읽음.
