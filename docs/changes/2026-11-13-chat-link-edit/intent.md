# 개인 대화 ▾ 「링크 수정」

## 문제와 사용자 효과
사용자(2026-11-13, 감염과 면역 1차 강의 12 패널 화면과 함께): 「가끔 링크가 자동으로 연결이 안 될 때가 있어서,
역삼각형 버튼을 누르면 링크 수정을 할 수 있게 해줘. 이것도 채팅이 있는데 연결이 안 돼.」
확장이 대화 주소를 못 돌려주면 대화는 AI 쪽에 있는데 패널의 개인 대화 칸은 비어 있고, 관리자가 아니면 손으로 넣을 곳이 없었다.

## 범위와 성공 기준
- 예습·복습 개인 대화 ▾ 메뉴에 「링크 수정」. 누르면 AI·주소 칸이 열리고 저장하면 그 칸이 열기(↗)로 바뀐다.
- 개인 링크만. 공통 대화(관리자 「링크 고치기」)는 그대로.

## 근거·미정 사항
- 서버 `PUT /api/lectures/…/my-preview`·`my-review`가 이미 있다(확장 저장 경로와 같음). 서버·DB 변경 없음.
- 확장이 없어 ▾가 없는 빈 칸(폰 등)은 이번 범위 밖.
