## Plan에 연결할 결과

- 탐색 묶음 다섯 개와 목표 후보 열다섯 개를 구별한다. 열다섯 개는 분할·필수 방향을 검토할 후보이며 확정 진행률 분모가 아니다.
- 첫 짧은 경로 후보는 **LNK001 → Q002 → Q005 → Q047 → Q036 → Q068 → Q063 → Q060**이다. 뿌리 전체 완료나 검증된 선수관계 그래프로 취급하지 않는다.
- 여러 대응을 묶은 과제는 한 번의 자기평가를 여러 목표에 일괄 배분하지 않는다. 첫 단일 평가 흐름에서는 보류하거나 명확한 단일 답 경계로 검토한다.
- 독립적인 AChE 억제 기전 분류 이름 회상 등 기존 과제가 부족한 후보는 준비 전으로 남긴다. 이번 작업에서 새 문제를 작성하거나 은행에 추가하지 않는다.

- 추가 범위·평가 계약의 채택은 사람 검토 후 Spec에 반영한다. 추천·복습 간격·하루 경계 수치는 여전히 별도 결정이다.

## 실행과 확인 근거

검토한 자료는 필기 35쪽의 페이지별 텍스트·이미지, 수신 트리·포인트, 합본 족보 MD, 로컬 69문항 은행, 관련 두 Spec이다. 합본 족보 원본 PDF 지면은 이번 대조 입력에 포함하지 않았다. 수신본의 실제 작성 대화 입력 목록까지 확인한 것은 아니므로 독립성은 기존 수신 기록의 한계를 유지한다.

CLI 세션은 `01a19a79-725a-7691-8796-0071c2a52ecc`이며 지면 이미지 35개의 도구 반환 기록을 확인했다. 입력 다섯 파일과 관련 두 설계 문서·렌더 35장 모두 대조 전후 지문이 같았다. 설계 문서의 실행 당시 원문은 후속 문서 갱신 전에 별도로 보존했다. 검토안에서 명시적으로 인용한 문항 ID 38개의 존재와 LNK001 질문·정답 원문 일치를 확인했다. 이 확인은 **참조·원문·보존 검사이며 의학적 정답성이나 제품 코드 테스트의 통과를 뜻하지 않는다.**

현재 에이전트는 원본 물리 4쪽의 학습목표와 33쪽의 2022년 문항 번호·수정 표시를 별도로 열어 대조했다. 기존 답을 고치거나 자료 간 충돌을 해결한 판정으로 사용하지 않는다.

원본 CLI 응답·전체 이벤트·사용량·입력 지문·사용자 전송 승인·시작 실패·참조/보존 검사 기록은 `work/concept-tree-cholinergic-20261029/plan-review-20261102/`에 보존했다. 초기 시작 실패와 자동 승인 거절은 이후 사용자 명시 승인 및 단회 대조 완료로 이어졌으며 삭제하지 않았다.

아래는 CLI의 검토 원문이다. 의학 내용과 문항 연결의 판단을 현재 에이전트가 다시 작성하거나 판정을 올려 기록하지 않았다.

## CLI 검토 원문

**첫 제품은 ‘강의 전체를 끝내는 축약 문제집’보다, 강의의 큰 구별을 실제로 회상하고 자기평가하는 뿌리 학습으로 제안합니다.** LNK001은 첫 화면 예시로 적합합니다. 다만 이 문항의 성공은 두 수용체 계열의 이름 회상만 확인하며, 분포·신호전달·장기 효과까지 성공으로 만들 수 없습니다.

아래는 단일 읽기 전용 비교에 따른 **후보 검토**입니다. 콘텐츠 확정, 의학적 검수 통과, 구현·공개 승인이 아닙니다. 입력·은행·기존 판정은 변경하지 않았고, 추가 생성·수리·네트워크 접근을 수행하지 않았습니다. `remainingRepairRounds=0`을 유지합니다.

### 1. 실제 열람 범위와 근거의 한계

`inputs.json`이 지정한 독립 개념트리와 독립 출제 포인트를 모두 읽었습니다. 강의의 전체 페이지 라벨 텍스트, 합본 `(1)~(2)` 족보 MD 전체, 실제 은행의 69문항 질문·답·해설·출제 근거와 객관식 선지별 이유를 대조했습니다. 첫 제품 spec과 합의된 learner-journey spec도 읽었습니다. 첫 제품 spec의 버튼·집계·저장·추천 규칙은 문서가 명시한 대로 **채택 전 제안**으로 취급했습니다.

강의 렌더 이미지에는 `view_image`를 사용하여 **물리 페이지 1–35를 각각 열람**했습니다.

| 실제 이미지 열람 페이지 | 관찰 범위 |
|---|---|
| 1, 2, 3, 4 | 필기 색상·표시 안내, 약물 요약표, 강의 제목, 다섯 구체적 학습목표 |
| 5, 6, 7, 8 | ACh 수용체 분기, 신경 경로별 분포와 교감 예외, 신호전달 도식, 직접·간접 작용 |

**미열람 페이지는 없고, 페이지 전체가 판독 불가능한 경우도 없었습니다.** 다만 축소 삽입 그림의 작은 글자, 흐린 주석, 23쪽의 겹친 더블클릭 자료 흔적까지 완전히 복원했다고 주장하지 않습니다. 인용한 핵심 표·문항·표시는 판독했으며, 텍스트 추출만으로 누락되는 9쪽 비교표와 33쪽 구조·수정 답 표시도 이미지에서 확인했습니다.

이하 ‘물리 9쪽’은 해당 PDF의 아홉 번째 페이지입니다. 제출물의 `p.9`, 은행의 `S1 p.9`, 합본 MD의 `[그림 1개: p28]`은 **각 자료가 제출한 locator**입니다. 특히 MD의 `p28`을 강의 물리 28쪽과 연결하면 안 됩니다. 이번 강의에서 2022년 42번 그림이 있는 곳은 물리 33쪽입니다.

합본 족보의 원본 이미지는 준비되지 않았으므로 열람하지 않았습니다. 강의 부록에 같은 연도·번호가 보이더라도 합본의 이미지 원본을 대신 검증한 것은 아닙니다. **이미지에 의존하는 동일성·정답 충돌은 미해결이며, 전면적인 의학적 검증을 수행한 결과도 아닙니다.**

### 2. 탐색 묶음과 초기 뿌리 목표 후보

독립 트리의 다섯 큰 가지는 탐색 구조로 활용할 만합니다. 권고하는 묶음은 **작용 표적 / 신호를 늘리는 방식 / 장기 반응 / 치료·진단 연결 / 과활성과 중독 대응**입니다. BBB는 작용 방식의 하위 기전으로 고정하기보다, 임상 연결에서도 참조하는 별도 속성 축으로 보여주는 편이 정확합니다.

물리 4쪽에 다섯 학습목표가 실제 존재하므로 트리의 해당 주장은 근거가 있습니다. 그러나 목표 하나에 여러 장기·기전·약물이 포함됩니다. 다섯 묶음을 목표 다섯 개로 저장하거나, 포인트의 체크리스트를 목표 열 개로 저장할 근거는 없습니다.

이 후보들은 학습목표 4의 중추·골격근을 빠뜨리지 않으면서도, 모든 약물의 세부사항을 초기 뿌리에 넣지 않는 출발점입니다.

구조 변형과 네 약물 비교(Q007–Q012), 직접제별 적응증(Q026–Q031·Q037), 억제제별 분류·용도(Q041·Q046·Q055–Q056), 세부 심장 경로(Q003·Q023–Q024), 선택적 독성(Q067), 친핵체 범주(Q064)는 **후속 심화 후보로 명시**하는 것이 좋습니다. 특히 물리 15쪽의 비교 특성, 23쪽의 선택적 독성에는 실제 강조 표시가 있으므로 초기 뿌리에서 뒤로 둔다는 이유로 시험 범위 제외나 중요도 하향을 선언해서는 안 됩니다.

같은 약물명이 여러 가지에 나타나는 것은 우선 **참조 관계**입니다. 예컨대 수용체 표적, 임상 용도, BBB 관계는 답 경계가 다르므로 이름만으로 병합하지 않습니다. 반대로 동일한 관계를 임상 가지와 기전 가지에서 함께 보여줄 때는 고유 목표를 두 번 세지 않습니다.

### 3. 기존 문항을 바꾸지 않는 초기 순서 후보

첫 짧은 경로는 다음 순서를 권고합니다.

**LNK001 → Q002 → Q005 → Q047 → Q036 → Q068 → Q063 → Q060**

분류 이름에서 시작해 작용 방식, 골격근·분비샘의 차이, 중독 인식과 치료 구별로 이어지는 **제품 경험용 후보 순서**입니다. 모든 문항을 수정 없이 사용할 수 있으며, 객관식은 원래 선지를 유지합니다. 이 순서가 의학적으로 검증된 선수관계 그래프라는 뜻은 아닙니다. 실패하거나 도움을 받았어도 다음 과제로 이동할 수 있습니다.

분포·BBB·기전 분류 등 표에 남은 후보는 이 짧은 경로의 완료로 덮지 않습니다. 특히 다음을 구별해야 합니다.

- Q001·Q012·Q026·Q040·Q041·Q053은 여러 대응을 묻습니다. 일괄 ‘스스로 떠올림’을 모든 연결 목표의 개별 성공으로 배분할 수 없습니다.
- Q005는 두 작용 방식의 대비를 하나의 답 경계로 채택할 경우 단일 평가가 가능합니다. 약물 분류·장기 반응까지 확장해서는 안 됩니다.
- Q063도 두 치료 역할의 **대비 자체**를 한 과제로 볼 수 있으나, 중독 진단·약물 선택·aging 조건의 성공을 함께 부여할 수 없습니다.
- 세 분류 이름의 독립 회상이나, 원자화한 분포 관계를 초기 필수로 선택한다면 **과제 준비 필요**로 남겨야 합니다. Q041의 약물명 대응 등 세부 문제를 대신 넣고 뿌리를 완료 처리하지 않습니다.

첫 버전이 단일 자기평가만 지원한다면 복합 문항은 후속 경로에 두고, 독립적인 목표별 판정이 가능한 연결을 준비해야 합니다. 이는 이번 은행 수정 요청이 아닙니다.

### 4. LNK001 한 문항 경험 제안

은행 원문은 다음과 같습니다. 형식은 **`list`**, 회상 방향은 **`direct`**, 선지는 없습니다. 원래 해설은 빈 문자열입니다.

질문 원문:

```text
Acetylcholine 수용체를 나누는 두 주요 수용체 계열은?
```

정답 원문 전체:

```text
Nicotinic receptor
Muscarinic receptor
```

이 예시는 ‘ACh 수용체의 두 계열 이름을 완결된 목록으로 회상하기’를 보여줍니다. 물리 5쪽의 두 분기와 부합하지만 Q002의 신호전달 구별, Q001의 분포 대응과 같은 과제라고 선언하지 않습니다. 두 이름 중 하나만 떠올렸다면 이 제한된 목록 과제 전체를 도움 없는 회상 성공으로 평가할 수 없습니다.

아래 수치는 **LNK001의 목표 1개·필수 방향 1개만 채택했다고 가정한 설명용 예시**입니다. 강의 전체 목표 수나 기억 확률이 아닙니다. 시작 상태는 `첫 학습 0, 미평가 0, 보완 필요 0, 회상 가능 0`이며 해당 목표는 미학습입니다.

| 행동 | 화면·사건 상태 제안 | 이 예시의 확정 집계 |
|---|---|---|
| 질문 열기 | 질문만 표시. 답을 노출하는 지도 제목은 중립적으로 표시 | 변화 없음 |
| `떠올려본 뒤 정답 확인` | 시도 여부를 명시한 행동 후 원래 답 전체 공개. 시도+확인 사건 저장 | 저장 확인 후 첫 학습 1, 미평가 1, 회상 가능 0 |
| `답만 보기` | 별도 열람 경로. 시도 사건 없이 답 공개 | 첫 학습 0 유지. 세 평가 버튼으로 회상 성공을 기록하지 않음 |
| `못 떠올림` | 시도+확인이 있는 경우 평가 후 다음 질문으로 즉시 이동 | 첫 학습 1, 미평가 0, 보완 필요 1, 회상 가능 0 |
| `도움 받아 떠올림` | 부분 회상 또는 단서 의존을 포함하는 중간 평가 후보. 즉시 다음 질문 | 첫 학습 1, 미평가 0, 보완 필요 1, 회상 가능 0 |
| `스스로 떠올림` | 공개 전 두 항목을 도움 없이 회상했음을 자기평가. 즉시 다음 질문 | 첫 학습 1, 미평가 0, 보완 필요 0, 회상 가능 1 |
| 지도·근거 도움 열람 | 질문·답 공개·평가 단계 보존. 답 관련 내용을 열면 도움 사용 표시 | 열람만으로 집계 변화 없음 |
| 평가 취소 | 직전 평가를 취소하고 LNK001의 답 공개·평가 전 단계 복원 | 첫 학습 1 유지, 미평가 1, 회상 가능 0 |
| 중단·재개 | 같은 콘텐츠 판·문항·답 공개 여부·평가 단계·도움 표시 복원 | 기존 확정 집계 유지 |
| 오늘 요약 | 저장된 사건 기준으로 새 목표와 평가 상태를 별도 표시 | 예: 첫 학습 +1, 미평가 1. 경로 완료와 강의 완료는 별개 |

위 세 자기평가는 상호 대안이며 연속해서 세 번 기록하는 단계가 아닙니다. 평가 버튼 자체가 다음 이동을 수행하고, 추가 ‘다음’ 확인을 요구하지 않는 방향이 합의된 여정과 맞습니다.

답만 본 뒤에는 이미 답을 본 상태에서 ‘스스로 떠올림’으로 전환시키지 않습니다. 이후 별도의 회상 기회가 필요합니다. 일반 `reveal` 사건만 가진 기존 답 열람 기록에서도 시도를 추정하면 안 됩니다.

도움을 연 사실만으로 학습자의 사고를 자동 판정할 수는 없습니다. 다만 **시도 중 답을 드러내는 도움을 본 뒤 높은 평가를 선택하는 충돌**은 조용히 통과시키지 말고 도움 평가로 정정하도록 안내하는 계약을 권고합니다. 평가를 보류하면 미평가로 남깁니다.

저장 중에는 다음 화면과 임시 변화를 보여줄 수 있지만 확정 막대·오늘 완료에는 반영하지 않는 제안입니다. 프런트엔드는 미확인 사건을 같은 사건 ID로 보관하고, 백엔드는 중복 전송을 한 번만 반영하도록 설계할 수 있습니다. 평가가 시도+확인보다 먼저 도착해도 유효한 연계가 확인되기 전에는 성공 집계를 만들지 않아야 합니다.

저장 실패는 회상 실패가 아닙니다. 미확인 상태와 현재 위치를 남기고, 안전한 로컬 보관도 불가능하면 추가 평가 누적을 멈추는 안이 적절합니다. 재개 시 서버 확인 상태와 미확인 요청을 먼저 대조하고, 확인되지 않은 오늘 완료를 확정하지 않습니다. 평가 취소는 평가만 되돌리고 시도+확인에 따른 첫 학습은 유지합니다. 잘못된 시도 기록 자체의 정정은 별도 행동이어야 합니다.

### 5. 범위에 영향을 주는 차이와 남은 결정

**포인트에만 명시된 신경전달 억제 가지는 근거 강도를 나눠야 합니다.** 포인트는 Vesamicol의 소포 저장 억제와 Botulinum toxin의 ACh 방출 억제를 `p.8, 2023-14`에 연결합니다. 실제 물리 8·18쪽 그림에는 Botulinum toxin이 표시되어 있지만, Vesamicol의 저장 기전을 설명하는 독립 강의 본문은 확인하지 못했습니다. 합본 2023년 14번은 잘못된 설명을 포함한 선지 집합이므로 선지 등장만으로 올바른 기전 전체를 강의 목표로 확정할 수 없습니다. 이 가지는 후속 탐색 후보로 남기고, 필수화한다면 근거·답 경계·과제 준비가 필요합니다. 현재 은행에서 이를 직접 확인하는 과제는 찾지 못했습니다.

**(1)/(2)의 경계는 약물명만으로 자를 수 없습니다.** 물리 31쪽은 부록에 이 강의만으로 풀 수 없는 문제가 많고 (2)까지 공부하라고 안내합니다. 과민성 방광 길항제·멀미·신경근 차단제 등은 이번 초기 뿌리 밖의 연결 후보입니다. 그러나 Atropine은 물리 27–28쪽 중독 치료에 직접 등장하므로 이번 치료 대비에 필요합니다. BBB 비교 선지에 Scopolamine이 등장한다는 이유로 길항제 전체를 이번 범위에 들일 필요는 없습니다.

**2022년 번호 차이는 명확히 표시해야 합니다.** 트리는 구조·선택성 연결에 2022년 39번을 인용하지만, 실제 구조 그림 문항은 강의 물리 33쪽과 합본 MD에서 **42번**입니다. 39번은 여러 약물 진술의 참·거짓을 고르는 문항이고, 65번은 약물–용도의 잘못된 연결을 묻습니다. 서로 관련되어도 같은 근거로 취급할 수 없습니다.

**정답 충돌은 관찰과 해결을 구분해야 합니다.**

- 2022년 42번: MD는 정답 ②, 강의 부록 물리 33쪽에는 `② → ②·④·⑤` 수정 표시가 실제 보입니다. 합본 원본 이미지는 미열람이므로 원본 간 동일성·정답은 미해결입니다. Q011의 텍스트 특성 식별은 실제 구조 그림 판독을 대신하지 않습니다.
- 2023년 14번: MD와 강의 부록은 ④를 답으로 제시하지만, 강의 물리 6쪽에는 교감 작동기관의 ACh–M 예외가 보입니다. 이는 제공 자료 안에서 확인되는 충돌입니다. 포인트의 ‘⑤가 타당하다’는 주장까지 이번 검토가 최종 정답으로 확정한 것은 아닙니다.
- 2018년 22번: MD의 ⑤와 포인트가 주장하는 ④의 충돌은 원본 이미지 없이 남습니다. 이번 35쪽 강의 부록에는 2018년 원문이 없습니다.
- 2021년 문항: MD는 정답 미확인으로 두지만 강의 부록에는 답과 일부 수정 표시가 있습니다. 한 자료를 읽었다고 다른 자료의 미확인을 소급 해제하지 않습니다.

‘동일 교수 19문항’과 ‘연도 간 반복률 0%’는 **합본 및 포인트의 제출 주장**입니다. 반복의 정의·산식·원본 대조를 검증하지 않았으므로 추천량이나 출제 확률의 수치 근거로 사용하지 않는 것이 적절합니다. 은행의 기존 의학적 `doubt`, 외부 미조회 정정 이력 역시 이번 비교로 해소되지 않습니다.

사람이 먼저 결정할 사항은 세 가지입니다. **첫째**, 표의 후보 중 첫 뿌리 필수 목표와 방향을 어디까지 채택할지입니다. **둘째**, 복합 문항을 보류할지, 향후 목표별 평가 계약을 준비할지입니다. **셋째**, 제안한 시도+확인·답만 보기·미평가·도움·취소·저장 상태를 채택할지입니다. 복습 간격, 하루 경계, 시간 경과에 따른 ‘현재 회상’ 전환은 별도 정책 결정으로 남기며, LNK001 한 문항 경험의 성립을 위해 수치까지 확정할 필요는 없습니다.
