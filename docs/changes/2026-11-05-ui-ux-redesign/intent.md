# UI/UX 개편: 좌측 메뉴·흰색 바탕·캘린더

## 문제와 사용자 효과

2026-11-05 사용자 지시: 화면 전체에서 "AI가 자동으로 디자인한 것 같은 느낌"을 없애고 UI/UX를 크게 개편한다.
참고 화면 5장(OpenAI Platform, Claude, Todoist, Grok, folk)의 공통점 — 흰 바탕, 회색 강조, 좌측 고정 메뉴,
넓게 비운 본문, 검정 주요 버튼 — 을 따른다. 개편에 맞춰 새 기능을 만들고 일부 기능은 없앤다.

사용자가 정한 방향:

- 상단 메뉴(`app-bar`)를 좌측으로 옮긴다. 프로필 정보도 좌측으로 옮겨 오른쪽 공간을 본문이 통째로 쓴다.
- 전체 색은 흰색, 강조는 회색. 깔끔한 느낌.
- 좌측 메뉴 순서: 1) 공부(캘린더, 강의 모아풀기, 통합퀴즈 등) 2) 커뮤니티(오류 토의, 진탐 공유 등)
  3) 프로필·결제·설정. 묶음 제목은 있어도 되고 순서만 지켜도 된다.
- 좌측 메뉴는 접어서 아이콘만 볼 수 있다.
- 홈의 메인 캘린더도 같은 느낌으로 개편한다.
- 진행 방식: 비주얼 프로토타입을 먼저 완성하고, 들어갈 부분을 수정해 가며 작업한다.
