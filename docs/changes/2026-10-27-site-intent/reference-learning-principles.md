# 개념트리 학습 참고 대화 — 읽기용 정리

출처: [공개 참고 대화](https://chatgpt.com/share/6ae00b73-ac04-83ec-82e8-56012a12b11d).
확인일: 2026-11-01 KST. 로그인 없이 본문을 읽었다. 아래는 핵심을 재서술한 것이며 원문 전체 인용이나 학습 효과의 연구 검증이 아니다.
원문 추출 결과는 [로컬 보관본](references/concept-tree-reference.json)에 있다.

## 대화가 제시한 중심 생각

1. **전체 구조를 먼저 잡고 부분의 깊이를 늘린다.** 모든 잎의 세부를 끝낸 뒤 다음 가지로 가기보다,
   큰 구조를 파악한 뒤 각 가지를 탐색하고 다시 방문한다. 고정된 탐색 순서보다 학습자의 상태가 중요하다.
2. **개념 이름뿐 아니라 관계를 공부한다.** 상위에서 하위 사례를 떠올리는 것과 사례에서 상위 분류를
   복원하는 것은 다른 과제다. 비슷한 사례의 구별이나 기전 설명도 별도로 확인할 수 있다.
3. **비교는 별도의 학습 역할을 가진다.** 개별 항목은 기억해도 서로 혼동할 수 있다. 같은 범주에 속한
   개념들의 공통점·차이·구별 조건을 회상하도록 한다.
4. **처음 학습의 맥락과 복습의 단서를 구분한다.** 처음에는 구조와 선행 지식이 이해를 돕는다.
   이후에도 고정 순서만 유지하면 위치가 답의 단서가 될 수 있으므로 배운 내용의 혼합 회상과 간격을 둔 재방문을 제안한다.
5. **다음 질문은 여러 필요를 함께 반영한다.** 중요도, 취약도, 복습 시점, 아직 충분히 만나지 못한 범위를
   함께 고려한다. 가장 낮은 숙련도만 골라 반복하면 편향될 수 있다는 지적이 있다.
6. **지도·문제은행·추천의 책임을 나눈다.** 같은 지식 구조를 첫 학습, 비교, 역방향 회상, 복습에 활용한다.
   학습 방식이 바뀔 때마다 지도나 문제 전체를 새로 만들 필요는 없다.
7. **모든 노드·연결을 기계적으로 문제화하지 않는다.** 목표를 충분히 회상시키는 문항을 활용하고 중복을
   줄인다. 이 생각을 StudyEZ에 적용할 때는 올해 범위 전체의 첫 접촉을 보장한다는 사용자 의도를 유지한다.

## StudyEZ에 반영하는 방식

2026-11-01 문서 분리 후 위 내용의 목적·원칙은 사이트 intent의 I3와 콘텐츠 파이프라인에,
방향별 상태·학습 흐름은 learner-journey/spec.md에, 혼합 시점·관계 표현 등 미확정안은 open-design.md에 기록했다.
이미 합의한 뼈대→가지 학습, 방향별 상태, 중복 없는 범위 집계, 새 진도 보호와 연결한다.
질문의 역할은 분류/하향 회상·상향 복원·비교 등으로 설명하되 전 관계의 역방향을 자동 의무화하지 않는다.

참고 대화에는 서로 다른 강조가 함께 있다. 초반 구현 제안에는 문제를 풀어야 다음 노드가 열리는
설명이 있고, 후반에는 완벽히 알 때까지 머물지 않고 여러 번 깊이를 늘리는 설명이 있다.
StudyEZ는 사용자의 후속 선택에 따라 오답이어도 다음 범위로 이동할 수 있도록 하며 정답 잠금을 채택하지 않는다.

참고 대화의 자료→Graph→문제 생성 순서는 그대로 옮기지 않는다. 현재 합의한 파이프라인은 문제·포인트·트리를
각각 원본에서 만든 뒤 대조하는 방식이다. 학습 상태에 따라 문제를 선택한다는 생각도 매 질문마다 문제를 새로
생성하거나 별도 모델 호출을 추가한다는 뜻으로 확대하지 않는다.

## 후속 설계 후보와 채택하지 않은 세부

- 같은 가지 안의 혼합에서 이미 배운 다른 가지의 혼합으로 넓히는 시점은 검토 후 정한다.
- 관계를 분류·비교·인과·선행으로 구별하는 표현은 후보이며 강의 간 지도를 연결하는 구현은 현재 범위가 아니다.
- 예시의 BFS/DFS 비율, 상위 층수, 숙련도 수치와 우선순위 가중치는 설계 설명용이며 StudyEZ 기본값으로 쓰지 않는다.
- 대화가 붙인 탐색 알고리즘 이름을 확립된 교육학 이론의 이름으로 사용하지 않는다.
- Anki/FSRS는 도입·연동이 확정되지 않았다. 지도 순서와 복습 시점을 구분한다는 아이디어만 제품 의도와 연결한다.
- 의학 예시와 그림·시뮬레이터 코드는 학습 흐름의 설명 자료다. 실제 시험 범위·문항·정답의 검증 근거로 사용하지 않는다.

제품 코드·은행·학습 기록·추출 요청문은 이 참고 정리로 변경하지 않았다.
