# 자유 노트

## 문제와 사용자 효과
UI/UX 개편 프로토타입(`web/src/redesign-prototype/notes.tsx`)에는 자유 노트가 있으나 실제 사이트에는 없다.
학생이 Notion처럼 md로 쓰고 글자색·형광펜을 칠하는 개인 노트를 사이트 안에서 쓰고, 어느 기기에서나 다시 열게 한다.

## 범위와 성공 기준
- 좌측 메뉴 「자유 노트」(`/notes`)에서 노트 목록·새 노트·편집기를 쓴다. 형태는 프로토타입 그대로다.
- 프로토타입의 「강의」 속성 칸은 「태그」로 바꾸고 학생이 자유롭게 쓰고 지운다(2026-11-07 사용자 지시).
- 노트는 계정별로 서버에 저장되어 새로고침·다른 기기에서도 그대로 보인다. 다른 사용자는 볼 수 없다.

## 근거·미정 사항
- 2026-11-07 사용자 요청: "디자인 프로토타입에 있는 형태 그대로", "\"강의\" 칸을 그냥 \"태그\"로 바꿔서 자유롭게 작성".
- UI/UX 개편 spec §8: 자유 노트는 서버 저장(새 표·API)과 함께 2단계에서 연다. 같은 2단계의 강의록 회독 기록은 이번 범위가 아니다.
- 이용현황 행동 등록은 하지 않는다(강의 단위 학습 행동이 아닌 개인 메모). 필요하면 별도 작업.
