# 콜린성 예시 핵심 보완 1회 예외

## 문제와 사용자 효과
사용자는 기존 93문항 예시의 Q077 비교 목표 재정의, Q101 정답 노출, Q142 원본 그림 오류, D21·D61 전체 회상 누락과 과도한 선행 조건을 추가 1회 예외로 교정·재검수하도록 명시 승인했다(“추가 1회 예외로 핵심 보완”, 2026-11-05 KST). 같은 PDF 35쪽·족보를 같은 OpenAI Codex 내용 모델로 처리한다. 운영 미게시를 유지하고 실제 갱신 트리를 제시한다.

## 범위와 성공 기준
지정 핵심 항목만 한 번 수정하고 독립 재검수 판정을 보존하여 실제 예시 트리에 반영한다. 정확한 범위는 spec.md 참조.

## 근거·미정 사항
현재 사용자 응답이 명시 예외 근거다. 미확인 내용은 모델 판정 후에도 보류할 수 있다.
