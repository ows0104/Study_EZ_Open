# 캘린더 복습 막대 채움을 연한 강조색으로 — 설계

## 요구사항과 수용 기준
- web/src/styles/calendar.css 막대 블록 끝: `.meter > span { background: var(--accent-line); }` (base.css의 `var(--accent)`를 덮는다).
- 기본 인디고 조합 밝은 화면에서 채움 ≈ rgb(201,211,245), 테두리 #616161 그대로.

## 책임·입출력 계약·오류 상태
색은 CSS만 고른다. `ReviewMeter`는 너비(학습률)만 정한다(변경 없음, 주석만 갱신).

## 호환성과 데이터 보존
강조색 토큰이라 사용자 조합·다크 모드를 따른다. 데이터 변경 없음.
