자료는 `pages/` 안에 슬라이드 한 장당 PNG 한 개로 있다 (`p001.png` … `p{N}.png`).
결과는 작업 폴더에 `cards.json` 으로 써라. 형태는 이렇다.

```json
{
  "cards": [
    {
      "q": "질문 (앞면)",
      "a": "정답 (뒷면)",
      "explanation": "부연. 없으면 null",
      "page": 14,
      "crop": [0.05, 0.12, 0.95, 0.78]
    }
  ]
}
```

- `page` — 이 카드가 쓸 슬라이드 번호. 그림 없이 텍스트만으로 낼 카드면 `null`.
- `crop` — 그 슬라이드에서 실제로 보여 줄 구간 `[x0, y0, x1, y1]`. 페이지 크기를
  1로 본 비율이다. 페이지 전체를 쓰려면 생략하거나 `null`.
- 다른 키는 넣지 마라. 카드 수도 네가 정한다.
